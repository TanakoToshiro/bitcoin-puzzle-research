# Bitcoin Puzzle Research

Research into the origins of Bitcoin Puzzle keys, historical generators, wallet derivation, signatures, statistical relationships, and state-recovery methods.

Исследование происхождения ключей Bitcoin Puzzle: исторические генераторы, дочерние ключи кошельков, подписи, статистические связи и восстановление состояний.
