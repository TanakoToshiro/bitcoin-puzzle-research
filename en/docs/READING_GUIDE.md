## Independent reviewer or Codex

Start with the [reviewer guide](REVIEW_GUIDE.md). Distinguish exhaustive searches, limited samples, incomplete SAT attempts, and synthetic successes. Do not execute historical plans as current instructions.

For chronology, use the [main journal](../reports/RESULTS.md) and [index](DOCUMENT_INDEX.md). A later clarification takes precedence only for the same model and problem formulation. It does not retroactively rewrite the original report.
