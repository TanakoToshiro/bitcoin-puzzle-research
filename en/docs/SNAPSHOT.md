# Snapshot contents and provenance

[Home](../README.md)

Prepared on 25 November 2026 from the puzzle71-hypotheses research directory. The latest final reports found are dated 14 November 2026. Address histories and current balances were not updated during packaging.

## Included

Research Markdown documents: problem statements, final reports, protocols, mathematical analyses, journals, and corrections. Experiment identifiers are retained, with series indexes and eight thematic routes added. The public solution-table snapshot retains its source metadata. Compact results from the four latest series are included under evidence.

## Adaptations

- Navigation and an explicit snapshot date were added.
- Local user paths, connection details, and SSH-key paths were replaced with placeholders.
- Executable code and command blocks were omitted from the documentation copies; formulas and tables were retained.
- Internal links were made relative. Artifacts not included are described as plain text rather than broken links.
- Unresolvable heading fragments were replaced with links to the document. External sources were retained but not downloaded again.
- The copied detailed README was supplemented with the 13–14 November results. Packaging did not modify the working research overview.
- The bilingual edition adds corresponding ru/ and en/ trees. English historical reports are machine translations; [translation metadata](TRANSLATION.md) distinguishes them from separately edited overview pages.

This is **not a fully reproducible computational repository**: it omits environments, CUDA/CPU implementations, full checkpoints, some raw responses, and third-party source trees. Commands mentioned in historical reports do not describe runnable contents of this snapshot. Historical evidence manifests can refer to original research code that is not included here.
