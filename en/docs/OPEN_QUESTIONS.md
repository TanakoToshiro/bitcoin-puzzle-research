# Open questions

[Home](../README.md) · [Latest results](LATEST_RESULTS.md)

This describes coverage. It is neither evidence that every question is promising nor an instruction to launch computations.

1. **An original artifact from the author.** An authentic MPK, chain code, export, log, or raw-to-Puzzle script could make conditional methods applicable. Broad archive searches have already been performed; specific new sources are needed.
2. **The full MyWallet 2012 registration flow.** All entropy sources and random-number consumption before the first key still need reconstruction. A standalone Math.random model does not replace the full chain.
3. **Product audits of MultiBit Classic and Hive.** Establish historical versions, bulk generation and export, migrations, and ordering. Auditing a shared library is not the same as auditing a product. [Wallet coverage](../reports/WALLET_COVERAGE_20261104.md).
4. **Ten open RNG64 constructions.** A new constraint-solving approach is needed. GPU brute force has not made 2^64 practical; variable-elimination pilots with up to nine additional bits rejected nothing in the subsets tested.
5. **Hidden models modulo n.** Möbius, second-order, and quadratic transitions have not been excluded as entire classes. Tested approaches have specific limits; more runtime does not replace an algorithmic advance.
6. **Key positions.** Assess global calibration and statistical power before adding combinations, and preregister a rule for future independent data. Running 241 tests on the old dataset does not create new confirmation.
7. **Additional signatures from a relevant key.** Current unknown keys have one message each; new data could change the applicability of specialized methods. Do not attribute later solvers' activity to the author.

Brainwallet work is deferred. Exhausted seed domains need not be searched again without a justified change of model. The latest reports have not established a new practical search reduction.
