# Public solution snapshot

[Home](../README.md)

[source.txt](puzzle-solutions/source.txt) retains the contents of the public table used by the main research. The snapshot contains 83 known solutions: puzzles 1–70, then 75–135 in steps of 5. This does not describe the current number of solved puzzles.

[source.json](puzzle-solutions/source.json) records the URL, the download time on 30 October 2026, and the SHA-256 of the original bytes. Text-export line endings may have been normalized; original and exported hashes are distinguished in the [manifest](../metadata/source-manifest.csv). Unknown keys are not observations of the generator.

The data and evidence files are byte-identical in the Russian and English editions. They are not translated.
