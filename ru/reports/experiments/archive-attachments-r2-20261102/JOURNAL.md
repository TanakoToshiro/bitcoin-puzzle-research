# Журнал ATT-02, 02–03.11.2026 МСК

1. После просьбы продолжить выбран ограниченный набор новых источников: полные архивные снимки трёх связанных тем, прежние вложения со статусом context-only, точечное восстановление исчезнувших URL. README исследовательского проекта и обзор кошельков прочитаны. Входы закреплены в INPUT_PINS.json; новая папка отделена от ATT-01.
2. Получены 12 страниц Ninjastic API. Объявленные totals достигнуты по всем трём темам. Извлечены ссылки и контекст; сравнение ID выполнено с E10, targeted-posts ATT-01 и его дополнительным окном. Нельзя трактовать это как получение всех исторических версий сообщений.
3. Прямо скачаны ZIP VanitySearch, текстовые Pastebin, список proofs и доступные Gist. Старые программы участников классифицировались по сообщениям и содержимому; скачанные скрипты/бинарники не запускались.
4. Через Google Drive connector проверены конкретные опубликованные ID. 17 сырых файлов скачаны с проверкой заявленного размера и SHA256; временные download URL удалены из сохранённых connector JSON. Папка hexplorer обойдена рекурсивно в пределах видимого дерева. Media, не скачанные после проверки metadata, отмечены отдельно. Три полученных PNG просмотрены визуально.
5. Проверены точные имена/ID в веб-поиске; ответы сохранены в search-mirrors.json. Прочитано обсуждение VanitySearch issue 35, ссылающееся на удалённый Gist. Дополнительно запрошенный BitCrack issue 52 оказался обсуждением random-search, не первоисточником ZIP; он сохранён как поисковый ответ, но не используется для атрибуции вложения.
6. CDX дал две страницы Filetransfer и один RAR. Обе страницы Filetransfer оказались просроченными ссылками. RAR успешно получен из replay 20251012143527, SHA1 совпал с CDX. Системный tar вывел 19 членов: 14 бинарных файлов и 5 папок. Ресурсы EXE не декодировались.
7. Нулевой scanner-результат по целевым сигнатурам отделён от неполного RAR content coverage. SCANNEDRANGES разобран с явной фиксацией 8 строк с U+200B; cores проверен на 8 hex; WIF proofs проверен по длине, сети, compression marker и checksum. Эти действия не проверяют правдивость сторонних заявлений о выполненном поиске.
8. Текущие первые страницы трёх тем сверены с архивными ссылками. Новых attachment URL нет. Пересчитаны page unions и проверены старые 115 файлов ATT-01; прежние результаты не изменены. Итоги и оставшиеся пробелы записаны отдельно, в общий исследовательский README добавлена ссылка.

Сетевые ошибки и ограничения: DNS bitchain, HTTP 404 на части Gist/Drive/хостингов, таймауты CDX и bitcoinpuzzle.ru сохранены в исходных ответах. Они не заменены отрицательными выводами о содержимом. Первоначальные sandbox DNS-ошибки ранее обходились разрешённым сетевым выполнением; в итоговом R2 SOURCES используются результаты сохранённых сетевых запросов, а не предположение об отсутствии файлов.

В ходе локального просмотра возникли ошибки кодировки консольного вывода и отказ read-only CIM-инвентаризации процессов; они не затрагивали скачанные байты. Последующие скрипты читают UTF-8 явно, итоговые проверки завершились успешно. Отметки времени источников сохранены в UTC; 21:00 UTC 02.11 соответствует 00:00 МСК 03.11.
