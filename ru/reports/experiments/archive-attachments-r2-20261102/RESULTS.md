# ATT-02: новые вложения получены, искомых параметров кошелька нет

Итог 03.11.2026 (Москва): расширение источников оказалось продуктивным для получения ранее не проверенных файлов. Однако ни одного пригодного Armory multiplier log, Electrum MPK/unsigned `.txn` или mSIGNA public export, связанного с создателем Puzzle, этот проход не дал. Отсутствие таких данных во всём Интернете не установлено.

Объединения страниц совпали с объявленными API totals; дубликатов в этих выгрузках нет. Это покрытие архивного индекса, не всех удалённых сообщений и редакций. Текущие первые страницы трёх тем просмотрены отдельно: 60 сообщений, дополнительных ссылок на подходящие типы вложений не обнаружено. Доказательства покрытия — артефакт исходного исследования (`TOPIC_COVERAGE.json`; вне снимка), сверка текущих страниц — артефакт исходного исследования (`LIVE_FIRST_PAGE_CHECK.json`; вне снимка).

Из 2 758 URL отобраны 17 ссылок-кандидатов, 15 новых относительно списка ATT-01. Дополнительная проверка `.dat/.backup/.bak/.keychain/.db/.sqlite/.7zip` новых ссылок не дала. В текстах нет совпадений с заданным набором конкретных маркеров форматов; это не проверка всех возможных синонимов. Ещё 20 прежних URL рассмотрены повторно с получением файлов, метаданных либо результата доступности.

Реестр 37 URL — артефакт исходного исследования (`LINK_REVIEW.json`; вне снимка): 13 проверены по содержимому, 1 уже был проверен в ATT-01, 1 архив проверен по inventory, 5 только по метаданным, 2 папки вернули пустой видимый список, 2 ссылки не относятся к заданию, 13 URL остались недоступны. Это счёт URL, а не независимых файлов: варианты одной Drive-ссылки и дочерние файлы папки считаются иначе.

## Что осталось неизвестным

- `bitchain.pl/100btc/btcpass.zip`, `cuda92.zip`, `pollard_kangaroo.txt`: ошибка DNS; запрос CDX по каталогу не вернул HTTP-200 capture. Контекст описывает инструменты участников, но неизвестные байты не объявлены проверенными.
- Sendspace `wdyg2o` и удалённый Gist `7dbd7e4f7c55d915db1e`: актуальные ответы 404. CDX веб-адреса пуст, raw-вариант Gist завершился таймаутом. Поиск точного ID дал ссылки на обсуждения алгоритма, пригодная копия не найдена.
- Filetransfer `2N4HS16CPM` и `IV153TFKUZ`: Wayback действительно содержит снимки, но оба — одинаковая HTML-страница «Le lien vers ce fichier a expiré». Это не восстановленные архивы Lostcoins/Fialka.
- Drive `19Fp1oBU9nPTqkztKlEdTV7CJYecam8Hl`, `1HvlzxWtziYY4Ewd1GsDHplaG851KqrqC`, `1OZQAwZjMUkfiySSr1GlQaYivY76uAUc3`, `1abZRyPMhC0A5W7esdp-odh_-ToB6hHaw`: metadata 404. Видимые списки двух других папок пусты; прошлое содержимое этим не установлено.
- Ссылка `bitcoinpuzzle.ru/files/download/276/...` завершилась таймаутом. Её тождество восстановленному RAR не доказано.
- Старый наиболее неоднозначный Drive `1au9y4npBxKaCjV3fIrn_ytemEBr0KTzN` из ATT-01 не восстановлен. Для Teknik `7fNYf.txt` дополнительный wildcard-CDX завершился таймаутом; прежняя точная проверка была пустой. Для Anonfiles `a750taA8n6/100bit_txt` новых данных нет.

CDX проверял перечисленные URL/маски, HTTP-200 captures с `collapse=digest`, лимит 1 000. Пустой ответ такого запроса не означает, что файл никогда не существовал или нигде не сохранён. Полная история правок форумных сообщений, медиа OCR/video и ресурсы упакованных EXE этим этапом не покрыты.

## Практический вывод

Обещанные направления продолжения выполнены: три связанных темы, разбор неоднозначных прежних вложений, восстановление конкретных исчезнувших ссылок. Полученные данные объясняются работой последующих участников; прямой зацепки на создателя и его параметры деривации нет. Поэтому запуск условных восстановителей на реальном Puzzle по этому материалу не обоснован.

Открыты конкретные недоступные файлы, прежде всего неоднозначный Drive из ATT-01. Их восстановление или новая прямая ссылка на диагностический/публичный экспорт могут изменить вывод. Повтор уже покрытого общего поиска без такого нового источника будет преимущественно повторять прежнюю работу.

Целостность проверена: 37 сохранённых HTTP-body, 17 Drive payloads, полный union страниц API, ZIP CRC и RAR CDX digest. Все 115 файлов прежнего ATT-01 и закреплённые входы совпали с хешами. Проверки — артефакт исходного исследования (`VALIDATION.json`; вне снимка), приёмка — артефакт исходного исследования (`ACCEPTANCE.json`; вне снимка). Перебор, recovery и запуск скачанного ПО не выполнялись.
