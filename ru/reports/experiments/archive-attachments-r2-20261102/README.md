# ATT-02 — продолжение поиска архивных вложений

Выполнено 02–03.11.2026 (Москва). Папка сохраняет дату начала. Это отдельное продолжение [ATT-01](<../archive-attachments-20261102/RESULTS.md>) по заданию пользователя «Продолжи поиски». Исторические результаты не перезаписывались.

[Результаты и ограничения](<RESULTS.md>) · [журнал](<JOURNAL.md>) · статус — артефакт исходного исследования (`STATUS.json`; вне снимка) · приёмка — артефакт исходного исследования (`ACCEPTANCE.json`; вне снимка).

Искали публично опубликованные, связанные с Puzzle вложения: Armory multipliers/diagnostics, Electrum unsigned/partial `.txn` с MPK, публичные экспорты mSIGNA/CoinVault. Основание — [обзор кошельков](<../../status-reviews/wallets-first-four-20261102/REVIEW.md>). Наличие подходящего формата само по себе не устанавливает связь с создателем Puzzle.

## Покрытие

- Полный доступный снимок Ninjastic API для тем 1305887, 5166284, 5218972: 2 118 сообщений; 2 039 новых ID относительно прежнего объединённого покрытия. Это не обещание полноты всех исторических редакций форума.
- 17 ссылок-кандидатов из этих тем, 15 ранее не встречались в ATT-01. Ещё 20 прежних URL получили уточнение. Реестр решений — артефакт исходного исследования (`LINK_REVIEW.json`; вне снимка) содержит все 37 URL с идентификаторами сообщений.
- 17 файлов Drive материализованы; ZIP прочитан с проверкой CRC; RAR восстановлен из Wayback, сверён с CDX и разобран по списку членов.
- Пригодных целевых кошельковых артефактов не найдено. Встроенные ресурсы бинарников RAR не декодировались; недоступные файлы остаются неизвестными.

## Данные и воспроизводимость

TOPIC_COVERAGE.json — артефакт исходного исследования (`TOPIC_COVERAGE.json`; вне снимка) фиксирует страницы API и хеши. MINING_SUMMARY.json — артефакт исходного исследования (`MINING_SUMMARY.json`; вне снимка) — прирост покрытия. SOURCES.json — артефакт исходного исследования (`SOURCES.json`; вне снимка) — результаты HTTP-запросов, включая ошибки; исходные ответы находятся в `cache-network/`. DRIVE_MATERIALIZED.json — артефакт исходного исследования (`DRIVE_MATERIALIZED.json`; вне снимка) фиксирует имена, размеры, идентификаторы и SHA256 17 файлов в `downloaded/`. Временные URL скачивания удалены из connector-ответов после материализации.

FORMAT_ANALYSIS.json — артефакт исходного исследования (`FORMAT_ANALYSIS.json`; вне снимка) содержит проверенные схемы текстовых и бинарных данных. ARCHIVE_REVIEW.json — артефакт исходного исследования (`ARCHIVE_REVIEW.json`; вне снимка) — ZIP/RAR inventory и проверки целостности. CONTENT_SCAN.json — артефакт исходного исследования (`CONTENT_SCAN.json`; вне снимка) и SCAN_SUMMARY.json — артефакт исходного исследования (`SCAN_SUMMARY.json`; вне снимка) — ограниченный поиск сигнатур; его нулевой результат не доказывает отсутствие произвольного неизвестного кодирования. Три PNG дополнительно просмотрены визуально.

Из корня проекта, офлайн:

> Исполняемый код/команды опущены в документационной копии.


`analyze.py` использует системный `tar` исключительно для списка RAR. Все исполняемые файлы и скрипты из внешних вложений остаются данными. Python-парсер форума импортируется из E10 без запуска его `main` и без записи bytecode. `collect.py --network` и `fetch.py <список-url.json> --network` применялись для сети; повторный вызов использует сохранённые ответы. Ошибки сети не стираются автоматическим повтором. Для нового сетевого прохода нужна новая папка эксперимента.

VALIDATION.json — артефакт исходного исследования (`VALIDATION.json`; вне снимка) подтверждает объединение страниц, SHA256 HTTP/Drive, неизменность 115 файлов ATT-01 и закреплённых входов. MANIFEST.json — артефакт исходного исследования (`MANIFEST.json`; вне снимка) фиксирует файлы ATT-02, исключая сам манифест. Повторный анализ обновляет временные отметки и требует нового манифеста.
