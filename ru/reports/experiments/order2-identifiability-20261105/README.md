Первая команда продолжает этапы с теми же inputs; завершённые stages переиспользуются. При изменении кода/данных старая серия не переиспользуется: нужна новая папка/приёмка. Вторая — независимая перепроверка сохранённых цепей, всех найденных toy-решений, точного класса сдвигов и одного полного скалярного перебора p7. Третья пересобирает отчёт из JSON без научных вычислений.

`toy/*/INPUT.json` содержит только модуль, индексы/маски/остатки, ширину цели. `CHECKER_TRUTH.json` отдельно хранит синтетические параметры и полные состояния. `toy_solver.solve` принимает только INPUT. В `OUTPUT.json` сохранены все совместимые пятёрки(a,b,c,s1,s2) и s71.

`witnesses/*.json` содержит полные проверяемые свидетельства одинаковых83 наблюдений, количество совместимых общих сдвигов и точную проекцию на№71. Там используется полная синтетическая truth: это контрпримеры идентифицируемости, не заявления о восстановлении вслепую. Для `selected-25` проверяются два различных прогнозируемых остатка№71; пример выбран по предзарегистрированному правилу и не входит в статистику32 старых fixtures.

Python3.11, NumPy; версии в ENVIRONMENT.json. Малые модули≤17 гарантируют отсутствие переполнения int64 в векторизованном коде. Полноразмерная арифметика использует Python integers. CPU, без GPU/облака. Старые хэши и mtime сверяет аудит; к ним не производится запись. Единственная разрешённая запись вне новой папки — отдельная итоговая запись общего RESULTS.md.

## Следующее возможное исследование

1. Решатель классов сдвига для общего второго порядка, использующий все83 наблюдения и реальные пропуски: a,b и модульные разности, затем отдельная совместимость общего сдвига.
2. Сначала диапазон уменьшенных модулей и сравнение со всеми ответами этого точного toy-эталона. Допуск — восстановление всех совместимых классов либо явно ограниченный результат; проверка только истинного класса недостаточна.
3. Отдельно оценивать проекцию множества совместимых моделей на№71, а не число параметров. Два разных класса могут иметь одинаковый прогноз и наоборот.
4. Проверить применимость публикаций по truncated multiple recursive/matrix generators к неизвестным коэффициентам и неодинаковым нашим маскам. Название/аннотация публикации не гарантирует применимости.

До такого допуска полноразмерный решёточный поиск и новые отрицательные заявления о настоящем Puzzle не обоснованы. Увеличение времени прежнего SEQ-18 не устраняет его установленную нечувствительность.
