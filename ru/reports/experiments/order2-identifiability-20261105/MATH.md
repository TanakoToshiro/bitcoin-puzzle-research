# O2-ID01 — различимость и точные симметрии

Здесь n — простой порядок secp256k1, s_i — канонические представители[0,n). Наблюдаются r_i=s_i mod2^k_i, k_i=i−1; старший принудительный бит не наблюдается. Индексы83 известных решений не сжимаются.

## Матрица и пропуски

Для v_i=(s_{i+1},s_i,1)^T:

```
v_(i+1) = A v_i mod n,
A = [[a,b,c], [1,0,0], [0,0,1]].
v_(i+g) = A^g v_i mod n.
```

det(A)=−b; при b≠0 переход обратим. Для линейной части T=[[a,b],[1,0]] на равномерной сетке g коэффициенты второй рекурсии равны A_g=tr(T^g), B_g=−det(T^g)=−(−b)^g. Постоянная C_g вычисляется без деления на1−a−b: `(A^(2g))[0,2]−A_g·(A^g)[0,2]`. Поэтому формула работает и при собственном значении1. Для неравных пропусков нужны разные степени одной общей матрицы; нельзя просто перенумеровать наблюдения подряд.

Равномерное прореживание может потерять информацию о исходных коэффициентах. Если отношение двух характеристических корней имеет порядок5, после пятого шага корни совпадают. В сохранённом примере modulo101 два разных невырожденных перехода дают одинаковые s1,s6,s11,…, хотя полные последовательности различны. Это пример на полной прореженной сетке, не установленная неоднозначность настоящих83 масок.

## Когда полные состояния определяют коэффициенты

Разности d_i=s_{i+1}−s_i mod n удовлетворяют d_{i+2}=a d_{i+1}+b d_i. Из пяти полных подряд состояний известны d0,d1,d2,d3. При D=d1²−d0·d2≠0:

```
a = (d2*d1-d0*d3)/D mod n
b = (d1*d3-d2*d2)/D mod n
c = s3-a*s2-b*s1 mod n.
```

Это обеспечивает однозначность для невырожденной **полной** последовательности. При D=0 возможна рекурсия меньшего порядка. Например, s_(i+1)=r*s_i+d представляется целым семейством вторых порядков: b=r²−a*r, c=(r+1−a)d. В CONTROL_TRACES.json есть две разные пары(a,b) с одинаковыми полными135 состояниями. Потому b≠0 само по себе не гарантирует минимальный порядок2.

## Общий сдвиг: параметры не обязаны быть однозначными

Для любого t∈F_n положим s'_i=(s_i+t) mod n. Тогда a'=a,b'=b,

`c'=c+(1−a−b)t mod n`.

Это точная симметрия семейства. Она уже встречалась для Мёбиуса в SEQ-08; здесь проверены её конкретная форма и проекция на второй порядок, а не заявлена новая общая идея.

Пусть J — наблюдаемые номера с k_i≥1, K=max k_i=134, L=2^K. Все совместимые с исходными масками переводы представлены **точно** как t=qL со знаковым целым q в интервале

`ceil(−min_(i∈J) s_i/L) ≤ q ≤ floor((n−1−max_(i∈J) s_i)/L)`.

Доказательство полноты: взять t0∈[0,n). При канонизации каждое наблюдаемое состояние либо пересекает n, либо нет; s'_i−s_i=t0−epsilon_i*n. Из сохранения хотя бы одного младшего бита у всех J и нечётности n следует, что все epsilon_i одинаковы. Следовательно есть общий знаковый перевод delta=t0−epsilon*n без пересечения границы для наблюдаемых состояний. Наблюдение с максимальной шириной требует delta≡0 mod L. Неравенства выше ровно обеспечивают канонические границы. №1 с нулём наблюдаемых битов на интервал не влияет. Длина интервала меньше n, поэтому одинаковые переводы modulo n не дублируются.

Для каждой полной синтетической цепочки этот интервал вычислен точно. Проверены крайние/нулевой перевод и границы смены прогноза№71. Если1−a−b≠0, все разные переводы дают разные c. Если a+b=1, c остаётся прежним, неоднозначность состояний сохраняется.

## Почему неоднозначное состояние не всегда означает неоднозначный№71

L кратно2^70. Если s71+qL не выходит из[0,n), все q сохраняют младшие70бит№71. Поэтому огромное число допустимых состояний может давать один искомый ключ.

Но s71 не наблюдается. Если оно находится вне диапазона наблюдаемых состояний, некоторые допустимые q могут пересечь границу именно для№71. Тогда остаток меняется на +n или−n modulo2^70. При нечётном n эти изменения ненулевые. Пересечение q-интервала с тремя областями

```
s71+qL < 0
0 ≤ s71+qL < n
s71+qL ≥ n
```

даёт точную проекцию класса. При данной конструкции их непустые области дают не более двух разных остатков: одновременная возможность пересечь обе границы исключена шириной интервала меньше n. Это точное утверждение о классе общих переводов, а не обо всех совместимых моделях с другими(a,b).

На32 исходных положительных примерах SEQ-18 у каждого класса много состояний, но один прогноз№71. Предзарегистрированный поиск отдельного контрпримера нашёл `selected-25`: все83 маски совпадают, а остатки№71 различны. Он использует исходный256-битный модуль и исходные маски. Это отобранный синтетический пример, не оценка частоты и не две модели настоящего Puzzle.

## Что означает бюджет наблюдений

83 маски содержат3767 наблюдаемых позиций битов;13 поздних —1352. Пять неизвестных полевых величин(a,b,c,s1,s2) дают около1280 номинальных битов. Сравнение чисел не доказывает независимости ограничений: точный класс переводов явно демонстрирует зависимость информации и неидентифицируемость полных параметров. Коэффициенты a,b, класс перевода и искомый остаток требуют отдельных проверок.

После факторизации переводов можно использовать координаты(a,b,d=s2−s1,c0=c−(1−a−b)s1). Они сохраняются при любом переводе modulo n. Но **нельзя** просто поставить s1=0 и наложить прежние маски: перевод меняет канонические представители. Совместимость масок и допустимый интервал перевода нужно восстановить отдельно.

Разностный ряд второго порядка имеет ранг Ганкеля≤2, поэтому det([[d0,d1,d2],[d1,d2,d3],[d2,d3,d4]])=0 mod n. Это необходимое кубическое условие на шесть подряд полных состояний или на равномерно прореженную последовательность; одного детерминанта недостаточно для существования общей рекурсии со всеми масками. SEQ-18 уже показал нечувствительность конкретных малых решёток к этому порядку. Новый решатель должен сначала показать восстановление класса на исходной форме масок.
