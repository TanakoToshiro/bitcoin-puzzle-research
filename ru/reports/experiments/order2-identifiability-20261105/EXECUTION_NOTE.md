# Уточнения выполнения

В PROTOCOL.md есть текстовая описка: утверждение о нулевой ширине№71 для p7/**11**. Зафиксированная формула k71=floor(70·bit_length(p)/256) и исполняемый код дают0 для p7, **1 для p11**,1 для p17. Никакой смены масок по результатам не было: все задания используют исходную формулу. В отчёте и числовых таблицах использованы фактические ширины. Протокол сохранён неизменным.

В источниках уже существовал SEQ-18, поэтому его малые решётки не запускались заново. Здесь проведены анализ идентифицируемости, построение точных свидетельств на сохранённой положительной синтетике и полный перебор на малых модулях.

Все27 toy-задач завершены без лимита времени. Свидетельства на n=порядок secp256k1 используют известные синтетические полные состояния только для построения/проверки неоднозначности. Это не скрытая передача состояния решателю: точный toy_solver получает исключительно INPUT.json, а полноразмерный решатель восстановления в этой серии не заявлен.
