# O2-ID01 — различимость скрытой рекурсии второго порядка

05.11.2026. До вычислений фиксируется следующий этап. Модуль n — известный простой порядок secp256k1, не координатный модуль p и не2^256. Состояния s_i лежат в[0,n); a,b,c неизвестны, b≠0. Наблюдения r_i=s_i mod2^(i−1), forced high bit удалён. Используется прежний снимок83 решений и их настоящие номера, максимум135. Для структуры наблюдений значения настоящих ключей не нужны.

SEQ-18 уже проверил малые решётки13×13 на32 положительных состояниях второго порядка; чувствительности нет. SEQ-08 уже учитывал общий сдвиг для Мёбиуса. Здесь ни эти решётки, ни универсальность идеи общего сдвига не заявляются новыми. Новые задачи — точный перенос неоднозначности на второй порядок, её влияние на №71 и полная совместимость уменьшенных моделей по всем83 номерам.

## 1. Формулы и контроли

Вывести матрицу3×3 для аффинного перехода, степени для пропусков и вторую рекурсию для разностей. Проверить реконструкцию a,b,c из5 полных последовательных состояний при ненулевом определителе; отдельно вырожденность и aliasing при шаге5. При известных a,b и b≠0 равномерное прореживание не обязательно сохраняет различимость исходных параметров.

Общий сдвиг s'_i=(s_i+t) mod n меняет c на c+(1−a−b)t. Вывести точный допустимый класс t, сохраняющий все83 маски. Считать число параметров/состояний отдельно от числа прогнозов №71. Никакие известные состояния синтетики не передавать алгоритму полного toy-поиска.

## 2. Свидетельства на исходных256-битных масках

Использовать все32 split/irreducible положительных входа SEQ-18. Их полные состояния доступны только построителю и проверяющему свидетельств: это проверка неоднозначности, **не восстановление из наблюдений**. Для каждого посчитать число совместимых общих сдвигов, диапазон разных c и точную проекцию класса на №71. Проверить как минимум крайние и нулевой сдвиги, а при разных прогнозах — явную пару полных цепочек со всеми83 совпадающими наблюдениями.

Если среди32 случаев нет неоднозначного №71, допускается заранее указанная дополнительная конструкция: SHA256-домен O2-ID01-witness, максимум512 попыток общих ненулевых b и невырожденных состояний; остановиться на первом примере двух прогнозов. Это отобранный контрпример, не оценка частоты. Если он есть среди старых32, новых не создавать.

## 3. Точное уменьшенное исследование

Модули7,11,17; по4 невырожденных входа(два split, два irreducible) с параметрами из SHA256-домена O2-ID01-toy. Всего12 входов. Коэффициенты a,c,s1,s2∈[0,p), b∈[1,p); перебрать весь p^4(p−1) домен без ограничений на seed. Вход solver — только модуль,83 номера, widths, residues. Все совместимые параметры сохранить.

Ширины k_i=floor((i−1)·B/256), B=bit_length(p); это округлённый масштаб исходных долей известных битов. В маленьких моделях многие k_i=0, а для№71 при p7/11 ширина0: отдельно показывать число полных s71 и число маскированных прогнозов, не выдавать постоянный нулевой остаток за успех. Нельзя экстраполировать доли успеха toy на256бит.

Для каждого входа: количество полных параметров, разных(a,b), классов общего сдвига, полных/маскированных s71. Сравнить всю83-точечную сетку с только13 поздними точками75…135. Дополнительно по одному входу каждого модуля проверить полные состояния на исходных83 номерах — при невырожденности единственное решение обязательно. Для p7 первый вход сверить независимым обычным Python-перебором всех моделей. Перестановка target или перестройка масок по результату не допускается.

Нулевые решения на синтетике — ошибка реализации. Много решений — настоящая неоднозначность уменьшенного входа, не timeout. Лимит одной векторизованной задачи120с; превышение фиксировать как незавершённость. Никакого полного256-битного поиска, GPU или повторного запуска SEQ-18.
