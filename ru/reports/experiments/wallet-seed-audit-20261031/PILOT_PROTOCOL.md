# E9-BX-GNU — зафиксированный ограниченный пилот

Гипотеза: `bx 2.0.0 seed` на libstdc++ с default_random_engine=minstd_rand0 → сырые байты → `bx hd-new` (BIP32) → последовательные дети → маска puzzle. Не применяется BIP39/PBKDF2; это другая цепочка.

Исторические формулы: s'=16807*s mod (2^31−1), s из 1..2^31−2, байт=s'%255 (именно 255, не 256). Стандартная длина seed — 16 байт; отдельно проверить 32. На входе initial random_device значение нормализуется по модулю p, ноль заменяется единицей. Перебираются нормализованные состояния, не UNIX timestamps и не Python seed.

Префиксы BIP32: m, m/0, m/0'/0, m/0'/1. Для puzzle i конечный non-hardened индекс i−1+offset, offset=0/1. Всего 16 гипотез (две длины × четыре префикса × два смещения). Префиксы — ограниченные варианты экспорта; использование их создателем не установлено. Внутри каждой гипотезы дети одного родителя, а не последовательная цепь child-of-child. Пропуски известных решений не сжимают нумерацию.

Пилот: нормализованные состояния 1..65536 включительно, блоки по 1024, общий потолок научных CPU-проверок этого прохода 900 секунд wall time. Сначала сопоставлять известные №1–50; все №51+ отложить для кандидата, прошедшего обучение. Подвыборка низких состояний выбирается для воспроизведения/измерения стоимости, а не из предположения об их повышенной вероятности. Это около 0,00305% полного пространства; отсутствие совпадения не исключает семейство.

До данных проверить: seed-байты C++ std::default_random_engine против Python-формулы; опубликованные master/child векторы самого bx 2.0.0 и BIP32; совпадение публичной точки двух арифметик; положительное восстановление искусственного состояния для каждой из 16 схем, отрицательный контроль с изменённым младшим битом. Сырые byte255 не появляются, но такое ограничение нельзя переносить на байты HMAC/дочернего ключа.

После полного совпадения всех известных решений — независимо проверить адреса и остановиться для отдельного подтверждения найденной гипотезы. Тайм-аут означает незавершённые блоки; resume только при совпадении кода, протокола и входных хешей. Полный 31-битный перебор и GPU в этом пилоте не запускаются.
