# E1g: стоимость поиска в сохранённых проекциях

2026-10-30. Продолжение E1d/E1e и каталога E5. Отдельно от E1f (межключевые связи). Реальные поиски ключей не запускаются. Старые MT-матрицы не строятся и не исключаются повторно: читаются сертификаты отдельных проекций, исключаются лишь системы шириной до 255 бит.

Порядок: обзор всех ограниченных проекций → рейтинг в RANKING.md → синтетический контроль выбранного преобразования → итог RESULTS.md. Рейтинг составляется до синтетического теста. Условия модели не становятся фактами о настоящих ключах.

Синтетический тест: публичная точка secp256k1, известная ширина W, фиксированный младший фрагмент L бит координаты pre_increment, дополнительные пять XOR-условий старшей части. Проверяем алгоритм сдвига точки и смены генератора, затем ограниченный interval-DLP. Сравнение с независимым поиском в исходном интервале тем же алгоритмом. Сначала детерминированный BSGS, затем ограниченный kangaroo с одной конечной ловушкой, публичными солями и максимум четырьмя попытками. Проверять долю успехов, а не считать тайм-аут опровержением. Максимум W=24. Параметры: (W,L)=(12,4),(16,6),(20,8),(24,10), по три положительных примера. Добавить границы, перенос +1 и отрицательные случаи. Для ранжирования не использовать секреты синтетических примеров.

Генератор контрольных задач и проверяющий код отделены от алгоритма. Алгоритм запускается отдельным процессом, получает только JSON с публичными полями и не читает контрольные ключи. Синтетические ключи доступны проверяющему коду, сохраняются отдельно. Это контроль интерфейса, не враждебная песочница.

Операции: реальные вызовы сложения/удвоения точек учитываются вместе с подготовкой; отдельно шаги, обращения к таблице, число записей. Память: tracemalloc Python, исключая нативную библиотеку и базовую загрузку интерпретатора. Фактический счётчик малых тестов не переносить напрямую на GPU. Теоретические оценки random-walk эвристические; BSGS конечен и точен.

Дальнейшие истории объединяются. Для трёх ведущих проекций сравнить уже сертифицированные sparse/zero. Полное покрытие всех историй не заявляется. Для №73 order2-geometric-b нет второго сохранённого допустимого пространства той же конфигурации; обозначить незавершённое покрытие, а не заменять его другой API-моделью.
