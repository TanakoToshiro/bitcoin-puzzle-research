Повторное чтение данных E1g (не требуется для чтения результатов): `analyze.py`, `derive.py`, `report.py` из этой папки, тем же Python с `-B`. `analyze.py` читает готовые сертификаты; `verify.py` только XOR-проверяет выбранные строки исходных матриц. Ни один скрипт не строит MT-матрицы. Завершённый `controls.py` проверяет SYNTHETIC_DONE.json и пропускает вычисления при совпадении хэшей. Для нового исследования с другими параметрами **создать новую папку**, чтобы сохранить этот результат. Автоматическое продолжение большого поиска не предусмотрено: большого поиска нет. Если новая синтетика прервана, `SYNTHETIC_PARTIAL.json` и отдельные request/result сохраняются; завершённый набор этого запуска уже находится в `SYNTHETIC.json`. `acceptance.py` проверяет интерфейс solver, независимую Python-криптографию, пропуск готовой стадии, побайтовую пересборку таблиц и хэши прочитанных старых входов.

`results/SPACES.json` — точные координаты, base, directions, все уравнения и номера сертификатов 436 неотвергнутых ограниченных E1e-проекций. `GEOMETRY.csv` — геометрия и сравнение с E1d. `E1D_GEOMETRY.json` — все 78 ограниченных пространств E1d, включая родительские пространства позднее отвергнутых продолжений. `HISTORY_UNIONS.json` — конечное расширение историй с точной нижней границей числа кандидатов. `TRANSFORM145.json` — настоящий публичный вход для условного interval-DLP, без его решения. `BLOCKS155.json` — точные восемь интервалов. `COSTS.json` — формулы и оценки перечисления. `INPUTS.json`, `VERIFICATION.json`, `VERSIONS.json`, `FINAL_MANIFEST.json` — воспроизводимость.

`public_solver.py` читает только публичный JSON из stdin и принимает ширину не более 24 бит. Секреты синтетики находятся только в `synthetic/VERIFIER_ONLY_FIXTURES.json`; solver их не открывает. `controls.py` создаёт задачи, запускает отдельные процессы и сверяет ответы.
