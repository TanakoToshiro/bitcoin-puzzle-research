# Прямые тесты положения ключей по координате Qx

11 ноября 2026 года. На сохранённой синтетике с номинальным согласованием 70% новые тесты обнаружили связь в 88,3–91,4% повторов с поправкой. У прежнего семейства из четырёх моделей доля составила 40,6% для обоих контролей. На 73 архивных ключах ни один из новых тестов не прошёл порог p≤0,05. Запуск занял 32,1 секунды.

## Методика

Сравниваются половины исходных диапазонов 73 ключей №11 и выше. Для каждого ключа вычислена точная четверть поля, в которую попадает Qx. Тест совпадений считает абсолютное отклонение числа согласований половин от 73/2. Критерий Пирсона использует таблицу 2×4, где строки соответствуют половинам диапазона, а столбцы — четырём четвертям поля Qx. [Биномиальный тест](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.binomtest.html) · [Критерий Пирсона](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.chi2_contingency.html).

Для каждого теста p рассчитано по рангу среди 4 095 свежих синтетических корпусов и наблюдения. Два контроля используют равномерные ключи из исходных диапазонов и равномерные ключи из фактической четверти каждого диапазона. Все точки получены умножением генератора на синтетические скаляры. Для семейства двух тестов применена поправка Бонферрони. Критерий для архива требует p≤0,05 у одного и того же теста при обеих схемах контроля. План, зафиксированный до запуска — артефакт исходного исследования (`PLAN.json`; вне снимка) · Хеши плана и кода — артефакт исходного исследования (`FROZEN.json`; вне снимка).

Проверены те же 128 корпусов на уровень и схему контроля. Уровни обозначают параметр отбора прежнего эксперимента. Столбец «Прежние четыре модели» показывает долю с p≤0,05 хотя бы у одной модели после поправки на четыре модели. В столбцах отдельных новых тестов приведены доли по их собственному p. Последний столбец показывает долю корпусов, в которых хотя бы один новый тест прошёл порог после поправки на два теста. Сравнение основано на значимости p, поскольку предыдущая оценка с переносом включала дополнительное условие.

Мощность при истинных вероятностях 55%, 60%, 65% и 70% составляет 10,5%, 34,5%, 68,7% и 92,2%. Это расчёт для одной заранее заданной формы связи.

## Новый сигнал «центр — края»

Кандидаты выбирались внутри заданной четверти ключа. Вероятность принятия зависела от согласия половины диапазона ключа с попаданием Qx в одну из двух крайних четвертей поля. Под каждую схему контроля создано по 128 корпусов на уровень. Половины поля Qx смешивают центральные и крайние четверти, поэтому тест совпадений мало чувствителен к этой форме связи.

| Номинальный уровень | Пирсон 2×4, диапазоны | Пирсон 2×4, четверти | С поправкой, диапазоны | С поправкой, четверти |
|---|---:|---:|---:|---:|
| 55% | 7,8% | 14,8% | 7,0% | 9,4% |
| 60% | 26,6% | 32,0% | 20,3% | 24,2% |
| 65% | 52,3% | 56,3% | 39,8% | 47,7% |
| 70% | 82,8% | 86,7% | 70,3% | 81,3% |

На уровне 70% тест совпадений сработал лишь в 2 и 3 из 128 повторов. На независимых нулевых контролях семейство дало 16/512 и 18/512 срабатываний после поправки.
