# Координаты публичного ключа и признаки подписей

11 ноября 2026 года. В обеих схемах порог прошли 0 из 24 тестов с поправкой на 24 и 0 с поправкой на 130. Основной расчёт занял 51,8 секунды.

## Данные и сверка контролей

Для Qx и Qy взяты координаты публичной точки каждого ключа. Для r, z, Ry и 2·min(s,n−s)/n взяты медианы по всем подписям ключа. Каждый из 73 ключей даёт одну строку. Использованы 208 подписей. Координата Ry относится к nonce-точке подписи. Для каждой пары проверены чётность половин, чётность четвертей и совместное распределение четвертей по Пирсону 2×16.

Координата Qx воспроизведена для тех же синтетических ключей. Сверены 392302 корзин Qy и четверти ключей. В 18 полных повторных расчётах подписей совпали координаты, все прежние признаки и состояния генератора. Для калибровки, независимого нуля и банка отбора взяты первый, средний и последний корпус в каждой схеме. Сохранены происхождение подписей, шаблоны операций и способы подписания. Для 33 январских подписей с неизвестным рецептом использован равномерный суррогат nonce. Происхождение подписей — артефакт исходного исследования (`../key-range-position-folded-s-pooled-20261111/runs/main/PROVENANCE.json`; вне снимка).

Поправка min-P использует 2 047 подписанных корпусов на схему. Первое семейство содержит 24 новых теста, второе также включает 106 прежних тестов с теми же контролями. Один тест должен пройти p≤0,05 и на полных диапазонах, и при сохранении четвертей. План — артефакт исходного исследования (`PLAN.json`; вне снимка).
