# E13: 32 новые схемы ветвей SX

Изолированное продолжение sx-cuda-20261101. Прежние восемь direct-master схем не сканируются.
Точная таблица — SCHEMES.json, по 16 схем для GNU16807 и LLVM48271.

Схемы 0–3: parent m/0; 4–7: m/0'/0; 8–11: m/0'/1.
В каждом квартете final index: i−1, i, 0x80000000+i−1, 0x80000000+i.
12–13: m/44'/0'/0'/0; 14–15: m/44'/0'/0'/1; final normal i−1/i.
Не добавлять hardened final в BIP44, новые accounts, длины или другие parents.

Entropy — 32 принятых байта прежнего точного SX uniform/rejection:
state←a×state mod2147483647; x=state−1; отвергать x>=2147483392;
GNU byte=x//8388607, LLVM byte=x&255. Seed один на master, не на задачу.
Домен каждого RNG: [1,2147483647), 2048 блоков по 1048576, последний 1048574.
Маска puzzle сохраняет младшие i−1 бит и устанавливает бит i−1.
GPU фильтрует 49 младших бит №50; CPU проверяет все №1–50;
holdout №51+ только после полного training-match. Любой реальный кандидат сохраняется
и останавливает серию до независимой affine/адресной проверки. Ошибка не является отрицательным результатом.

Контроли: исходные pins; 1173 RNG/entropy/draws; точные родители, дети и промежуточные
узлы с историческим libwallet, Python и CUDA; affine-проверка всех 32 planted-схем;
официальные BIP32-векторы 1–4, включая leading zeros; positive/negative всех схем;
границы и targeted rejection, bits0, overflow, invalid-master/child; stop/resume,
хэши завершённых блоков, конкурентный lock и retry Windows/WSL sharing violation.
Пилот: 3 блока по 1048576 состояний на каждый RNG. Измерять API perf_counter и UTC,
CUDA events отдельно; не переносить скорость прежней серии. Полные проходы последовательно.

SHA256 inputs фиксируется до приёмки и полного поиска. Блок содержит prev_hash,
config_sha256 и собственный digest. Checkpoints не перезаписываются при продолжении.
Повторная приёмка/пилот с теми же inputs не выполняется. Постоянная ошибка записи
останавливает выполнение, временная sharing violation повторяет только rename.
Любое изменение вычислительных входов требует отдельной серии.

Официальные источники: sources/bip-0032.mediawiki и bip-0044.mediawiki,
URL/дата/SHA256 в PROVENANCE.json. Эти пути исторически возможны, но выбор автора не доказан.
Число гипотез и полнота покрытия не являются вероятностью истинности модели.

Новая версия наследует EC/HMAC/RNG принятого SX; исторические HD-функции CPU остаются
неизменными, новый wrapper задаёт пути. setup-перенос: prepare.py, завершение получения
векторов: finish_prepare.py, дополнение тестов: configure_controls.py; итоговые исходники
фиксируются manifest. Старые SX/BX сертификаты/checkpoints только читаются.
