# ATT-01 — поиск архивных вложений, 02.11.2026

Начать с [RESULTS.md](<RESULTS.md>). Цели: связанные с Puzzle Armory multipliers/diagnostic ZIP, unsigned Electrum `.txn`, public exports mSIGNA/CoinQ. Это исследование источников и форматов; поиск ключей не запускается.

- [FORMATS.md](<FORMATS.md>) — полезные поля и пределы распознавания.
- [LINK_TRIAGE.md](<LINK_TRIAGE.md>) — решения по 68 URL, с различением чтения содержимого и отбора по контексту.
- `SOURCES.json`, `cache-network/` — сырые публичные ответы, URL, UTC и хеши. `cache/` сохраняет ранние ошибки DNS песочницы.
- `TARGETED_ARCHIVE_QUERIES.json`, `TARGETED_POST_REVIEW.json`, `search-*.json` — сохранённый целевой поиск.
- `CONTENT_SCAN.json`, `ARCHIVE_INTEGRITY.json`, `PSEUDO_XPUB_66.json`, `ACCEPTANCE.json` — воспроизводимые проверки.
- `INPUT_PINS.json` фиксирует четыре используемых файла E10. Они читаются по соседнему пути, не копируются на 170 MiB.

Из корня проекта, без сети:

> Исполняемый код/команды опущены в документационной копии.


`mine.py` повторяет только извлечение из сохранённого E10, без сети. `fetch.py urls-01.json --network` и аналогичные списки 02/03 используют отдельный кеш разрешённого сетевого запуска; существующий ответ проверяется по хешу и повторно не скачивается. `archive_queries.py --network` — восемь запросов с интервалом ≥1 s и пределом трёх страниц по 200 записей; в принятом запуске каждый завершился на первой странице. Для новой попытки недоступного URL нужен новый каталог/контекст, чтобы не потерять старый ответ.

Скачанные скрипты и программы не исполняются. Общая .venv, старые отчёты, проекты перебора и checkpoints не изменяются. В общий исследовательский README добавлена только ссылка на этот этап.
