# Что означает перенос начала координат

Пусть B — состояние перед первым наблюдаемым выходом (offset 0), T — переход
xorshift128+, а a — offset первого полностью известного выходного слова.
Старое прямое разворачивание использовало B как 128 независимых битов.
Теперь независимые биты — A=T^(a+1)(B), состояние сразу после выхода a.
Два слова A=(u,v) удовлетворяют `u+v=z_a mod 2^64`.

Само z_a не раскрывает u и v. Известная сумма остаётся ограничением со всеми
переносами. Число допустимых состояний не меняется: T обратим, поэтому переход
между B и A — биекция. Не создаётся ни нового наблюдения, ни дополнительного бита
настоящего ключа. Меняется структура формулы, что может повлиять на решатель.

Для параметров (a,b,c) один переход из (x,y) имеет вид:

```
t = x XOR (x << a)
v = t XOR y XOR (t >> b) XOR (y >> c)
T(x,y) = (y,v)
```

Все слова 64-битные, правые сдвиги логические. Для обратного перехода из (u,v):

```
t = inverse(I XOR R_b) [v XOR u XOR (u >> c)]
x = inverse(I XOR L_a) t
T^-1(u,v) = (x,u)
```

Обратная линейная операция — конечный ряд `I XOR S XOR S^2 XOR ...`, поскольку
сдвиг на конечном слове нильпотентен. В XOR-кодировке он развёрнут по линейным
формам; в cvc5 — через удвоение величины сдвига и точные bit-vector операции.
Эти реализации различаются и сверяются на всех 128 базисных векторах.

Выход t берётся как сумма двух слов состояния `T^(t-a)(A)`. При t<a используются
обратные переходы. Возвращаемый свидетель: `B=T^(-(a+1))(A)`; блокировка найденного
B переводится обратно в A. Нулевое состояние исключено в обоих представлениях.

Для восьми оставшихся перестановок anchor=0. Смена координат убирает линейный
переход перед первым ограничением суммы. Для двух схем с offsets (0,2,4,6) после
нормировки наблюдений anchor=2: более ранний частичный выход требует двух обратных
шагов. Он не теряется и не заменяется независимыми свободными битами.

Для попарного сравнения используются прежние synthetic-входы, те же версии CMS/cvc5
и лимиты 120 с/запрос, 240 с/задачу. Прежний Z3 уже использовал другую редукцию
к 64-битному неизвестному через `(u,z-u)`; она не объявляется новой и не повторяется.
Здесь проверяется именно перенос базы 128-битных XOR/bit-vector моделей.
