# RNG64-04 — координаты у первого полностью известного выхода

10 ноября 2026. Ровно 10 строк synthetic_incomplete из RNG64-03.
Не менять семейства, наблюдения, синтетические состояния, packing, маски и split.
Fitting №135; №130 — дополнительный fitting; остальные 81 решения — holdout.
Предыдущие файлы и checkpoints только читать.

Пусть a — минимальное время выхода с полной 64-битной маской. Неизвестные — два
64-битных слова состояния СРАЗУ ПОСЛЕ этого выхода. В момент a сумма этих слов
равна наблюдению z modulo 2^64. Для t>a прямой переход; для t<a точный обратный.
При возврате свидетеля вычислять состояние ДО выхода 0 через T^(-(a+1)); при
блокировке возвращать свидетель в координаты a. Нулевое состояние запрещено.
Известная сумма остаётся точным ограничением, не XOR и не бесплатным знанием слов.

Два прежних движка, без изменения их версий/параметров: CryptoMiniSat 5.18.0
(XOR+CNF), cvc5 1.4.2 (bit-vectors). Изменяется координатная система и направление
разворачивания переходов. 120 с/запрос, 240 с/движок/задачу, до 8 состояний,
как RNG64-03. Четыре независимых случая одновременно, один поток на решатель.
Внутри случая CMS первым, cvc5 вторым. Для чистого парного сравнения полный
synthetic-контроль каждого из двух движков выполняется на всех десяти входах.
Baseline не пересчитывать: использовать сохранённые ответы RNG64-03.

До слепых контролей: исчерпывающий reduced-width перебор, включая частичные
наблюдения ДО anchor; проверка всех 128 базисных векторов при полных параметрах;
положительные/отрицательные случаи с фиксированными состояниями, неоднозначность,
запрет нуля, UNKNOWN. Алгоритм не получает CHECKER_SECRET.

Реальные данные конкретный движок получает только после собственного завершённого
слепого перечисления synthetic, содержащего посаженное состояние, и проверки
серии 83 номеров + скрытого №71 для обоих прежних межключевых шагов.
Оба допущенных движка могут независимо проверять реальный вход. Вторичный real-
запрос нельзя выполнять раньше собственного полного blind-контроля этого движка.
UNSAT после найденных SAT означает полное перечисление; UNKNOWN/cap/budget —
неполноту. Реальный локальный UNSAT исключает схему для любых межключевых шагов.
При реальных состояниях проверять только max(offsets)+1 и max(offsets)+4.
Кандидат по полному holdout останавливает новые задания до адресной проверки.

Сохранять все формулы, состояния в обеих координатах, ответы, время, версии и хэши.
Повторный запуск не пересчитывает завершённые задачи. ОС-блокировки для runner
и worker; внешний watchdog адресно завершает непосредственный процесс solver,
запускаемый без дополнительного venv-launcher. Тайм-ауты не считать исключениями.
