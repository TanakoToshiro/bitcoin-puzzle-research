# E9g — минимальный BIP44-набор, 16 новых схем

01.11.2026. Пользователь разрешил запуск следующего BIP44-этапа. Изолированная версия, старые научные файлы не меняются.

Два RNG: minstd_rand0/16807 и minstd_rand/48271, mod2147483647, новый state%255 на байт. Начальные состояния1..2147483646. Entropy16/32 байта напрямую в BIP32 master, **без BIP39/PBKDF2**.

Родители ровно два: path0=m/44'/0'/0'/0 (external), path1=m/44'/0'/0'/1 (change). Последний child normal, index=puzzle−1+offset, offset0/1. Маска прежняя:2^(i−1)+(child mod2^(i−1)). Всего8 схем на генератор,16 в серии. Внутренний scheme=length_id*4+path*2+offset. Нельзя считать старые16 GPU-слотов за16 новых схем одного генератора.

Общий parent account=m/44'/0'/0' вычисляется один раз на entropy; branch0/1 используют его общий public key. CUDA/CPU/Python должны совпасть по всем промежуточным узлам и счёту схем. Hardened только44',0',0'; branch и последний index обычные. Стандарт BIP44 существовал с2014, но его применение автором puzzle не установлено; raw BX entropy→BIP32 остаётся конкретной гипотезой.

Перед поиском: повторно проверить источники и старые законченные серии без вычислений; 14 исторических BIP32-векторов;40 родителей/360 детей;256×8 random fingerprint и516×8 contiguous/tail;8 synthetic положительных схем с отрицательными/holdout/ранними training мутациями;20 RNG-векторов; точные HMAC payloads; CPU baseline/filter; невалидные диапазоны/overflow; stop/resume и candidate halt. Добавить прямую сверку узлов m/44',m/44'/0',m/44'/0'/0' и обеих branches для обоих RNG.

Пилот4×1048576 на генератор, block256. Полные проходы последовательные:2048 блока, последний1048574, точная область[1,2147483647). Чекпойнты атомарные, SHA-цепочка и lock; ошибка не даёт покрытия. Обвязка использует исправленное повторное чтение STATUS на DrvFS. При training candidate остановить серию для независимой проверки адресов. Полный отрицательный результат исключает только16 перечисленных BIP44-цепочек. Другие entropy/accounts/пути не включены; облако не арендуется.

Core multiplier=48271; schemes=8.
