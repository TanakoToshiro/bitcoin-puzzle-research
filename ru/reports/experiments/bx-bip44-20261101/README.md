# E9g — минимальные BIP44-пути BX, полный проход

Пользователь разрешил запуск следующего этапа. Ровно16 новых схем: два RNG16807/48271 × entropy16/32 × родители m/44'/0'/0'/0 и m/44'/0'/0'/1 × final index i−1/i. Последний child **normal**. Сырые BX-байты передаются в BIP32; BIP39/PBKDF2 здесь нет. Другие accounts, длины и пути не включены. [Протокол](<PROTOCOL.md>).

Статус всей серии — [RESULTS.md](<RESULTS.md>), STATUS.json, stdout.log/stderr.log. Каждый генератор выполняет8 схем на состояние; два полных прохода по2^31−2 состояний выполняются **последовательно** на3070 Ti Laptop. Последний блок1048574, остальные1048576; итог каждого —2048 блока, итог серии —4096. Root COMPLETE.json появляется только после двух полных аудитов. Отсутствие совпадений относится к этим16 схемам, не ко всем кошелькам или стандарту BIP44.

SERIES.lock предотвращает одновременный второй запуск. Для штатной остановки создать STOP в корне серии; обвязка передаст его работающему worker. После выяснения причины для продолжения убрать STOP в корне и соответствующей подпапке full, повторить run_series.py. Законченные блоки проверяются и пропускаются. Candidate/error останавливают серию; их нельзя автоматически обходить.

Данные в16807/ и48271/: engine.cu, CPU-verifier, новый Python reference, точные BIP44-эталоны, ACCOUNT_EXPECTED/CHECK.json, controls/, EXTRA_CONTROLS.json, ACCEPTANCE.json, FINAL_MANIFEST.json, pilots/, full/blocks/ и FULL_AUDIT.json. Восстановленная исправленная обвязка повторяет чтение атомарно обновляемого STATUS наDrvFS и не прерывает вычисление из-за временной недоступности отчёта.

Подготовка: setup.py/prepare_inputs.py выполнялись вWindows Python3.11 venv; build_cpu.sh и build_controls.sh — вWSL. Эти команды не нужны для возобновления и не должны переписывать принятую версию. Для другого кода/данных нужна новая версия. setup.py сохранён как журнал происхождения; логические исправления подготовки и обвязки отмечены вJOURNAL.md. Старые snapshots и checkpoints не изменяются. Облако не арендуется, настройки питания не меняются; компьютер должен оставаться включённым.

Основание путей: [BIP44](https://github.com/bitcoin/bips/blob/master/bip-0044.mediawiki), Bitcoin coin_type0, account0, external0/change1. Это исторически возможная схема, но не установленная программа автора puzzle. GPU-фильтр сравнивает49 младших битов №50; редкие кандидаты проверяет CPU по №1–50, затем №51+. При совпадении нужна независимая проверка адресов.
