# RNG64-05 — сеть переносов известной суммы

Новая серия для прежних 10 открытых случаев. Протокол: [PROTOCOL.md](<PROTOCOL.md>),
точная математика: [METHOD.md](<METHOD.md>). Старые данные не изменяются.

Команды PowerShell из этой папки:

> Исполняемый код/команды опущены в документационной копии.


run.py удерживает ОС-блокировку RUN.lock; worker.py — WORKER.lock своей попытки.
Наличие файла не означает живой процесс. PROCESS.json хранит PID/путь/время.
Проверяйте живой процесс и блокировки перед продолжением после аварии; не запускайте
параллельный worker в тот же каталог. Завершённые OUTPUT/RESULT и отдельные ответы
solver используются повторно. Принятый код и окружение зафиксированы в MANIFEST.json.

Скрытые синтетические состояния лежат отдельно в CHECKER_SECRET.json. Worker
получает только family/observations. Каждый движок отдельно должен завершить свой
blind-контроль перед реальным входом. Один SAT без конечного UNSAT не даёт допуска.
Проверка с фиксированным состоянием служит проверкой кода и не заменяет blind recovery.

formula-*.json содержит точные CNF/XOR и блокировки по 64 битам x; formula-*.smt2 —
модель cvc5. query-*.json сохраняет оба слова anchor и состояние до выхода 0,
ответ, время, причину UNKNOWN и хэш формулы. При тайм-ауте отрицательный вывод не делается.
Внешний watchdog работает с непосредственным процессом solver, без venv-launcher.

Результаты: cases/, RUN_RESULT.json, SUMMARY.csv, JOURNAL.md и RESULTS.md.
FINAL_REPORT.md пересобирается из сохранённых данных, без solver. COMPLETE.json
означает завершение зарегистрированного цикла с явно указанными незавершёнными случаями.

Версии прежние: Python 3.11.9, pycryptosat 5.18.0, cvc5 1.4.2.
Документация API и исторических генераторов уже сохранена в предшествующих сериях;
новые модели PRNG не вводятся. Вычисления локальные CPU, четыре независимых случая.
