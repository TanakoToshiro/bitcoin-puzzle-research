# Точная сеть известной суммы

Известно z=x+y mod 2^w для состояния сразу после первого полного выхода.
Для каждого бита j обычное сложение задаёт:

`y_j = x_j XOR c_j XOR z_j`, `c_0=0`.

Подстановка в majority(x_j,y_j,c_j) даёт:

- z_j=0 ⇒ `c_(j+1)=x_j OR c_j`;
- z_j=1 ⇒ `c_(j+1)=x_j AND c_j`.

Все 8 локальных комбинаций сохранены в controls/CARRY_MATH.json. Конечный перенос
отбрасывается: это modulo 2^w, а не ограничение отсутствия переполнения.
При фиксированных x,z все переносы и y однозначны; y=(z−x) mod 2^w.
Из локального тождества и c_0=0 по индукции по позиции бита следует корректность
для любой ширины w; проверки малых слов и 64-битных границ проверяют реализацию.

В CMS переменные 1..64 задают x. Остальные — вспомогательные переменные переносов
и линейных форм. Константа аффинной формы хранится отдельным битом маски, не
подменяется неизвестной переменной. y строится из x/c/z, затем формы распространяются
прежними точными прямыми и обратными переходами. Лишнее общее ограничение anchor-
суммы не добавляется. Для остальных выходов остаётся прежняя модель сложения.

Cvc5 использует отдельную реализацию: извлечение битов одного 64-битного x,
однобитные OR/AND-переносы, XOR и конкатенацию y. Вычитание как готовая операция
не используется; обычное модульное вычитание служит независимой проверкой результата.

Нулевая сумма не означает нулевое состояние. Например, x=y=2^63 допустимы и дают
z=0 modulo 2^64. Поэтому запрещается только x=0 при z=0. При z!=0 нулевое
состояние невозможно уже по конструкции. Эти случаи проверены обоими решателями.

Блокировка найденного решения — только по x. Это полно, поскольку другое y при
том же x,z невозможно; отдельные тесты прямо запрещают правильное y при фиксированном
x и требуют UNSAT. Возврат состояния до offset0 и последующие маски проверяются
прежней числовой реализацией генератора.

Редукция не даёт дополнительных данных о реальном ключе. Прежняя известная сумма
уже ограничивала 128-битное состояние теми же 2^64 парами до остальных наблюдений.
Тестируется лишь эффективность явной сети для solver. 64 независимых входных бита
не означают 64 SAT-переменные: вспомогательные переменные тоже входят в размер формулы.
Сравнение с предыдущей серией производится на тех же входах и лимитах.
