# E1c — итог: вероятности среди совместимых состояний MT

Дата: 2026-10-30. Запуск `20261030-124415-78192a38`. Приёмка: **passed**.

## Результат

Для 12 ранее проверенных схем без неизвестных отказов доказано: при равномерном prior по ненулевым состояниям MT каждый ключ №71 имеет одинаковую условную вероятность 2^-70. Каждому ключу соответствует ровно 2^16100 состояний. Ни отдельный бит, ни нетривиальный XOR не предпочтителен. Это точный вывод при указанном prior, не утверждение о реальном seed создателя. [Доказательство](<../../EXACT_UNIFORM.md>).

Для трёх API со скрытыми отказами рассмотрено 1728 proposal-историй: 1254 совместимых и 474 несовместимых. Отдельно проверены 12 истинных историй синтетических наборов; они не включались в оценки.

Во всех совместимых proposal-ветвях целевой остаток имел полную размерность: 70 бит для №71 и 74 для №75. Условные вероятности всех проверенных битов и XOR, а также их взвешенные оценки — ровно 1/2. Выигрыш перед случайным выбором не обнаружен.

## Проверка ключей по адресу

Из новых совместимых состояний получено 425 различных кандидатов №71; совпадений с адресом — 0. Вместе с ранее проверенными 172 значениями это 597 различных ключей. Compressed и uncompressed адреса сверены локально, точки — coincurve и независимой Python-арифметикой. Все кандидаты и происхождение — артефакт исходного исследования (`CANDIDATE_ADDRESS_AUDIT.json`; вне снимка).

Загрузка в кошелёк не нужна: проверяемое условие — совпадение полученного адреса с адресом puzzle, а не показанный баланс. Совпадение подтверждает подходящий ключ, но не единственность исходного состояния генератора. Несовпадение исключает конкретного кандидата.

## Допустимый вывод и продолжение

Для равномерного prior и 12 фиксированных линейных схем случайное совместимое состояние не уменьшает ожидаемое число проверок ключей. Для скрытых отказов пилот не обнаружил сигнала в изученных ветвях, но не доказывает равномерность полной смеси. Не доказаны ни историческое использование MT, ни равномерный prior исходного seed. Нельзя превращать количество подогнанных состояний в оценку вероятности реального ключа без модели их происхождения.

При равномерной цели N=2^70 проверка различных ключей в любом фиксированном порядке требует в среднем (N+1)/2 попыток. Независимый равномерный выбор с возвращением требует в среднем N попыток. Построение совместимого состояния и проверка адреса добавляют вычислительную стоимость; ускорение такого поиска относительно GPU-перебора не измерялось и не заявляется.

Текущий объём полностью завершён. Для воспроизведения истории достаточно manifest, отдельных samples, RESULTS/NOTES и команд в README; предыдущие эксперименты и рабочие проекты не изменялись.

## Будущие эксперименты

1. Обоснованные ограничения на исторический seed/скрипт, которые действительно сокращают множество состояний.
2. Аналитическая оценка массы неувиденных историй или точно калиброванное условное предложение; простое увеличение числа случайных историй само по себе не решает вопрос охвата.
3. Полное моделирование randrange с границей порядка secp256k1, без достаточных ограничений только на подсемью accepted/rejected значений.
4. Новые проверки любых появившихся смещений на новых данных по отдельному заранее зафиксированному протоколу.
