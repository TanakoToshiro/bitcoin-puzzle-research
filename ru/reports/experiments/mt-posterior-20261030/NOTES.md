## 2026-10-30 — переход от существования к вероятностям

Для 12 схем без неизвестных отказов прежние сертификаты дают точное равномерное условное распределение №71 при равномерном prior по ненулевым состояниям. Каждому ключу соответствует ровно 2^16100 состояний. Поэтому выбор случайного совместимого состояния в этих схемах не даёт преимущества. Этот вывод не относится автоматически к неизвестному механизму seed создателя. [Доказательство и источники рангов](<EXACT_UNIFORM.md>).

Для неизвестных отказов простое усреднение историй неправильно: на маленьком примере оно даёт 1/2 вместо 1/3. Построен importance-sampling пилот с весом 2^(g+m-rank). Исчерпывающий контроль всех 1023 ненулевых состояний маленького генератора проверил 2816 систем для 176 историй. Дополнительно 8192 случайных предложений восстановили искусственное смещение: оценка 0,248950 при точном значении 0,225806. Разница 0,023143 удовлетворяет заранее выбранной контрольной границе 0,05; это контроль реализации, не точность будущих оценок MT.

До фиксации запуска усилен положительный контроль: вместо вырожденной вероятности 0 выбран искусственный случай с обеими возможными метками. Реальные данные не использовались для выбора. Первоначальный технический smoke-контроль не был научным запуском. После этого код и протокол зафиксированы в `20261030-124415-78192a38`.

## 2026-10-30 — исторические API и продолжение

Все 12 синтетических наборов сверены с настоящими Python 2.7.9/3.4.2, включая полную последовательность 135 ключей и фактическое число отказов. После первого proposal выполнена штатная остановка `--max-new 1`; продолжение пропускает этот checkpoint. Приёмка отдельно проверит его хеш и время изменения.

Задача пилота — выявить сигнал или предел применимости метода. Даже если все попавшие в выборку истории дают вероятность 1/2, это не доказывает равномерность смеси по всем неизвестным историям. ESS оценивает только наблюдённые веса и не исключает редкие тяжёлые истории.

## 2026-10-30 — обнаружен предел охвата случайных историй

Детальное сравнение весов истинной истории с предложениями усилило ограничение предыдущего вывода. У interval3-synthetic-0 log2 importance-веса истинной истории равен 32, максимум в выборке 3: разница 2^29. У interval3-synthetic-1 — 21 против 2, то есть 2^19; у synthetic-2 — 5 против 2. Это веса после деления на proposal-вероятность, не отношение вероятностей отдельных историй. Все эти подлинные ветви также имеют d=70.

Следствие: независимые геометрические предложения не дают подтверждённого охвата условного распределения историй. Наблюдённый ESS может выглядеть приемлемым и не обнаружить пропущенный большой вес. Поэтому все оценки пилота остаются диагностическими; «50% на выборке» не повышается до утверждения о полной смеси. Научные параметры не менялись; уже назначенные реальные наборы доводятся до конца для воспроизводимой диагностики, а не для заявления об извлечённом бите. Точное доказательство для 12 схем без отказов от этой проблемы не зависит.
