# Точный posterior для 12 линейных схем

При явно выбранном равномерном prior по ненулевым состояниям MT все совместимые с наблюдениями состояния равновероятны. Опубликованный RHS ненулевой, поэтому нулевое состояние не попадает в условное множество.

Для 12 схем без скрытых отказов rank(A)=3767 и rank([A;B])=3837. Всего совместимых состояний 2^16170, а для каждого из 2^70 остатков №71 ровно 2^16100. Поэтому условная вероятность любого ключа **точно 2^-70**, каждого неизвестного бита — 1/2. Это относится также к любому нетривиальному XOR неизвестных битов. Любая смесь этих 12 условных равномерных распределений остаётся равномерной.

Это новый вероятностный вывод при заданном prior, а не вывод о неизвестном реальном seed создателя. Он опирается на уже проверенные сертификаты E1b; повторять случайное сэмплирование для этого доказательства не нужно. Модели и хеши сертификатов — артефакт исходного исследования (`EXACT_UNIFORM.json`; вне снимка).
