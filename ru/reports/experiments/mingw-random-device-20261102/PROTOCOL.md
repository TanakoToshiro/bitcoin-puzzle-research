# MINGW-RD-01 — фиксированный random_device

Дата постановки: 2026-11-02. CPU, без изменения SX/GPU-процессов. Это отдельный аудит исторической реализации и ограниченная проверка конкретного фиксированного состояния, не новый полный перебор.

1. Сохранить GCC 4.7.4/4.8.2/4.9.2 random.h/random.tcc/random.cc и настройки выбора fallback. Проверить ветку без `_GLIBCXX_USE_RANDOM_TR1`, default seed и число вызовов в SX/BX. Отдельно различать MinGW/libstdc++ и MSVC.
2. Воспроизвести исторические функции fallback с явными адаптерами; сопоставить MT19937 с независимой Python-реализацией и NumPy RandomState. Проверить сброс при создании нового объекта и продолжение одного объекта. Не использовать Python random.seed как эквивалент C++ seed.
3. Вычислить первое значение random_device и нормализованное состояние GNU minstd_rand0. Получить SX uniform8 entropy32 и BX %255 entropy16/32. Пересчитать ограниченный набор прежних путей на этом одном состоянии, не повторять их полные проходы.
4. При чтении исторического журнала обнаружена отдельная версия SX от 23.05.2014: uniform16 с последующим >>8 для всех компиляторов. Добавить её точную цепочку для того же фиксированного состояния, entropy32. Это не прежняя MSVC-ветка uint16 с отбрасыванием старших битов. Сравнить исторический distribution с независимой формулой до реальных решений.
5. Пути: родители m, m/0, m/0'/0, m/0'/1 с normal/hardened последним индексом i−1/i (16); родители m/44'/0'/0'/0 и /1 с normal i−1/i (4). Всего20 на entropy-модель; четыре entropy-модели =80 комбинаций. Это ограниченный перечень, не все возможные пути. Для SX глубинные пути — проверяемая условная композиция HD-функций, не доказательство использования конкретным кошельком.
6. Реальные решения1–50 — проверка гипотез. Holdout51+ просматривать только после полного совпадения обучения. Принудительно установленный старший бит исключён из наблюдений. Сохранить точные предсказания и первое противоречие каждой модели. Независимые проверки BIP32/криптографии и синтетические положительные/отрицательные контроли обязательны.
7. Завершить классификацией: повтор ранее покрытого пространства; новая конечная фиксированная цепочка; непроверенная историческая конфигурация. Не объявлять исключёнными MinGW, SX или Windows вообще. Никаких выводов о программе автора без отдельного свидетельства.

Источники и неудачные загрузки: SOURCES.json. Результаты и продолжение: RESULTS.md. Прежние исследования только читаются, заимствованные файлы копируются с хэшами.
