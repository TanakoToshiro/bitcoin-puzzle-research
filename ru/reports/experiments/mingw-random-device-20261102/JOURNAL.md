# Журнал MINGW-RD-01

## 2026-11-02 — постановка и источники

Создан отдельный эксперимент. Старые проекты и запущенный SX не изменяются. Подтверждены сообщение MinGW #338 от 06.05.2013, upstream fallback GCC 4.7.4/4.8.2/4.9.2 и исправление GCC9 2019 года. Исходный seed MT =5489, но downstream minstd получает **первый выход MT**, а не5489.

Первоначальная сеть в sandbox:21 DNS-ошибка; затем источники загружены с разрешённым расширенным доступом. Ошибки сохранены в SOURCES.json. Два предположенных расположения random.cc для GCC4.7.4 дали404: в этой версии нужный fallback целиком находится в random.h, поэтому отсутствие этих файлов не блокирует воспроизведение.

WSL из sandbox дал E_ACCESSDENIED; сборка продолжена с расширенным доступом. Первая сборка выявила ошибку извлечения distribution GCC4.7.4: захвачены соседние методы. Извлечение исправлено на границу тела функции по скобкам; исходники архива не менялись. Эти подготовительные ошибки не являются результатами проверки гипотез.

## 2026-11-02 — уточнение объёма до проверки реальных данных

Историческая версия SX от23.05.2014 содержит uniform16>>8 **для всех платформ**, а не толькоMSVC. Добавлена к протоколу как четвёртая entropy-модель для фиксированного состояния. Полный перебор этой модели не заявляется и не запускается. Для других путей используется ограниченный перечень20 BIP32-схем, явно обозначенный как гипотезы композиции, не установленное поведение кошелька автора.

Первая исходниковая assert-проверка остановилась до native/реальных тестов: GCC4.7.4 ещё не содержит явного запрета RANDOM_TR1 для native MinGW в acinclude.m4. Там используется проверка доступности /dev/random и /dev/urandom; в crossconfig MinGW не определяет RANDOM_TR1. В4.8.2/4.9.2 запрет уже явный, включая MSys. Скорректировано описание конфигураций; fallback по-прежнему проверяется условно при неопределённом макросе. Нельзя объявлять все исторические бинарники одинаковыми без build metadata.

## 2026-11-02 — расчёт завершён

Точное время: AUDIT.json (UTC01.11.2026 21:55:54 соответствует02.11.2026 00:55:54МСК). MT seed5489 → rd_first3499211612 → minstd1351727965. Три native fallback дали по10000 выходов, совпавших с независимыми Python/NumPy;1590 uniform-примеров совпали.83 известных адреса проверены, synthetic controls пройдены.80 комбинаций отвергнуты на №2–5. Две SX entropy на этом состоянии одинаковы, поэтому только60 разных последовательностей. Реальные решения51+ не использовались для отбора/holdout, только для общей проверки адресного набора. Сохранены все предсказания1–50 и первые ошибки; закрытая выборка не потребовалась.

Неравенство SX uniform8 и uniform16>>8 на всём пространстве подтверждено сохранённым native-контролем при **minstd-state5489**, который не надо путать с фактическим minstd-state1351727965. На default MinGW обе модели совпали, расширения поиска ради этого fallback не требуется. Для произвольного состояния майская версия остаётся отдельным открытым вопросом.
