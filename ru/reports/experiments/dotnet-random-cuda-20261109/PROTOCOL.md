# DN-G01 — CUDA-перенос 16 исторических System.Random схем

9 ноября 2026. Входы/маски/API/разделение train1–50 и holdout51+ — ровно
DN-R01. GPU обнаружена: RTX3070Ti Laptop, CUDA через WSL Ubuntu24.04.
Старый CPU-эксперимент не менять. Полный 2^31 проход в приёмку переноса не входит.

Один CUDA thread — один canonical seed в [0,2^31). Все16 схем разделяют
InternalSample. Состояние55 слов хранить в uint32: переполнение реализуется
unsigned-операциями, знак проверяется битом31; не полагаться на signed UB.
NextBytes — low8; Next(256) — literal double с явными RN multiplication и
truncate-to-zero. Не использовать fast-math или менять API на предположительно
эквивалентный PRNG. Положительные и отрицательные signed seed нужны для векторов.

Train-события компилируются в таблицы масок отвергаемых схем для каждого
байта и номера вызова. Отдельные active-маски позволяют пропускать ненужные
чтения; сами вызовы RNG не пропускать. Каждое событие должно быть покрыто.
GPU выдаёт seed+16-битную маску; CPU проверяет все train и holdout по исходному
Python-эталону. При кандидате остановка для независимого разбора.

Контроли до пилота: все40*8704 исторических векторов, оба byte-API; все33
синтетических набора и полные множества CPU-совпадений; малое прямое сравнение
всех масок на256 seed; мутация train каждой схемы; неполные блоки и верхний
seed2147483647; пустой диапазон; ошибочные границы; переполнение candidate
buffer. Overflow/error никогда не завершают checkpoint и не означают0совпадений.
Проверить остановку/возобновление и OS-lock. Готовые блоки не повторять.

Запуск128threads/block, без тюнинга по ответам реальных ключей. Три прежних
CPU-пилота повторяются наGPU только для парной проверки/измерения; это не
новое уникальное покрытие. После контролей пять новых непересекающихся
блоков по2^20 seed: start=2^28+j*2^20, j=0..4. При слишком долгом первом
kernel (>1с) уменьшить следующие блоки и явно зафиксировать изменение.
Сохранить CUDA-event kernel-time, API wall-time, буферы и характеристики GPU.
Прогноз полного прохода по persistent GPU context, без платы за WSL startup
в каждом блоке. Пилотное измерение не гарантирует длительную скорость.

Перед сборкой/после испытаний проверить SHA-256 старого COMPLETE. Источник,
компилятор, флаги, библиотеку, входы, JSON-результаты и журналы сохранить.
Полный runner должен работать в новой папке, проверять manifest, использовать
flock, импортировать проверенныеGPU-пилоты при совпаденииграниц/входов и
завершаться при кандидате. Его полный диапазон пока не запускать.
