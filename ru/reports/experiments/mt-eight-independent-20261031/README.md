# E1j — независимая реализация общего поиска №155

2026-10-31. Только новые синтетические точки на secp256k1. [Протокол](<PROTOCOL.md>), [живой журнал](<RESULTS.md>), [таблицы](<TABLES.md>). После завершения — CONCLUSION.md и ACCEPTANCE.json. Старые проекты и матрицы не изменяются.

Код поиска `native.cpp` написан отдельно и использует C++17/OpenSSL вместо Python/coincurve. Он не импортирует E1i и не читает файлы; получает публичные данные через stdin. Функция скачков и параметры сохранены, чтобы можно было проверить точное совпадение ответов и шести счётчиков. Полный транскрипт промежуточных точек не сохранялся. Полная математическая независимость не заявляется — проверяется реализация той же идеи другим кодом и другой арифметикой кривой.

Из `research/puzzle71-hypotheses` (локальный WSL Ubuntu-24.04 необходим только для нативного исполнения):

> Исполняемый код/команды опущены в документационной копии.


Бинарник `native`, исходник, компилятор и версия/хэш OpenSSL фиксируются в manifest.json и BUILD.json. Изменение кода/параметров требует нового эксперимента. Все запросы контролируются временем 900 с; незавершённые остаются с ERROR.json, завершённые с DONE.json. RESULTS.md обновляется после каждого запроса. EVENTS.jsonl — подробная история в UTC; пользовательская дата протокола — Europe/Moscow.

Верификатор хранит искусственные приватные скаляры и seed только в VERIFIER_ONLY_FIXTURES.json. Алгоритм получает point, starts, length и независимую соль; ID случая/номер блока/seed ему не передаются. `runs/*/native-input.txt` содержит ровно отправленные байты. Схема строки: SEARCH K N compressed_Q salt32hex start1hex … startKhex. До четырёх попыток. `--selftest` — отдельный режим проверки арифметики, не поисковые запросы.

Результаты содержат все попытки, число сложений/удвоений/шагов/поисков, отдельные расходы подготовки и проверки скаляра, время и RSS. RSS — накопленный пик всего процесса, не точная память отдельного случая. Нативный worker последовательный, без GPU. Восемь запусков старого неизменённого Python E1i служат сверкой ключей и точных счётчиков, не сравнением скорости библиотек с разным профилированием.

296 новых задач: 264 основные, 32 подтверждающие; 336 C++ сравнений плюс 8 Python. Дополнительно 24 проверки арифметики и 144 контрольных поисковых случая. Большие интервалы имеют длину до 2^32; сами искусственные скаляры около 2^154. Это не перебор настоящего №155 и не подтверждение MT-модели.

Бинарник принимает N≤2^40; длины/расстояния uint64_t, начала и скаляры BIGNUM. Для настоящих интервалов N=2^146 понадобится отдельная реализация широких расстояний. [Что именно независимо проверено](<INDEPENDENCE.md>).
