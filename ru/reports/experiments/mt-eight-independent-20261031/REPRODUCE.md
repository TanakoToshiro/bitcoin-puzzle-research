# Продолжение и независимое воспроизведение E1j

Для чтения результатов достаточно README.md, CONCLUSION.md, TABLES.md и STATISTICS.json. Для пересборки числовых таблиц используется report.py: поиск не запускается. Для проверки сохранённых входов, счётчиков и пропуска готовой работы — acceptance.py после завершения серии.

Сборка выполнялась локально, без установки пакетов, командой из корня workspace:

> Исполняемый код/команды опущены в документационной копии.


Для собственной сверки сборки использовать другой выходной файл или отдельную копию исследования: исходный binary участвует в manifest и не должен заменяться в зафиксированном запуске. BUILD.json содержит компилятор, флаги, SHA исходника/бинарника и версию/хэш загруженной libcrypto. Сама libcrypto не копировалась в папку; нужна зафиксированная среда или новый эксперимент с явно другой версией.

Пример точного публичного ввода можно взять из любого runs/*/native-input.txt. Вход состоит из одной строки SEARCH K N Q salt start1 ... startK; все приватные скаляры отсутствуют. Нативный worker принимает несколько таких строк последовательно, выводит по одному JSON и сбрасывает локальное состояние поиска между задачами. `--version` показывает OpenSSL; `--selftest` выдаёт отдельные арифметические контроли.

experiment.py run проверяет manifest, FIXTURES_HASH и DONE каждого запроса. Если всё завершено, дочерние процессы не запускаются. Если стадия прервана, готовые запросы пропускаются, остальные продолжаются из сохранённого набора. Алгоритм не менялся по результатам промежуточного просмотра. Для изменения числа скачков, T, лимитов или способа группировки нужна новая папка и новый независимый подтверждающий набор.

Файлы воспроизводимости:

- manifest.json — неизменные научные входы и план;
- BUILD.json, VERSIONS.json — окружение;
- VERIFIER_ONLY_FIXTURES.json, FIXTURES_HASH.json — искусственные секреты и замороженная генерация, только для верификатора;
- controls/ — 24 арифметических и 144 поисковых контроля;
- runs/ — 336 нативных измерений и восемь Python-сверок;
- reference-audit/ — два дополнительных контроля веток после наблюдений, исключённые из сравнительной статистики;
- RETRIES.json — все измерительные случаи, потребовавшие повторов;
- ACCEPTANCE.json, FINAL_MANIFEST.json — итоговая приёмка и хэши артефактов.

Формат времени: события в UTC, пользовательская дата отчёта Europe/Moscow. Расходы CPU внутри native не включают написание кода/сборку/генерацию данных. `roundtrip_seconds` отдельно учитывает обмен с процессом. RSS — высокий уровень использования памяти одного процесса за весь сеанс, а не сумма памяти всех задач.
