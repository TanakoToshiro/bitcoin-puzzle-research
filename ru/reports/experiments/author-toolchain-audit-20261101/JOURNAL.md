# E10 — журнал аудита публичных архивов

## 2026-11-01, начало и фиксация источников
Создан отдельный эксперимент. E5/E8 читаются без изменения; сохранены хэши использованных файлов и 56 ранее загруженных ответов E8. Из пяти опорных транзакций выделены подписавшие непазловые адреса, SEC-ключи и родительские outpoints. Они являются поисковыми идентификаторами, а не доказанной единой личностью.

## 2026-11-01, профиль и первые поисковые совпадения
Текущий профиль и API Ninjastic возвращают одно сообщение account 991321, msg18765941. В собственном тексте названа Large Bitcoin Collider с похвалой проекта; использование этой программы автором не заявлено. Electrum, Python и иные генераторы в этом сообщении не названы. Цитата другого участника исключается из собственного текста.

Совпадение адреса 173uj… в BlockCypher Java требует проверки происхождения тестовых данных; само по себе не свидетельствует об использовании библиотеки владельцем адреса. Самоназвание на saatoshirising.wiki не связывается с форумным аккаунтом: в просмотренной странице нет проверенного доказательства контроля, предлагается платный ключ. Взаимодействий с этим предложением не производилось.

## 2026-11-01, сбор основной темы
На снимке пагинации основной темы 701 страница (offsets 0…14000). Первый сбор тремя соединениями получил HTTP503 Too fast / overloaded и остановлен. Ошибки сохранены. Продолжение идёт одним соединением с задержкой 2,5 секунды дополнительно к 0,3 секунды downloader; при перегрузке предусмотрен backoff и остановка. Неполученные страницы не считаются проверенными. Промежуточное покрытие — FORUM_PROGRESS.json; итоговый корпус будет пересобран после завершения.

## 2026-11-01, границы технической атрибуции
Родительская транзакция 2015 имеет общий крупный адрес и несколько получателей. Платёж не доказывает общий кошелёк или принадлежность программного набора. Подготовка пополнения 2017 предшествовала форумному сообщению; один временной порядок не доказывает и не опровергает авторство. E5 уже установил RFC6979 для известных подписей раскрытия 2019; это признак подписывающего ПО 2019, не генератора 2015. Проверяются исторические исходники и альтернативные объяснения.

## 2026-11-01, завершение сбора и исправления

Живой обход остановлен штатно на 364 страницах / 7280 сообщениях после перехода на пакетную выдачу публичного архива. STOP_FETCH оставлен намеренно. Все неполученные живые страницы и HTTP-ошибки сохранены. API основной темы получен полностью: 16 169 post_id на 81 непересекающейся странице; 21 межтематический запрос — 441 сообщение из 53 тем. Полнота API не равна полноте Интернета: в живом корпусе обнаружено 30 отсутствующих в этой архивной выдаче сообщений.

Исправлены параметры API: author_uid не поддерживается, нужен author; after возвращает новые записи, last — более старые. Первоначальная отметка complete на 200/16169 недействительна и сохранена в v1-invalid-pagination. Независимый аудит исключает ошибочную страницу и проверяет исходный total, уникальность и хэши всех принятых страниц. Неполная выдача alias241 дополнена после исправления курсора.

Сопоставлены девять Wayback-снимков авторского сообщения: нормализованный собственный текст одинаков. Контроль вложенных цитат прошёл. Точная атрибуция выявленных упоминаний программ сохранена в EVIDENCE; поздние сторонние догадки, вставленные фрагменты кода, входящие сообщения и тесты других участников не включены в авторские признания.

## 2026-11-01, выводы и итоговая сверка

Новый ограничивающий признак: high-R подписи раскрытия2019 исключают стандартный проверенный путь CKey::Sign Core0.17.0 с grind=true. Исторический Electrum3.3.4 совместим, но признак не уникален. Применение Electrum/Python для исходной генерации2015 не установлено. Java-совпадение относится к публичному тесту чтения баланса, добавленному в2016; метка Bitstamp/BitGo относится к соседнему получателю.

Уточнение первой записи журнала: фактически REUSED_E8.json содержит 57 ответов, не 56. Все их тела дополнительно проверяются по SHA256. Новые сырые ответы, входные E5/E8 pins и независимая проверка покрытия проходят derive_audit.py. Числовой отчёт пересобирается из JSON без сети, интерпретации остаются отдельными документами. Итоговая фиксация — COMPLETE.json. Следующие исследования не запускались.
