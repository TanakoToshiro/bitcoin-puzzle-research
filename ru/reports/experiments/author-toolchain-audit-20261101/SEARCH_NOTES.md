# E10 — охват поиска и ограничения

Дата среза: 2026-11-01. Проверялись сообщения предполагаемого создателя, точные адреса, SEC-ключи, HASH160 и txid из E5/E8, ранние обсуждения Puzzle, программные репозитории и исторические версии исходников. Цель — техническая атрибуция программ, не установление личности человека.

## Сохранённые запросы

Файлы `search/01-identifiers.json` … `search/11-service-claim.json` содержат запросы и ответы интернет-поиска. `ARCHIVE_SEARCH.json` содержит 21 завершённый межтематический запрос к публичному архиву, включая поиск автора и точных идентификаторов. `SOURCE_INDEX.csv` связывает URL с исходным ответом, временем загрузки, HTTP-статусом и SHA-256. `REUSED_E8.json` указывает отдельно повторно использованные ответы прошлого исследования.

Первые ориентирующие интернет-запросы не были сохранены отдельными JSON в момент исполнения. Ретроспективная запись их направлений: `"saatoshi_rising" wallet`, Electrum и posts; `"bitcoin puzzle" creator wallet software original transaction 2015`; точные 1Cz…, 1CEND…, bc1quks…; `"saatoshi_rising" "wallet" site:bitcointalk.org`; варианты исключения reddit/github/facebook; 173uj… wallet/Bitfinex; `"Bitcoin puzzle" "creator" "Armory"`; точные 1LTG… и 1Fdt…; alias+Electrum до 2018; документация Ninjastic API. Это описание направлений, не подмена отсутствующих исходных ответов. Существенные выводы опираются на отдельно сохранённые первичные страницы и исходники.

## Корпус

Основная тема: `topic_id=1306983`. Полностью получена выдача архивного API на момент загрузки: 16 169 уникальных post_id, сверка с объявленным total и независимое объединение исходных страниц. Это не утверждение о полноте всех когда-либо существовавших сообщений. Текущая HTML-тема собрана частично; точный список пропусков — `MISSING_PAGES.json`. Wayback-проверки авторского сообщения и профиля — `ARCHIVE_COMPARISON.json`.

Все доступные тексты автоматически сопоставлены с 284 идентификаторами и словарём программ. Приоритетные совпадения сохраняются с контекстом; выполнен ручной разбор существенных утверждений. Полного ручного чтения каждого из 16 169 сообщений не заявляется. Различия текущего текста и архивной версии не стираются. Вложенные формальные цитаты исключены из own_text, но свободно вставленные чужой код и пересказы требуют ручной атрибуции.

## Исправления сбора

Параметр `author_uid` API оказался неподдерживаемым; рабочий поиск — `author=saatoshi_rising`. Для обратной хронологии нужен `last=post_id`, а `after` возвращает более новые записи. Первоначальное ошибочное завершение на 200/16169 отменено; старые файлы сохранены с именем v1/invalid-pagination, в окончательную проверку покрытия не входят. Выдача alias из 241 записи после исправления получена полностью. `derive_audit.py` независимо сверяет исходные страницы и не принимает старое состояние за завершённый сбор.

## Что осталось за пределами

Не покрыты удалённые до архивирования сообщения, закрытые профили/переписка, неиндексируемые вложения, весь набор страниц Wayback и все форумы Интернета. HTTP-ошибки сохранены как ошибки, не как отсутствие упоминаний. История адреса 1NZUP3… получена только последней страницей и не используется для полного исторического отрицания. История 1LTG… получена в пределах объявленных девяти транзакций. Публичные метки бирж и общие входы не приравниваются к доказанной собственности автора. Индексные даты поисковика не заменяют даты первичных источников.
