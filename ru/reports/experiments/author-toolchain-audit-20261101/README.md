# E10 — публичные архивы и программный набор создателя Bitcoin Puzzle

Начало: 2026-11-01. Задание — проверить сообщения автора, цитирование адресов, публичных точек и транзакций на связь с программами и генераторами. Это архивный аудит; новый поиск seed/приватных ключей, GPU-проходы и другие пункты roadmap не запускались.

Начать чтение с [RESULTS.md](<RESULTS.md>), затем EVIDENCE.csv — артефакт исходного исследования (`EVIDENCE.csv`; вне снимка), [NUMERIC_REPORT.md](<NUMERIC_REPORT.md>), [JOURNAL.md](<JOURNAL.md>). Границы исследования — [PROTOCOL.md](<PROTOCOL.md>). Результаты прежних E5/E8 используются без изменения: INPUT_PINS.json — артефакт исходного исследования (`INPUT_PINS.json`; вне снимка).

## Артефакты

- `cache/`, `slow-pass/cache/`: исходные HTTP-ответы и metadata с URL, UTC и SHA256, включая ошибки; `text/` — производный текст.
- `SOURCE_INDEX.csv`, `SOURCES_ALL.json`: единый индекс новых ответов; `REUSED_E8.json` — отдельно 57 ответов прежнего исследования.
- `search/*.json`: сохранённые поисковые запросы и выдачи. Ранние несохранённые выдачи перечислены отдельно в `SEARCH_NOTES.md`; они не выдаются за воспроизводимые снимки.
- `FORUM_POSTS.json`, `FORUM_COVERAGE.json`, `MISSING_PAGES.json`: полученная часть текущего форума. Пагинация701 страниц не означает, что все701 страницы скачаны.
- `TOPIC_ARCHIVE_POSTS.json`, `TOPIC_ARCHIVE_PROGRESS.json`: полный проход основной темы в доступном API Ninjastic, с проверкой исходного total и уникальных post_id.
- `ARCHIVE_SEARCH.json`, `ARCHIVE_SEARCH_POSTS.json`: точные запросы по всему индексу форума, а не только основной теме. Полнота относится к выдаче API, не ко всем когда-либо существовавшим сообщениям.
- `UNIFIED_POST_VERSIONS.json`: объединённые версии собственного текста из текущего форума и архива. `CORPUS_MATCHES.json`, `PRIORITY_REVIEW.json/.md`: автоматический отбор по284 идентификаторам и словарю программ для ручной проверки. Дубликаты и формальные цитаты отделены; цитата без форумной разметки может оставаться в `own_text`, поэтому автоматическая атрибуция запрещена.
- `ARCHIVE_COMPARISON.json`, `PARSER_CHECKS.json`: сравнение Wayback-версий и контроль исключения вложенных цитат.
- `ANCHORS.json`, `SIGNATURE_FINGERPRINTS.json`: признаки пяти транзакций из уже проверенного E5, без повторного криптографического аудита.
- `EVIDENCE.json/.csv`: интерпретации с источниками, автором, силой связи и альтернативами. Автогенератор чисел этот файл не заменяет.

## Продолжение сетевого сбора

`topic_archive.py` продолжает с сохранённого курсора, а завершённый проход с совпавшим total не повторяет. Он использует проверенный параметр `last` (меньшие post_id). Старое форумное описание API перепутало направления `last/after`; первоначальная попытка сохранена как `TOPIC_ARCHIVE_PROGRESS-v1-invalid-pagination.json`. Её ранний статус complete недействителен: всего200 записей из16169. Итоговую полноту определяют исправленный collector и независимая сверка.

Для новых точных поисков использовать `archive_search.py`, соблюдая один запрос/сек и сохранение исходных ответов. Кеш ошибок не удаляется; отдельная повторная попытка должна иметь новый metadata-контекст. `slow_forum.py` остановлен через `STOP_FETCH` после перехода на пакетный архив; его не требуется возобновлять для пересборки отчёта. Существование стоп-файла намеренное.

Запускать внешние скачанные программы не нужно. E5/E8, старые проекты и checkpoints не изменяются.
