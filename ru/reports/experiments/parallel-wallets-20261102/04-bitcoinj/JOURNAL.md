# Журнал B4

## 2026-11-02 — начало

Прочитаны общая постановка, HD-01 RESULTS/WALLETS/MATH и E9 WALLET_MAP.
Собственная папка отсутствовала, продолжать существующий запуск не требуется.
Общий snapshot решений и прежние результаты не изменяются.
В bitcoinj 0.12 замечены два заслуживающих отдельной проверки edge case:
`assertLessThanN` использует `> 0`, а retry накапливает номер ребёнка.
Это пока наблюдения по исходнику, криптографическая польза не установлена.

## 2026-11-02 — первый Java-контроль и исправление ожидания

Найден установленный JDK 8; оригинальный bitcoinj-core 0.12 и зависимости
сохранены локально. JUnit BIP32Test прошёл. Первый harness завершился на
ошибочном ожидании порядка: свежий wallet уже материализует lookahead, поэтому
ранние external children появляются перед internal независимо от первых двух
API-вызовов. Исходник `LinkedHashMap` сам по себе не определяет момент вставки.
Неудачный запуск сохранён в `runs/java-fd639e4d1143` (включая steps/stdout/stderr).
Исправлен контроль: выдача выходит за исходный пул, после чего проверяется
перемешивание блоков ветвей в порядке вставки. Предположение о раннем
change-first порядке снято; новый запуск имеет другой хэш исходника.

## 2026-11-02 — завершённые контроли

Java run `java-679b54999ef0`: исторический JUnit BIP32Test прошёл (2 tests),
75 проверок harness прошли, включая private leaf rederivation, protobuf
roundtrip, migration selection/clones, padding, bound helper и retry injection.
Результат уточнил HD-01: lookahead-size не равен числу строк private dump.
Обнаружено, что Android Report Issue собирает dump с account xpub без private.
Артефакт автора не найден; общий поиск MPK или перебор xpub не запускался.

Python run `controls-861ce64b4b6a` завершён за 27.125 s: 15929 checks,
83 real input validations, 8702 exact small prefix systems, 3222 Java nodes
сверены независимым reference. 4 conditional synthetic predictions и 16
negative controls прошли в отдельных public-input subprocesses; по 79 других
synthetic masks проверены после прогноза. Старый HD-01 arithmetic не объявляется
новым криптографическим результатом. Ни один реальный ключ не найден.

Миграционный prefix-domain для residue №135 содержит ровно 2^122 вариантов H,
если этот raw ключ был выбран migration origin. Это счёт кандидатов данного
метода до проверки HMAC/public связей, а не информационная нижняя граница атаки.
В реальных данных принадлежность строки old origin не установлена.

Первичные HTTP-загрузки из sandbox завершились DNS error, затем те же конечные
списки успешно прочитаны с разрешённым network access; все ошибки сохранены
в SOURCES.json. Системный py launcher не нашёл Python; найденный python.exe
3.11.9 использован напрямую. Ошибка первого поиска пути JDK исправлена на
существующий вложенный каталог jdk8u302-b08. Никаких пакетов в общий venv
не устанавливалось; процессов соседних GPU-экспериментов не касались.
