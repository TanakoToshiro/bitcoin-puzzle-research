# EL-02: запуск и проверка

Python3.11.9, только стандартная библиотека. Ничего устанавливать не нужно.
Все команды выполнять из этой папки. `-B` предотвращает __pycache__.

> Исполняемый код/команды опущены в документационной копии.


`run.py` сохраняет стадии в `runs/el02-v1`. Уже существующие inputs/outputs
и CHECKS не пересоздаются; проверяется соответствие ответов контрольным данным.
Не удалять завершённые outputs ради "resume". `report.py` только строит
NUMERIC_REPORT.md из JSON; `acceptance.py` проверяет SHA256 источников, копий,
общих оригиналов и всех JSON запуска. После первого вызова RUN_MANIFEST.json
фиксирует научные артефакты; последующие вызовы отвергают их изменение.

В данном запуске все34 public-input задания завершены. При аварии до появления
output повторный run.py запускает только незавершённое задание; checkpoint
совместного перебора каждые128 кандидатов сохраняет пройденную границу/ответы
для аудита. Автоматический resume внутри одного незавершённого задания пока
не реализован: оно повторяется целиком, максимум1024 кандидата/30s, без
повтора завершённых задач. Для новых исследований создайте другой run ID,
измените протокол до вычислений; не подмешивайте новые данные в el02-v1.

Восстановитель/предиктор работает отдельным процессом:

> Исполняемый код/команды опущены в документационной копии.


Пример выше создаёт новый output условного synthetic предиктора; штатная
приёмка не требует повторного запуска. Выходной файл не перезаписывается.
Формат новых реальных входов описан в ARTIFACT_PROFILE.md. solve.py читает
ровно заданный public-input JSON; SYNTHETIC_SECRETS.json ему не передаётся
и его код не читает соседние файлы. Это отдельный интерфейс/процесс, не
изоляция файловой системой: секреты остаются доступны проверяющему процессу.

`prepare.py` копирует исходные известные входы с контролем хэша и получает
основные upstream источники. Готовые загрузки не повторяет. Дополнительные
проверенные версии скачаны через prepare.fetch; точные URL/UTC/SHA в SOURCES.json.
Для восстановления отсутствующего источника используйте его label/url из
этого manifest через fetch; существующие источники не заменяются. Первые6
запросов получили DNS error в sandbox; повтор с разрешённым доступом прошёл.
Всего20 новых попыток в установленном лимите25; ошибки сохранены.

Файлы:

- RESULTS.md — вывод, ограничения и конкретный следующий вход.
- MATH.md — точные байты, совместная модель и цена алгоритмов.
- NUMERIC_REPORT.md — таблица из научных JSON.
- SOURCE_FACTS/SOURCES/INPUT_PINS — цитируемые места, загрузки и пины.
- runs/el02-v1/SOURCE_CONTROLS.json — выполнение выделенных исторических методов.
- runs/el02-v1/*.input.json и *.output.json — отдельные public-input задачи.
- runs/el02-v1/SYNTHETIC_SECRETS.json — исключительно контрольные секреты.
- SUMMARY_FOR_MERGE.md — краткий итог для основного чата.

LegacyDict в source fixtures воспроизводит только list-returning keys/values
Python2. Реальный Python2 hash-table iteration не воспроизведён и не
приписывается Python3. Fixture transaction hex="00" — metadata-контроль,
не полноценная Bitcoin transaction. Всё это отражено в выводах.
