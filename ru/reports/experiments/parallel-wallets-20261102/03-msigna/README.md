# Задание3 — mSIGNA

Итог: [RESULTS.md](<RESULTS.md>). Кратко для сведения: [SUMMARY_FOR_MERGE.md](<SUMMARY_FOR_MERGE.md>).

Все команды выполняются из этой папки, Python3.11+; внешних пакетов нет. Код использует только synthetic keys и открытый snapshot известных решений. Запись только в03-msigna.

> Исполняемый код/команды опущены в документационной копии.


`collect.py` требует сеть только для отсутствующих исходников; уже полученные файлы повторно не загружает. Исторические Git blob сверяются с сохранённым HD-01 tree. Общие inputs копируются и проверяются побайтово, источник не изменяется. При работе вне этого проекта нужно сохранить источники/inputs из текущего пакета; collector рассчитывает на исходную структуру HD-01.

`run_controls.py` вычисляет ID по коду/входам, сохраняет config/progress/results. При завершённом идентичном запуске выходит без пересчёта. Незавершённый запуск можно продолжить той же командой (он повторит короткий набор внутри своего незавершённого ID); частичных долгих поисков нет. Первый неудачный запуск сохранён и описан в JOURNAL.md. `check_constant_export.py` — отдельная O(83) проверка узкой гипотезы, также переиспользует результат. Бюджеты заранее заданы в PROTOCOL.md.

`build_report.py` проверяет хэши источников/inputs/результатов и формирует NUMERIC_REPORT/ACCEPTANCE/STATUS без повторения вычислений. Основной код — независимая математическая Python-модель; оригинальный GUI/CLI binary не запускался. Нельзя называть source-model граничные тесты исполнением исходного C++.

Все xprv/private_hex в runs — **SYNTHETIC CONTROL, не реальные кошельки**. В inputs/known_solutions.json лежат только уже опубликованные решения. Новых реальных private keys нет.
