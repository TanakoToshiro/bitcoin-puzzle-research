# Журнал A1

## 2026-11-02 — до вычислений

Прочитаны общая постановка, HD-01 RESULTS/WALLETS/MATH, E3 NOTES, E6H NOTES,
armory_hnp.py, recover_watchonly.py, ARMORY_HNP_SUMMARY.json. Существующих
результатов в 01-armory не было. Инструкций AGENTS.md в проверенной иерархии нет.
В коде найдены отдельный PKCC export и повторение C в дочерней записи.
Обычный текстовый список выводит PublicX/PublicY и опциональный ChainIndex,
но не C у каждого child. Это разные типы артефактов.
Прямое web-открытие страницы commit вернуло cache miss; raw PyBtcWallet.py
доступен. Основные доказательства — локальные файлы с закреплёнными хэшами E3.
Системный python не содержит coincurve; общая среда не изменяется.

## 2026-11-02 — новая ветка до запуска

При проверке safeExtend обнаружен multiplier log: PyBtcAddress.py:425–510,
ArmoryUtils.py:428. Полный 32-байтный XOR-множитель записывается независимо
от CRYPTO_DEBUG при успешной штатной private/public деривации. Это позволяет
подать HNP коэффициенты без P/C, а затем восстановить C по найденному scalar.
Протокол дополнен до контролей. Проверяемое новое условие — подходящий журнал,
не только уже известный watch-only. Пользователь подтвердил контекст публичного
Bitcoin Puzzle; исследование продолжается в назначенной папке.

## 2026-11-02 — историческая проверка и первый контроль

Закреплён официальный v0.92.3: 268db0f3fa20c989057bd43343a43b2edbe89aeb,
2014-10-02T20:30:15Z. Журнал есть и в релизе, и в январском срезе.
MULT_LOG_FILE приходит также через завершающий `from armoryengine.BDM import *`
(BDM импортирует ArmoryUtils.*); отсутствие имени в верхнем selective import
не означает NameError. Recovery копирует multipliers.txt в диагностическую папку.
Системный сетевой вызов не прошёл DNS sandbox; разрешённая загрузка конкретного
релиза с расширенным сетевым доступом успешна, общая среда не менялась.
Первая стадия перепроверила все 83 входа независимой affine-арифметикой.
Toy-контроль остановился на сравнении порядка двух кандидатов C после XOR:
множества совпадали, список не был отсортирован. Исправлена нормализация порядка,
ошибочный запуск сохранён; принятую проверку входов переносим без пересчёта.

## 2026-11-02 — принят запуск 20261102T010953Z

6/6 log-only, 6/6 anchor+C; 48 неверных пакетов отвергнуты отдельным процессом.
В log-only пакетах нет P, C, root или raw children. Scalar якоря и C совпали
с отдельным synthetic oracle; все достижимые отложенные значения совпали.
Реальные маски сохранены, но значения всех recovery-цепочек синтетические.
Поздний anchor=119 имеет 0 holdout из известных индексов; №140/160 — новые
synthetic цели, а не реальные решения. Исчерпывающий toy проверил 1386+1386
interval случаев, 16 пар unknown-C и 16 log-систем.
Full-size interval с b=240 успешен; реальные b=134 отвергнуты по лимиту до
таблицы. Для соседних известных №69/70 оценка порядка 2^94 EC.

Исполнены неизменённые тела исторических safeExtendPrivateKey/PublicKey
с прозрачным адаптером C++/данных для обоих срезов: точный log-формат совпал.
Сериализатор 237-byte записи также исполнен с адаптером и совпал побайтно.
35 дополнительных переходов проверены независимой affine-реализацией.
Завершённые стадии при resume не повторились (new_stages=0). Оформлены
форматы артефактов, математические ограничения, отчёт и отдельная сводка.
Реальный авторский multiplier log не получен; историческое применение Armory
к Puzzle не доказано. Общие журналы и чужие папки не менялись.
