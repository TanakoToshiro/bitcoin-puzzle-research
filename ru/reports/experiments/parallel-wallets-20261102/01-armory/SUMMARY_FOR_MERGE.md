# A1 Armory — для общего журнала
- Завершён условный synthetic этап, run `20261102T010953Z`; реального нового ключа нет.
- Новое: штатный `multipliers.txt` даёт HNP-коэффициенты без root public key и C.
- Проверено в январском commit 61a596f и релизе v0.92.3 / 268db0f (02.10.2014).
- В журнале — HASH160 исходного parent и полный 32-byte XOR-множитель, до mod n.
- Из найденного scalar выводится C; все записи проверяются по постоянному C.
- Исторический recovery копирует журнал в диагностическую папку; GUI умеет её архивировать.
- Log-only: 6/6 успехов, 24/24 negative; четыре реальные маски №120/125/130/135.
- Время log recovery 4.56–16.16 мс без старта Python и последующих предсказаний.
- Только anchor=-1 даёт root; поздний anchor восстанавливает suffix, не прошлые ключи.
- Anchor+C: ещё 6/6 positive, 24/24 negative; реализованы PKCC/237-byte record parsers.
- Toy: 1386+1386 interval-контролей, 16 C-пар, 16 полных log-систем.
- Независимый affine: 35 переходов; исторический serializer совпал побайтно.
- Неизвестный C без журнала: interval-DLP требует исходных raw points и private residues.
- Для соседних №69/70 цена около 2^94 EC, не 2^32; b=240 тесты явно усиленные.
- Все 83 решения перепроверены, hash d291351169b1bb483b580af8cf4c30e503941f7b15b81aabd418e93809a40b70.
- Настоящего журнала/PKCC/дочерней записи автора нет; связь Armory с Puzzle не установлена.
- Следующий конкретный вход: связанный с автором журнал/диагностический архив + index mapping.
