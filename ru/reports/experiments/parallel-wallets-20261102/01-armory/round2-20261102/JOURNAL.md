# Журнал A1-R2

## 2026-11-02 — до контролей

Прочитаны STATUS, RESULTS, MATH, ARTIFACT_PROFILE и PROTOCOL первого цикла.
Новый математический путь: точное пересечение двух младших остатков при
известном отношении детей через floor-sum, без LLL и без полного raw point.
Требование упорядоченного короткого log можно ослабить: произведение коммутирует,
а исходные hashes позволяют проверить порядок после получения кандидата.
Официальная документация ACL подтверждает Euclidean floor-sum и O(log m);
реализация здесь собственная на Python arbitrary precision, без 32/64-bit
ограничений библиотеки. До запуска записан отдельный протокол.
