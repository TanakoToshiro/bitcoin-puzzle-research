# Armory R2 — дополнение для общего журнала

- Run `20261102T013922Z`; условный synthetic результат, реального нового ключа нет.
- Новый exact pair solver: y=A*x mod n + два младших остатка, без LLL/BSGS.
- Floor-sum считает весь набор; бинарный поиск перечисляет только непустые интервалы.
- №130/135: 8/8 цепочек, по1 арифметическому кандидату, всего5 уникальных log-строк.
- №125/130: 8/8, от8 до21 кандидата, log hashes/C оставляют1; №135 — holdout.
- Вход не содержит исходные points, chaincode или полные raw private keys.
- Порядок5 строк восстанавливается по parent hashes; дубли удаляются.
- 16 positive,48 negative; 26702 floor-sum и57660 полных малых pair-систем.
- 32 независимых affine-перехода; synthetic №140/160 предсказаны вперёд.
- Bounded scan по479 окнам нашёл сегмент в2 журналах с неизвестной позицией.
- При строгом interleaving в2 контролях окна нет; произвольные подмножества не искались.
