# Пары с нормализованным s и половина диапазона

11 ноября 2026 года. Порог в обеих схемах прошли 0 из девяти тестов после поправки на девять и 0 после поправки на 94. Расчёт занял 6,1 секунды.

## Данные и методика

На каждый из 73 ключей приходится одна медиана признака по всем его подписям. Для s сначала вычислена величина 2·min(s,n−s)/n в каждой подписи. Тесты чётности сравнивают совпадение половин или совпадение чётности номеров четвертей двух признаков с половиной диапазона ключа. Отклонения учитываются в обе стороны. Пирсон 2×16 сравнивает совместные распределения по всем комбинациям четвертей.

Сохранённые подписанные контроли учитывают происхождение 208 подписей, шаблоны операций и способы подписания. Для 33 январских подписей с неизвестным рецептом использован равномерный суррогат nonce. В каждой схеме поправка min-P получена по 2 047 корпусам. Основное семейство включает девять новых тестов, расширенное включает ещё 85 предыдущих. Один и тот же тест должен пройти p≤0,05 в обеих схемах. План — артефакт исходного исследования (`PLAN.json`; вне снимка) · Происхождение подписей — артефакт исходного исследования (`../key-range-position-folded-s-pooled-20261111/runs/main/PROVENANCE.json`; вне снимка).
