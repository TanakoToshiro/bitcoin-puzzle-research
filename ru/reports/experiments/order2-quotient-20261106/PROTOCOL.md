# O2-Q01 — классы сдвига и полная проекция на №71

Дата: 6 ноября 2026, Europe/Moscow. Продолжение O2-ID01. Старые результаты только читаются.

Модель: s[i+2]=a*s[i+1]+b*s[i]+c mod p, b!=0, канонические состояния. Наблюдения — те же номера и маски, без принудительного старшего бита. Класс представлен (a,b,d,c0), где x1=0, x2=d, c0=c-(1-a-b)*s1. Совместимость масок вычисляется после восстановления общего сдвига, а не наложением старых масок на x.

Предварительно фиксируем проверки:
1. Все 27 прежних малых входов p=7,11,17: независимый поиск классов должен дать в точности прежние полные множества пятёрок и прогнозов. Truth решателю не передаётся.
2. Для каждого найденного класса отдельный интервальный алгоритм должен вернуть в точности все допустимые сдвиги и остатки цели. Дополнительно сравнение со скалярным перебором сдвигов на 500 детерминированных произвольных входах, включая противоречивые маски, нулевую ширину и полные наблюдения.
3. Четыре новых синтетических входа: p=31,61, по два невырожденных примера, SHA-256('O2-Q01|p|case|attempt|field') mod p. Сравнение с прежним прямым перебором на том же INPUT; бюджет каждого решателя 60 секунд, остановка на границе блока. Таймаут не считается отрицательным результатом. Ширины floor((i-1)*bit_length(p)/256), цель floor(70*bit_length(p)/256). Такие малые модули не тестируют 70 бит цели.
4. 33 прежних полноразмерных синтетических класса: интервальная проекция из канонического представителя, сравнение с сохранёнными свидетельствами. Здесь класс задан проверяющим кодом; это НЕ восстановление неизвестных коэффициентов.
5. Проверка остановки/продолжения и неизменности старого опыта; завершённые блоки не повторять. Набор входов и кода хэшируется. Результаты этапов сохранять и отражать в RESULTS.md.

Новый поиск классов: полный домен p^3*(p-1), блоки 8192; для каждой канонической цепочки перебор сдвигов, заданных самым широким наблюдением (не более ceil(p/2^K)), остальные маски фильтруют. Этот вариант удобен для пакетной NumPy-проверки полноты. Второй, независимый интервальный метод вообще не перечисляет сдвиги: O(m^2) сравнений на класс и O(m) интервалов. Не смешивать выигрыш внутри класса с нахождением класса.

Объединяются прогнозы ВСЕХ совместимых классов, включая вырожденные. Нельзя объявлять один найденный прогноз доказанным при незавершённом покрытии. Реальный 256-битный поиск не запускать, пока масштабирование не оправдывает его. Полный toy-перебор не является алгоритмом практического восстановления modulo n. Отдельно сообщить стоимость и препятствие.
