# O2-Q01: точная факторизация и проекция

Пусть p нечётен, b!=0; простота p нужна для интерпретации полевых коэффициентов, но следующие формулы сдвига верны и для нечётного составного модуля. Каждая исходная пятёрка имеет единственное представление

```
d  = s2-s1 mod p
c0 = c-(1-a-b)*s1 mod p
x1 = 0; x2 = d
x[i+2] = a*x[i+1]+b*x[i]+c0 mod p
t = s1, 0 <= t < p
s[i] = (x[i]+t) mod p
c = c0+(1-a-b)*t mod p.
```

Поэтому полный домен классов (a,b,d,c0) имеет p^3(p-1) элементов. Подмена исходных наблюдений масками x недопустима. Восстанавливаем совместимые t отдельно. Все фактические порядки <=2 включены: b!=0 не означает невырожденность.

Это в точности параметризация через коэффициенты и разности: d1=d, d2=(a-1)*d+c0 mod p. Обратно c0=d2-(a-1)*d. Далее d[i+2]=a*d[i+1]+b*d[i], x[i+1]=x[i]+d[i] mod p. Такая замена убирает общий сдвиг, но оставляет четыре свободных полевых элемента; новый независимый аудит проверяет эту форму исполнения.

## Точная проекция без перечисления сдвигов

Для наблюдения (i,k,r) обозначим eps_i(t)=1, если x_i+t>=p, иначе 0. Порог равен p-x_i. На интервалах, образованных всеми этими порогами, eps_i постоянны. Добавляем порог цели p-x_71. Внутри каждого интервала:

```
t = r_i-x_i+eps_i*p mod 2^k_i.
```

Два таких сравнения совместимы тогда и только тогда, когда их остатки совпадают modulo 2^min(k_i,k_j). При совместимости остаётся одно сравнение t=R mod 2^K, K=max k_i. Пересечение этого сравнения с целочисленным интервалом [lo,end) — пусто либо арифметическая прогрессия. Её первый элемент, последний, шаг и мощность вычисляются целочисленным делением. При K>=h, где h — ширина цели, и неизменном eps_71, остаток цели один на всю прогрессию.

Объединение прогрессий по непересекающимся интервалам содержит в точности ВСЕ совместимые сдвиги данного класса. Число интервалов не превышает m+2 для m наблюдений с ненулевой шириной; O(m^2) сравнений, O(m) хранения. Реализация использует Python big integers и применима непосредственно к 256-битному p. Никакие скрытые значения s1/c в неё не передаются; но четыре координаты класса ДАНЫ, а не восстановлены ею.

Для нахождения неизвестного класса реализован отдельный полный малый поиск. NumPy строит цепочки для всех p^3(p-1) классов блоками8192, затем использует самое широкое наблюдение: перебирает его допустимые канонические значения z=r+q*2^K<p и вычисляет t=z-x_i mod p. Это биекция со всеми сдвигами, удовлетворяющими выбранному наблюдению. Прочие маски проверяются точно. Порядок фильтров не меняет математического множества. Результат сравнивается с независимым старым перебором всех p^4(p-1) пятёрок, а каждый найденный класс — с интервальным проектором.

## Полнота и предел масштабирования

Полнота конечного поиска следует из единственности канонических координат и исчерпывающего домена классов; каждый блок содержит непересекающийся диапазон индексов. Она дополнительно проверяется полным совпадением множеств решений с независимым малым эталоном. Проверка истинного синтетического ответа в множестве сама по себе полноту не доказывает.

Снятие одного неизвестного не делает полный поиск практичным: n^3(n-1) приблизительно 2^1024 классов для порядка secp256k1. Для пакетного перебора добавляется до ceil(n/2^134) сдвигов на класс, поэтому его нельзя переносить на реальный модуль. Даже замена этого шага на полиномиальный интервальный алгоритм сохраняет 2^1024 классов. Быстрые степени матриц сокращают работу при известных коэффициентах, но не количество неизвестных классов.

Уменьшенные модули 7..61 сохраняют номера и относительный рост ширин, но округление даёт цели всего0..1бит. Из успешного определения этого бита нельзя выводить возможность восстановления реальных70бит или вероятность истинности модели. Все83 наблюдения используются как ограничения; отдельного holdout в данном опыте нет. Реальные Puzzle-значения не подставлялись в решатель.
