# SXN-01 — newseed/genpriv: нативный аудит и стоимость поиска

**Подтверждена новая конечная приватная цепочка SX/MSVC. Полный поиск не запускался.**
Нативный генератор и дочерние ключи совпали с независимой моделью. На RTX 3070 Ti
Laptop полный uint32-проход по четырём схемам оценивается примерно в **5.49 суток**.
На этом этапе принято решение не переходить автоматически к многосуточному поиску.
Отрицательного результата по Bitcoin Puzzle здесь нет.

## Точная подтверждённая модель

```text
uint32 seed, включая 0
  → MSVC std::default_random_engine = MT19937(seed)
  → первые 16 draw % 255
  → 32 символа hex в нижнем регистре, с сохранением ведущих нулей
  → 100000 раундов SHA256(previous_bytes || original_hex32_ASCII)
  → master private scalar
  → сжатый SEC public key, удалить первый байт → только X (32 байта)
  → offset = SHA256d(decimal(index) || ':' || branch || ':' || X)
  → private child = (master + int_big_endian(offset)) mod secp256k1_order
```

Первое previous_bytes равно исходной ASCII hex-строке; затем это 32 сырых байта
предыдущего SHA256. В SHA попадает **строка hex**, а не 16 декодированных байт.
%255 не выдаёт байт ff. Домен — не более 2^32 исходных последовательностей;
попарная уникальность всех entropy не утверждается.

Будущая конечная постановка: receive/change × индекс i−1/i — четыре схемы из
PROPOSED_SCHEMES.json — артефакт исходного исследования (`PROPOSED_SCHEMES.json`; вне снимка). Маска пазла прежняя:
`2^(i-1) + (private_child mod 2^(i-1))`. Полный объём — 4 294 967 296 seed,
17 179 869 184 пар seed×scheme. Прежние 20 BIP32-путей здесь неприменимы.

## Почему это исторический X-only вариант

В commit libwallet `5a01940e282e94279403b7db211148fb49aac7ce` от 10.05.2014
**одновременно** произошли две замены: OpenSSL BN_rand → single-seed engine %255,
и явный uncompressed public key → `secret_to_public_key(secret)` без второго
аргумента. API libbitcoin с момента введения 24.04.2014 имеет compressed=true
по умолчанию. Код libwallet затем удаляет первый байт как будто это префикс 04.
Поэтому в нашем историческом наборе остаётся X, а не X||Y.

[Исторический diff libwallet](https://github.com/EdgeApp/libwallet/commit/5a01940e282e94279403b7db211148fb49aac7ce),
[API libbitcoin](https://github.com/libbitcoin/libbitcoin-system/blob/382fa8c5abd5c98df10908d4db86e07bb2f0e8ac/include/bitcoin/utility/ec_keys.hpp).

До этого изменения использовались BN_rand с запросом 128-битного числа и
несжатый публичный ключ. Сочетание **MT + обычный 64-байтный Electrum MPK**
в просмотренной истории штатной версией не подтверждено. Оно проверено только
в отдельно помеченной диагностической сборке с compressed=false и не предлагается
как второй полный uint32-поиск. Примеры README соответствуют обычному XY-пути.

История подтверждена шестью Git blobs, включая одинаковый майский файл в двух
архивах libwallet. Июньский commit присутствует в EdgeApp; его отсутствие в
BWallet не заменялось вымышленным совпадением. HISTORY.json — артефакт исходного исследования (`HISTORY.json`; вне снимка).
Это вывод о доступной истории и конкретных зависимостях, не обо всех сторонних
форках и не об использовании программы создателем пазла.

## Нативная сборка и ограничения

Использована полная x64-сборка SXM-02: SX `76813dd9`, libwallet `f7289e1b`,
libbitcoin `e11af9c4`, CTP Nov2013 / VS2013 RTM / SDK8.1. Старые исходники,
объекты, библиотеки и EXE сохранены. Перекомпилирован один новый тестовый object
electrum_keys с подстановкой заданного uint32 вместо random_device и трассами;
остальная программа перелинкована из прежних объектов в новую папку.
Диагностический XY EXE имеет отдельный дополнительный патч и не выдаётся за
оригинальную программу. BUILD.json — артефакт исходного исследования (`BUILD.json`; вне снимка), `build/*/instrumentation.patch`.

**Работает подтверждённый путь private export `newseed → genpriv`.** Полноценная
публичная деривация этим не подтверждается: `generate_public_key` пытается читать
32 байта Y начиная с `MPK.data()+32`, хотя логический MPK имеет только 32 байта.
Этот некорректный публичный путь не исполнялся и не превращался в модель поиска.
В диагностической XY-сборке публичная деривация совпала с независимыми точками.

`set_seed` обрезает LF/CRLF, поэтому ограничение hd-priv из SXM-02 не переносится
на genpriv. Uppercase hex меняет растяжение; newseed выводит lowercase.
Приватные скаляры и их маски можно проверять независимо от исторического
uncompressed WIF и неисправного публичного экспорта этого снимка.

## Измерение на RTX 3070 Ti Laptop

Время включает MT/hex, 100000 SHA256, публичную точку на принятом CUDA-ядре,
вычисление четырёх приватных ключей и синтетический фильтр на CPU.
Не включены будущие checkpoints, перерывы и восстановление процесса.
Каждый stretch kernel выполняет не более 1000 раундов; состояние сохраняется
на GPU. Основной kernel: 56 регистров, без spill/local memory.

| Серия | Обработано seed | Скорость, seed/с | Прогноз полного домена |
|---|---:|---:|---:|
| Первичный пилот, 3 размера пакета | 114,688 | 9,240.18 | 5.38 суток |
| Устойчивость, 5 × 65536 | 327,680 | 9,060.28 | 5.49 суток |
| 64 threads, два крупных пакета | 131,072 | 9,322.75 | 5.33 суток |

Дополнительно на крупных пакетах сравнены 64/128/256 threads в прямом и обратном
порядке; лучший средний результат остался у 64. Проверены 18 независимых
свидетельств полных ключей. Разброс отдельных stability-блоков соответствует
**5.32–6.08 суток**. Это короткие синтетические измерения, не гарантия
непрерывной работы на той же скорости в течение нескольких дней и не нижняя
граница цены для иных реализаций/устройств.

PILOT.json — артефакт исходного исследования (`PILOT.json`; вне снимка), STABILITY.json — артефакт исходного исследования (`STABILITY.json`; вне снимка),
LARGE_BATCH_TUNING.json — артефакт исходного исследования (`LARGE_BATCH_TUNING.json`; вне снимка). Повторяющиеся синтетические

## Решение по применимости

**Модель новая, воспроизводимая и конечная; E15/BIP32 и SXM-03 её не исключают.**
Есть основание сохранить её как кандидата для отдельного поиска. Однако на
текущей реализации цена составляет около 5,5 суток GPU, а связи автора с этой
приватной цепочкой не установлено. Автоматически такой проход не запускается.
Следующий вычислительный шаг — снижение цены либо отдельно выделенный полный
проход именно четырёх X-only схем с durable checkpoints и независимой проверкой
кандидатов №1–50. XY-вариант не добавляется без нового исторического основания.

**Покрытие настоящего Puzzle: 0.** Реальные ключи/holdout не использовались;
новых ключей или битов не получено. Результат этого этапа — точная модель,
проверенная история, принятые контроли и измеренная цена, не исключение гипотезы.
DECISION.json — артефакт исходного исследования (`DECISION.json`; вне снимка).
