# Уточнение детерминантной оценки SEQ-17

Это описательный разбор уже сохранённых структурных результатов, выполненный
после фиксации выбора q=4. Он не меняет научную очередь и не является новой
попыткой восстановления. Для q=3 в SEQ-17 выполнялась только структурная
подготовка; численной LLL и извлечения корней для троек в плане нет.

Пусть каждая центрированная переменная-разность ограничена |u_i| ≤ 2^H.
Для равномерных усиленных контролей h20/h24 значение H совпадает с 20/24.
При исходных неравных масках границы разностей различаются, и заменить
их единым числом скрытых битов нельзя.

Сохранённая оценка логарифма геометрического среднего, делённого на n²:

    g_q(H) = (e_q/d_q − 2) log2(n) + H D_q/d_q,

где d — размер, e — показатель индекса n, D — сумма степеней мономов.
Правило выбора максимизировало точку пересечения g_q(H)=0: для q=3
получено 18,046997, для q=4 — 18,063505. По этому заранее заданному
правилу выбран q=4. Разность составляет около 0,0165 бита.

Однако наклоны этих прямых различны. В точке H=24 уже сохранённые
значения g_3=26,131805 и g_4=26,615114: геометрическое среднее для
четвёрки хуже примерно на 0,4833 бита, а размер больше в 569/349 ≈ 1,6304
раза. Прямые пересекаются около H=18,837502. При округлении log2(n) до
256 это число точно равно 116736/6197.

Поэтому преимущество четвёрки по выбранному порогу не означает преимущество
по средней длине при фактическом H=24 и тем более по времени LLL. Результаты
по коротким строкам или восстановлению троек из этого не следуют: средняя
длина не определяет минимальную длину, число независимых строгих отношений
или успех решателя. Сравнение q=3 с q=4 по восстановлению осталось отдельным
непроведённым численным испытанием.
