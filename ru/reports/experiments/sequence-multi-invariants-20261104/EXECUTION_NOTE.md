# Исполнение и границы SEQ-17

Структурная стадия построила все десять зарегистрированных блоков без LLL.
Размеры для q=1,2,3,4: 88,194,349,569. Индексные степени n равны
159,334,590,958. На усиленном h24 пересечения средней длины по
определителю с n² составили около 12,876;16,879;18,047;18,064 бит.
Это не предел восстановления: прежний двухинвариантный метод уже
восстанавливал h20, несмотря на меньшее значение такого показателя.
Правило отбора зарегистрировано до вычислений и выбрало q=4.

Символьный API cuso вызван отдельно на общих кубиках в координатах
D_i=a_i+b_i*u_i, с общей параметрической границей n^delta, k_pre=1
и без дополнительных t-сдвигов. Для q=2 получено delta=79/619.
Это асимптотическое семейство больших степеней, а не оценка именно
конечной матрицы n². Условия обратимости коэффициентов проверены
отдельно; q=3,4 закончились MemoryError при 4 GiB. Одномерный контроль
воспроизвёл известную границу 1/2. Эти исходы не исключают корни.

HNF-контроли: 24 непустых модуля. Старый module_basis не
обрабатывает список полностью нулевых строк: V2-контроль сохраняет
12 таких отказов отдельно. Научные строки имеют ненулевой ведущий
коэффициент 1 или n. Сопоставление с принятыми одно- и двухкубическими
конструкциями подтвердило равенство целочисленных решёток; для q=2
совпадает сам базис. При первом импорте аудитору понадобился пустой
совместимый модуль experiment; старые аудиторы не редактировались.

Первая Windows-очередь запускала venv-загрузчик. Его handle позволял
наблюдать только память загрузчика. При попытке добавить Job Object
проверка кодов завершения сперва неверно предполагала ненулевой код
принудительно завершённого теста. Исправленная проверка подтвердила
немедленное завершение 30-секундного теста с кодом 0. Затем присоединение
одного из существующих потомков получило Windows error 5; его PID не
записан, поэтому точный тип потомка не утверждается. Закрытие job при
выходе guard прервало первый научный расчёт. Координатор успел начать
следующие блоки; все его собственные процессы остановлены по проверенным
командным строкам и их отсутствие сверено перед повтором.

Принятых LLL в прерванной очереди нет. Исходные worker_error,
preparation_unavailable, матрицы и heartbeat сохранены. Завершённые
интервалы времени и резерв последнего незаконченного блока учтены в
SCIENCE_PLAN_V2.json. Суффикс positive_h24_general_retry обозначает
побайтный повтор прежнего blind-пакета, а не новую выборку.

Действующая очередь запускает scientific worker напрямую через тот же
CPython 3.11.9. Контроль подтвердил загрузку тех же vendor/flint и
vendor/sympy. Проверка дерева увидела вычислительный код непосредственно
в PID, которым управляет координатор; дочернего Python нет. Console host
не выполняет научного расчёта. Математический worker, выбор q и параметры
LLL не менялись. Таймер Windows perf_counter, опрос памяти раз в 2 с:
8 GiB private bytes на процесс или менее 2 GiB свободной физической
памяти останавливают попытку. Поле peak_private_bytes — максимум
наблюдавшихся значений при опросе, без заявления точного пика между отсчётами.

Смена контроллера записана отдельными манифестами. Исходный план,
неуспешные guards и их код сохранены. Неудачи инфраструктуры не
участвуют как отрицательные математические ответы в парном сравнении.
