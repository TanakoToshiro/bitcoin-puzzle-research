# SEQ-17 — три и четыре совместных инварианта

Начато 04.11.2026 по поручению пользователя. Проверяется расширение
совместной n²-конструкции SEQ-12/14. Все методы получают одинаковые восемь
наблюдений 100,105,...,135 и одинаковые остальные маски из 83 наблюдений.
Семь центрированных разностей дают четыре перекрывающиеся кубики.

Раздельный метод объединяет строгие уравнения четырёх отдельных кубик.
Парный метод объединяет уравнения трёх перекрывающихся пар. Новый метод
объединяет две тройки либо одну четвёрку. Во всех случаях используется
один неизменённый решатель SEQ-10 в семи переменных и полный декодер цепи.
Увеличение числа раскрытых наблюдений относительно SEQ-14 отмечается явно;
победа засчитывается только относительно сравнений на тех же восьми точках.

Для блока из q инвариантов M — объединённый носитель кубик, константа и
линейные мономы; S=M+M. Генераторы: все Gi*Gj, n*u^beta*Gi (beta∈M),
n²*u^alpha (alpha∈S). Точное модульное исключение с аннуляторами из SEQ-12
не меняется. LLL .99/.51, один проход, все строгие L1<n² строки.
Сравнение разных блоков использует тот же алгоритм и параметры редукции.

Сначала выполняется структурная стадия без LLL: размеры, точный индекс
решётки, масштабы каждой переменной и детерминантная оценка при q=1..4.
Её вывод эвристический: средняя длина по определителю не определяет
минимальную длину и не доказывает отсутствие HG-отношений. Отдельно
испытывается символьный API cuso на q=2..4 с фиксированным бюджетом;
он тоже не даёт общего отрицательного доказательства. Исходные неравные
маски оцениваются структурно на положительном синтетическом контроле.
Настоящие ключи в научные входы не входят.

Фиксированные blind-входы до выбора конструкции: оба семейства h24,
один general h20 как положительная калибровка, один случайный h24.
Seed: 17102400,17102401,17102000,17102499 соответственно. Ещё два
синтетических входа с исходными масками (17100000,17100001) используются
только для структурной оценки. Truth хранится отдельно и не передаётся
процессам построения, редукции или решения.

После структурной стадии выбор q∈{3,4} фиксируется до первой LLL:
среди успешно построенных конструкций размером не более 768 выбирается
наибольшая оценка допустимых равномерных битов по определителю, при
равенстве — меньший размер. Если обе подготовки ограничены, выбор q=3
фиксируется как диагностический, без заявления благоприятной оценки.
Все три метода q=1,2,selected запускаются на четырёх blind-входах.
Пакет, порядок и бюджеты конкретных блоков сохраняются в SCIENCE_PLAN.json.

Бюджеты: структурная подготовка до 300 с на блок; символьная оценка до
180 с на q; отдельная LLL до 600 с для q≤2 и до 1800 с для нового q;
алгебра до 180 с на метод/вход. Один вычислительный процесс, общий
научный бюджет 14400 с. Достижение лимита сохраняется как неизвестный
исход. Входные матрицы, готовые редукции и алгебра сохраняются до аудита.
Истина не влияет на выбор q, сдвигов, строк или порядка попыток.

Независимый аудит заново раскрывает кубики и генераторы, проверяет оба
включения целочисленных решёток, T*B=L, det(T)=±1, строгие нормы и
алгебраические сертификаты. Для каждого кандидата проверяются исходные
кубики, точные границы, 135 состояний и 83 маски; истина используется
только после решения. Малая арифметика сверяется с независимой HNF.
Успех — новый полный восстановленный класс на h24 относительно обоих
сравнений. При лимите сравнения превосходство над ним не объявляется.

Принятые 8062 прежних файла сохраняются по SHA-256 и mtime. Изменения
кода до запуска отражаются манифестом; изменения после запуска требуют
отдельной версии, без переписывания прежних результатов.
