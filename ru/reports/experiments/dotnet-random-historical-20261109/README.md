# DN-R01 — исторический System.Random

Сначала [FINAL_REPORT.md](<FINAL_REPORT.md>), [PROTOCOL.md](<PROTOCOL.md>),
[RESULTS.md](<RESULTS.md>). COMPLETE означает завершение подготовительного
эксперимента. **Реальный seed-поиск выполнен только на 3×2^18 значениях.**

Исторический источник и метаданные — `sources/`; служебно адаптированная
сборка — `build/`; Python — `reference.py`; независимое C#-ядро — `Worker.cs`.
Изолированный криптографический эталон `crypto_ref.py` скопирован без изменений.
Версии, команды компиляции и хэши записаны в BUILD/ENVIRONMENT/MANIFEST.
GPU и облако не использовались, новые Python-зависимости не устанавливались.

33 синтетических случая — `synthetic/`; закрытые для worker истины обозначены
`TRUTH_CHECKER_ONLY.json`. Worker получает только events.tsv, границы и имя
выходного файла. EVENTS содержат только train ≤50. Holdout проверяет Python
после train-совпадения. Реальные пилоты — `pilot/0..2`, каждый со своим диапазоном
и звеном хэш-цепочки. `NUMERIC_REPORT.json` и CSV построены из сохранённых данных.

Первоначальный цикл запускается `lab.py`; после запечатывания не запускать его
в этой папке для сохранения журнала. Полный поиск вынесен в `full_scan.py`,
который не вызывается автоматически и пишет только в новую серию.

Для следующего полного прохода, **команда подготовлена, но ещё не выполнена**:

> Исполняемый код/команды опущены в документационной копии.


Команда работает из этой папки. По умолчанию диапазон [0,2147483648), блок
262144, одна CPU-очередь, все16 схем. Уже проверенные три пилотных диапазона
импортируются с проверкой хэшей и нового звена цепочки; повторного worker нет.
При прерывании повторить **ту же команду**: готовые блоки только проверяются,
последний незавершённый блок рассчитывается заново. Ошибка процесса не
записывается как отсутствие кандидатов. При train-кандидате очередь
останавливается; Python сохраняет проверку holdout для независимого разбора.

OS byte-range lock защищает от двух одновременных runner. PROCESS.json хранит
PID и время, но один факт наличия файла не считается активной блокировкой.
CONFIG запрещает незаметную смену кода/данных/диапазонов. Окончательный
COMPLETE будущего прохода требует дополнительного независимого аудита
покрытия и цепочки; наличие файла не заменяет этот аудит.

Испытания runner находятся в соседней папке
`../dotnet-random-runner-controls-20261109`; ссылки и хэши —
`reviews/RUNNER_ARTIFACTS.json`. Это малые технические тесты, не второй
полноценный поиск. Исправления при приёмке — `reviews/NOTES.md`.

`reviews/finalize.py` пересобирает отчёт и таблицы из JSON без повторного
поиска и обновляет подпись. Новый независимый аудит проводить отдельно,
сохраняя прежний COMPLETE и результаты. Общий журнал дополнен записью DN-R01.
