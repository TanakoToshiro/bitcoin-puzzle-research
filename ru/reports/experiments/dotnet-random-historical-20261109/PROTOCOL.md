# DN-R01 — исторический System.Random

9 ноября 2026, Europe/Moscow. Реализация, синтетическое восстановление и
пилот стоимости. Связь автора Puzzle с C# не установлена.

Источник: Microsoft Reference Source, random.cs, commit
9da503f9ef21e8d1f2905c78d4e3e5cbb3d6f85a от 2014-11-12. Сохранить оригинал,
метаданные загрузки и SHA-256. Не считать современный .NET историческим
эталоном; он используется только дополнительным контролем. Исторический
исходник компилируется отдельно с документированными служебными заменами.

Фиксируются 16 схем: API NextBytes / 32 раза Next(256); unsigned big/little
endian 32 байта; stride 1/2 исходных блоков; phase 0/1 начальных блоков.
Нулевая позиция raw-блока для puzzle i: phase+stride*(i-1). Один экземпляр
генератора на всю серию, ровно 32 вызова InternalSample на raw-блок.
key_i=2^(i-1)+(raw_i mod 2^(i-1)). Число i не сжимается при пропусках.
Это 16 конкретных допущений, а не исторически подтверждённые экспорты.

Обучение: известные задачи 1–50. Holdout: остальные опубликованные решения
из неизменённого снимка 83 ключей. Все решения проверяются coincurve и
независимой арифметикой secp256k1 до реального пилота. При противоречии стоп.
Holdout не передавать сканеру. После train-совпадения Python воспроизводит
всю последовательность и проверяет holdout. Реальный кандидат — стоп для
независимой проверки; не объявлять найденный ключ только по фильтру.

Python-реализация использует точную unchecked Int32-арифметику. Независимый
C#-сканер имеет собственный код и переиспользует массив. Сравнить их с
компилированным историческим источником: 8704 последовательных выходов
на граничных и детерминированных случайных seed, оба API. Проверить
signed-seed aliases, Int32.MinValue, двойную арифметику Next(256), split
NextBytes, продолжение состояния, отрицательные контроли.

Синтетика: все 16 схем, два seed на схему (малый и из верхней половины
31-битного домена), правильные 83 маски и пропуски. Восстановить seed в
4096-элементном окне вокруг каждого случая. Диапазон известен алгоритму;
это ограниченное восстановление, НЕ доказательство глобальной уникальности
на всём 2^31. Дополнительно один поиск на 2^20 seed для схемы NextBytes/big/
stride1/phase0. Truth-файл читает только проверяющий код. Оценить полный
домен отдельно. Все train-совпадения проверяются полным holdout.

До настоящих данных: сравнить полный набор ответов C# и Python на малом
диапазоне 256 seed; тесты отрицательного входа, обеих границ, сохранения и
возобновления checkpoint. C# обязан проверять каждый маскированный байт,
в том числе неполный последний; ранний фильтр не заменяет train-проверку.

Реальный пилот после контролей: 3 непересекающихся диапазона по 2^18 seed:
[0,2^18), [2^30,2^30+2^18), [2^31-2^18,2^31).
Один seed обрабатывается сразу для 16 схем с общей последовательностью
InternalSample. Сохранить время, число внутренних вызовов и кандидатов,
пики памяти процесса. Измеренный прогноз полного прохода — оценка CPU,
не обещание времени GPU. Полный проход 2^31 в этот цикл НЕ входит.
Ошибки/тайм-ауты не считать исключением гипотезы.

Новая папка изолирована. Checkpoint содержит диапазон, входные и кодовые
хэши и цепочку предыдущих блоков. Готовые блоки не повторять. Числовой
отчёт строить из JSON; сохранить RESULTS.md после каждого этапа. Не менять
старые snapshots и проекты. CPU локально, без облака и новых зависимостей.
