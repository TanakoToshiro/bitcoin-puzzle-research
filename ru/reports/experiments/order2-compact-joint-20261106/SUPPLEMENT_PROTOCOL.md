# O2-C01-S1 — устранение общего сдвига

6 ноября 2026. Протокол дополнения зафиксирован после завершения основной серии,
до получения результатов дополнения. Основная серия: 8/8 полных контролей,
0/12 завершённых частичных поисков; два запуска нашли допустимое семейство.

Проверить только запись coefficients на тех же четырёх полных контролях и
шести частичных входах. Лимиты, ветви, восстановление и проверка всех 83 масок
сохраняются. Скрытые состояния, EXPECTED и коэффициенты алгоритму не передавать.
EXPECTED читает только проверяющая обвязка после завершения поиска.

Вместо свободного T выбрать наименьший допустимый общий сдвиг для каждой
относительной последовательности x135=0. Это сохраняет множество классов,
а не множество отдельных SMT-свидетелей. Полный проектор по-прежнему возвращает
все допустимые сдвиги и значения цели, а не только выбранный минимальный T.

Пусть маска якоря 135 равна (K,R), L=2^K, T=R+qL.
Для каждой положительной ширины k<=K допустимы два остатка x_i по 2^k:
(r_i-R) и (r_i-R+p). При нечётном p они различны и определяют перенос eps_i.
При eps_i=1 требуется q>=ceil((p-x_i-R)/L).
При eps_i=0 требуется q<=floor((p-1-x_i-R)/L).
Выбрать q_min=max(0,всех нижних границ); проверить верхние границы и T<p.
Никакого перечисления q или троек старших частей.

Реализация адаптером в reviews/, без изменения принятого ядра. Удаляются
только ограничения, содержащие T; их число проверяется. Все прочие ограничения
ядра сохраняются. Отдельная идентичность фиксирует код адаптера и протокол.

До основных запросов: 700 детерминированных малых контролей формулы минимального
сдвига против независимого перебора всех T, включая совместимые/несовместимые
маски и нулевые ширины. Затем четыре полных контроля. При их провале частичные
входы не запускать. UNKNOWN не считать исключением или ограничением ключа.

Результаты дополнения хранить отдельно; сравнение с исходной записью только
описательное: единственный запуск на вход, без статистического доказательства
преимущества. Время и память фиксировать из статистики решателя.
