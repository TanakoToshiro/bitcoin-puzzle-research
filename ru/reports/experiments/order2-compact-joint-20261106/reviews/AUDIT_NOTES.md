# Замечания при аудите

Первый запуск audit.py остановился на Z3 `from_file`: `file access error`
для пути Windows с кириллицей. Это ошибка загрузки сохранённого SMT в
проверяющем коде, не результат решателя и не изменение вычислительного ядра.
Исправлено чтением UTF-8 средствами Python и `from_string`. Содержимое SMT
и его SHA-256 сохранены. Аудит повторяется после исправления.

На следующем запуске контроль с подставленными состояниями p257/interval
получил UNKNOWN за 10 с при ещё неизвестных A/B/C. Для проверки корректности
кодировки в проверяющем коде дополнительно подставлены вычисленные коэффициенты,
разности и минимальный сдвиг. Это полная подстановка свидетеля, явно **не**
слепое восстановление. Основные результаты и тайм-ауты не изменены.
