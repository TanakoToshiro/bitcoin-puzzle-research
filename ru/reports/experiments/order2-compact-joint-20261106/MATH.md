# Компактная система: область точности

Работа ведётся над простым полем F_p, p>=7, b!=0, gcd(5,p(p²−1))=1.
Для реального порядка secp256k1 это условие выполнено. Гипотезы с b=0,
другими модулями, отображениями или историей генерации сюда не добавляются.

Положим y_j=s_(5j), x_j=y_j−s135 modulo p. Сетка начинается с первого
информативного кратного 5, но не позже 75. Остальные наблюдения проверяются
после восстановления полного шага; номера не сжимаются.

## Ранг вместо неизвестных коэффициентов

Разности d_j=x_(j+1)−x_j obey d_(j+2)=A d_(j+1)+B d_j.
Для пяти последовательных разностей a,b,c,d,e:

```
a*c*e + 2*b*c*d − a*d*d − b*b*e − c*c*c = 0 (mod p).
```

Это определитель матрицы Ганкеля [a b c; b c d; c d e]. На последнем
окне из четырёх разностей требуем D=d1²−d0*d2!=0 и K=d1*d3−d2²!=0.
Тогда A=(d2*d1−d0*d3)/D, B=K/D!=0 однозначны; C находится из одного
перехода x. Каждый предыдущий кубический определитель линеен по новому
левому элементу, его коэффициент K не равен нулю. Поэтому левое продолжение
единственно и совпадает с обратной рекурсией. При сдвиге окна
D_next=−B*D_previous; вырождения по пути не возникают.

Без условий D,K это доказательство не действует. Нельзя выдавать одни
локальные кубические равенства за полное описание всех рекурсий.

Вторая запись непосредственно задаёт общие A,B,C и B!=0. На общей
невырожденной ветви она задаёт то же множество, что и rank.

## Вырожденные ветви

Если разности ненулевые и d_j*d_(j+2)=d_(j+1)², их отношения постоянны,
а x следует аффинной рекурсии первого порядка. Ненулевыми должны быть все
разности; одного последнего не хватает для такой эквивалентности.
Случай всех нулевых разностей обрабатывает отдельная constant-ветвь.
Для обратимой рекурсии второго порядка иных вырожденных ветвей нет:
определитель соседних пар разностей переносится множителем −B; при нуле
везде и ненулевой последовательности это первая степень.

Семейство первого порядка r,d представляет p−1 наборов второго порядка:
a!=r, b=r(r−a), c0=(r+1−a)d. Постоянная последовательность представляет
p(p−1) наборов. Эти семейства не сводятся произвольно к одному коэффициенту.

## Возврат к исходному шагу

Матрица аффинного шага 5 обратима. Показатель E=p(p²−1) кратен порядкам
элементов используемой аффинной группы в размерности 2. При gcd(5,E)=1
G=H^(5^−1 mod E) — единственный пятый корень. Координаты H здесь
(x_(i+5),x_i), а не (x_(i+1),x_i). Из G восстанавливаются 135 состояний
и параметры обычной рекурсии; они проверяются прямым исполнением.
Первая степень использует показатель p(p−1). Ранее доказанные условия
и независимые проверки корня находятся в O2-L01; матрицы заново не строятся.

## Точное устранение T

При x135=0 маска якоря задаёт T=R+q*L, L=2^K. Для положительного k<=K:

```
x_i mod 2^k = (r_i−R+eps_i*p) mod 2^k.
```

p нечётно, поэтому два остатка различны. Перенос eps_i определяется
самим x_i. eps=1 требует x_i+T>=p, eps=0 требует x_i+T<=p−1.
Это соответственно нижняя и верхняя целочисленные границы q. Прибавляются
0<=q<=floor((p−1−R)/L). Пересечение — интервал; если непусто, его минимум
даёт канонический SMT-свидетель. Отбрасывание остальных T не отбрасывает
ни одного класса относительных состояний.

Здесь требуется максимальная маска именно на якоре 135. Нулевые k не
накладывают переноса. При вычислении верхней границы сначала проверяется
x_i<=p−1−R, чтобы unsigned-underflow не создавал ложную совместимость.
Полный проектор затем заново возвращает **все** сдвиги, совместимые со всеми
83 наблюдениями; минимальный сдвиг сетки 5 сам по себе не обязан им подходить.

## Границы результата

SAT проверяется прямым исполнением, всеми наблюдениями и независимым
перечислением сдвигов на малых данных. Для полноты требуется UNSAT обеих
символических ветвей после блокировки каждой найденной четверки/пары.
UNKNOWN не даёт верхней оценки оставшегося множества. Даже если все
найденные до тайм-аута модели предсказывают один бит, этого недостаточно.

Отсутствие внешнего перебора троек не означает полиномиального алгоритма:
битовый SAT-поиск остаётся потенциально экспоненциальным. Из времени на
малых полях здесь не выводится срок полноразмерного восстановления.
