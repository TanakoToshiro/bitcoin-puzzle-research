# E11: исторические пути подписания

Проверяем только опубликованные решения и принятые подписи/sighash E5. Восстановление неизвестных ключей не входит в эксперимент. Основная группа — 15 известных ключей раскрытия2019; остальные известные подписи рассматриваются как группа разных решателей, не как подписи создателя. Для2015/2017 нет известных приватных ключей входов: доступны лишь свойства формы подписей и транзакций.

До сравнения зафиксированы: стандартный RFC6979 SHA256 + low-S; тот же путь без low-S; raw-digest nonce вместо bits2octets; Core0.17 low-R с дополнительным32-байтным little-endian счётчиком; исторические исходники Electrum1.9.8/2.9.3/3.3.4, Core0.9.3/0.10.0/0.16.3/0.17.0, bitcoinjs1.5.7/2.3.0 и pybitcointools до раскрытия. Ошибка загрузки/адаптации не считается несовпадением. Порты функций называются портами, не запуском старого кошелька.

Контроли: независимая Python арифметика кривой и coincurve, точный DER, неправильный digest, digest>=n для различения raw/reduced, low-R retry. Проверить совпадения r и s отдельно. Одинаковые реализации объединяются в класс эквивалентности, без вероятностного ранжирования брендов. Не переносить signer2019 на generator2015.

При отсутствии различающего результата — дополнительный ограниченный поиск на других сайтах, с фиксацией запросов, первоисточников и границ. Не изменять E5/E10.
