# SEQ-12 — два перекрывающихся инварианта

План: [PROTOCOL.md](<PROTOCOL.md>). Итог: [FINAL_REPORT.md](<FINAL_REPORT.md>).
Два отдельных базиса по 88 измерений сравниваются с общей решёткой
произведений на одинаковых шести состояниях. Алгебра SEQ-10 неизменна.

Из корня проекта в PowerShell:

> Исполняемый код/команды опущены в документационной копии.


Сначала проверка целостности. Завершённые стадии и таймауты не повторяются;
JOURNAL.jsonl дописывается. Новый бюджет требует новой попытки.

- experiment.py, PROTOCOL.md, MANIFEST.json: фиксированные данные и лимиты.
- joint_solver.py: генераторы, точный базис modulo n², LLL, раздельный метод.
- inputs/: все 12 входов, созданные до первого научного запуска.
- constructions/, lattices/: исходные конструкции, базисы и преобразования.
- algebra/, algebra_checkpoints/: законченная алгебра и доступные преобразования.
- results/, progress/: статусы, бюджеты, хэши и последняя сохранённая стадия.
- ARITHMETIC.json, audit.py, AUDIT.json: независимые сертификаты и проверки.
- MEASUREMENTS.json, COMPARISON.json: все измерения и парные результаты.
- RETRY_INDEX.json: только незавершённые исходы SEQ-12; исторический индекс в SEQ-11.
- INTERRUPTION.json, interruptions/, continuation.py: сохранённая оборванная
  попытка и продолжение после внешнего прерывания. Её точное время неизвестно;
  полный лимит 120 с отдельно зарезервирован в первоначальном бюджете.
- REAL.json: структурный расчёт, без поиска настоящих ключей.
- PROVENANCE.json, PRIOR_SNAPSHOT.json, ENVIRONMENT.json: происхождение и целостность.
- RESUME_CHECK.json, ACCEPTANCE.json, COMPLETE.json, ARTIFACTS.json: приёмка.

Интерпретация: timeout — неизвестный исход в бюджете;
no_certified_equations — метод не получил достаточных строгих уравнений;
unit_ideal — сертификат противоречия конкретному входу/границам.
Успешные контроли относятся к синтетическим классам с общим сдвигом.

Один вычислительный CPU-процесс, существующие Python 3.11.9,
python-flint 0.9.0 и SymPy 1.14.0. Без GPU и установок.
Общий научный бюджет 1800 с; аудит до 180 с на вход отдельно.
