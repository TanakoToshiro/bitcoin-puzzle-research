# RNG64-GPU-01

Точный GPU-поиск кандидатов x для десяти синтетических входов RNG64-05. Состояние
у первого полного выхода: (x,z−x modulo 2^64). Две реализации второго слова:
арифметическая и явная сеть переносов. Маски/переходы прежние.

Требуется 64-битный Python и установленный OpenCL GPU-драйвер. GPU и CLI используют
только стандартную библиотеку Python. Для CPU-бенчмарка дополнительно NumPy/Numba.
На этой машине использован Python 3.11.9 из
`[USER_HOME]\AppData\Local\Programs\Python\Python311\python.exe`.
Системные пакеты/драйверы не менялись. GPU выбирается среди OpenCL GPU, с приоритетом NVIDIA.

Для сети переносов: `--mode carries`. Числа допускают `0x`-формат. Концы диапазона
не зацикливаются modulo 2^64. Максимальный batch — 2^26. `--seconds` ограничивает
новые батчи; полностью законченные интервалы сохраняются до выхода. Повтор
с теми же параметрами читает завершённые chunks, сохраняя их mtime и содержимое.
Идентичность закрепляет исходный вход, GPU source и host code; несовпадение отвергается.
RUN.lock защищён блокировкой ОС. При переполнении буфера кандидатов batch не
засчитывается; нужно повторить его меньшими порциями в отдельном запуске.

`interval_complete` означает только завершение указанного диапазона. Ни один
контроль со специально выбранным диапазоном не даёт допуска к реальным данным.
CLI этой версии работает с synthetic INPUT, реального режима нет.

Файлы: [протокол](<PROTOCOL.md>), контроли — артефакт исходного исследования (`CONTROLS.json`; вне снимка),
бенчмарк — артефакт исходного исследования (`BENCHMARK.json`; вне снимка), [итог](<FINAL_REPORT.md>). Генерируемые kernels/ содержат
точный OpenCL C и build logs; `SOURCE_SNAPSHOT.json` проверяет сохранность RNG64-05.

Справочник API: [OpenCL 1.2 specification](https://registry.khronos.org/OpenCL/specs/opencl-1.2.pdf).
Скорость и допустимые выводы основаны на сохранённых локальных измерениях.
