# O2-L01 — поздние подъёмы и обращение шага5

6 ноября 2026. Новая серия после O2-S01/O2-Q01. Старые опыты не пересчитывать и не изменять.

Гипотеза: исходная аффинная рекурсия второго порядка modulo простого p, b!=0. Точная факторизация общего сдвига относительно s135, затем перебор четырёх канонических разностей x115,x120,x125,x130, где x_i=(s_i−s135) mod p, x135=0. Каждая наблюдаемая маска задаёт два возможных остатка x_i: (r_i−r135) mod2^k_i и (r_i−r135+p) mod2^k_i. После восстановления цепочки окончательная совместимость всех масок проверяется независимым интервальным проектором O2-Q01.

Пять полных значений на сетке115..135 позволяют исключить три коэффициента прореженной аффинной рекурсии, если определитель разностей ненулевой. Для p>=7 с gcd(5,p*(p²−1))=1 матрица прореженной рекурсии имеет единственный корень пятой степени в соответствующей аффинной группе; он восстанавливается степенью e=5^(-1) mod p*(p²−1). Представление матрицы — в координатах (x_(i+5),x_i,1), а не ошибочная подмена обычной companion-матрицей исходного шага. Коэффициенты исходного шага берутся из следа и определителя линейной части корня; состояния воспроизводятся по второму компоненту.

Случаи нулевого определителя НЕ отвергать как отрицательные. При указанном условии на p порядок не теряется при прореживании5. Их покрывает отдельный полный поиск аффинных последовательностей первого порядка r!=0 (p*(p−1) вариантов относительно x135=0) плюс постоянные цепочки. Коэффициенты второго порядка для них хранить семействами; для сравнения старых малых входов раскрывать семейства в полный набор пятёрок.

Контроли до поиска: обращение пятого шага на 33 прежних 256-битных generic-свидетельствах; добавочные Jordan/constant/первого порядка; полная проверка всех обратимых аффинных2×2-переходов modulo7 на корень и малый alias-контроль modulo11, который алгоритм должен явно отклонить как неподдерживаемый. Полностью перечислять GL2×translations modulo7 допустимо, это98784 перехода.

Сравнение: все18 старых входов p7/p17 O2-Q01 (all/late/full), полные множества пятёрок и прогнозов. Модули11/31/61 не имеют нужного gcd; для них метод не заявляется, восстановление всех корней не реализовывать в этом опыте.

Новые синтетические примеры p=37,67,127,257,523, по два; seed-правило SHA256('O2-L01|p|case|attempt|field'), невырожденные, прежние83 номера/маски, truth не передавать solver. Все предикторы/параметры заданы до просмотра результата. Блок65536 подъёмов, до60с на этап поиска generic и60с на поиск первого порядка на вход. Предел по домену: свыше10миллионов подъёмов — только оценка стоимости, не запуск. Модуль65537 и настоящий n — только расчёт числа кандидатов/стоимости без поиска. При превышении бюджета сохранять checkpoint/UNKNOWN, не выдавать частичный список за полный.

Каждый SAT-кандидат перепроверяется обычной исходной рекурсией, проекция всех сдвигов — отдельным кодом. Результаты на новых синтетических входах должны включать скрытый истинный класс/прогноз; это проверяет включение, но не само по себе полноту. Полнота метода обосновывается разбиением generic/первый порядок/constant и подтверждается точным старым эталоном.
