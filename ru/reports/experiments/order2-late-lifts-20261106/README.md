# O2-L01

Сначала прочитать FINAL_REPORT.md, MATH.md, PROTOCOL.md и SUPPLEMENT_PROTOCOL.md. Работа только в этой папке; старые опыты читаются по хэшам.

Из текущей папки:

> Исполняемый код/команды опущены в документационной копии.


run.py проверяет математику, готовые старые входы и фиксированные новые синтетические входы. solver.py получает только INPUT, не читает CHECKER_TRUTH/EXPECTED. Старые18 входов сравниваются с сохранёнными полными множествами; новые — с truth только после поиска. Все83 наблюдения используются как ограничения, отдельного holdout в этом опыте нет.

search/PROFILE.json — точный домен, IDENTITY.json — вход и код. generic/ и first_order/ имеют отдельные блоки65536, SHA-256-цепочки, непрерывные диапазоны, счётчики и время. Готовые блоки не вычисляются заново. INPUT/код поменялись — отказ, нужен новый каталог. Для продолжения конкретного незавершённого входа:

> Исполняемый код/команды опущены в документационной копии.


Одна копия runner на каталог. Незавершённый статус не доказывает полноты прогнозов. Бюджет60с на очередную попытку каждой ветви, остановка на границе блока. Домен свыше10миллионов подъёмов не запускается. Нет автоматического бесконечного продолжения. Полноразмерные256-битные контроли восстанавливают цепочку из ДАННЫХ полных пяти значений; это проверка реконструкции, не слепой поиск реальных состояний.

Аудит и пересборка отчёта:

> Исполняемый код/команды опущены в документационной копии.


finalize.py использует сохранённые числа и обновляет отчёт/хэши, не повторяя поиск. RESULTS.md сохраняет предыдущие записи. Полные исходные пятёрки больших семей сохранились сжатым представлением; тип generic/first_order/constant и прогрессии сдвигов раскрывают их точно. Список прогнозов — объединение всех семейств.
