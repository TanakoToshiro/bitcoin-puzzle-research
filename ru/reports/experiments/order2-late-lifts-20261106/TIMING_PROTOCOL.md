# O2-L01-T — согласование измерения времени

После парной проверки видно, что tracemalloc существенно влияет на Python-реконструкцию корней (p127). Поэтому нельзя выдавать отношение базового NumPy-перебора с tracemalloc к исходному запуску нового алгоритма без него за чистое ускорение.

Ровно два дополнительных измерения нового алгоритма: p37-new0 и p67-new0, одинаковые INPUT с уже завершёнными comparison_baseline. Новый каталог comparison_measured; tracemalloc включён, как в baseline. Это намеренное контрольное повторение ради сопоставимой инструментированной оценки, не обычное продолжение рабочего опыта и не перенастройка модели. Старые результаты не менять. В отчёте отдельно показать wall и время вычислений блоков, memory tracked != RSS. Завершённые измерения повторно не исполнять.
