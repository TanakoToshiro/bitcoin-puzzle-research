# O2-L01-P — парное сравнение после основной серии

Основная серия завершена:18 старых входов совпали полностью,10 новых положительных восстановлены,65537 остановлен оценкой стоимости до поиска. Код алгоритма не меняется.

Для прямого сравнения с O2-S01 используем ровно четыре его INPUT: p127-new0/1 и p257-new0/1. Они ранее дали UNKNOWN с обеими SMT-кодировками. Новый solver получает только неизменённый INPUT, без truth. Каждый запуск измеряется tracemalloc (включая NumPy), файлы в paired_cases. Это уже существовавшие контрольные входы, не дополнительная независимая оценка вероятности модели.

Для сравнения с полным перечислением классов запускаем неизменённый quotient_solver.py из O2-Q01 на двух новых входах этой серии: p37-new0 и p67-new0. Лимит60с, блок8192, новые checkpoint-каталоги comparison_baseline. Сравнить точные полные множества при завершении обоих методов. При таймауте не экстраполировать полное время как замер и не считать сравнение завершённым.

Также сохранить аналитическую оценку числа четырёх подъёмов для настоящего n по уже проверенной таблице83 решений: без перечисления кандидатов. Это оценка стоимости условной модели, не проверка реальной рекурсии и не предсказание ключа.
