## Данные и продолжение

- `SOURCES.json`, `cache/`: URL, время, статус, SHA-256 и исходные сетевые ответы; HTTP 200 не означает самостоятельный или достоверный источник.
- `CANDIDATES.json`: валидные точки и контекст каждого вхождения; `CANDIDATE_TESTS.json`: проверка только новых точек.
- `root256-result.json`: обе корневые точки, 48 моделей, синтетические контроли, первые противоречия.
- Внешние входы E7: `../seed-inversion-electrum-20261030/runs/20261030-124911-1a7e70/inputs/known_solutions.json`, `inputs/high-points.json`, `electrum.json`.
- Внешний вход E6H: `../high-points-xor-20261030/runs/20261030-122003-bb9bb8/real-points.json`.
- `MANIFEST.json`: хеши локальных артефактов на момент завершения. Хеши внешних входов включены в научные JSON.

Для новых источников/отображений создать новую ревизию/папку; сохранить этот снимок. `fetch` намеренно не обновляет старые URL. Не удалять кэш ради повторной попытки — новую попытку оформить отдельным снимком. Исполняемый код со сторонних сайтов не запускался.
