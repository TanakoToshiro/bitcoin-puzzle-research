# ARM-IMP-01 — версии и варианты импорта Armory

05.11.2026, Europe/Moscow. Ограниченное продолжение A1/A1-R2; без повторного поиска неизвестного root и без GPU.

Срезы до 15.01.2015: v0.88-beta, v0.90-beta, v0.91.1, v0.92, v0.92.3, commit 61a596fa94f9cacf9fb00c4e02d0eb65d8b17513 от 08.01.2015. Теги, commit/date, архивы и SHA256 сохраняются. Два прежних среза проверяются по предыдущим pins. Остальные версии автоматически не считаются проверенными.

Сначала сравниваются генерация root/chaincode, C++-переходы, utility parsers, импорт, списки и GUI-экспорт. Затем выбранные Python-методы исполняются без перевода на Python3, на CPython2.7.9 Windows amd64 и Linux64. Настоящие PyQt4, SWIG/C++, файловый wallet, шифрование, сетевые операции не запускаются: оболочки заменены явно обозначенными адаптерами. Примеры исключительно синтетические. CSPRNG заменён детерминированными байтами только при трассировке числа запросов; качество RNG таким тестом не измеряется.

Матрица: 16 parser-входов на версию; raw/uppercase/WIF/checksum/mini, исправление одного байта и reverse, неверные/compressed/нулевые/предельные входы. Три маршрута создания с supplied root/C или отсутствующими параметрами. Две вставки и повторный импорт; chainIndex=-2 и root неизменность. Четыре фильтра адресного списка, sorted helper и три варианта реального GUI writer на контролируемом порядке записей, включая chained запись после импортов.

Независимая Python3-проверка вычисляет ожидаемые ключи, WIF, chaincode и публичные адреса. Уточнения по paper/SecurePrint/fragments/watch-only/sweep, которые прослежены только статически, должны быть отделены от исполненных операций. Отсутствие артефакта автора не заменяется искусственным chaincode или публичной точкой masked ключа. Массовый перебор не запускается без конечной обоснованной модели.
