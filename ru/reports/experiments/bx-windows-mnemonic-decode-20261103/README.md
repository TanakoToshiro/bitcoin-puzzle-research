# BMD-01: официальный Windows decoder

**Эффект подтверждён настоящим BX2.0.0 Windows x64.** Новая конечная область
поиска специфицирована, её bounded CPU reference прошёл synthetic controls.
Полный поиск и GPU-пилот не запускались.

- [Итог](<RESULTS.md>), [поисковая постановка](<SEARCH_SPEC.md>), [протокол](<PROTOCOL.md>).
- 216 бинарных случаев — артефакт исходного исследования (`BINARY_CONTROLS.json`; вне снимка), 180 HD children — артефакт исходного исследования (`HD_TRACES.json`; вне снимка),
  20+20 worker filters — артефакт исходного исследования (`BLOCK_CONTROLS.json`; вне снимка), итоговая проверка — артефакт исходного исследования (`COMPLETE.json`; вне снимка).
- Первичные источники и происхождение EXE — артефакт исходного исследования (`SOURCES.json`; вне снимка), [журнал](<JOURNAL.md>).
