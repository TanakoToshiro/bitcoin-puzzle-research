# O2-P01 — исключение полиномами

Основные документы: [FINAL_REPORT.md](<FINAL_REPORT.md>), [PROTOCOL.md](<PROTOCOL.md>),
[MATH.md](<MATH.md>), [RESULTS.md](<RESULTS.md>). Числа генерируются из JSON в CSV.

Код `poly.py` — собственная точная арифметика F_p[w]; `elimination.py` —
исключение в фактор-кольце и контроль оставшегося общего сдвига.
Перенесённые вспомогательные файлы сохранены побайтно относительно O2-N01.
Python и NumPy зафиксированы в MANIFEST.json. GPU, облако, сеть и новые
зависимости не использовались.

Всё вычисление закрыто. Артефакты каждого входа:
`cases/<имя>/INPUT.json`, `EXPECTED.json`, `elimination/` и `baseline/`.
Пилот — первый блок основной цепочки, повторно не вычислялся.
Результаты памяти находятся отдельно в `benchmark/`.

Команды из этой папки (новый запуск проводить в копии, сохраняя архив):

> Исполняемый код/команды опущены в документационной копии.


Точечное продолжение незавершённого поиска использует `elimination.run` с
тем же INPUT и каталогом: он сверяет код/входы и пропускает завершённые
блоки. В текущей серии все случаи завершены. Для нового бюджета/протокола
нужно создавать новую серию, не заменять выводы этого опыта.

`reviews/finalize.py` пересобирает таблицы и отчёт без повторного поиска и
обновляет COMPLETE. `reviews/audit.py` создаёт аудит и тест продолжения;
новый независимый аудит следует проводить в копии, сохраняя прежнюю подпись.

Проверка существующей подписи, только чтение:

> Исполняемый код/команды опущены в документационной копии.

контекста повторять не требуется. Общий журнал пополнен отдельной записью O2-P01.
