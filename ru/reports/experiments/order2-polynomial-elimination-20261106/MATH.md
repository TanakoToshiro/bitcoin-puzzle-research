# Полиномиальное исключение: что доказано и что оно стоит

Сохраняются условия предыдущих опытов: простое поле, b!=0, обратимый
пятый шаг, младшие биты без принудительного старшего бита. Общий сдвиг
отсчитывается от состояния 135. Номера наблюдений не сжимаются.

## Параметризация без предыдущих высоких частей

Пусть w=x115, u=x120, v=x125, t=x130, x135=0. При фиксированных u,v,t:

```
c=v-u, d=t-v, e=-t
K=c*e-d*d
D(w)=c*c-(u-w)*d
AN(w)=d*c-(u-w)*e
CN(w)=v*D(w)-u*AN(w)-K*w
```

На общей ветви K!=0 и D(w)!=0. Коэффициенты грубой рекурсии:
A=AN/D, B=K/D, C=CN/D. Следовательно,

```
x_(i-5) = [D(w)*x_(i+5) - AN(w)*x_i - CN(w)] / K.
```

После выбора трёх опор деление идёт на константу K, поэтому все предыдущие
значения — полиномы от w: степени 2,3,4,... . Эти высокие части не перебираются
независимо и не вводятся как SMT-переменные. При K=0 общая ветвь отсутствует;
первый порядок и постоянные последовательности обрабатываются отдельно.

## Точное конечное множество как полином

Префикс даёт интервал T=s135 на прогрессии R+q*2^Kmask. Из маски 115 и
этого интервала получаем конечное множество W. Полином

```
H(w)=prod_(a in W)(w-a)
```

квадратсвободен и раскладывается над F_p. Удаляем gcd(H,D), тем самым
исключая все вырожденные w без потери общей ветви.

Для предыдущего наблюдения i множество S_i содержит все значения x_i,
которые допускают хотя бы один сдвиг из **начального** интервала префикса.
Пусть P_i(w) — выведенный полином. Тогда условие P_i(w) in S_i равносильно

```
Q_i(P_i(w))=0, Q_i(z)=prod_(a in S_i)(z-a).
H_new=gcd(H,Q_i(P_i)).
```

Корни H_new — ровно пересечение двух конечных множеств. Это верно также
при постоянном P_i, нулевом остатке Q_i(P_i), пустых множествах и повторных
корнях Q_i(P_i). НОД берётся нормированным. Все вычисления можно проводить
по модулю H; после уменьшения H ранее вычисленные состояния сокращаются
по новому модулю. Это не эвристическое ограничение степени: H_new делит H.

При степени H=1 корень извлекается сразу и передаётся прежней точной
проверке оставшихся масок. Для степени больше 1 после конца сетки корни
извлекаются просмотром исходного W. Эта работа учитывается; факторизация
или извлечение корней не считаются бесплатными.

Отдельные i могут иметь различные допустимые T. Поэтому пересечение через
НОД — необходимое отсечение, а не доказательство существования общего
сдвига. После него joint.evaluate пересекает интервалы для всей сетки;
затем обычное исполнение и точный проектор проверяют все 83 наблюдения.

## Почему это не устраняет главную размерность

Три опорных значения u,v,t по-прежнему перечисляются. Для исходных масок
число совместимых с общим сдвигом префиксов около 2^398 (точный подсчёт
O2-N01 сохранён и проверяется, не вычисляется перебором). Новый НОД не
объясняет, как исключить сами три опоры совместно.

Кроме того, плотный полином H имеет размер, равный числу кандидатов W.
Для любого непустого интервала префикса можно выбрать один допустимый T.
Отображение s115 -> (s115-T) mod n биективно, поэтому W содержит как минимум
все s115 с опубликованной 114-битной маской: приблизительно 2^142 элементов.
После удаления линейного D исчезает не больше одного. Таким образом,
плотная запись H требует порядка 2^142 коэффициентов, примерно 2^147 байт
даже при идеальных 32 байтах на коэффициент без служебных расходов.
Это ограничение **исследуемой плотной записи**, не нижняя оценка сложности
любого алгоритма для рекурсии. Компактное произведение арифметической
прогрессии само по себе не даёт столь же компактного НОД композиции.

Для учебных модулей степень мала. Здесь можно честно проверить корректность
и измерить, окупается ли замена скалярного перебора полиномиальными операциями.
Даже успешное исключение всех зависимых состояний ещё не даёт применимого
256-битного восстановления. Проверенные варианты модулей и преобразования
масок перечислены в протоколе; остальные гипотезы не затрагиваются.
