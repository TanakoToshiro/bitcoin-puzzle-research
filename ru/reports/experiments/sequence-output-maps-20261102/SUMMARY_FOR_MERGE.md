# SEQ-05 — 02.11.2026

Проверены три функции вывода скрытой аффинной цепочки modulo n:
старшие b бит, младшие b после разворота256 бит, младшие b после
разворота32 байтов. Для последнего частичный байт проверяется точно
через объединения интервалов, хотя решётка использует полные байты.

По24/24 новых полноразмерных положительных контролей на map (72/72),
по0/64 совместимых нулевых результатов (0/192). На настоящих данных
кандидатов нет во всех трёх случаях:156 полиномов,936 gcd-пар, общих
делителей положительной степени нет. Эвристический отрицательный
результат, не доказательство невозможности модели. Реальных ключей,
битов или сокращения диапазона не получено.

Независимо проверены1116 решёток,87 048 gcd-пар, точные интервалы
и сериализация, изоляция нижних наблюдений. Все334 старых файла
и seals неизменны. Итог: FINAL_REPORT.md.
