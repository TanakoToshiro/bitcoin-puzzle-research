Завершённые научные стадии пропускаются. Перед повтором проверить seal.
Для полного пересчёта/изменения кода использовать отдельную копию
с новыми результатами. `setup` и `audit` записывают файлы; не запускать
их поверх принятого seal. Обычная проверка — `verify.py`, только чтение.

`engine.py` — maps, решётки отношений, новая решётка состояния,
точные интервалы и проекции. `helpers.py` — неизменённая копия helper
из SEQ-04; используются N, affine_coefficients, babai. Источник и SHA
сохранены в `HELPER_SOURCE.json`; старые drivers не запускаются.

В `fits` поля `babai_state`/`babai_increment` — первоначальное
предложение, не обязательно допустимый представитель. Приёмка
относится к непустым `state_family`/`all_family`. Полные множества
условны на найденные a,d, не на все возможные параметры генератора.

`controls/{kind}` и `replication/{kind}` содержат синтетическую истину,
наблюдения, все матрицы, полиномы и интервалы. `null/{kind}` — нулевые
реплики, `degenerate/{kind}` — границы метода. `REAL.json` содержит
три реальные проверки без найденных кандидатов.

`MANIFEST.json` фиксирует код/протокол/данные до реального расчёта.
`ARTIFACTS.json` — итоговый seal, журнал исключён из immutable.
`PROJECTION_COVERAGE.json` различает2393 завершённые малые проекции
и7 случаев лимита; исходное поле `projection_checks=2400` означает
число попыток. Полноразмерные положительные проекции завершены все.

Python3.11 и NumPy из прежней `.venv`; SymPy/FLINT из существующего
`child-derivation-audit-20261102/vendor`. Запись bytecode отключена;
установок библиотек и GPU-расчётов нет. Настоящий неизвестный ключ
или бит в этой серии не получен.
