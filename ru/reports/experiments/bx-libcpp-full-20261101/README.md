# E9e — полный BX/libc++ проход

Разрешён пользователем: «Внеси изменения в gpu код прошлой проверки и запусти поиск». Проверяется minstd_rand с множителем **48271**, не прежний GNU16807. Состояния1..2147483646; 16 прежних схем. GPU-фильтр №50 и CPU-verifier из отдельной принятой версии `../bx-libcpp-search-20261101` используют одинаковую новую гипотезу.

Текущее состояние: [RESULTS.md](<RESULTS.md>), STATUS.json — артефакт исходного исследования (`STATUS.json`; вне снимка), stdout.log/stderr.log. После окончания появляется COMPLETE.json. Готовые блоки по1048576 состояний связаны хэшами; всего2048, последний1048574. Candidate или ошибка останавливают проход и сохраняются. RUN.lock предотвращает параллельный запуск этого задания.
