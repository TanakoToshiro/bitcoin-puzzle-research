Флаг `--full-prior` дополнительно перепроверяет старый архив и зависимости. Обычный `verify` проверяет новый seal, замороженные входы/код и пять использованных источников; полный архив уже проверен при принятии результата.

`setup`, `run`, `audit`, `seal` — однократные команды создания артефактов, не команды просмотра. Существующий каталог не пересоздавать. Для воспроизведения расчёта нужна отдельная копия кода и новый выходной каталог; оригинальные артефакты сохраняются.

`TRUTH.json` содержит параметры и полные синтетические состояния. `blind/` содержит только ID и 83 маскированных наблюдения; `worker.py` читает только этот интерфейс и использует 13 последних индексов. `outputs/` — четыре матрицы, преобразования и метрики каждого завершённого случая. `logs/` — статусы и время всех попыток. `RESULTS.json` — заранее заданные пороги, результаты проверки чувствительности и решение о допуске к реальным данным. `AUDIT.json` и `METRICS_AUDIT.json` — проверки арифметики и независимого подсчёта метрик. Дополнительный аудитор и поясняющие документы создавались после фиксации протокола; научный worker и критерии не менялись.
