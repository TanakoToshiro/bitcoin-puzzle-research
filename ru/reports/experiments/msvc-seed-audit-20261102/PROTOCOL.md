# MSVC-01 — исторический Windows BX/SX

02.11.2026. Проверить незакрытый MSVC-вариант без вмешательства в текущие SX/GPU-процессы.

1. Закрепить официальные исходники, старую документацию Microsoft, build-файлы и метаданные релизов до 15.01.2015. Даты commit, release и загрузки asset различать. Не приписывать современный STL старому бинарнику.
2. Установить engine, разрядность входного seed, число обращений random_device, распределение байтов. Проверить, существует ли короткий полный домен; качество random_device само по себе не устраняет сужение при передаче одного слова в engine.
3. Если модель подтверждена, реализовать отдельный CPU-эталон и сравнить с независимым MT19937. По возможности проверить официальный бинарник статически или эмуляцией выделенного вычислительного участка, не запускать загруженную программу целиком.
4. Проверить ранний SX и готовый BX раздельно: Windows-поддержка, uniform uint8/uint16, shift и %255 не объединяются без доказательства эквивалентности. Не распространять модель BX на ранние сборки.
5. Только после подтверждения конечного домена — ограниченные синтетические контроли, измерение CPU, постановка отдельного поиска с training/holdout. Полный GPU-проход и аренду в этом аудите не запускать. Частичные проверки не называть исключением семейства.

Сохранять SOURCES с URL/UTC/SHA-256 и ошибками, код, промежуточные выводы JOURNAL, машинные результаты и итог RESULTS. Старые принятые артефакты не изменять. Неподтверждённые исторические участки явно оставлять открытыми.
