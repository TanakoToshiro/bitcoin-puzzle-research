# Пары публичных признаков подписей и половина диапазона

11 ноября 2026 года. На 73 ключах порог в обеих схемах прошли 0 из шести тестов с поправкой на шесть и 0 из шести с поправкой на 78. Расчёт занял 4,5 секунды.

## Методика

Для каждой пары используются две медианы одного ключа по всем его подписям. Каждый признак разбит на четыре прежние равные корзины. Первый тест сравнивает совпадение половин двух признаков с меткой верхней половины диапазона ключа. Статистика двусторонняя и использует абсолютное отклонение числа согласований от 73/2. Второй тест сравнивает совместные распределения в 16 комбинациях четвертей. В таблице Пирсона 2×16 номер столбца равен 4a+b для четвертей a и b от 0 до 3. Нулевое распределение получено из подписанных контролей, поэтому редкие клетки учитываются по эмпирическому распределению.

Сохранённые контроли используют 208 подписей на 73 ключах с исходными шаблонами операций, происхождением подписей и алгоритмами подписания. Для 33 январских подписей с неизвестным рецептом в генерации использован равномерный суррогат nonce. Схемы включают полные диапазоны и сохранение четверти каждого ключа. В каждой схеме используется 2 047 корпусов для min-P. Основная поправка охватывает шесть новых тестов. Расширенная включает 72 прежних и шесть новых. План — артефакт исходного исследования (`PLAN.json`; вне снимка) · Происхождение подписей — артефакт исходного исследования (`../key-range-position-folded-s-pooled-20261111/runs/main/PROVENANCE.json`; вне снимка).

## Синтетика

Целые истории подписей отбираются из банка для того же ключа и четверти. При связи по половинам вес увеличивается за согласие ключевой метки с равенством половин пары. В случае чередования четвертей используется равенство чётности номеров четвертей. Параметры 60% и 70% задают вес отбора. Для каждого условия выполнено по 256 повторов на схему. Отбор сохраняет историю одного ключа, а совместный контекст разных ключей в транзакции может меняться.
