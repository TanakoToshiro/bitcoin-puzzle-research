# E12 GPU: историческая цепочка SX, конечный протокол

Источник: ../sx-historical-20261101/GPU_HANDOFF.md; E12 COMPLETE проверен по 457 файлам.
Цель — исключение или подтверждение восьми точных схем, не атрибуция автора.

На каждый RNG GNU a=16807 и LLVM a=48271: нормализованные состояния [1,2147483647),
32 принятых байта, master m. После перехода x=state−1; отвергнуть x>=2147483392.
GNU byte=x//8388607, LLVM byte=x&255. Ни %255, ни фиксированные 32 перехода.
Схемы 0..3: final i−1, i, 0x80000000+i−1, 0x80000000+i.
Прежняя маска: принудительный бит i−1 и младшие i−1 бит. Никаких дополнительных родителей.

GPU сравнивает младшие 49 бит №50. CPU исторический libwallet проверяет все №1–50;
holdout №51+ используется только после полного совпадения обучения. Любой настоящий
кандидат сохраняется и останавливает серию для независимой affine/адресной проверки.
Ошибка invalid BIP32 или переполнение кандидатов не означает отрицательный результат.

Приёмка: entropy/draws всех 1173 исторических случаев, master/chain/public/дети,
точные HMAC payloads, перенесённые EC/SHA/HMAC контрольные значения, все восемь
положительных и отрицательных моделей, отбраковка RNG, границы, overflow и fault builds.
Отдельно проверяется runner: CPU-имитация остановки, продолжения, ошибки, кандидата,
повреждения блока, конкурентной блокировки; затем короткий GPU stop/resume обоих RNG.
Три пилота по 1048576 состояний на RNG. Основная скорость — внешняя API wall,
отдельно сохраняются CUDA events и суммарное время обвязки. Пилоты перекрывают поиск
и не прибавляются к его покрытию.

Полный проход: два последовательных RNG, 2048 блоков на каждый; первые 2047 по
1048576 состояний, последний 1048574. Конфигурация и входы фиксируются до первого
блока. Блоки содержат SHA-256 содержимого и цепочку prev_hash; законченные блоки
не перезаписываются. При возобновлении все уже существующие блоки проверяются.
Независимый audit.py не запускает GPU и не меняет checkpoints. Кандидат/ошибка/
неполное покрытие запрещают COMPLETE. Старые результаты и checkpoints только читаются.

setup.py — первоначальный перенос, не средство перезаписи принятой серии. Последующие
изменения CUDA fault injection, CPU include path и runner отражены в принятых исходниках;
точное воспроизведение: сохранённые исходники + build.sh, а не повторный setup.py.
Сборка sm_86, локальная RTX 3070 Ti Laptop GPU, WSL Ubuntu-24.04. Облако не используется.
