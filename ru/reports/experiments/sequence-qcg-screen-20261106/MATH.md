# SEQ-22: вывод условий и точный смысл препятствий

## Наблюдения

n — простой порядок secp256k1; s[i]∈[0,n). Проверяется модель s[i+1]=a*s[i]²+b*s[i]+c mod n, a≠0, с тем же порядком экспорта, что в прежних SEQ. Известны r[i]=s[i] mod q[i], q[i]=2^(i−1), для №1..70 и №75..135 с шагом 5. Старший принудительный бит Puzzle не наблюдает s[i].

В 83 масках суммарно 3767 бит; модель задают четыре полевых параметра a,b,c,s[1], то есть менее 1024 бит. Этот подсчёт **не доказывает** независимость наблюдений или однозначность восстановления. Он также не даёт основания объявлять глобальную модель недоопределённой только из-за отдельных коротких окон. Проверки ниже относятся к конкретным конструкциям.

## Исключение коэффициентов без деления

Четыре перехода квадратичного полинома дают линейную зависимость столбцов матрицы со строками [1,s[j],s[j]²,s[j+1]], j=t..t+3. Её определитель равен нулю по n. Общий сдвиг пяти состояний не меняет определитель: это элементарные операции над столбцами с единичным определителем. Поэтому можно положить первое состояние равным нулю и записать остальные через D[j]=s[j+1]−s[j].

Непосредственное раскрытие определителя даёт его отрицание:

```text
G(D0,D1,D2,D3) =
 (D0*D2−D1²)*D2*(D1+D2)
 − (D1*D3−D2²)*D0*(D0+D1).
```

Это необходимое условие, включая нулевые разности. Достаточность не заявляется: вырожденные данные и линейный переход a=0 тоже могут обращать G в нуль. Одно локальное условие само по себе не устанавливает общие коэффициенты всей цепочки.

Пусть s[i]=r[i]+q[i]*u[i]. Тогда

```text
T[i] = D[i]/q[i] mod n,
Y[i] = (r[i+1]−r[i])/q[i] mod n,
e[i] = 2*u[i+1]−u[i],
T[i] = Y[i]+e[i] mod n.
```

Из 0≤s<n следует |e[i]|≤floor((n−1)/q[i])<n/q[i]<2^(257−i). Здесь отрицательные e допустимы. Вводим R[i]=2^(257−i); межоконные e — общие переменные. Точные допустимые e связаны также существованием u и ограничениями состояний; независимый box является ослаблением.

Подстановка D[t+j]=q[t]*2^j*T[t+j] даёт G(D)=16*q[t]^4*Q(T). Полином Q:

```text
−T0²*T1*T3 + T0²*T2² − 2*T0*T1²*T3
+4*T0*T1*T2² + 4*T0*T2³ − 2*T1³*T2 − 4*T1²*T2².
```

Для каждого t=1..66 строится P_t(e)=Q(Y+e) mod n. Это условия степени 4 по четырём относительным ошибкам, а не степень 32. Независимый аудит выводит Q из определителя SymPy, раскрывает P символически, а значения на полных синтетических цепочках проверяет через целочисленный определитель FLINT.

## Отдельный идеал и строгий HG-L1

Используется доказательство SEQ-16, копии которого находятся в `reference/`. Для I=(n,P), фиксированных положительных границ R и допустимого мономиального порядка: если ведущий коэффициент P обратим по n, а вес ведущего монома M, W(M)=∏R[i]^M[i], не меньше n, то любой ненулевой H∈I^m удовлетворяет

```text
||H(R*X)||_1 ≥ n^m,  m≥1.
```

Следовательно, строгий критерий ||H(R*X)||_1<n^m, превращающий модульный нуль в целый нуль на всём box, получить внутри этих степеней идеала нельзя. Это **достаточный критерий**, его недоступность не исключает ни корни, ни иные способы получить целые уравнения.

Краткая основа доказательства: нормируем P по модулю n до монического F с тем же ведущим мономом; (n,F)=(n,P). Моническое деление даёт единственное разложение H=ΣA_k*F^k с носителями A_k вне кратных M. Для H∈(n,F)^m коэффициенты A_k делятся на n^max(0,m−k). Ведущие мономы различных A_k*F^k не совпадают: степень кратности M однозначно определяет k. Ведущий член H поэтому имеет вес хотя бы n^max(0,m−k)*W(M)^k≥n^m. Остальные веса не меньше 1. Это нижняя граница уже для одного слагаемого взвешенной L1-нормы.

В любом допустимом порядке ведущий моном P максимален по делимости. У Q(Y+e) таких мономов ровно семь, все степени 4, с коэффициентами ±1,±2,±4. Коэффициенты обратимы по n, перевод между целочисленными идеалами проверяется в обе стороны. Значит барьер действует для любого допустимого порядка.

Для лучшего соседнего окна №66..70 границы ошибок — 2^191,2^190,2^189,2^188, а веса семи максимальных мономов — от 2^758 до 2^760, намного больше n<2^256. Более ранние окна слабее. Уменьшение потолка R до точного floor((n−1)/q)+1 не даёт существенного выигрыша; **сохранённые сертификаты формально относятся к указанным степенным R**, без утверждения о других box/сдвигах.

Итог не переносится на совместный идеал (n,P_1,…,P_66), дополнительные зависимости между e, другой экспорт или критерий. Не запускать LLL отдельного идеала после сертификата — следствие доказанной границы этой конструкции, не таймаут.

## Совместная линеаризация: что именно закрыто

Берём объединённый структурный носитель всех P_t, включая постоянный моном: 1332 координаты для 69 переменных e. Нулевые коэффициенты конкретного входа не удаляют структурную координату. Линеаризация заменяет каждый моном e^α независимой переменной z_α. У каждой из 66 строк есть уникальный моном e[t]²*e[t+1]*e[t+3] с коэффициентом −1. В других строках его нет: его крайние индексы определяют всё окно. Поэтому ранг матрицы A по n точно равен 66 для любых наблюдений.

Обозначим B_α=∏R[i]^α[i], K=max B_α=2^1020, W_α=K/B_α. Рассматривается **однородная решётка ядра**

```text
L = { diag(W)*z : z∈Z^1332, A*z=0 mod n }.
det(L) = n^66 * 2^458633.
```

Детерминант следует из сюръективности отображения A:Z^1332→F_n^66 и последующего диагонального масштабирования. Для настоящего мономиального вектора z_0=1, поэтому его постоянная координата равна K, а евклидова норма ≥K. Но для координаты с B_α=K вектор n*unit_α лежит в L и имеет норму n<K. Найдено 1263 линейно независимых координатных свидетеля n*W_α*unit_α с нормой <K.

Таким образом, **истинный мономиальный вектор не является кратчайшим в этой решётке**. Посторонние свидетели имеют постоянную координату 0 и нарушают мономиальные зависимости. Они не принадлежат аффинному срезу z_0=1. Доказательство не исключает CVP/поиск на этом срезе, другое вложение, полезность других строк редуцированного базиса или совместное нелинейное исключение. Значение `log2_encoded_lower_bound_minus_geomean` — только описательная величина, не дополнительный сертификат или p-value.

Этот пункт не выполняет прежнее пожелание пользователя учитывать мономиальные зависимости при решении: здесь явно проверяется ограниченность их снятия. Нелинейный решатель для QCG в SEQ-22 не реализован и не запускался.

## Пять шагов и ложная свобода степени 32

Для f(X)=aX²+bX+c, a≠0, степени f,f²,…,f⁵ равны 2,4,8,16,32; два старших коэффициента f⁵:

```text
[X^32] f^5 = a^31,
[X^31] f^5 = 16*a^30*b.
```

Здесь f^5 означает композицию, не обычную степень. Пять исходных переходов эквивалентно представляются четырьмя промежуточными скрытыми состояниями и пятью квадратичными уравнениями: степень 32 не обязательна при сохранении промежуточных переменных, но число неизвестных возрастает. Обе постановки сохраняют только три общих коэффициента a,b,c; свободных 33 коэффициентов у настоящей композиции нет.

На 13 поздних наблюдениях №75..135 допустимы lifts x_j=r_j (все скрытые старшие биты равны нулю). Для различных 12 входных узлов интерполяция H степени ≤11 удовлетворяет H(x_j)=x_(j+1). Полином

```text
P32(X)=H(X)+X^20*∏(X−x_j), j=0..11,
```

имеет степень 32 и удовлетворяет тем же 12 переходам. Он построен для реальных данных и всех 64 контролей. Это **не восстановленные состояния или коэффициенты QCG**, а допустимое решение ослабленной модели с произвольным полиномом.

Дополнительно показано, что каждое из этих 65 конкретных P32 не является пятой итерацией никакого квадратичного полинома. Для настоящего f центр h=−b/(2a); f(X+h) чётен, значит f⁵(X+h) тоже чётен. Для любого полинома степени 32 возможный центр однозначен: h=−[X^31]P/(32*[X^32]P). У построенных P32 после этого сдвига остаются ненулевые нечётные коэффициенты. Это необходимый тест композиции, не достаточная классификация всех композиций.

Наконец, y=a*s+b/2 переводит QCG в y_next=y²+C, C=a*c+b/2−b²/4. Тождество проверено на 32 контролях. Неизвестное аффинное преобразование по n не сохраняет известные младшие биты, поэтому нормальная форма сама по себе не переносит алгоритм для известных старших приближений на нашу задачу.

## Уровень вывода

Все арифметические тождества проверены на полных состояниях синтетики. Полные состояния являются **oracle для аудита формул**, а не входом восстановления. Чувствительность скрытого детектора не измерялась; ни 32 успешных тождества, ни 32 нулевых контроля не являются результатом обнаружения связи по одним маскам. На Puzzle не решалась задача существования QCG: модель остаётся открытой.
