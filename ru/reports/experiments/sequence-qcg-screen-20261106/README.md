## Файлы

- `INPUTS.json`, `known_solutions.json`: реальные маски и 32 QCG + 32 независимых случайных контроля; полные состояния синтетики сохранены только для аудита.
- `screens/*.json`: 65 полных записей, в каждой 66 полиномов, ведущие сертификаты и демонстрационный полином степени 32; у синтетики также проверки истинных ошибок.
- `GEOMETRY.json`: каталог 1332 мономов, ранг, веса и явный более короткий посторонний вектор.
- `mathcore.py`, `experiment.py`: формулы и одноразовые стадии `setup`, `run`, `seal`; `audit.py`: независимые SymPy/FLINT проверки и сохранность прежнего архива.
- `RESULTS.json`, `AUDIT.json`: численные итоги и аудит. `finish_report.py` формирует текст по сохранённым итогам, не повторяя научный расчёт.
- `MANIFEST.json`: фиксация до запуска; `ARTIFACTS.json`: итоговый список SHA-256, включая отчёты; `COMPLETE.json`: завершение только указанного объёма.
- `reference/`: неизменённые копии двух ранее доказанных утверждений об отдельном идеале; происхождение фиксирует `SOURCES.json`.

Для воспроизведения расчёта нужен отдельный новый каталог и новая фиксация до запуска. Не запускать `setup/run/audit/seal` поверх этого завершённого каталога.
