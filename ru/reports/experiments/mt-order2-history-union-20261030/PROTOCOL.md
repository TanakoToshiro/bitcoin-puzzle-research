# E1h — новые истории order2, цели 73/78/79/99/133

2026-10-30. Предварительный протокол. База: E1d/E1e geometric-b, d=65 по каждой из пяти целей. Альтернативы объединяются, не пересекаются.

До 16 новых историй до draw №135, SHA-256(`E1h-order2-history-{trial}-{call}`), число младших единиц задаёт число отказов. Это детерминированный конечный набор, не вероятностная оценка историй. Модель исторического Python 2.7.9: randrange(1,n), getrandbits(257), stride=1, после draw маскирование и установка старшего бита. Прежние достаточные guards: отклонённое значение имеет бит256=1; принятое биты256=255=0. Такие guards сужают, но не расширяют допустимые исполнения.

Новые матрицы допускаются только для НОВЫХ историй. Старые завершённые матрицы не пересчитываются. Перед каждым подбором по 83 ключам — синтетическая проверка guards/числовой последовательности и исторического Python. Все координаты целей pre_increment. Известные данные — прежние 83 решения, без повторной загрузки.

Для первого нового совместимого пространства с полной свободой пяти целей: получить случайно выбранного свидетеля с фиксированной публичной меткой воспроизводимости, продолжить его исполнение до №256, добавить достаточные точные comparison-cell guards будущих принятий/отклонений. Добавить raw256[254]=0: тогда реальный ключ256 <=2^255+2^254<n, включая перенос +1. Это дополнительное достаточное ограничение, не наблюдение. Если после этого пять проекций полны, остановиться: одной допустимой подсемьи достаточно доказать полное объединение. Если нет — перейти к следующей истории.

Для успешной ветви сохранить все проекционные сертификаты и конструктивные состояния для базиса каждой цели. Проверить обычное исполнение и CPython 2.7.9, неизменность всех 83 решений, истории и скалярной границы. Никакого восстановления seed и поиска адреса. Все результаты относятся к выбранной API-модели; истинность её происхождения не утверждается. Полное покрытие историй не требуется для контрпримера обязательности ограничения и не заявляется.

Результаты каждой законченной истории сохраняются отдельно с хэшами и пропускаются при resume. При исчерпании 16 вариантов — явный ограниченный результат, без объявления невозможности других историй.
