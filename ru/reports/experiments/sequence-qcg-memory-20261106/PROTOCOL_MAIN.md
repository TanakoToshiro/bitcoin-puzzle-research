# SEQ-25: зафиксированное сравнение шести входов

Пилот C показал 185 МиБ выборочного пика за минуту для исходной формулы при ff.preprocess=false, против 305 МиБ для Boolean-подстановки B. Основная мера — только параметр ff.preprocess=false. Существующие исходные маски, модуль, коэффициенты, состояния, квадраты и все утверждения берутся из неизменённого encoding_seq23.py. Уменьшение алгебраических лимитов и отключение BV fallback не применяются.

Перед основной серией десять малых эталонов дополнительно решаются с этим параметром. Требуются правильные SAT/UNSAT и проверка всех полученных кандидатов независимой целочисленной арифметикой. Ранее завершённые 20 тестов двух представлений и восемь закрытых подстановок сохраняются.

Для full00..full05 запускаются пары original и no_preprocess, строго по одному процессу. В обоих вариантах: check 120000 мс, max_memory=2048 МиБ, мягкая внешняя граница 2 GiB с Context.interrupt, аварийная 2.5 GiB/5 с после прерывания, внешний таймаут 150 с. Порядок внутри пары чередуется (original первым на чётных номерах). Это одинаковый разрешённый бюджет, но фактическая длительность может отличаться из-за памяти. Нельзя трактовать отношения пиков как сравнение памяти при одинаковом выполненном объёме поиска.

Сохраняются память ОС, фазы, статистики и причины unknown. Пик сообщается отдельно как максимум выборок private/working и как максимальный доступный high-water из счётчиков ОС; единицы MiB=2^20 байт. Валидационные/пилотные/основные результаты не объединяются для статистической независимости. Шесть входов уже изучались, выбор оптимизации адаптивен. Восстановление означает только независимо проверенный SAT-кандидат, отсутствие такого ответа — вычислительная незавершённость. Нулевое число BV fallback за 120 с не обещает его отсутствия при более долгом поиске.

Для полноты причинного анализа сохраняются оба пилота: Boolean-подстановка и исходная формула с ff.preprocess=false. Если все шесть двухминутных проверок ограничены временем, серия завершает проверку памяти в этом бюджете, не объявляет восстановление или опровержение квадратичной модели.
