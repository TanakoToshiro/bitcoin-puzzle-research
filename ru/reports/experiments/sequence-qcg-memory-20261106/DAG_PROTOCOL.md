# Уточнение структуры, после основной очереди

Для объяснения 268 устранённых определений один раз инспектируется full00 до и после ff-unique/ff-simplify. Считаются уникальные узлы DAG, оставшиеся свободные переменные и синтаксическая верхняя степень по s1: константы/прочие переменные — 0, s1 — 1, умножение — сумма, сложение/булевы связки — максимум. Мономы не разворачиваются. Это описание формы, не независимое алгебраическое восстановление и не оценка числа живых байтов.

Проверка выполняется только после завершения основной очереди, в отдельном процессе с мягкой границей 2 GiB, аварийной 2.5 GiB и внешним временем 90 с. Ограничения и выбранный вариант основной серии от её исхода не зависят. Цель — различить сохранение множества коротких локальных уравнений и подстановку промежуточной цепочки в наблюдения.
