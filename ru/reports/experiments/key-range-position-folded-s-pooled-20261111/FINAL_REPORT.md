# Объединённая проверка нормализованного s

11 ноября 2026 года. Из двух тестов на 73 ключах порог прошли 0 с поправкой на два и 0 с поправкой на 58. Расчёт занял 331,0 секунды.

## Данные и контроль

Величина 2·min(s,n−s)/n вычислена для каждой из 208 подписей. Затем взята одна медиана по всем подписям каждого ключа, включая операции раскрытия 2019 года. У 15 ключей подписи из нескольких исторических групп. После объединения медиана сменила корзину у 8 ключей относительно медианы подписей расходов.

Сначала воспроизведены 5374 полных подписанных корпусов. Во всех совпали 28 прежних признаков и четверти ключей. Для каждого ключа сохранены число и происхождение подписей, шаблоны транзакций, алгоритмы подписания и классы high-S или low-S. Для 33 январских подписей с неизвестным рецептом используется прежний равномерный суррогат nonce. Происхождение подписей по ключам — артефакт исходного исследования (`runs/main/PROVENANCE.json`; вне снимка).

Схемы контроля используют полные диапазоны или сохраняют четверть каждого ключа. В каждой схеме 2 047 нулевых корпусов задают общую поправку min-P. Основная поправка охватывает два новых теста. Расширенная охватывает 56 прежних и два новых. Один и тот же тест должен иметь скорректированное p≤0,05 в обеих схемах. План — артефакт исходного исследования (`PLAN.json`; вне снимка) · Фиксация — артефакт исходного исследования (`FROZEN.json`; вне снимка).
