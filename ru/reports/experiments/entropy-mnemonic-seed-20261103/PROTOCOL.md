# EMS-01 — исторический допуск прежде вычислений

03.11.2026. Область: только публичная Puzzle и заданный handoff. Полный поиск
не поручен. Этот документ записан до синтетических контролей; реальный поиск
не выполнялся. Отрицательные ответы HTTP сохранены и не доказывают отсутствие кода.

## Исторический gate

Точное дерево BX 2.0.0 содержит mnemonic-encode/decode, использующие старый
Electrum codec; обе команды содержат TODO перехода на BIP39. Код зависимости
libbitcoin version2 на 13.12.2014 найден. Маршрут BIP39/PBKDF2 не принят.
SCHEMES.json содержит пустой accepted_search_schemes. Список E15 сохраняется
только как справочная копия, без нового search run ID.

Следствие: GPU-реализация, приёмка search buffers/checkpoints, 3–5 пилотных
блоков и оценка полного прохода не применяются до принятия исторической цепочки.
Не измерять современную композицию под именем BX 2.0.0. Bitcoinj из предыдущего
аудита автоматически не подставлять. Нулевая измеренная скорость не заявляется:
скорость/стоимость нового BIP39-поиска остаётся null (не измерялась).

## Синтетические контроли исторического кодека

1. Проверить SHA-256 источников и Git blob SHA-1 против полных tree JSON.
   Скопировать E15 MT reference и исторические RNG vectors с pin происхождения.
   Проверить прежние manifest/readback, но не выполнять прежние вычисления.
2. Независимо реализовать Python-кодек по формуле 3 слов на 32-битный BE chunk.
   Сверить с неизменённым mnemonic.cpp libbitcoin через минимальные C++ shims
   типов, assert и byte→hex. Современная компиляция не равна запуску релизного PE.
   Использовать g++ -fwrapv: signed intermediate arithmetic исходника иначе
   может иметь UB для значений старше INT_MAX. В отчёте явно назвать ограничение.
3. Официальный baadf00d-вектор, zero/one/leading-zero, границы 32-bit chunk,
   длины 16/32 и обрезание хвостов, повторяющиеся слова, регистр/неизвестные слова.
   Сохранять mnemonic, UTF-8, hex decode, лишний stdout newline, статус hex/hd-new.
4. Все 136 сохранённых RNG cases, включая 0/1/2^32−1: Python MT, std::mt19937
   и исторические байты. Сохранённые 80 бинарных сценариев проверяются по данным,
   PE заново не эмулировать. RNG не смешивается с Python random.
5. Для допустимого hex ≥16 байт вычислить HMAC-SHA512("Bitcoin seed", bytes),
   master scalar/chaincode; это диагностические синтетические данные, не поиск
   по реальным маскам. Проверить тождество только там, где decode не потерял нули.
   Не заявлять тождество всех 32-байтных путей старому E15.
6. Исторический decode недостаточно валидирует слова, отбрасывает неполную
   тройку и не дополняет hex до 8 символов. Не исправлять его молча.
7. Повторный запуск контролей с теми же входами должен проверить хэши готовых
   результатов и не выполнять повторные вычисления. Ошибки сохраняются отдельно.

## Если позже появится основание для поиска

Нужен новый протокол, точная composition/library и отдельный run ID. Для BIP39
нужны dictionary/checksum/NFKD/PBKDF2/BIP32 и полная CPU/GPU-приёмка handoff.
Training №1–50, holdout №51+ только после отбора; прежние пути/маска и номера
без сжатия пропусков. Настоящие решения в текущих codec controls не загружаются.
Историческая потеря нулей — отдельная возможная гипотеза, автоматически не ищется.
