# SEQ-04 — 02.11.2026

Проверен новый метод для произвольного a в скрытой аффинной цепочке
modulo n: взвешенные полиномиальные отношения геометрических разностей
наблюдений №75,80,...,135. Все36 новых полноразмерных положительных
цепочек восстановили истинные a,d; нижние70 наблюдений использованы
только после fit. На64 случайных последовательностях кандидатов нет.

Реальные данные:52 полинома,312 gcd-пар, общих делителей положительной
степени нет; a не предложен. Это эвристический отрицательный результат,
не точное исключение всех множителей. Для вырожденного a=1 множитель
найден, но восстановление состояния не завершилось. Реальных ключей,
битов и сокращения поиска не получено.

Независимо проверены420 решёток и32 240 gcd-пар, состояния/проекции,
изоляция нижних данных. Все204 старых файла неизменны.
