# SEQ-04 — полиномиальные связи скрытых разностей

02.11.2026, Москва. Следующий метод после SEQ-03.

**Метод восстановил произвольные большие множители на36 из36 новых
полноразмерных искусственных цепочек. На настоящих Puzzle-решениях
кандидат не найден.** Это отрицательный результат конкретного эвристического
восстановителя, не доказательство отсутствия любой аффинной цепочки.
Реального нового приватного ключа, подтверждённого бита или сокращения
пространства поиска не получено.

## 1. Что изменилось

Сохраняется гипотеза о скрытой последовательности:

```text
s[i+1] = (a*s[i]+c) mod n
r[i] = s[i] mod 2^(i−1)
```

n — порядок secp256k1. В SEQ-03 точно исключён короткий подписанный
множитель, а общий прямой SMT не прошёл контроли. Здесь a,c,s[1]
разрешены во всём [0,n); SMT и перебор значений a не используются.
Реальный способ генерации автором остаётся неизвестным.

Использованы решения №75,80,…,135:13 наблюдений с74–134 известными
младшими битами. Они используются для поиска множителя и состояния.
№1–70 поступают только на последующую проверку. Все83 решения ранее
изучались; это не новый закрытый тест.

## 2. Как устранена прибавка

Для i_j=75+5j, b_j=i_j−1, q=32:

```text
z[j] = s[i_j] / 2^b_j mod n
y[j] = r[i_j] / 2^b_j mod n
z[j] = y[j] + u[j] mod n,  0 <= u[j] < n/2^b_j

t[j] = 32*z[j+1] − z[j] mod n
t[j+1] = rho*t[j] mod n,  rho = a^5/32 mod n
```

Деление обозначает умножение на модульную обратную величину.
Доступно Y[j]=32*y[j+1]−y[j] mod n. Его ошибка относительно t[j]
равна e[j]=32*u[j+1]−u[j], причём |e[j]|<n/2^b_j.
Это точное преобразование. В нём учтён исходный шаг5; номера не сжаты
так, будто соседние опубликованные решения созданы одним исходным шагом.

Ищем короткий H(X)=sum h_j X^j с H(rho)=0 modulo n. Тогда его
свёртки с Y дают малые модульные остатки, ограниченные неизвестными e.
Четыре заранее зафиксированные взвешенные решётки размерности13
ищут полиномы степеней3,4,5,6. Веса учитывают рост наблюдаемой ширины
на5 бит на каждом шаге. Формулы и матрицы — в [PROTOCOL.md](<PROTOCOL.md>)
и научных JSON.

LLL даёт базис коротких векторов. Общий линейный делитель двух полученных
полиномов над F_n предлагает rho. Проверено gcd(5,n−1)=1, поэтому
пятый корень a^5=32*rho восстанавливается однозначно modulo n.
Нелинейные общие делители не подменяются произвольным выбранным корнем.

Ключевой предел: короткий вектор, найденный LLL, **не обязан** быть
истинным отношением, и LLL не перечисляет все подходящие векторы.
Поэтому отсутствие общего корня среди найденных полиномов не исключает
все возможные rho.

## 3. Проверка предложенного множителя

Для каждого a используем условный восстановитель из SEQ-03, сохранённый
неизменённой локальной копией. По тем же13 верхним наблюдениям он
предлагает инвариант d=(a−1)*s[1]+c mod n. При фиксированных a,d
полное множество допустимых s[1] вычисляется точно как объединение
арифметических прогрессий; c=d−(a−1)*s[1] mod n.

После этого добавляются №1–70. Подтверждение означает непустое множество
состояний, согласованное со всеми наблюдениями, а не просто красивый
корень полинома. Сохраняется выявленная в SEQ-03 неоднозначность общего
сдвига: восстановление инварианта не равно единственному полному seed.

## 4. Полноразмерные контроли

Все новые a,c,s[1] получены из независимых SHAKE-доменов. У множителей
249–256 значащих битов. Восстановитель получает только наблюдения,
не истинные параметры. Истина используется после выполнения метода.

| Серия | Сценариев | Правильно восстановлены a,d | Неверных принятых параметров |
|---|---:|---:|---:|
| Первоначальные контроли | 12 | 12 | 0 |
| Новая репликация | 24 | 24 | 0 |
| Случайные последовательности | 64 | Совместимых кандидатов нет | 0 |

В каждом из36 положительных случаев был ровно один предложенный a.
В решётках с длиной полинома k=4,5,6,7 находилось соответственно
4,5,6,7 полиномов, обращающихся в ноль на истинном rho.
Это проверено после отбора; истинный rho не использовался для выбора.

После всех83 наблюдений условные множества начальных состояний имели
порядок2^113.43–2^118.12 элементов. Это мощность явно описанных
множеств при найденных a,d, не энтропия реального генератора и не
подсчёт всех альтернативных моделей.

Проекция на искусственный №71 дала один вариант в33 случаях,
два варианта в3 случаях; истинное значение входило всегда. Эти
проекции не являются прогнозом настоящего №71.

Время одного положительного восстановления:0.213–0.362s,
медиана0.238s без старта Python. Сумма сохранённых времён основных
36 положительных и64 нулевых случаев —18.902s. Подготовка, разработка,
первичные проверки полиномов, вырожденные контроли и аудит сюда не входят.

## 6. Где метод неполон

Отдельно исследованы a=0,1,−1 и постоянная цепочка. Для a=1 правильный
множитель предложен, но условный LLL/Babai-восстановитель состояния не
дал принятого результата. Таким образом, даже среди положительных
моделей есть документированный случай неполного восстановления.

Для постоянной цепочки совместимый a не обязан равняться использованному
при генерации: разные a с соответствующими c дают ту же последовательность.
Эти случаи не включены в36/36 и не объявлялись ошибочным определением
единственных параметров. Артефакты: degenerate/ — артефакт исходного исследования (`degenerate/`; вне снимка).

36/36 успешных случайных контролей не гарантирует успех для всех
множителей, периодов, начальных состояний или их распределений.
Не исследовались другой модуль, переменные параметры, неизвестная
перестановка экспорта, другое маскирование или криптографическая деривация.

## 7. Независимый аудит и сохранность

- 300 полиномиальных gcd основного Python-алгоритма сверены с SymPy
  до реального расчёта.
- Независимый аудит использовал нативные полиномы FLINT:32 240 пар
  по105 сохранённым пакетам, включая все312 реальных пар.
- Заново построены420 решёток отношений из наблюдений, проверены
  U*B=B_reduced и det(U)=±1; также проверены решётки состояния и
  точные множества допустимых s[1].
- По представителям, включая границы прогрессий, выполнена независимая
  прямая генерация и проверены все соответствующие наблюдения/проекции.
- Замена69 нижних наблюдений не изменила решётки, кандидаты a,
  инварианты или fit по верхней панели; испорченная цепочка была
  отвергнута только на дополнительной проверке. Контроль изоляции — артефакт исходного исследования (`ISOLATION_CONTROL.json`; вне снимка).
- Все204 принятых файла и seals SEQ-01/02/03 сохранили SHA-256 и mtime.
  Их поисковые стадии не повторялись. Общая среда и GPU не изменялись.

Независимый аудит занял3.985s. Приёмка аудита — артефакт исходного исследования (`AUDIT.json`; вне снимка),
итоговая приёмка и повтор без вычислений — артефакт исходного исследования (`ACCEPTANCE.json`; вне снимка).

Математический контекст — решёточные атаки на усечённые генераторы
линии Stern / Contini–Shparlinski. Авторы отдельно отмечают эвристические
границы этой линии методов; совпадение с конкретной исторической
реализацией здесь не утверждается. [Первичный источник](https://researchers.mq.edu.au/en/publications/on-sterns-attack-against-secret-truncated-linear-congruential-gen/).

## 8. Следующая развилка

Повторять этот же набор решёток или увеличивать старый SMT-тайм-аут
оснований сейчас нет. Для точного отрицания общей модели потребовался
бы полный алгоритм или сертификат отсутствия всех допустимых отношений,
чего данная серия не даёт.

Дальнейший самостоятельный класс должен менять предположение, например
функцию вывода скрытого состояния или его модуль, с отдельной конечной
постановкой и новыми контролями. Следующий класс в этой серии не запускался.
