# Четвёрка r–z–Ry–нормализованное s и половина диапазона

11 ноября 2026 года. На 73 ключах порог в обеих схемах прошли 0 из четырёх тестов с поправкой на четыре и 0 из четырёх с поправкой на 85. Расчёт занял 4,1 секунды.

## Методика

Для r, z, Ry и 2·min(s,n−s)/n использованы сохранённые медианы по всем подписям каждого ключа. Чётность половин сравнивает чётность числа признаков в верхней половине шкалы с меткой половины ключа. Чётность четвертей использует чётность суммы номеров четвертей от 0 до 3. Оба теста двусторонние. Пирсон сравнивает распределения по 16 комбинациям половин и по 256 комбинациям четвертей. Столбцы упорядочены по r, z, Ry и нормализованному s.

Нулевые распределения получены из сохранённых подписанных корпусов. В них учтены происхождение 208 подписей, шаблоны операций, способы подписания и классы high-S или low-S. Для 33 январских подписей с неизвестным рецептом использован равномерный суррогат nonce. Поправка min-P рассчитана по 2 047 корпусам на схему для четырёх новых и для всех 85 проверок. Один и тот же тест должен пройти p≤0,05 и на полных диапазонах, и при сохранении четвертей. План — артефакт исходного исследования (`PLAN.json`; вне снимка) · Происхождение подписей — артефакт исходного исследования (`../key-range-position-folded-s-pooled-20261111/runs/main/PROVENANCE.json`; вне снимка).
