# RNG64-01 — восстановление состояния из прямой сборки 64-битных слов

05.11.2026, Europe/Moscow. Протокол фиксируется до решения ограничений реальных ключей.

## Область

Три точные исторические модели: xorshift64* R12 L25 R27, multiplier 2685821657736338717; xorshift128+ L23 R17 R26; xorshift128+ L23 R18 R5. Первая — Figure19 arXiv1402.6246v1, вторая — Figure3 arXiv1404.0390v1, третья — TableI той же версии2014. Источники сохранены. Последние версии статьи и современные движки не подменяют исторические параметры.

Четыре последовательных next() дают сырой 256-битный ключ. Проверяются прямой/обратный порядок четырёх слов и big/little-endian байты внутри каждого слова; итоговая строка байтов читается как big-endian integer. Старт следующего ключа через d выходов, d=4,…,16: ноль…12 дополнительных отброшенных выходов. Номера задач не сжимаются, в том числе пропуски неизвестных решений. Всего3×4×13=156 схем.

key[i]=2^(i−1)+(raw[i] mod2^(i−1)). Старший принудительный бит не наблюдение. Нулевое состояние запрещено. Начальное состояние произвольное, seed не перебирается. Фиксированный предварительный прогрев и pre/post-output сдвиг на целое число next покрываются свободным начальным состоянием для обратимого перехода; это не отдельные независимые гипотезы. Переменные пропуски между словами одного ключа, произвольные перестановки4!, reseeding, float, хеширование, другие маски и семейства не входят.

## Разделение данных и метод

Снимок83 известных решений перенести из E15, проверить диапазоны/SEC/address coincurve и независимой affine арифметикой. Использование поздних решений необходимо для полных64-битных наблюдений. Поэтому это **новый split**, а не прежний train1–50: только №130 и №135 — fitting; все остальные81 решения — holdout, не участвуют в восстановлении или выборе схем. Параметры моделей/упаковки/stride зафиксированы выше, не подгоняются по holdout.

Первый фильтр — только один ключ: №130 для64*, №135 для128+. Два полных слова и часть третьего внутри ключа дают необходимые условия, независимые от d. Если они противоречивы, все13 stride для этой модели/упаковки исключены. Это не восстановление всей последовательности и не требует доступа к holdout.

64*: умножитель нечётный, обращается modulo2^64. Полное слово даёт точное внутреннее состояние; обратный/прямой переходы восстанавливают весь4-word блок. Противоречие проверяется обычной целочисленной арифметикой, без SMT. При совпадении состояние до первого слова однозначно.

128+: после известного полного выхода y состояние(u,v), y=u+v mod2^64, поэтому v=y−u. Решатель получает только64 неизвестных бита u; переходы/сложение/маски точные BitVec64. Нельзя заменять сложение XOR. Для локальных решений запрашивается следующий отличный u, пока не получен unsat или лимит. Полнота множества состояний требует unsat после исключения найденных; timeout/лимит сохраняются как незавершённость.

Лимит одного SMT-запроса60с, максимум256 состояний локального блока. Основная серия не расширяет эти лимиты адаптивно на реальных данных. Для каждого SAT обычным исполнением сверить все наблюдаемые биты; состояние отмотать к началу последовательности для каждого d, проверить второй fitting-ключ, только затем holdout. При полном совпадении вычислить №71 и проверить его опубликованный адрес, не импортировать ключ в кошелёк.

## Контроли до реальных запусков

Исторический C99 переход и Python: произвольные ненулевые состояния, крайние биты, точные64бит overflow, оба128+варианта; обратимость шагов. Синтетика с теми же83 номерами, маской/упаковкой/пропусками, скрытые состояния отдельно от solver-входов. Проверить восстановление, полную проверку holdout, искажение fitting-бита, недостаточные наблюдения/неоднозначность, исчерпание ресурса решателя, сохранение/продолжение без повторения завершённых задач. Неуспешный положительный контроль блокирует применение соответствующего метода к реальным данным; записать его предел.

Независимость состояний не равна числу наблюдаемых битов. Для64* показать инверсию полного слова как64 независимых ограничений. Для128+ показать отдельно ранг линейных LSB-необходимых условий и точные нелинейные результаты; не называть134 наблюдения134 независимыми уравнениями. LSB(sum)=LSB(xor) допустимо только для самого младшего бита настоящего выходного слова.
