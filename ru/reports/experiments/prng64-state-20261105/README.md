# RNG64-01

Восстановление произвольного состояния трёх исторических64-битных PRNG по частично раскрытым Puzzle-ключам. [Итог](<RESULTS.md>), [математика](<MATH.md>), [зафиксированный протокол](<PROTOCOL.md>), источники — артефакт исходного исследования (`SOURCES.json`; вне снимка).

Python3.11 используется из `../../.venv/Scripts/python.exe` относительно этой папки; версии Z3/coincurve и ОС — ENVIRONMENT.json. Вычисления локальные CPU, GPU не требуется. Исторические переходы отдельно собраны gcc O0/O2 в WSL, информация — NATIVE_ENVIRONMENT.json; C-векторы сохранены, повторять сборку для чтения результатов не нужно.

Команда проверяет совпадение входов и переиспользует DONE.json завершённых задач. Изменение исходников или данных требует новой отдельной серии с новой приёмкой, а не правки старых свидетельств. Серия имеет эксклюзивную Windows-блокировку RUNNING.lock; PROCESS.json носит диагностический характер, существование файла само по себе не признак живого процесса. Ошибки основного запуска сохраняются в errors/.

Аудит повторно решает сохранённые SMT2, проверяет четыре целочисленных контрпримера и продолжение без повторения завершённых задач. Это повторная проверка, она тратит CPU. Исходный audit.py сохранён: Z3 parse_smt2_file не смог открыть Windows-путь с кириллицей; wrapper читает текст Python и использует parse_smt2_string. Решатель, задачи и принятый код не менялись. Дополнительное прямое кодирование в audit_v2.py упёрлось в60с timeout на первой задаче; основной аудит до этого завершился успешно. Повторять медленную дополнительную проверку для приёмки не нужно.

Результаты можно читать/пересобирать из `runs/<ID>/RESULTS.json`, `SCHEMES.csv`, `RANKS.json`; `reviews/finalize.py` пересобирает итоговый текст без повторных вычислений. Синтетические INPUT.json не содержат скрытых состояний, они лежат отдельно в CHECKER_SECRET.json и доступны только генератору/проверяющему коду; recover() получает лишь модель, номер, маскированный ключ и упаковку.

## Не повторять

Тест seed32, GPU-перебор BX/SX, MT19937-матрицы и прежние32-битные PRNG здесь не запускались. В этой серии неизвестно всё внутреннее64/128-битное состояние; локальные противоречия исключают весь его домен для выбранных схем.

## Будущие эксперименты — не выполнены

1. Другие конкретные исторические параметры xorshift64*/128+, имеющие исходное подтверждение.
2. Все24 перестановки четырёх слов; это расширение текущих прямого/обратного порядков.
3. Конечные схемы пропусков **между словами одного ключа**, если появится основание в API/коде.
4. Иные отображения сырых слов в Puzzle-ключи, только с отдельным протоколом. Хеширование уничтожает непосредственные64-битные наблюдения и требует иной оценки стоимости.

Увеличивать одни межключевые интервалы для уже отвергнутых моделей бесполезно из-за локального противоречия. Историческая доступность этих генераторов не устанавливает ПО автора.
