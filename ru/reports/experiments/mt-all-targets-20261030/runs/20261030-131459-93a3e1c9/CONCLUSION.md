## Что можно использовать

CANDIDATE_SPACES.json — артефакт исходного исследования (`CANDIDATE_SPACES.json`; вне снимка) задаёт для каждого ограниченного ключа точное аффинное пространство: базовый остаток и независимые направления. Все допустимые остатки получаются XOR любого поднабора направлений с базой; их количество 2^dimension. Затем добавляется принудительный старший бит, а в order-схемах предварительно выполняется +1 mod 2^w. Это готовое описание условно сокращённого пространства поиска, а не список найденных настоящих ключей.

[EQUATIONS.md](<EQUATIONS.md>) показывает короткие формулы, в том числе между разными ключами; EQUATIONS.json — артефакт исходного исследования (`EQUATIONS.json`; вне снимка) сохраняет сертификаты. Межключевая связь может ограничивать совместный поиск или дать дополнительную информацию после решения одного из связанных ключей. Сама по себе она не обязательно фиксирует бит отдельного ключа.

Конкретный пример модели getrandbits(i−1), stride=2: `k71[1] XOR k71[4] XOR k71[22] XOR k127[32] XOR k150[96] = 0`. Это обычные биты ключей, с нулевого младшего бита. №71 отдельно остаётся полностью свободным, но участвует в совместной связи. Полный сертификат сохранён в разделе relations_involving_71 машинного файла уравнений.

В фиксированной упаковке reverse-big stride1, соответствующей getrandbits(256), найдена связь `k111[15] XOR k111[30] XOR k132[46] XOR k132[61] XOR k160[142] XOR k160[157] = 1`. Каждый из 77 ключей при этом отдельно свободен. Дополнительная проверка стандартного getrandbits(256) — артефакт исходного исследования (`STANDARD_GETRANDBITS256.json`; вне снимка) совпала с этой упаковкой на 480 значениях текущего CPython; историческая упаковка уже проверялась в E1/E2.

Ограничения, выведенные из прежних 83 решений, нельзя добавлять обратно как новые независимые наблюдения: сертификаты уже выражают их через старые строки. Новая независимо подтверждённая информация о ключе или генераторе может снизить размерность дальше.

Для примера, условное пространство №108 всё ещё содержит 2^76 значений — в 64 раза больше полного диапазона №71 из 2^70 значений. Найденное сокращение существенно внутри модели, но само по себе не делает эту задачу проще текущего полного перебора №71.

## Почему это ещё не доказанные биты puzzle

Существует другая совместимая модель `getrandbits(i)` stride=1, в которой все 8953 неизвестных бита совместно свободны. Сохранён конкретный контрпример — артефакт исходного исследования (`MODEL_COUNTEREXAMPLE.json`; вне снимка): состояние другой модели воспроизводит все 83 известных решения, но нарушает один из объявленных условных фиксированных битов. Поэтому из одного соответствия известным решениям нельзя выбрать модель и объявить её прогноз истинным.
