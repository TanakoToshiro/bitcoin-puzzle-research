# E1d: все нерешённые цели и совместные ограничения

Зафиксировано до нового расчёта: 2026-10-30. Данные — прежний проверенный снимок: 83 решения среди №1–160, 77 неизвестных приватных ключей. Проверяются все 77, без отбора по результату. Исторические адреса №161–256 не входят в эту таблицу и этот этап.

Состояние MT: 19937 достижимых координат. Принудительный старший бит не является наблюдением. Условия: все 83 опубликованных решения. Цели: каждый нерешённый ключ отдельно и объединение всех неизвестных остатков. Ищутся фиксированные биты, внутриклю́чевые XOR и связи между несколькими ключами.

Модели: восемь фиксированных 256-битных упаковок E1 и все 32 совместимые ветви E1b (24 конфигурации API). Семь противоречивых ветвей E1b повторно не рассчитываются. Номера, шаги, порядок слов/байтов сохраняются. Используется ранее сохранённый свидетель каждой ветви; никакого перебора seed.

Для E1b сохраняются условия истории до №135. Чтобы вычислить №136–160, история продолжается естественным исполнением сохранённого состояния. Для степенных randrange это точные однобитные условия принятий/отказов. Для randrange(order) до №135 остаются прежние достаточные условия; после №135 берётся линейная клетка сравнения с границей: общий двоичный префикс и первый различающийся бит фактически полученного значения. Это ограничивает подсемью состояний, но не фиксирует будущий ключ целиком. Продолжение контролируется числовым MT и настоящими историческими Python.

В схемах order линейная величина — `(key[i]-1) mod 2^(i-1)`. XOR этих величин нельзя выдавать за XOR исходных ключей: переносы нелинейны. Полная свобода нормализованного остатка означает полную свободу ключа, поскольку прибавление единицы по модулю — биекция. Любое найденное ограничение маркируется в своей системе координат.

Для каждой проекции B вычисляется `d=rank([A;B])-rank(A)`, число ограничений — `width-d`. Сохраняются точные сертификаты: комбинация строк A и B даёт нуль, а комбинация RHS — заявленное значение. Для совместной проекции используются метки `(номер, бит)`; отдельно учитываются ограничения внутри ключей и дополнительные связи между ключами. Найденная связь между неизвестными величинами сама по себе не предсказывает конкретный бит одной из них.

Ограничение модели без отказов является следствием этой модели и данных, но не доказательством, что создатель использовал её. Ограничение фиксированной истории randrange условно: нельзя переносить его на неизвестную историю. Если хотя бы одна допустимая ветвь допускает все значения ключа, никакого гарантированного ограничения этого ключа во всём семействе нет. Для сравнения ветвей сохраняются все сертификаты; вероятности состояний и seed в этом этапе не оцениваются.

Контроли: маленькие системы с фиксированным битом, только XOR, полностью свободными отдельными ключами при совместной связи, противоречием; синтетические состояния того же формата, тех же 83 наблюдаемых индексов и всех 77 целей; числовая проверка каждой строки карты и историческое исполнение до №160. Все сертификаты перепроверяются напрямую, ранги отдельно — противоположным порядком pivot. Для согласованных реальных систем сохраняются несколько различных состояний и проверяются их полные последовательности.

Новый каталог, замороженные исходники/входы, идентификатор запуска, промежуточные результаты, SHA-256, журнал ошибок. Поэтапные checkpoints; завершённые задачи не повторяются. README/RESULTS/NOTES позволяют продолжить без истории чата. Старые эксперименты и основные проекты не меняются. CPU, без нового бюджета seed-перебора.

Будущие эксперименты: оригинальные №161–256 как отдельный набор; пересечение ограничений разных допустимых историй; использование подтверждённых связей для DLP/совместного поиска; дополнительные seeded-модели. Эти расширения не выдаются за выполненную часть E1d.
