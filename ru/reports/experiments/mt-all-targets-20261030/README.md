# E1d — ограничения всех нерешённых ключей

Проверяются **все 77 нерешённых задач №1–160** из прежнего снимка: каждый ключ отдельно и совместно все 8953 неизвестных бита. Исследуются фиксированные биты, XOR внутри ключа и связи между ключами. Исторические №161–256 — отдельный будущий набор, отсутствующий в используемой таблице решений.

[Протокол](<PROTOCOL.md>), [результаты](<RESULTS.md>), [промежуточные выводы](<NOTES.md>). Запуск: `20261030-131459-93a3e1c9`. Восемь фиксированных упаковок E1 и 32 ранее совместимые ветви E1b, всего 40 задач / 32 конфигурации.

## Артефакты

- `manifest.json`: замороженные модели, данные, исходные состояния продолжения, хеши кода и источников.
- `tasks/<id>/matrix.bin.gz`: точная матрица (сначала guards, затем известные биты, затем все неизвестные биты); формат MTGF2V1, 19937 столбцов, 2493 байта на строку после заголовка.
- `layout.json`, `rhs.json`: метки строк, значения наблюдений, порядок неизвестных битов, история отказов.
- `per-key.json.gz`, `joint.json.gz`: все ограничения и сертификаты. `target_mask` задаёт XOR целевых строк; `observation_mask` — комбинацию исходных уравнений. Их XOR должен быть нулевой строкой, RHS — равен `value`.
- `SYNTHETIC.json`, `WITNESSES.json`, `validation-*.json`: синтетический контроль и обычное исполнение восстановленных состояний, включая исторические Python.
- `result.json`: небольшая сводка; `DONE.json`: контрольные суммы законченного этапа.
- `EVENTS.jsonl`: дописываемый журнал этапов и ошибок. Числовые таблицы пересобираются без повторного расчёта.

Нумерация битов от младшего, с нуля. Для order-схем ограничения относятся к `(key-1) mod 2^(i-1)`: переносы при +1 не позволяют назвать их обычным XOR ключей. Для остальных схем это непосредственно младшие биты ключа.

Stride в API-моделях определён как в E1b: перед каждым используемым draw для i>1 отбрасывается stride−1 draw **текущей ширины i**, затем используется очередной. Это не пропуск индексов таблицы и не подмена i на 2i. В bits_im1 для i=1 возвращается ноль без вызова Python 2 getrandbits(0).

Ограничения справедливы **при гипотезе соответствующего генератора**. Для случайных отказов они дополнительно обусловлены конкретной историей; отсутствие ограничения хотя бы в одной допустимой ветви опровергает его обязательность во всём API. Связь между неизвестными ключами сама по себе не означает знание одного из её битов.

Найденные из прежних данных ограничения нельзя добавлять обратно как новую независимую информацию: их сертификаты уже выражают их через старые уравнения. Новое подтверждённое решение либо новая информация о генераторе может сократить пространство дальше.

## Будущие эксперименты

Оригинальные №161–256; пересечение ограничений разных историй; дополнительные обоснованные ограничения seed; практическое применение подтверждённых связей в совместном поиске. Расширения требуют отдельной постановки, а не объявления текущих условных битов найденными битами реальных ключей.
