# SIG-01 — подписи, публичные точки и порядок операций

11 ноября 2026 года. Пять проверок по принятому снимку E5 от 30 октября и сохранённым сравнениям E11. Основной расчёт занял 38,82 секунды, независимая сверка — 10,01 секунды. Суммарно 48,83 секунды при общем пределе 900 секунд. Измерения — артефакт исходного исследования (`runs/main/OUTER.json`; вне снимка), аудит — артефакт исходного исследования (`AUDIT.json`; вне снимка), границы проверок — артефакт исходного исследования (`PLAN.json`; вне снимка).

## 1. Связи nonce-точек

Для всех 324 подписей повторно извлечены `r, s, z, Q` из raw-транзакций и родительских выходов. Восстановлены полные точки `R = s⁻¹(zG + rQ)`. Независимая аффинная арифметика подтвердила обе координаты всех 324 точек. Проверки учитывают эквивалентность знаков при нормализации S. [RFC 6979, §2.4](https://www.rfc-editor.org/rfc/rfc6979.html#section-2.4).

| Точная проверка | Объём | Совпадения |
|---|---:|---:|
| HASH160 обеих SEC-сериализаций `±R` по словарю всех 256 исходных адресов | 1 296 запросов | 0 |
| `Rᵢ ± Rⱼ = δG` при `abs(δ) ≤ 65 536` | 104 652 знаковые проверки | 0 |
| `Rᵢ ± mQⱼ = δG`, `m = 1,…,8`, тот же предел `δ` | 979 776 знаковых проверок с 189 точками | 0 |
| `Rᵢ = ±(Qⱼ ± Qₖ)` для двух разных точек подписантов той же транзакции | 9 806 шаблонов, 324 поиска | 0 |

Поиск по HASH160 включает №71. В найденных отношениях ранг ограничений на секреты, отсутствующие в архиве, равен нулю. Точки и счётчики — артефакт исходного исследования (`runs/main/01_NONCE_POINTS.json`; вне снимка).

## 2. Разбор 87 несовпадений RFC6979

Эффективные nonce всех 218 подписей с опубликованным секретом независимо сверены с восстановленными точками. Исходный RFC6979/HMAC-SHA256 воспроизвёл 131 nonce с учётом знака, включая 15 из 15 известных подписей раскрытия 2019 года. Среди оставшихся 87 **45 подписей точно воспроизведены по DER** алгоритмом подбора low-R из Bitcoin Core 0.17.0. Это повторное подтверждение записей E11. Эти 45 подписей относятся к десяти ключам и блокам 2019–2026 годов. Совпадение устанавливает совместимость пути подписания. Авторство остаётся неустановленным. [Ранее проверенный исходник Core](https://github.com/bitcoin/bitcoin/blob/v0.17.0/src/key.cpp), сравнения E11 — артефакт исходного исследования (`../historical-signers-20261101/COMPARISONS.json`; вне снимка).

Оставшиеся 42 относятся к расходованиям Puzzle №2–46 в январе 2015 года. На каждый такой ключ приходится одно оставшееся несовпадение. Из них 19 находятся в блоке исходного финансирования. Время блока фиксирует включение транзакции. Происхождение генератора nonce этих подписантов остаётся открытым.

| Проверка на оставшихся 42 | Объём | Итог |
|---|---:|---|
| RFC6979 с HMAC-SHA1, SHA224, SHA384, SHA512 | 168 кандидатов | 0 |
| Следующие принятые кандидаты потока RFC6979 | 16 на подпись | 0 |
| 32-байтовая добавка со счётчиком 0–255 в трёх представлениях с удалением дублей | 32 172 кандидата | 0 |
| Длина меньшего из `k, n−k` | 42 значения | минимум 250 бит |
| Общие 32 бита на той же позиции или 64 бита на произвольных позициях внутри транзакции или ключа | 31 пара, 124 варианта знаков | 0 |
| Рекурсия степени 1 или 2 по соседним vin одной транзакции | 4 линейных и 2 квадратичных окна, 128 вариантов знаков | 0 |

Для каждой рекурсии коэффициенты определяются по первым переходам окна. Два последующих перехода служат точной проверкой. Порядок vin — наблюдаемая последовательность для этого теста. Фактический порядок генерации nonce остаётся неизвестным. Варианты добавки — LE32 и BE32 в начале 32-байтового блока и BE32 в его конце, остальные байты нулевые. Разбиение по ключам, датам и операциям — артефакт исходного исследования (`runs/main/02_NONCE_CLASSIFICATION.json`; вне снимка).

## 3. Достаточность подписей одного ключа

Составлена таблица 189 различных публичных ключей с числом разных sighash, происхождением, датами и идентификаторами подписей. Для каждого из **106 ключей без известного в архиве секрета** доступно ровно одно подписанное сообщение. Среди 83 ключей с опубликованным секретом у 31 есть не менее двух сообщений, у 10 — не менее четырёх, у 8 — не менее пяти, у 6 — не менее шести. Максимум — 33 сообщения у №66. Таблица CSV — артефакт исходного исследования (`runs/main/03_SIGNER_GROUPS.csv`; вне снимка), полные группы JSON — артефакт исходного исследования (`runs/main/03_SIGNER_GROUPS.json`; вне снимка).

Для Polynonce неизвестная рекурсия степени `D` требует как минимум `D+3` подписей одного ключа в подходящей последовательности. Для метода общих битов требуется несколько подписей того же ключа и основание для общей битовой структуры nonce. На архивных группах без секрета обе проверки применимости останавливаются по числу сообщений. [Polynonce](https://kudelskisecurity.com/research/polynonce-a-tale-of-a-novel-ecdsa-attack-and-bitcoin-tears), [Adamoudis, Draziotis, Poulakis](https://arxiv.org/abs/2307.03979).

## 4. Единая карта исторических операций

Сверены пять транзакций, их входы и родительские выходы. Шесть непустых последовательностей с несколькими Puzzle-позициями совпали с порядком исходных выходов после фильтрации. На 11 пересечениях последовательностей относительный порядок одинаков.

| Операция | Точная привязка |
|---|---|
| Финансирование 2015 | Все 256 номеров идут по `vout = i−1`. Сумма каждого выхода равна `100 000 × i` sat |
| Перераспределение 2017 | Первые 96 входов расходуют исходные vout 160–255 по порядку. Затем идёт дополнительный вход. Выходы — №1, №53–160 с суммой `900 000 × i` sat |
| Подготовка раскрытия 2019 | №1, затем №65, 70, …, 160. Каждый из 21 выходов по 1 000 sat |
| Раскрытие 2019 | 20 Puzzle-входов расходуют vout 1–20 подготовки в том же порядке. Затем идёт дополнительный вход. Единственный выход ведёт на №1 |
| Пополнение 2023 | №1 и 84 последующих номера в исходном порядке. Суммы `9 000 000 × i` sat |

**Состав выходов 2017 и 2023 точно совпал с одним наблюдаемым правилом.** Выбраны все исходные выходы №1–160, ещё не потраченные до соответствующего блока, плюс №1. Получилось 108+1 и 84+1. Расходований исходных выходов из этого диапазона в самих пограничных блоках не было. Этот тест сформулирован по историческим операциям и проверяет наблюдаемый состав их выходов.

Все выходы пяти транзакций сопоставлены с исходными Puzzle-адресами. Назначение повторяющегося выхода №1 остаётся неустановленным. Комиссии составили 400 000, 2 000 000, 79 000, 269 000 и 1 000 000 sat соответственно. Исходная транзакция имеет версию 1, остальные — версию 2. Во всех locktime равен нулю, у всех входов sequence равен `0xffffffff`. Witness присутствует в пополнении 2023 года.

Сортировка по сумме допускает наблюдаемый порядок, включая равные суммы в подготовке раскрытия. У этого объекта 87 парных инверсий по компаратору выходов BIP69. Проверенные разбиения по чётности и кратности пяти не дают общего правила для всех шести последовательностей. Полученная карта описывает позиции в транзакциях. Внутренние ветви, порядок генерации и время инициализации остаются неизвестными. Карта, суммы и компараторы — артефакт исходного исследования (`runs/main/04_HISTORICAL_ORDER.json`; вне снимка), [BIP69](https://bips.dev/69/).

## 5. Точные отношения публичных точек

Покрыты 184 Puzzle-точки и пять дополнительных публичных ключей подписантов опорных транзакций. В том числе 70 точек №1–70, 18 точек №75–160 и 96 точек №161–256. На 17 766 парах проверены равенство, противоположность и `Pᵢ ± Pⱼ = δG` с `abs(δ) ≤ 65 536`. Для множителей 2–16 проверены оба знака.

Найдено 240 знаковых малых разностей и шесть точных кратностей. **Все 246 совпадений относятся к опубликованным ключам №1–17.** Равенств и противоположностей разных точек нет. Между историческими группами совпадений нет. Независимая скалярная арифметика воспроизвела все 246 совпадений. Вывод ограничен проверенными публичными точками и выбранным каталогом формул. Список отношений — артефакт исходного исследования (`runs/main/05_PUBLIC_POINTS.json`; вне снимка).

Сверены хеши 312 входных файлов. Расчёты выполнялись с сохранёнными raw-байтами и таблицами E5. Для повторения пяти проверок используйте исследовательский Python и `run.py` с новым именем запуска. Источники и хеши — артефакт исходного исследования (`runs/main/INPUT_PINS.json`; вне снимка), код запуска — артефакт исходного исследования (`run.py`; вне снимка), код независимой сверки — артефакт исходного исследования (`audit.py`; вне снимка).
