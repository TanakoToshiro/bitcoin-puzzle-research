# Краткий поиск связи с Puzzle

02.11.2026. Два запроса через web search:

- `"bitcoin puzzle" "sharedcoin-seed"`
- `site.bitcointalk.org "puzzle" "SharedCoin"`

Подтверждённой связи автора Puzzle с SharedCoin или опубликованного seed этой задачи не получено. Возвращены в основном материалы о смешивании/приватности и других смыслах слова puzzle. Пример нерелевантного результата: https://bitcointalk.org/index.php?topic=5213493.0 — технологический стек/TumbleBit. Эти результаты не используются как доказательство устройства SharedCoin. Поиск ограниченный, не исчерпывающий.

Открытие GitHub blob и raw через web-инструмент дало cache miss. Сами файлы успешно получены Python downloader напрямую с официального архива, сохранены с UTC/URL/SHA-256 и сверены с Git blob; см. SOURCES.json и CHECKS.json. Для алгоритмов используются исключительно сохранённые первичные исходники.
