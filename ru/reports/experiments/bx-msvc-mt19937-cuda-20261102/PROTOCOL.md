## Конечный механизм и схемы

Один uint32 seed задаёт std::mt19937(single integer), его32 выхода преобразуются %255.
Entropy32 и её первые16 байт дают два master. Ноль допустим; не нормализовать seed
modulo2^31−1 и не заменять0 на1/5489. Seed извлекается один раз на master, не на puzzle.
Домен[0,4294967296), включая0xffffffff. Все end/stop/позиции блока используют64-битные числа.
4096 блоков по1048576 seed; последний[4293918720,4294967296), такой же полный размер.

SCHEMES.json скопирован без изменения:40 схем, не40 на RNG. Для entropy16 и32:
m,m/0,m/0'/0,m/0'/1 final normal/hardened, индексi−1/i;
m/44'/0'/0'/0 и m/44'/0'/0'/1 final normal i−1/i. Итого20 на длину.
Полный объём171798691840 state×scheme. Маска сохраняет младшиеi−1 бит и ставит битi−1.
GPU filter —49 младших бит реального №50. CPU проверяет№1–50; holdout№51+ только
после training-match. Кандидат сохраняет seed,entropy,все узлы и останавливает поиск;
независимый affine-проверяющий должен подтвердить известные решения/адреса до любых заявлений о ключе.

## Реализация и контроли

CUDA хранит первые33 init-слова и текущий state. Генерация первых32 MT outputs требует
значений init0..428. Умножение1812433253 и temper11/7/15/18 выполняются в uint32 с wrap.
Первые32 entropy-байта общие для обеих длин; master/parents кэшируются между схемами.
CPU проверяющий использует полное std::mt19937 и исторические HD-функции с прежними адаптерами.
Python-эталон model_mt.py/NumPy и отдельный полный MT reference проверяют слова, не только байты.

RNG-контроли включают исходные136 seed, обе стороны всех4096 границ блоков и все верхние биты.
Проверяются entropy,word output,оба master,parent/final key-chain-public;40 исходных
planted-positive/negative и2 новых крайних seed. Последний полный GPU-блок должен найти
искусственный target у0xffffffff. BIP32 official vectors,EC/SHA/HMAC,payload,invalid nodes,
bits0/overflow,нарушение диапазонов,stop/resume,порча checkpoint,lock и sharing retry обязательны.
Синтетика и реальные данные разделены. Ошибка не считается отрицательным результатом.

Пилоты:3 блока по2^20, у0,2^31 и верхней границы. Скорость — всех40 схем на seed,
API perf_counter/UTC и CUDA events отдельно. Регистр/spill/local-memory сведения в build logs/GPU.json.
После измерения оценить полный локальный срок. Облачной аренды нет.

Перед full фиксируются input/acceptance hashes; блоки образуют SHA256 цепочку.
Готовые блоки при продолжении не повторяются. Независимый Windows readback после полного
покрытия повторно проверяет4096 блоков,конфигурацию,код/источники,диапазон0..2^32 и итог.
Отчёт формируется из файлов, общий журнал дополняется новой записью.

Отрицательный результат относится только к этим40 комбинациям Windows BX MT/%255,
entropy16/32,путей/индексов/маски. x86 не выдаётся за динамически проверенный;
связь автора с BX не доказана. Ранний MSVC/SX distribution,иные lengths/paths вне покрытия.
