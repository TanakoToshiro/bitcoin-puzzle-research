# E15 — Windows BX MT19937 GPU

Изолированное продолжение исторического MSVC-аудита. [Протокол](<PROTOCOL.md>),
схемы — артефакт исходного исследования (`SCHEMES.json`; вне снимка), [результаты](<RESULTS.md>), [журнал](<JOURNAL.md>).

WSL Ubuntu-24.04, из этой папки:

> Исполняемый код/команды опущены в документационной копии.


Полный проход — один MT RNG,40 схем,все seed[0,2^32),4096 блоков. Не применять старую
minstd нормализацию. Точный список length/path/hard/offset скопирован из MSVC-аудита.
run.py all переиспользует приёмку/пилоты и готовые блоки при совпадающих входах.
SERIES.lock — flock; PROCESS.json содержитPID/start ticks. STOP останавливает перед
следующим блоком; убрать перед продолжением. При ERROR/кандидате автоматического пропуска нет.

Windows launch_and_audit.ps1 держит отдельный mutex и запускает WSL-проход в фоне.
После успеха выполняет readback.py и finalize_report.py: FINAL_REPORT.md,
READBACK_COMPLETE.json и запись в общий RESULTS.md. POSTRUN_STATUS.json/HOST_PROCESS.json
описывают координатор, POSTRUN_MANIFEST.json фиксирует его код. Успех подтверждается
только COMPLETE + независимый READBACK_COMPLETE,не остановкой процесса.

prepare.py — однократный перенос/генерация эталонов; не запускать поверх принятой серии.
Сборка воспроизводится по pinned исходникам. Старые BX/SX/MT checkpoints не изменяются.
Оригинальные EXE не запускаются; их историческая эмуляция уже сохранена и проверена по хэшам.
