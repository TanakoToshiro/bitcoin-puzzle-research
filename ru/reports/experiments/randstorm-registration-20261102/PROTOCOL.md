# RND-02 — достижимость ранней KSA при регистрации

02.11.2026. Ограниченное продолжение RND-01; предыдущие78 принятых файлов не изменять. CPU, без настоящего поиска, аренды/GPU/словаря паролей.

Основной кошелёк: My Wallet29.12.2013 commit031863d30590754f5d02fc10488236b1dc30f7f7. Конкретный браузер для исходникового анализа: настольный Chrome31.0.1650.63, опубликованный04.12.2013. Установить соответствующий Blink commit через .DEPS.git, проследить window.crypto→getRandomValues→реальный источник случайности. Отсутствие функции не предполагать искусственно для этого браузера.

Воспроизвести **полный неизменённый wallet-signup.js** с регистрацией document.ready/click/async UUID callback в инструментированной DOM-заглушке. BitcoinJS bundle и _seed/generateNewKey использовать точные из RND-01; заглушки должны быть перечислены. Записывать время/порядок entropy/первого nextBytes/KSA/сохранения. Нормальный новый кошелёк, отказ проверки пароля, сетевой отказ UUID и уже существующий адрес — разные ветки. Искусственно вставленный ранний запрос RNG только контроль детектора, не исторически доказанный путь.

Проверить доступные другие потребители SecureRandom и очередность mnemonic/paper-wallet/signing. Искать первичный JSP/HTML для проверки полного списка загружаемых scripts; если его нет, явно ограничить отрицательный вывод доступным клиентским кодом. Нельзя объявлять весь сайт свободным от ранних вызовов на основании заглушек.

Завершение: журнал, источники/хэши, трассы, контроли и конкретное решение — есть ли основание для ограниченного поиска по этой конфигурации. Если WebCrypto активен до KSA и ранний обход не найден, снизить приоритет этой цепочки; не расширять перебор автоматически.
