# RND-02 — регистрация My Wallet и Chrome 31

[Итог](<RESULTS.md>), [протокол](<PROTOCOL.md>), [журнал](<JOURNAL.md>), [таблицы](<NUMERIC_REPORT.md>).

Комбинация: My Wallet от 29.12.2013 и Windows/Chrome 31.0.1650.63. Выполнены анализ исходников браузера и исполнение JS-регистрации с явными заглушками. Старый браузер целиком не запускался. Настоящего поиска и GPU нет.

> Исполняемый код/команды опущены в документационной копии.


audit.py проверяет совпадение входов и результатов, затем использует cache. Новые входы требуют новой папки. report.py формирует таблицу из AUDIT без вычислений. Не запускать registration.cjs вручную в принятой папке: он перезаписывает TRACES.

Все 10 сценариев и заглушки видны в registration.cjs; сетевые запросы не отправляются. Пароли, UUID и entropy синтетические. Исполняется неизменённый signup IIFE; DOM, AJAX-ответы, сохранение и шифрование после первого ключа заменены адаптерами.

Артефакты: SOURCES/URLS и sources; SOURCE_AUDIT с декодированными Gitiles-файлами и Git blob проверками; INPUT_PINS и inputs — копии RND-01; NODE_RUN/TRACES — сырые вызовы; AUDIT/ACCEPTANCE/COMPLETE — результаты и целостность. Старые RND-01/SX не меняются.

Использованы существующие Python 3.11/coincurve и Node 24.18.0. Зависимости не устанавливались. Время AUDIT относится к контролям, не к скорости поиска. Для продолжения достаточно RESULTS, PROTOCOL и артефактов; история чата не требуется.
