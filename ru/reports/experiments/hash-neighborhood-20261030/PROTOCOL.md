# E4 — условный локальный эффект HASH160: протокол до просмотра результатов

2026-10-30. Гипотеза: если HASH160 сжатой точки центрального ключа совпал с целью
по первым p битам, новые ключи рядом с центром успешнее новых равномерных ключей.
Проверяются p=8/12 **битов** и радиусы R=16/4096/16777216. Это ограниченный пилот,
не воспроизведение редких совпадений 8–14 шестнадцатеричных знаков чужого solver.
Полные puzzle-ключи не смешиваются с гипотетическими значениями до маскирования:
здесь используется непосредственно скаляр k в [2^70,2^71).

## Выборки и неизменяемые правила

- 32 независимые новые синтетические цели. Отдельный seed целей сохраняется в
  vault; отбор кандидатов получает только HASH160, не целевые приватные ключи.
- 32768 свежих равномерных центров на цель, всего 1048576=2^20. Ключи получаются
  из SHAKE256 с сохранённым случайным 256-битным seed и разделением доменов;
  ровно 70 случайных младших битов, старший бит 70 установлен.
- Из совпавших центров равномерно выбрать максимум 24 для p=8 и 8 для p=12 на цель.
  Один центр может попасть в обе группы; это учитывается кластеризацией по цели.
  Если совпадений меньше, взять все, не подбирать новые центры.
- На каждый выбранный центр: 16 новых соседей при R=16, 120 при R=4096 и 120
  при R=2^24; смещения равномерны среди допустимых ненулевых смещений. Всего
  максимум 1024*256=262144 соседей. Против каждого — один новый равномерный
  контроль из того же диапазона. Выбор и перестановки используют фиксированные
  seed, выведенные из master seed; сохранены версии NumPy.
- Все центры генерируются до соседей. Глобально исключаются уже просмотренные
  ключи, центры, контрольные ключи и повторы между целями/порогами/радиусами.
  Границы учитываются отбрасыванием кандидата, без обёртывания или прижимания
  к границе. При исчерпании конечной окрестности сохранить фактический размер
  и такой же размер контроля; это отдельное событие, не нулевой результат.
- Сохраняются все скаляры, HASH160, выбранные центры, принадлежность к группам,
  счётчики исключений. По 128 фиксированным центрам сверяется независимая Python
  арифметика secp256k1. Существующие выборки эксперимента B не используются.

## Метрики и статистика

Две основные метрики для каждой пары p,R: совпадение первых p бит и совпадение
следующих восьми бит, не участвовавших в отборе. Итого **12 односторонних тестов**
преимущества соседей, Holm, семейный alpha=0.01. Совместное совпадение p+8 бит и
полный HASH160 учитываются описательно; дополнительных тестов по ним нет.

Единица независимости — целая цель со всеми центрами, порогами и радиусами.
Сравнение парное, число соседей и контроля в каждом блоке одинаково. Переставлять
целиком два плеча внутри цели (65535 случайных знаковых перестановок; p с поправкой
(b+1)/(B+1)), одни и те же знаки для всех 12 тестов. Это тест нулевой обменности
плеч; не предполагать независимость отдельных соседей.

Кластерный парный bootstrap по 32 целям: 65536 повторов, интервалы разности
частот (95% и Bonferroni 99% одновременно для 12 метрик). Это приближённые
интервалы; при суммарно <20 успехах, <8 информативных целях или вырожденном
распределении явно помечать ненадёжность редких событий. Для таких строк не
заявлять практически полезного исключения малых эффектов по bootstrap.
Дополнительно сохранить консервативную границу Hoeffding по независимым целям
и ориентир мощности при идеальной независимости хешей (80%, alpha/12).
Относительный эффект показывать как сосед/контроль и как разность/p0,
p0=2^(-p) для префикса и 1/256 для следующих битов. Нулевой знаменатель не
заменять произвольной псевдочастотой.

## Контроли до основного прогона

1. Криптографический вектор k=1, границы диапазона, эквивалентность извлечения
   битов двоичной строке, точные значения Holm, нулевой/положительный/обратный
   статистические контроли; проверка удаления повторов и границ малой окрестности.
2. Положительный контроль целого конвейера: функция SHA256(domain || BE(k>>30))[:20],
   постоянная в блоках 2^30. 32 цели, 8192 центра/цель, пределы центров 4/2,
   по 8/16/16 соседей. Все шесть префиксных тестов должны пройти Holm 0.01.
   Следующие 8 бит не обязаны показывать сигнал; их результат сохраняется.
3. Восемь независимых отрицательных прогонов: SHA256(domain || BE(k))[:20] как
   псевдослучайный оракул без близости соседних входов, 32 цели, 4096 центров/цель,
   остальные уменьшенные параметры как выше. При >1 прогона с семейным ложным
   срабатыванием остановить основной опыт. Сохранить все срабатывания; 8 прогонов
   не считать точной валидацией уровня 1%.
4. Штатная остановка после контролей, resume без их повторения, финальный resume
   с нулём новых задач и независимый аудит непересечения сохранённых скаляров.

## Бюджет, отчёт и продолжение

До 900 секунд CPU wall time основного цикла с контролями, без написания кода.
Проверка между стадиями; стадия — один контрольный прогон либо одна цель, не
жёсткое прерывание в середине стадии. Невыполненное сохраняется незавершённым.
На каждую стадию JSON + NPZ (где нужны данные), SHA-256, время, checkpoint и
обновлённый RESULTS.md; интерпретации дописываются в NOTES.md. Входы и код
заморожены, их изменение требует нового ID. Отчёт пересобирается без вычислений.

При основном сигнале — повторить неизменный протокол с новым seed и новыми целями,
если остаток бюджета позволяет (ориентир не менее 180 секунд). Без репликации
результат предварительный. Даже подтверждённый эффект короткого префикса не
экстраполируется на 160 бит. Учитывать поиск центров и полное число уникальных
хеширований; рабочий порядок поиска №71 по результату пилота не менять.
