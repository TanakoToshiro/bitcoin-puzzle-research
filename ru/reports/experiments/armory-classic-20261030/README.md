# E3 — историческая классическая цепочка Armory

**Уточнение терминологии:** опубликованные решения — полные приватные ключи
puzzle-адресов. Частичные наблюдения относятся только к предполагаемым исходным
значениям до маскирования. См. [исправление и проверенное сообщение автора](<CLARIFICATION.md>).

Статус: реконструкция и контрольные вычисления завершены. Бит/XOR №71 не получен;
Armory как источник puzzle не исключён. Поиск неизвестного корня не запускался.

Используется исходный BitcoinArmory до появления puzzle: commit
`61a596fa94f9cacf9fb00c4e02d0eb65d8b17513`, 2015-01-08. Историческая деривация
chaincode проверена исполнением выбранных исходных AST-функций в CPython 2.7.9;
приватная/публичная цепочка — официальными векторами и двумя независимыми реализациями.
Полный кошелёк не собирается. Все сохранённые синтетические приватные ключи публичны
и предназначены исключительно для тестов.

## Команды PowerShell из папки эксперимента

> Исполняемый код/команды опущены в документационной копии.


Нужны Python 3.11 и coincurve 21.0.0 из существующего исследовательского venv;
для исторического оракула — WSL `Ubuntu-24.04` и сохранённый архив CPython 2.7.9
эксперимента `../python-seed-20261030/`. Launcher E2 автоматически восстанавливает
архивированную сборку, если WSL `/tmp` очищен, и проверяет её SHA-256. Никаких
пользовательских кошельков, облака, GPU и поисковых checkpoints код не открывает.

`config.json` фиксирует входы, версии и копии кода. `state.json` хранит законченные
стадии и затраченное время; `invocations.jsonl` показывает остановку/продолжение.
Изменение кода/входов блокирует resume и требует нового запуска. Исторические
артефакты сохраняются; интерпретации в NOTES.md дописываются отдельно от таблиц.
Тайм-аут процесса оракула — 180 секунд; прочие стадии атомарны (в выполненном
прогоне каждая заняла менее трёх секунд). Лимит бюджета проверяется между стадиями,
это не жёсткое прерывание посередине стадии. Ошибки пишутся в errors.jsonl при появлении.

## Дальнейшая работа

Не расширять перебор произвольных корней без новых данных. Для продолжения E3 нужны
проверяемая связь создателя с версией Armory, механизм экспорта/маскирования,
конкретная слабость энтропии либо полные исходные данные цепочки. Следующий отдельный
пункт обзора — E4, контроль гипотезы поиска около совпавших префиксов HASH160;
он в этот запуск не включён. Остальные будущие эксперименты сохраняются в
[общем плане](<../../review-20261030/NEXT_EXPERIMENTS.md>).
