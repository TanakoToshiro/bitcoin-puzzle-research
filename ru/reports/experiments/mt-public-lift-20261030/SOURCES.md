# Источники и происхождение данных

Проверено 2026-10-30.

1. E1e, run `20261030-150813-643fdd30`: итог, MIXED_EQUATIONS.json (5566 записей), SMALL_UPPER_SETS.csv, четыре сохранённые matrix.bin/layout.json/native.json, список 173 неизвестных целей с 101 публичной точкой. Точные SHA-256 и исходные пути — в manifest.json E1f. Копии выбранных документов — в inputs/.
2. E6H, run `20261030-122003-bb9bb8`: CONCLUSION.md, REPORT.md, comparison.csv, README и toy.py. Известный отрицательный результат совместного chaincode-MITM принят как исходный; его цепочки и тесты не повторялись.
3. [Menezes, van Oorschot, Vanstone, Handbook of Applied Cryptography, Chapter 3](https://cacr.uwaterloo.ca/hac/about/chap3.pdf), §3.6.2, Algorithm 3.56, печатная стр. 105. Первичный учебный источник для baseline baby-step giant-step и его порядка операций/памяти. Использована интервальная версия после вычитания известной нижней границы из точки.

Разложение по характерам, доказательство ранга, границы через частные характеры, перечисление прямых сокращения и выводы о конкретных E1e-ветвях — собственные вычисления этого эксперимента; они не приписываются источнику BSGS. Внешние утверждения о невозможности извлечения битов ECDLP или доказанные нижние границы для произвольных алгоритмов не используются.
