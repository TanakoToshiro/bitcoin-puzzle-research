# E1f — арифметический подъём связей E1e и малые поправки

2026-10-30. Исходный E1e `20261030-150813-643fdd30` и E6H `20261030-122003-bb9bb8` прочитаны. Матрицы, сертификаты и старые журналы остаются неизменными. Новые вычисления — только анализ готовых строк и отдельные синтетические задачи на secp256k1. Цель — использование публичных точек без бесплатного знания верхних скаляров.

## Конечный объём до просмотра результатов

1. Четыре ветви: fixed-reverse-big-s1, fixed-forward-big-s1, api-bits_i-na-s1-zero (три начальных примера); api-order3-na-s1-zero — контроль pre_increment. Используются все 173 неизвестных скаляра, а не выбранные строки базиса. По сохранённым A/rhs и целевым строкам построить точные разложения числовых скаляров по характерам Boolean-группы, над полем порядка secp256k1. Проверить ранг матрицы этих коэффициентов. Полный ранг исключает универсальное арифметическое равенство с фиксированными коэффициентами modulo n на соответствующей семье состояний.
2. Для точного учёта границ работать на непустом аффинном срезе: старший непринудительный бит координаты №256 равен нулю. Для pre_increment дополнительно выбрать по одному нулевому биту каждой координаты из допустимого свидетеля: переполнение при +1 тогда невозможно. Отсутствие тождества даже на таком срезе исключает тождество на всей семье. Это не исключает тождества на других специально выбранных подсемействах.
3. На тех же разложениях исследовать комбинации двух доступных публичных скаляров. Включить все 101 опубликованную точку среди 173 неизвестных (№140,145,150,155,160 и №161–256). Для пары коэффициенты нормируются к (1,b). Рассматривать ±1 и все b, способные сократить хотя бы один общий ненулевой характер; прочие b имеют тот же набор оставшихся характеров. Это конечный полный анализ наборов поддержки для двухчленных комбинаций, а не перебор n коэффициентов. Измерять число независимых GF(2)-форм оставшейся поправки, число членов и частные характеры каждого скаляра. Не объявлять размерность нижней границей для всех алгоритмов.
4. Не перебирать большие поправки. Для исследуемого перечислительного метода потолок реального применения: 32 независимых неизвестных бита и доказанная аддитивная разделимость для MITM. Если соответствующая малая поправка не найдена, зафиксировать препятствие; не запускать DLP настоящих адресов.
5. Новый синтетический положительный контроль: X=2^w+x, Y=2^w+(x XOR C), C публично, popcount(C)=r. Из QX,QY вычисляется D=QX−QY+C G=2(x AND C)G. MITM по r выбранным битам определяет только поправку; полного x алгоритм не получает. Цель t — упаковка этих r битов, опубликован только HASH160((2^r+t)G). Независимые методы: BSGS верхнего x и прямой поиск цели по HASH160. Метод сравнения выбирается заранее по худшим оценкам стоимости, дополнительно измеряются оба.
6. Синтетические (w,r): (12,4),(16,8),(20,8),(24,12),(28,16),(28,20), и плотные контроли (12,12),(16,16),(20,20), по два экземпляра. Все операции проходят на настоящей secp256k1 с уменьшенными диапазонами. Не повторять Armory-chaincode модели E6H. Измерять сложения/удвоения/хеши/поиски в таблице, число записей, пик Python-памяти tracemalloc и время. Tracemalloc не измеряет внутреннюю память libsecp256k1; явно указать границу метрики.
7. Алгоритм запускается отдельным процессом и принимает только JSON с публичными параметрами, точками и целевым HASH160. Его модуль не читает файлы и не получает seed или приватные значения. Истина текущего случая хранится только в памяти проверяющего процесса до завершения всех алгоритмов случая; затем сохраняется для воспроизводимости. Это разделение интерфейсов исследования, не утверждение о защите от вредоносного процесса с доступом ко всему компьютеру.

## Контроли

Исчерпывающая проверка Fourier/Walsh-разложения и ранга на малых Boolean-примерах, включая известное арифметическое тождество и его отсутствие; исключение ошибочной замены XOR сложением; pre_increment с переполнением и срез без него; скалярная граница. Положительные/отрицательные задачи публичного алгоритма, согласие с прямым поиском на малых случаях. Сверка разложения реальных строк на новых допустимых состояниях, без их передачи публичному алгоритму. Проверка хэшей входов и пропуска завершённых стадий.

## Границы вывода

Ранг по характерам исключает только универсальные арифметические линейные комбинации скаляров в данной семье. Он не исключает алгоритмы с коэффициентами, вычисленными нелинейно из конкретных публичных точек, специальные подсемейства, дополнительные наблюдения или иной генератор. Размерность поправки описывает стоимость испытанной параметризации, не доказанную сложность ECDLP. При неизвестной целевой точке нельзя применять BSGS к её HASH160. Новый положительный синтетический пример сам по себе не переносит выигрыш на E1e.
