# Что доказывает граница для нескольких публичных точек

Эта постобработка использует сохранённые новые разложения E1f, не пересчитывает матрицы E1e и не меняет основной протокол. Полные числовые результаты находятся в `multi-bounds/`, `triple-arrangements/` и `MULTI_BOUND_VERIFICATION.json` текущего запуска.

## Размерность линейной параметризации

Для F(z)=c+Σ a_m χ_m(z), a_m≠0, множество периодов t функции F равно ортогональному дополнению линейной оболочки её ненулевых m. Действительно, из F(z+t)=F(z) для всех z и независимости характеров следует a_m(χ_m(t)−1)=0 для каждого m. В поле нечётной характеристики это эквивалентно <m,t>=0.

Если F можно записать h(Lz) для линейной GF(2)-карты L, её ядро состоит из периодов F. Поэтому rank(L) не меньше rank(span{m}). Равенство достигается выбором базиса этой оболочки. Таким образом, измеренный ранг — **минимальное число линейных двоичных параметров** для точного описания функции на данном срезе. Замена базиса GF(2) сама по себе его не уменьшит.

Это не размер образа F. Например, AND d битов имеет два значения, но Fourier-поддержка порождает d-мерное пространство. Поэтому ранг r не доказывает наличие 2^r различных поправок, r бит энтропии или необходимость 2^(r/2) операций у произвольного алгоритма. Вывод относится к испытанному перечислению линейных параметров и к отсутствию малой sparse-mask структуры. Компрессия числового образа F здесь не исключена.

## Как охвачены все фиксированные коэффициенты нескольких точек

Для каждого из 173 столбцов известны все его характеры. Глобально частный характер встречается только в одном столбце. При любом ненулевом коэффициенте этого столбца он остаётся в сумме, сколько бы других столбцов ни добавили. Ранг объединения таких частных форм — нижняя оценка ранга остатка для любого набора ненулевых коэффициентов выбранных столбцов.

Для 101 доступного публичного столбца:

1. Двухчленные комбинации нормируются к коэффициентам (1,b), b≠0. Набор оставшихся характеров меняется лишь при b=−a_i/a_j для общего характера. Все такие значения и один общий представитель остальных значений проверены. Сдвиги/знаки и любые иные фиксированные коэффициенты modulo n входят в эту проверку.
2. Если частный ранг любой пары в тройке ≥140, то ранг всей тройки ≥140. Только треугольники графа слабых пар требуют новой проверки. В трёх ветвях слабых пар нет; в bits_i имеется 49 рёбер и 63 треугольника. Лишь две тройки имеют частный ранг <140.
3. Для этих двух троек коэффициенты (1,b,c), b,c≠0, проверяются через прямые отмены a+b*d+c*e=0. Поддержки могут различаться только вне всех прямых, на одной прямой вне пересечений и в пересечениях. В обоих случаях найдено две прямые и три класса; минимальные фактические ранги 458 и 461. Случаи с нулевым коэффициентом уже охвачены парами.
4. Любое множество из четырёх столбцов содержит четыре различные тройки. Всего две тройки не имеют частной нижней оценки ≥140; значит, в любом четырёхэлементном наборе есть тройка с нужной **глобально частной** оценкой. Она сохраняется при добавлении любых столбцов. Поэтому все наборы размера ≥4 также имеют ранг ≥140. Для этого не требуется перебор четырёх-, пяти- и остальных наборов.

Отдельно для формул с неизвестной точкой №71 получены нижние оценки через объединение её частных форм с формами каждого доступного публичного столбца. Добавление дальнейших столбцов их не уменьшает. Но неизвестный HASH160 не даёт групповую цель для BSGS/MITM по этой поправке.

Границы вычислены на допустимых непустых аффинных срезах. Любое линейно-параметризованное описание всей исходной функции при ограничении на срез остаётся описанием не большей размерности. Поэтому нижние оценки на срезе применимы к такой параметризации полной семьи. Они не утверждают, что множество реальных состояний после учёта конкретных публичных точек совпадает с этим срезом.
