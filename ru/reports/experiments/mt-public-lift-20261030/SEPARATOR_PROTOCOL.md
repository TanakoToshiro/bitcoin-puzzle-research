# Дополнительный контроль: XOR со сдвигом, неизвестная поправка

Постановка добавлена после завершения основной серии, до запуска этих контролей. Sparse-mask положительный пример существенно проще MT: маска известна. Чтобы проверить смешанные члены, добавить X=2^w+x, Y=2^w+(x XOR ((x<<s) mod 2^w)). Целевой остаток — младшие w−2 бита x, публикуется только его HASH160. Полные x,y доступны только проверяющему процессу.

Публичный алгоритм использует D=QX−QY. Разделение x на две половины не разделяет XOR-члены на границе. Фиксируются s нижних граничных битов; при каждом назначении остаточная сумма точно раскладывается в левую и правую части. Выполняется MITM по точкам этих частей. Совпадение поправки не доказывает правильность назначения: каждый кандидат дополнительно сверяется с QX. Все расходы, включая эти проверки, учитываются.

Оценка до запуска: h=floor((w+s)/2), по 2^(h−s) левых и 2^(w−h) правых назначений при каждом из 2^s граничных состояний. Верхняя оценка работы O(2^((w+s)/2)) с постоянным числом изменений точек на Gray-шаг; память O(2^((w−s)/2)) записей. Независимый interval BSGS x требует O(2^(w/2)); ожидаемого улучшения показателя нет. Этот тест проверяет точность препятствия, не заявляет новый быстрый метод.

Конечный объём: w=12,16,20; s=2,4; по два свежих экземпляра. Максимум 8192 суммарных назначений половин на один случай, плюс проверки коллизий и подготовка. Никакого поиска настоящих скаляров. Сравнение с interval BSGS того же публичного X, затем вычисление целевого HASH160; при этих параметрах прямой поиск целевого HASH160 имеет более высокую ведущую оценку. Не повторять цепочки E6H. Малые исчерпывающие контроли w=5, s=1,2 должны пройти до серии.
