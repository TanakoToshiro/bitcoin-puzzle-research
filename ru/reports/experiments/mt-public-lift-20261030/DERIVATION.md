# Точные равенства и область проверяемого отрицательного результата

Пусть после известных линейных наблюдений каждый бит имеет вид b_j(z)=c_j XOR <m_j,z>, где z — свободные двоичные координаты. Над нечётным простым полем F_n ввести χ_m(z)=(-1)^<m,z>. Тогда

`2 k_i(z) = constant_i + Σ_m d[i,m] χ_m(z) (mod n)`,

где вклад непринудительного бита j с ненулевым m равен `d=−(-1)^c * 2^j`; одинаковые m объединяются. Фиксированные биты входят в константу. Характеры линейно независимы над F_n: матрица Walsh удовлетворяет H Hᵀ=2^d I, а 2 обратимо modulo n. Поэтому `Σ a_i k_i = c mod n` тождественно на аффинной семье тогда и только тогда, когда `Σ a_i d[i,m]=0` для каждого ненулевого m. Это проверка всех фиксированных коэффициентов modulo n одновременно, не подбор нескольких строк GF(2).

Полный столбцовый ранг исключает вычисление целевой точки фиксированной линейной комбинацией остальных точек и G, корректной для всей семьи. Ненулевые миноры/треугольные свидетельства ранга сохраняются. Публичные точки не подставляются вместо неизвестных битов скаляров.

В pre_increment координата x не равна младшим битам k:

`k = 2^w + x + 1 − 2^w * [x=2^w−1]`.

Индикатор переполнения в общем случае имеет до 2^rank характеров; его нельзя бесплатно опустить. Для отрицательной проверки выбирается непустой аффинный срез, содержащий нулевой бит каждого x. На нём индикатор точно равен нулю. Если тождества нет даже на этом срезе, его нет на всей исходной семье. Условие старшего бита координаты №256=0 гарантирует допустимость скаляра, включая +1: k256≤3*2^254<n. Изменения от этих срезов не объявляются новыми наблюдениями puzzle.

Для XOR двух целых:

`x XOR y = x + y − 2(x AND y)`.

Даже это равенство не даёт точку `(x XOR y)G` по xG,yG без точки `(x AND y)G`. Выделение части скаляра также не является групповым гомоморфизмом. Сдвиги с отбрасыванием битов требуют неизвестного отброшенного остатка; modulo n нельзя заменять modulo 2^w.

Полезный частный случай — публичная маска C и Y=2^w+(x XOR C), X=2^w+x. Тогда

`D = QX − QY + C G = 2(x AND C)G`.

Если C содержит r единиц, D имеет вид суммы r известных точек `2^(j+1)G` с неизвестными двоичными коэффициентами. Разделение этих r позиций пополам даёт MITM за O(2^ceil(r/2)) сложений/записей. Не требуется узнавать оставшиеся w−r битов x. Проверка кандидатов и исходные операции включаются в стоимость. При r≈w преимущество по показателю перед независимым BSGS x отсутствует; при r≪w и доступной паре QX,QY возможен действительный выигрыш. Испытание проверяет именно этот механизм.

У произвольного оставшегося Walsh-полинома m разных характеров могут зависеть от r независимых форм. Полное перечисление параметров имеет 2^r назначений. MITM с показателем r/2 не следует автоматически: характер, зависящий от переменных обеих половин, нарушает аддитивное разделение. Поэтому r/2 используется лишь как явно оптимистический ориентир там, где разделимость не доказана; реальный алгоритм запускается только для разделимой sparse-mask модели. Большое r не является универсальной нижней границей для других математических методов.

Базовый BSGS: [Handbook of Applied Cryptography, §3.6.2, Algorithm 3.56](https://cacr.uwaterloo.ca/hac/about/chap3.pdf). Для ограниченного интервала длины N используются O(sqrt(N)) групповых операций и записей; в контролях известная нижняя граница вычитается из точки. Для целевого HASH160 без самой точки этот алгоритм неприменим: отдельный baseline проверяет кандидатов последовательно.
