# Сопоставление соседних исторических версий

Это сравнение исходников, не отдельная сборка/исполнение дополнительных runtime. Сопоставлены целиком Modules/_randommodule.c и Lib/random.py, сохранены commit, SHA-256 и diff. При любом отличии токенов автоматическое расширение отрицательного вывода не производится.

| Версия | Эталон | Оба файла совпали с точностью до пробелов |
|---|---|---|
| 2.7.8 | 2.7.9 | да |
| 3.4.1 | 3.4.2 | нет — требуется отдельный аудит diff |

В Python 3.4.1 единственное отличие обёртки от 3.4.2 находится в triangular(), который здесь не вызывается. Дополнительно сопоставлены AST методов __init__, seed, randrange, randint, _randbelow: они совпадают. C-ядро совпадает побайтно. Поэтому использованные алгоритмы выдачи и integer seeding эквивалентны для обеих соседних версий; это перенос по равенству исходников, не заявление о запуске четырёх runtime.

Машинный результат и ссылки на официальные commit — артефакт исходного исследования (`adjacent-version-audit/AUDIT.json`; вне снимка). Совпадение относится к исходникам генератора и Python-обёртки при тех же математических/платформенных предположениях. Другие версии, изменённые сборки и неохваченные протоколом API не считаются проверенными.
