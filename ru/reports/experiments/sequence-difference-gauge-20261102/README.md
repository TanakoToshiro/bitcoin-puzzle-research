# SEQ-08 — соседние разности до построения решётки

[Итоговый отчёт](<FINAL_REPORT.md>). Парное сравнение нового исключения
общего сдвига и принятого метода SEQ-07B на одних и тех же новых входах.
Модуль и дробно-линейная модель остаются прежними.

Зарегистрированы 72 входа и 144 метод-запуска: панели 5/9/13,
равномерная шкала 12,16,20,24,32,48,64,80,96,120 скрытых битов,
случайные контроли и отдельные положительные контроли с настоящими масками.
Наличие кандидатов, таймауты и ограничение общего бюджета учитываются
раздельно. Единственность всех классов и полнота LLL-поиска не заявляются.

Команды из корня проекта в PowerShell:

> Исполняемый код/команды опущены в документационной копии.


Сначала проверяется целостность. При наличии результатов команды
не повторяют LLL и дописывают только `JOURNAL.jsonl`. Для новой серии
нужна отдельная папка: принятые пакеты не удалять и не перезаписывать.

- `PROTOCOL.md`, `MANIFEST.json`: заранее заданная постановка, seed, код,
  лимиты и допуск реального поиска.
- `difference_solver.py`: новая система на соседних разностях.
- `solver.py`, `translation_decoder.py`, `mobius.py`: идентичные копии
  принятых реализаций для парного контроля и условного решателя сдвига;
  источник подтверждает `PROVENANCE.json`.
- `data.py`, `inputs/`: новые контрольные цепочки; истина не передаётся
  в функции восстановления.
- `results/legacy/`, `results/differences/`: раздельные исходы двух методов.
- `lattices/`: сжатые точные сертификаты редукции, без скрытого перебора.
- `audit.py`, `audit_common.py`, `audit_packets/`, `AUDIT.json`:
  независимое раскрытие коэффициентов, проверка решёток и просмотр всех
  строк ±S другим декодером. Старые стадии не исполняются.
- `CONTROLS.json`, `COMPARISON.json`, `PAIRED_MEASUREMENTS.json`:
  сводка успехов, времена и парные различия.
- `REAL.json`: структурный расчёт и статус допуска каждого метода/панели.
- `PRIOR_SNAPSHOT.json`: SHA256/mtime прежних принятых файлов SEQ-01..07.
- `ENVIRONMENT.json`: хэши существующих зависимостей, без установки.
- `ACCEPTANCE.json`, `COMPLETE.json`, `ARTIFACTS.json`: приёмка и целостность.

Один вычислительный CPU-процесс. Python 3.11.9, python-flint 0.9.0,
SymPy для аудита. Никаких GPU-стадий, внешних поисков или новых пакетов.
