## Что изменилось в математике

Модель прежняя: `s_next=(A*s+B)/(C*s+D) mod n`, det!=0, C!=0,
без полюсов в первых 135 состояниях. n — порядок secp256k1; наблюдаются
младшие i−1 битов. Историческая атрибуция генератора не установлена.
Верхние наблюдения №75,80,...,135 имеют шаг 5 и подчиняются переходу M^5.

Вместо абсолютных скрытых состояний используются соседние целые разности
`D_j=s[j+1]−s[j]`. Кубическое условие двойного отношения принимает вид:

```text
G = D1*D3*(D0+D1) − D0*D2*(D2+D3) = 0 mod n.
```

Общий сдвиг отсутствует уже в системе переменных, до LLL. На панели
из k состояний остаются k−1 разностей. Для неодинаковых масок записано:

```text
s_j = r_j + 2^b_j*q_j, 0 <= q_j < C_j
D_j = r_(j+1) − r_j + 2^b_j*v_j
v_j = 2^(b_(j+1)−b_j)*q_(j+1) − q_j
−(C_j−1) <= v_j <= 2^(b_(j+1)−b_j)*(C_(j+1)−1).
```

Это формула целой разности исходных состояний в [0,n). Перенос mod n
не отбрасывается под видом известного младшего остатка. Указаны точные
границы интервальных оболочек; независимость разных v_j не предполагается.
После восстановления относительного хода их совместимость проверяется
точными интервалами общего сдвига по всем 83 наблюдениям.

Каждое G линеаризуется по мономам; строится взвешенная модульная решётка.
Выполняется одна LLL с прежними настройками, рассматриваются только строки
с последней координатой ±S. Из линейных координат получаются кандидаты
разностей; обратными суммами восстанавливаются относительные состояния
с z[135]=0. Затем проверяются M^5, единственный пятый корень M, отсутствие
полюсов, весь относительный ход и все исходные маски.

Дополнения состояний, значения общего сдвига и комбинации строк не
перечисляются. Как в SEQ-07B, вспомогательные мономиальные координаты
не выдаются за настоящие произведения: кандидаты принимаются только
после проверки исходной нелинейной модели.
