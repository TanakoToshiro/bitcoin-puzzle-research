# SEQ-20/21 — завершение малого цикла применимости на исходных масках

Две отдельные гипотезы; параметры и решения о допуске для каждой независимы. Общие код и аудит не объединяют их положительные контроли. Этот цикл завершается этими двумя проверками; автоматического расширения семейств или лимитов нет.

## Модели и фильтры

**SEQ-20, alternating:** `s[i+1]=a*s[i]+b+c*(-1)^i mod n`.
Для S[j]=s[75+5j] применяем T[j]=S[j+2]-S[j], фильтр [-1,0,1]. При a не 0,1,-1 решение состоит из геометрической, постоянной и чередующейся частей; фильтр устраняет последние две. T[j+1]=a^5*T[j]. Резонансные a=1/-1 проверяются отдельно, та же необходимая связь сохраняется при ненулевом T.

**SEQ-21, quadratic:** `s[i+1]=a*s[i]+b*i²+c*i+d mod n`.
Применяем T[j]=S[j+3]-3*S[j+2]+3*S[j+1]-S[j], фильтр [-1,3,-3,1]. При a!=1 решение — геометрическая часть плюс полином степени 2; третья разность устраняет полином. Для a=1 состояние является полиномом степени 3 и T постоянна. В обоих случаях T[j+1]=a^5*T[j].

n — порядок secp256k1. Наблюдения: младшие i-1 бит, 83 прежних индекса 1..70 и 75..135 с шагом 5. Старший принудительный бит не учитывается; пропуски не сжимаются. Детектор читает только 13 последних наблюдений, остальные сохраняются. Ни коэффициенты модели, ни полные состояния ему не передаются.

Положим z[j]=S[j]/2^(74+5j) mod n. Для фильтра v[h] нормированная разность t[j]=sum(v[h]*32^h*z[j+h]) имеет отношение rho=a^5/32. Для наблюдаемых остатков получаем Y и неизвестную целую ошибку e=sum(v[h]*32^h*u[j+h]), u[j]=floor(S[j]/2^(74+5j)). Верхняя граница |e[j]|*2^(74+5j) < B*n, где B=1 для alternating, B=4 для quadratic. Именно эти границы задают веса, а не результаты калибровки.

## Фиксированные размеры

В каждой модели k=4,5,6,7, SymPy LLL delta=3/4. alternating: 11 значений Y, размер 12×12, веса коэффициентов 2^(182-5j). quadratic: 10 значений Y, размер 11×11, веса 2^(184-5j). Вес окна 32^i. Базис: k диагональных коэффициентных строк с центрированными Y в оконных координатах и dim-k диагональных n-строк. Известные биты не добавляются. Ни увеличения решёток, ни перебора коэффициентов, ни полного восстановления состояний.

## Контроли — отдельно для каждой модели

180 новых входов на модель:

- 32 generic: 16 calibration + 16 validation. alternating: c!=0, a не 0,1,-1; quadratic: b!=0, a не 0,1. Отбрасываются только случаи t[0]=0 и указанные вырождения.
- 12 affine sanity: добавка постоянна, a вне вырождений, t[0]!=0.
- 8 special: alternating — четыре a=1 и четыре a=-1; quadratic — восемь a=1. t[0]!=0. Только описательная проверка специальных случаев, не настройка порога.
- 128 null: независимые равномерные полные состояния в [0,n), 64 calibration + 64 validation.

Домены SHAKE256: SEQ-20-21-final-v1/{model}/..., rejection sampling. Все состояния, seed-метки, разбиение и непрозрачные ID фиксируются до запуска. Worker получает только ID, название тестируемой модели и наблюдения; не семейство, параметры или разбиение. Реальные входы RALT/RQUAD тоже фиксируются заранее, исполняются только после допуска соответствующей модели.

## Два канала для каждой модели

Полиномы всех четырёх редукций приводятся к monic mod n и объединяются без масштабных дубликатов с сохранением k. НОД всех пар ищутся вслепую. Кандидат — НОД ровно степени 1 с ненулевым свободным членом. Счёт: число различных кратных ему полиномов, если они представлены минимум в двух k, иначе 0. Порог 4; общий score — максимум по кандидатам. rho=-F[0], a — единственный пятый корень 32*rho (gcd(5,n-1)=1). Большие НОД сохраняются, не факторизуются. Это кандидат связи, не доказанный исходный генератор.

Краткость: S=max_k(log2(det B)/dim-log2(min norm2)/2), округление 10 знаков. Минимум только среди строк с минимум двумя ненулевыми коэффициентами полинома mod n; нули, константы и мономы исключены. Порог — максимум на 64 calibration null этой модели; превышение строгое. Это статистический признак, не HG-сертификат.

Все 180 синтетических входов соответствующей модели должны завершиться, affine sanity >=10/12. Допуск множителей: истинный F на >=14/16 validation generic, ложные срабатывания 0/64 validation null. Допуск краткости: >=14/16 validation generic выше порога, <=1/64 validation null выше; все S определены. Special не входят в численные пороги чувствительности. Отдельно сообщаются результаты обеих половин.

Если хотя бы один канал модели проходит, исполняются четыре реальные решётки этой модели. Интерпретируются только прошедшие каналы. Для них p=(1+#null score>=real)/129, поправка min(1,4p) на четыре заранее зарегистрированных канала двух моделей, alpha=0.05. Максимум по k уже включён в score. Эта поправка относится к текущей паре тестов, не ко всей истории исследований. Реальные ключи многократно использовались, поэтому не являются независимым holdout; p не вероятность гипотезы.

Если оба канала модели не проходят, реальная стадия для неё не запускается. Таймаут, ошибка, отсутствие чувствительности и эвристическое отсутствие кандидата — разные статусы. Ни один не объявляется строгим отрицанием существования скрытой цепи.

## Бюджет, источники, аудит

Один worker последовательно. 5 с на вход включая запуск Python, 1200 с на модель, общий предел 2400 с. До 360 синтетических и двух реальных попыток. Прямой sys._base_executable, CREATE_NO_WINDOW, worker не создаёт дочерних процессов. Все статусы, stderr, времена и матрицы сохраняются, автоматических повторов нет. Аудит/хеширование считаются отдельно.

Из SEQ-19 без изменения копируются relations.py, recovery.py, probe.py и known_solutions.json с проверкой seal. Используются полиномиальные helpers и collect(), но не прежние lattice(), norms() или recover(). Новый detector.py задаёт две конструкции явно. vendor сверяется с SEQ-17 ENVIRONMENT.json.

До запуска фиксируются протокол, научный код, аудитор, inputs, зависимости и разбиение. Использованные источники хешируются сразу. Для 9719 прежних артефактов сначала сверяются метаданные, в итоговом аудите выполняется один полный SHA-256 проход; старые результаты не изменяются. Общий seal покрывает обе серии и их отдельные итоги.

Аудитор независимо проверяет полные 135 состояний закрытыми формулами, необходимые связи, границы ошибок, матрицы из наблюдений, U*B=L, det(U)=+-1, полиномы и все НОД через FLINT, нормы, поддержку и правила допуска. Каждая реальная стадия должна следовать после сохранённого допуска своей модели. Отчётные документы могут создаваться после фиксации; научные критерии не меняются.
