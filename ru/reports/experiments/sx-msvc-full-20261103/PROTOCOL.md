# SXM-03 — полный проход исторической SX/MSVC low-byte модели

Авторизован пользователем 2026-11-03 после SXM-02. Отдельная серия; прежние
контроли и пилот не включаются в реальное покрытие.

- Весь uint32 seed: [0, 4294967296), включая 0 и 4294967295.
- MT19937 с одним uint32 seed; 32 последовательных draw, entropy[j] = draw & 255.
- entropy напрямую в BIP32. Ровно прежние 20 схем id 20–39 из SCHEMES.json.
- Для номера i: индекс i + offset, при hard добавляется 2^31;
  ключ пазла = 2^(i-1) + (child_key mod 2^(i-1)).
- GPU-фильтр №50: 49 младших битов известного ключа. Прошедший кандидат
  проверяется независимой CPU affine реализацией по всем №1–50.
  №51+ не участвуют в фильтре и не используются для выбора модели.
- 4096 последовательных блоков по 1048576 seed; 85899345920 seed×scheme.
- Неизменённая принятая библиотека CUDA SXM-01, launch_threads=128.
- Каждый завершённый блок атомарно сохраняется с границами, счётчиками,
  SHA256 предыдущего блока и конфигурации. fsync перед replace. Незавершённый
  блок не считается покрытым. Межпроцессный lock исключает двойной запуск.
- Ошибка CUDA, недопустимый BIP32-узел, overflow или изменение входов запрещают
  принимать результат. Кандидат сохраняется до CPU-проверки. Полное совпадение
  training останавливает серию для отдельной проверки; ложный фильтр сохраняется
  в блоке и поиск продолжается.
- До старта: сверка печатей SXM-01/02, синтетические положительные/отрицательные
  GPU-контроли всех 20 схем, верхняя граница seed, переполнение и ошибки,
  контроли resume/lock/повреждения. После: повтор GPU-контролей и независимое
  чтение всех 4096 файлов, проверка диапазонов, цепочки и входных SHA256.

Историческое ограничение: обычный pipe SX hd-seed → hd-priv этого снимка
ломается из-за LF/CRLF; точный xprv без перевода строки работает. Исследуется
генератор и определённые HD-схемы, не буквальный неисправный shell-конвейер.
Отрицательный результат исключает только эту конечную постановку, не SX/MSVC
вообще и не любые другие способы генерации пазла.
