# SEQ-07, 02.11.2026

Из инварианта двойного отношения выведено кубическое условие на пять
соседних по шагу 5 скрытых состояний, без параметров дробно-линейного
перехода. Построены мономиальные решётки размерностей 27/91/155.

Строгий декодер SEQ-07A дал 0/60 усиленных положительных восстановлений.
Диагностика показала правильные разности при изменённом общем сдвиге.
Отдельно зарегистрирован SEQ-07B: относительная цепочка, затем точное
пересечение интервалов для общего сдвига; перечисления дополнений нет.

На 24 новых положительных примерах (панели 5/9/13, h=2/4/8/12) найдены
24 истинных класса; внутри каждого синтетический ключ №71 однозначен.
На h=12 остаются 44–123 допустимых полных состояния, поэтому единственность
полного состояния не заявляется. Шесть новых случайных наборов дали 0 классов.
Дополнительно 60/60 старых усиленных примеров восстановлены новым декодером,
но это диагностическая, не независимая подтверждающая выборка.

Настоящие маски: 0/6 в SEQ-07A и 0/6 на новых примерах SEQ-07B.
Реальный поиск не запускался; модель открыта, реального ключа/бита нет.

Независимо проверены 114 решёток, 84 класса, 300 малых условных задач
сдвига. Все 714 прежних принятых файлов SEQ-01..06 сохранены SHA256/mtime.
Run `SEQ-07-a387b84e2164`; полный отчёт `FINAL_REPORT.md`.
