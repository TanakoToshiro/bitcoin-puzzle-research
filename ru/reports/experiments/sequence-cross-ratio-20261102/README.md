# SEQ-07 — двойное отношение и относительное скрытое состояние

[Итоговый отчёт](<FINAL_REPORT.md>). На 24 новых усиленных контролях
восстановлены классы, содержащие истинные цепочки; условная проекция
на синтетический ключ №71 во всех случаях однозначна. Настоящие маски
положительный допуск не прошли, реального поиска и исключения модели нет.

SEQ-07A — мономиальная решётка со строгим декодером. SEQ-07B — отдельно
зарегистрированный декодер класса сдвигов и новые контрольные данные.
Результаты первого подхода сохранены без подмены.

Сначала проверяется целостность. При наличии результатов команды
пропускают вычислительные стадии, дописывая только `JOURNAL.jsonl`,
исключённый из манифеста целостности. Результаты для повторного расчёта
не удалять: отдельный новый эксперимент должен иметь свою папку.

- `PROTOCOL.md`, `MANIFEST.json`: исходная постановка и замороженный код.
- `translation/PROTOCOL.md`, `translation/MANIFEST.json`: новый декодер,
  его причина и независимые контрольные примеры.
- `solver.py`: кубические условия, модульная линеаризация, LLL и строгий декодер.
- `translation_decoder.py`: проверка относительной цепочки, точные интервалы
  общего сдвига и условная проекция ключа №71.
- `inputs/`, `results/`, `lattices/`: 78 исходных пакетов и сжатые сертификаты.
- `translation/inputs/`, `translation/results/`, `translation/lattices/`:
  36 новых пакетов; контрольная истина хранится отдельно от входа решателя.
- `translation/DIAGNOSTIC.json`: применение нового декодера к старым
  контрольным решёткам; не независимая подтверждающая выборка.
- `audit.py`, `audit_packets/`, `AUDIT.json`: независимая проверка без новой LLL.
- `REAL.json`, `translation/REAL.json`: структурная оценка и закрытый допуск.
- `ENVIRONMENT.json`: SHA256 1792 файлов локальных зависимостей.
- `PRIOR_SNAPSHOT.json`: SHA256 и mtime 714 прежних принятых файлов.
- `ARTIFACTS.json`, `ACCEPTANCE.json`, `COMPLETE.json`: целостность и границы приёмки.

Python 3.11.9, существующий python-flint 0.9.0; SymPy только для аудита.
Пакеты не устанавливались. Один вычислительный CPU-процесс, без GPU.
Не принимать `heuristic_no_candidate` за доказательство несовместимости;
не принимать один найденный класс за доказательство глобальной единственности.
