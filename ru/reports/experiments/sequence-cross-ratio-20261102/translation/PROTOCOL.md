# SEQ-07B — декодирование класса сдвигов

Отдельная зарегистрированная проверка после диагностики SEQ-07A.
SEQ-07A остаётся неизменным и не переименовывается в успешный эксперимент.
В первой рассмотренной положительной задаче при h=2 линейные координаты
строки LLL отличаются от истинных на общий сдвиг +1. Это основание
изменить декодер; исходные усиленные данные не используются как новые
независимые контроли.

Решётка, масштабирование, панели, единственная LLL и просмотр строк ±S
остаются прежними. Новый декодер использует только линейные координаты;
он НЕ предполагает, что прочие координаты равны их мономам. Полученные
состояния приводятся mod n, затем из всех вычитается состояние №135.
Относительные значения проверяются по исходным кубическим F и полному
относительному дробно-линейному ходу. Любая ложная строка отбрасывается.

Пусть z[135]=0 и t=s[135]=r[135]+2^b*q. b не меньше всех наблюдаемых
масок. Тогда s[i]=(z[i]+t) mod n. Для каждого i возможны только два
режима переноса w=0/1. Проверка остатка становится
`(z[i]+r[135]−w*n) mod 2^b_i == r[i]`, а режим переноса задаёт интервал
для q. Интервалы пересекаются точно; q не перечисляются.

Таким образом восстанавливается класс допустимых сдвигов, а не обязательно
единственная матрица/состояние. Условная проекция на младшие 70 битов
состояния №71 содержит не более двух значений, если b>=70. Их единственность
внутри найденного класса не доказывает единственность всех классов модели.

Входы и код фиксируются до запуска новых цепочек:
- панели 5/9/13, h=2,4,8,12; по одному общему и инверсивному примеру:
  24 новых усиленных положительных контроля;
- по два случайных набора h=4 на панель: 6 отрицательных контролей;
- по одному общему и инверсивному примеру с настоящими масками на панель:
  6 контрольных задач допуска;
- прежние 78 наборов используются отдельно как диагностическая выборка,
  только с уже сохранёнными LLL, без новой редукции;
- точный условный решатель сдвига сверяется полным перебором на малых
  полях; независимый аудит строит интервалы другим способом.

30 секунд на новый пример, 10 минут на всю новую серию. Свой допуск
реального поиска для каждой панели: обе новые цепочки с настоящими
масками должны восстановить класс, содержащий истину. При неполучении
допуска — никакой интерпретации нулевого результата как исключения модели.
Ни GPU, ни установки, ни перебор четырёх дополнений не используются.
