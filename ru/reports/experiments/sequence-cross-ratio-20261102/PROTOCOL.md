# SEQ-07 — восстановление через двойное отношение

02.11.2026. Продолжение SEQ-06 по прямому указанию пользователя.
Протокол фиксируется до синтетических восстановлений и обращения к
реальным остаткам. Старые SEQ-01..06 сохраняются SHA256 и mtime.
Один CPU-процесс вычислений, без GPU/установок; существующий python-flint.

## Условия и новое уравнение

Та же модель M: s_next=(A*s+B)/(C*s+D) mod n, det(M)!=0, C!=0,
без полюсов на позициях 1–135. n — порядок secp256k1.
Наблюдаем r[i]=s[i] mod 2^(i−1), индексы 1–70 и 75,80,...,135.

Для пяти последовательных по шагу 5 состояний a,b,c,d,e:

```text
F(a,b,c,d,e) = (a−c)(b−e)(c−d) − (a−d)(b−c)(c−e) = 0 mod n.
```

Это равенство двойных отношений соседних четвёрок после сокращения
ненулевого b−d. Для невырожденных соседних троек оно равносильно
продолжению единственного дробно-линейного отображения a→b→c→d на e.
Рассматривается проективное двойное отношение: период 3, где обычный
знаменатель может быть нулём, не исключается ошибочно. Повторяющиеся
соседние тройки не дают общей достаточности; требуется финальная проверка.

## Решётка без перебора дополнений

Панели: последние 5, 9 или 13 известных верхних состояний с шагом 5.
В каждой опоре s_i=r_i+2^b_i*(center_i+u_i), где center_i — середина
точного диапазона допустимых дополнений. Подставляем в F; получаем
кубические сравнения в u. Все встречающиеся непостоянные мономы заменяем
переменными y. Получаем A*y+c=0 mod n; это ослабление исходной системы.

Строим точную целочисленную решётку ядра этих сравнений и один сдвинутый
слой для c, используя модульное исключение Гаусса. Координаты масштабируем
по верхним степенным границам мономов. Добавляем одну координату вложения
со значением масштаба S. Один LLL (delta=0.99, eta=0.51) на панель/пример.
Просматриваем только строки с последней координатой ±S. Ни дополнения
четырёх состояний, ни комбинации строк решётки не перебираются.

Каждая строка проверяется: делимость масштабов; пределы u; равенство всех
мономов произведениям восстановленных u; истинность исходных F;
невырожденная матрица M^5 из последних четырёх состояний; единственный
пятый корень M; C!=0; отсутствие полюсов; все 83 наблюдения.
Непосредственно при редукции и при аудите проверяются T*B=L и det(T)=±1.

LLL/вложение здесь эвристический искатель короткой строки. Отсутствие
найденной модели не исключает модель. Один найденный кандидат не
доказывает единственность. Объём ослабленной мономиальной системы —
диагностика, не нижняя граница сложности исходной нелинейной задачи.

## Зарегистрированные проверки

1. Алгебра: все 7^5 пятёрок над F7; эквивалентность F и независимого
   восстановления дробно-линейной матрицы при невырожденных тройках.
   Отдельно вырожденные пятёрки, полюсы, период 3.
2. Независимое символическое раскрытие F и проверка мономов/центров;
   сохранение двойного отношения на синтетических траекториях.
3. Полный n: на каждой панели 5/9/13 по 2 общих и 2 инверсивных новых
   цепочки при 2,4,6,8,12 скрытых битах ВО ВСЕЙ выбранной панели.
   Итого 60 положительных задач. Вне панели маски остаются настоящими.
   Это усиленные данные, не настоящий профиль масок.
4. На каждой панели по 2 независимых случайных набора при h=4 и h=8:
   всего 12 отрицательных задач. Фильтрация всех кандидатов та же.
5. Полный n, настоящие маски: по одному общему и инверсивному примеру
   на каждой панели, всего 6 задач. Это отдельный допуск реального поиска.
6. Реальное восстановление допускается только для панели, восстановившей
   обе положительные цепочки с настоящими масками. Иначе разрешён только
   структурный расчёт размера/ранга/масштабов решётки на реальных данных.

Seed и список задач определяются кодом до запусков. Отказ от неудачных
примеров, подбор seed после результата или усиление реальных масок
не допускаются. Генерация неполярных цепочек — детерминированный
rejection sampling, число попыток сохраняется.

На одну задачу максимум 30 с, на все восстановительные задачи 10 минут.
Таймаут — самостоятельный неуспешный исход; он не равен отсутствию модели.
Новый алгоритм/панели/параметры после результатов в этот прогон не добавлять.
