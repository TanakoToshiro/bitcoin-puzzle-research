# DN-G02 — полный GPU-проход исторического System.Random

10 ноября 2026, Europe/Moscow. **Проход завершён и независимо проверен:
все 2 147 483 648 canonical seed проверены для каждой из16 схем.
Совпадений со всеми обучающими ключами нет. CUDA-ошибок и переполнений нет.
Один сбой записи STATUS устранён возобновлением из проверенных checkpoint.**

## Покрытие

- Точный диапазон `[0,2147483648)`, включая seed0 и2147483647.
- 2051 непересекающихся последовательных блоков, без пропусков.
- 2043 новых GPU-блоков: 2,141,454,336 seed.
- 8 ранее принятых GPU-пилотов: 6 029 312 seed, импортированы без пересчёта.
- Всего 34,359,738,368 пар seed/схема; внутренние выходы разделяются между16 схемами.
- Кандидатов0: ни одна пара не прошла все50 обучающих ключей. Holdout33
  используется только для проверки кандидата; в этом проходе до него не дошло.

## Какие гипотезы исключены

Исторический Microsoft System.Random из официального исходника2014-11-12,
один экземпляр на всю серию, исходные блоки по32 байта. Полный декартов набор:

| Параметр | Варианты |
|---|---|
| API | NextBytes / 32 вызова Next(256) |
| Числовой порядок32 байтов | unsigned big-endian / little-endian |
| Расход raw-блоков | stride1 / stride2 |
| Начальный raw-блок | phase0 / phase1 |

Для puzzle i: номер raw-блока `phase+stride*(i−1)`, отображение
`key_i=2^(i−1)+(raw_i mod 2^(i−1))`. Номера не сжимаются при пропусках.
Правила unchecked Int32 и double Next(256) сохранены из принятых CPU/GPU
контролей. Все signed Int32 seed покрываются canonical диапазоном:
обычные отрицательные дают тот же конструктор, что положительный модуль,
а Int32.MinValue соответствует Int32.MaxValue. Seed MaxValue не заменялся0.

**Исключены именно эти16 комбинаций генератора, расхода и маскирования.**
Результат не исключает System.Random с другими начальными пропусками,
пересозданием генератора, переменным расходом, иными API/порядком экспорта,
преобразованием через хэш, mnemonic/HD или другой обработкой raw-ключа.
Он не доказывает и не опровергает использование автором C# вообще.

## Сбой записи и возобновление

Первый runner завершился с PermissionError при атомарной замене
STATUS.json.tmp → STATUS.json на границе Windows/WSL. Сбой произошёл при
обновлении сводки после сохранения вычисленного блока; CUDA о сбое не сообщала.
Другая работающая очередь отсутствовала, OS-lock был свободен. Перед повтором
проверены непрерывный префикс [0,1341128704) и все
3850 его файлов. После завершения их хэши
сверены повторно: ни один готовый файл не изменён, GPU-блоки не пересчитывались.
Код ядра, обвязки и конфигурация не менялись. Первая ошибка и оба журнала
сохранены. Точная причина временного запрета файла не установлена; во время
возобновления активный STATUS не читался через Windows.

## Независимый аудит после завершения

Проверены все2051 записи диапазонов, границы, число обработанных seed,
нулевые счётчики кандидатов, отсутствие overflow/error, SHA-256 каждого
результата и каждого звена цепочки, конфигурация и ссылки из исходного
COMPLETE. Восемь импортов побайтно сверены с исходнымиGPU-пилотами.
Таблицы отбрасывания16 схем заново построены независимо из50 числовых
известных ключей; их хэш совпал во всех блоках. CUDA-контекст/worker завершились,
OS-lock свободен. Старые101 GPU-файл и482 CPU-файла совпали со своими подписями.

Это аудит покрытия и принятых вычислительных результатов, а не второй
полный пересчёт на другом устройстве. Корректность ядра опирается на
исторические векторы,33 синтетических поиска и граничные контроли DN-G01.

Первоначальные `COMPLETE.json`, `STATUS.json` и checkpoints не изменялись
при аудите. Новый результат: FULL_AUDIT.json — артефакт исходного исследования (`FULL_AUDIT.json`; вне снимка),
NUMERIC_REPORT.json — артефакт исходного исследования (`NUMERIC_REPORT.json`; вне снимка), все блоки CSV — артефакт исходного исследования (`BLOCKS.csv`; вне снимка).

и [приёмка CUDA](<../dotnet-random-cuda-20261109/FINAL_REPORT.md>) сохранены.
