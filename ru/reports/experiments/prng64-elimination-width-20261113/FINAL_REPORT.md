# RNG64 — ширина графа ограничений

13 ноября 2026 года. Проверены 20 сохранённых синтетических формул CMS для десяти открытых случаев, по одной формуле из RNG64-04 и RNG64-05. Хеш каждой формулы совпал с её COMPLETE.json. Для оценки использованы составы ограничений. Совместимость наблюдений не оценивалась.

Рёбра соединяют переменные, входящие в одно ограничение. Для исходных графов взяты сохранённые XOR и дизъюнкции. Для второго варианта длинные ограничения представлены графом цепочек бинарных XOR и OR с промежуточными переменными.

Нижняя оценка получена по наибольшему исходному ограничению и минимальной степени графа после последовательных стягиваний. Верхняя оценка равна меньшей ширине двух реально построенных порядков. Первый выбирает вершину минимальной степени, второй выбирает минимум добавляемых рёбер среди 12 вершин с наименьшей степенью. Оценки относятся к этим представлениям графа.

При ширине w одна плотная таблица после исключения требует 2^w бит даже при хранении одного бита на комбинацию. В расчёт памяти не входят другие таблицы и служебные данные. При 32 ГиБ на одну такую таблицу помещается w=38, при 8 ГиБ помещается w=36.

| plus23-17-26-little-02 | 129–131 | 33–132 | 51–128 | 33–129 |
| plus23-17-26-little-03 | 128–130 | 34–129 | 52–127 | 33–127 |
| plus23-18-5-big-02 | 128–129 | 33–116 | 53–117 | 32–119 |
| plus23-18-5-big-03 | 128–129 | 33–116 | 53–117 | 31–116 |
| plus23-18-5-big-06 | 128–129 | 31–125 | 46–115 | 28–117 |
| plus23-18-5-little-02 | 128–130 | 36–118 | 54–117 | 35–117 |
| plus23-18-5-little-03 | 128–129 | 34–119 | 56–116 | 34–118 |
| plus23-18-5-little-06 | 128–129 | 47–129 | 62–127 | 44–127 |

Найденные порядки дали ширины 115–131 для исходных графов и 116–132 для цепочек. Наименьшая ширина 115 получена для исходной формулы RNG64-05 plus23-18-5-big-06. Для плотной таблицы в этом порядке потребовалось бы 2^112 байт. Таблицы не строились.

Нижние оценки для исходных графов составили 46–129. Поэтому для всех двадцати исходных графов даже одна плотная таблица при любом порядке превышает 32 ГиБ. Для графов цепочек нижние оценки составили 28–47 и превышают 38 в двух случаях. Для остальных восемнадцати оценки допускают существование порядка шириной 38 или меньше.

Независимый пересчёт на множествах воспроизвёл ширину порядка минимальной степени для всех двадцати исходных графов. Основная оценка заняла 7,89 с. [Результаты по всем графам](<../../../evidence/prng64-elimination-width-20261113/RESULTS.json>).

Методы расчёта описаны в работах [Bucket Elimination](https://ics.uci.edu/~csp/r48b.pdf) и [Contraction and Treewidth Lower Bounds](https://www.jgaa.info/index.php/jgaa/article/view/paper117).
