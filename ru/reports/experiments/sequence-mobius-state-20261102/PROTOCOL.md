# SEQ-06 — новый нелинейный переход: дробно-линейная цепочка

02.11.2026. Пользователь разрешил перейти к новому переходу/обоснованному
модулю. Здесь меняется переход, модуль n остаётся порядком secp256k1.
Постановка фиксируется до проверки настоящих данных. Предельное время
вычислительных стадий15 минут; один CPU-процесс, без GPU и установок.

## Модель

```text
s[i+1] = (A*s[i]+B)/(C*s[i]+D) mod n
AD−BC != 0 mod n; C != 0 mod n
```

Коэффициенты неизвестны, определены с точностью до общего ненулевого
множителя. C!=0 выделяет нелинейный класс и исключает прежнюю аффинную
модель. Для наблюдений используется прежнее r[i]=s[i] mod2^(i−1).
Предполагается отсутствие полюсов в первых135 состояниях/134 переходах.
При полюсе кандидат не соответствует этой конечной модели; бесконечность
не подменяется нулём. Частный случай: s_next=beta+alpha/s, alpha!=0.
Историческая связь с создателем Puzzle не установлена.

На проективной прямой переход задаёт матрица M=[[A,B],[C,D]].
Пятый переход M^5 также дробно-линейный: верхние решения №75,80,...,135
можно использовать без неверного сжатия индексов. Специальное правило
ICG `inverse(0)=0` не рассматривается в ветвях с попаданием в0;
это отдельная модель, а не проективный переход через бесконечность.

## Точный метод и его вычислительный предел

Четыре полных состояния №120,125,130,135 с различными соседними
тройками однозначно задают R=M^5. Восстанавливаем дробно-линейное
отображение по трём парам, через отображения троек в0,1,infinity.
Проверяем остальные верхние наблюдения обратным ходом R.

Для простого p, |PGL(2,p)|=p*(p^2−1). Проверяется gcd(5,|PGL|)=1;
тогда M=R^(inverse(5,|PGL|)). Это верно для n и выбранных малых
p=7,127,227. Пятый степенной переход проверяется явно.
По M и состоянию №120 восстанавливаем s[1], затем проверяем ВСЕ83
наблюдения прямым ходом, не подставляя истинные будущие значения.

Для частично наблюдаемых состояний перечисляются ВСЕ дополнения
s=r+2^b*q в[0,p). Это **перебор скрытых частей четырёх состояний**,
не полиномиальный алгоритм и не ускорение общего криптоанализа.
До перечисления точно считаем произведение четырёх размеров.
Лимит1 000 000 сочетаний на задачу, до4096 принятых моделей.
Превышение — `domain_budget`/`model_budget`, НЕ отрицательное заключение.

Выбранные якоря дают наиболее длинные доступные четыре остатка на
равномерной верхней панели. Отдельно явно сохраняется область
неразличимых/повторяющихся якорных троек; они не объявляются отвергнутыми.
Результат `complete_nondegenerate` означает полноту только для
зарегистрированного класса с невырожденной якорной тройкой.

## Контроли и реальные данные

- Точное сравнение матричного и скалярного исполнения, композиции,
  интерполяции, обработки полюсов и извлечения пятого корня.
- Все336 элементов PGL(2,7) для проверки пятого корня;
  малые задачи восстановления сверяются независимо полным перебором
  матриц/начального состояния, включая нулевые результаты.
- p=127 (7 бит),227 (8 бит): по4 новых нелинейных цепочки, две общие,
  две инверсивные. Маски масштабированы floor((i−1)*w/256), все83
  исходных индекса сохранены. Неполярные цепочки выбираются
  воспроизводимым rejection sampling; число попыток сохраняется.
- Полноразмерный n: для общего и инверсивного семейства по4 новых
  цепочки на каждом уровне1,2,3 скрытых битов в четырёх якорях
  (24 случая). ОСТАЛЬНЫЕ79 масок остаются настоящей формы i−1.
  Это усиленные положительные контроли, не настоящая полнота наблюдений.
- По4 случайных отрицательных контроля на малой настоящей форме
  и8 полноразмерных с усиленными якорями.
- Два полноразмерных положительных примера с настоящими масками:
  сначала preflight. Если лимит превышен, поиск не запускается и
  допуск реального поиска считается неполученным.
- Для настоящих83 решений разрешён точный preflight стоимости,
  независимо от допуска. Реальное перечисление только при успешных
  положительных контролях с той же формой данных и соблюдении лимита.

Не экстраполировать успех при практически полностью известных якорях
на настоящие74–134 наблюдаемых бита. Неудача/невыполнимость этого
базового точного метода не означает невозможность более сильного
решёточного или нелинейного алгоритма.

SHA256/mtime всех принятых SEQ-01..05 сохраняются; новые результаты
кешируются и sealed. Независимый аудит использует другое получение
матрицы по линейным уравнениям. Старые научные стадии не исполняются.
