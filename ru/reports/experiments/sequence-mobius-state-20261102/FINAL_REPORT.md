# SEQ-06: дробно-линейный переход скрытого состояния

02.11.2026, Москва. Run `SEQ-06-422b74557e11`.

**Новый нелинейный переход исследован, точный базовый восстановитель
проверен. Для настоящих масок он вычислительно непригоден: около 2^518
сочетаний скрытых частей четырёх опорных состояний. Реальные состояния
не перебирались; модель не отвергнута, нового ключа или бита нет.**

Это завершённый цикл разработки, контрольного восстановления и оценки
применимости. Это не завершённый поиск параметров модели на Puzzle.

## Что изменилось после SEQ-05

Меняется переход, а не порядок байтов или произвольно выбранный модуль:

```text
s[i+1] = (A*s[i]+B)/(C*s[i]+D) mod n
AD−BC != 0 mod n; C != 0 mod n
r[i] = s[i] mod 2^(i−1)
```

Здесь n — порядок secp256k1; A,B,C,D и s[1] неизвестны. Общий ненулевой
множитель матрицы не меняет переход. Внутри класса находится инверсивный
генератор `s_next = beta + alpha/s`. Связь этого класса с историческим
генератором создателя Puzzle не установлена.

Модель требует конечных состояний на позициях 1–135: полюсы запрещены.
Проективная бесконечность не заменяется нулём. В частности, специальное
правило некоторых ICG `inverse(0)=0` не включено для траекторий, которые
посещают ноль. Общий такой ICG остаётся отдельной моделью.

## Что именно умеет метод

Пять шагов дробно-линейного перехода снова дают дробно-линейный переход
R=M^5. Четыре полных состояния №120,125,130,135 определяют его по трём
парам «вход → выход», если соседние тройки состоят из различных значений.

Пятый корень здесь однозначен. Для простого p группа PGL(2,p) имеет
порядок q=p(p²−1); для n и контрольных p=7,127,227 проверено gcd(5,q)=1.
Если 5e=1 mod q, то `(M^5)^e=M` по теореме Лагранжа. Поэтому `M=R^e`;
коммутативность группы для этого аргумента не требуется.

После получения M восстанавливается s[1], затем заново проигрываются
все 135 состояний и проверяются все 83 известных остатка. Истинные
параметры синтетических примеров в восстановитель не передаются.

Но опорные состояния известны частично. Реализованный метод перечисляет
все допустимые дополнения `s=r+2^b*q` для четырёх опор. Именно эта стадия
делает прямое применение невозможным. Ограничения заранее заданы:
1 000 000 сочетаний на задачу, до 4096 принятых моделей. Обнаружение
4097-й модели возвращает `model_budget`; перебор не объявляется полным.

Статус `complete_nondegenerate` означает полноту только для конечных
неаффинных траекторий с невырожденными опорными тройками. В реальных
данных все шесть пар опор имеют несовместимые остатки по общим младшим
битам: их значения заведомо различны. Эта частная проблема вырождения
не препятствует реальному восстановлению; препятствует объём дополнений.

## Точная стоимость на реальных данных

Число допустимых дополнений для опоры с остатком r и b известными битами:

```text
count = floor((n−1−r)/2^b)+1
```

| Индекс | Известно младших битов | Осталось позиций до ширины 256 |
|---:|---:|---:|
| 120 | 119 | 137 |
| 125 | 124 | 132 |
| 130 | 129 | 127 |
| 135 | 134 | 122 |

Произведение точных четырёх размеров — примерно **8,581×10^155 ≈ 2^518**.
Это примерно в 8,581×10^149 раз выше лимита. Точное целое и четыре
размера сохранены в `REAL_PREFLIGHT.json`; число немного меньше 2^518,
хотя его логарифм округляется до 518,0.

**Это стоимость конкретного перечислителя, не нижняя граница сложности
криптоанализа и не доказательство недостаточности наблюдений.** Во всех
83 решениях открыто 3767 битовых позиций; метод использует остальные
наблюдения для проверки уже построенных дополнений. Другой алгоритм
может задействовать эти связи раньше. Независимость этих битовых условий
здесь не предполагается и не доказывается.

## Вывод для продолжения

Переход к новому классу выполнен. Получен точный и проверенный базовый
восстановитель, но **работающего метода восстановления из реальных масок
для этого класса пока нет**. Увеличивать лимит прямого перечисления
практического смысла не имеет.

Содержательное продолжение этой модели — отдельный метод, использующий
связи между усечёнными состояниями до перебора. Конкретная отправная
точка: сохранение двойного отношения при дробно-линейном переходе,
которое позволяет исключать параметры A,B,C,D и получать полиномиальные
условия на скрытые части. Эффективный решатель этих условий здесь
**не реализован и не проверен**; малые и реальные маски должны быть
отдельными допусками, как в этой серии. Другие переходы/модули в SEQ-06
не запускались.

Первичный контекст: Blackburn, Gómez-Pérez, Gutierrez, Shparlinski,
[Predicting Nonlinear Pseudorandom Number Generators, Math. Comp. 74 (2005)](https://personales.unican.es/gomezd/Articles/Blackburn/mathcomp.pdf).
Авторы исследуют восстановление нелинейных генераторов при достаточно
точных частичных наблюдениях. Их условия не дают автоматического решения
для наших масок; SEQ-06 не является реализацией их решёточного алгоритма.

Данные и воспроизведение: `CONTROLS.json`, `REAL_PREFLIGHT.json`,
