# SEQ-06 — дробно-линейное скрытое состояние

[Итоговый отчёт](<FINAL_REPORT.md>). Новый переход исследован на синтетике;
реальный поиск не запускался из-за стоимости около 2^518 дополнений.
Это ограничение метода, не исключение модели.

Полностью локальная серия; стандартная библиотека Python 3.11, один CPU,
без GPU, установок и повторного исполнения прежних поисков. Модуль —
порядок secp256k1; маска — младшие i−1 битов состояния. Все 83 решения
скопированы без изменения из принятой SEQ-05.

Команды из корня проекта в PowerShell:

> Исполняемый код/команды опущены в документационной копии.


`verify.py` только читает файлы. Остальные команды при наличии результатов
пропускают уже завершённые стадии и дописывают только исключённый из
манифеста целостности `JOURNAL.jsonl`. Сначала выполнять проверку целостности.
Принятые файлы для нового расчёта не удалять: новая серия должна иметь
отдельную папку и постановку.

- `PROTOCOL.md`: заранее заданная модель, классы примеров и ограничения.
- `core.py`: арифметика PGL, интерполяция, точное перечисление дополнений.
- `study.py`: создание данных, исходная обвязка и замороженные параметры.
- `execute.py`: принятая обвязка с учётом исхода `model_budget`;
  объяснение в [EXECUTION_NOTE.md](<EXECUTION_NOTE.md>).
- `controls/*.json`: все 50 контрольных пакетов, включая незавершённые.
- `CONTROLS.json`: сводка; 24 усиленных полноразмерных примера восстановлены
  однозначно, исходная полноразмерная форма данных не прошла допуск.
- `REAL_PREFLIGHT.json`: точные размеры реального перебора, поиск отсутствует.
- `PREFLIGHT_DETAIL.json`: общие остатки опор и границы толкования стоимости.
- `audit.py`, `AUDIT.json`, `TINY_EXHAUSTIVE.json`: независимые проверки.
- `PRIOR_SNAPSHOT.json`: SHA256 и mtime 637 принятых прежних файлов.
- `MANIFEST.json`, `EXECUTION_MANIFEST.json`: замороженные входы и код.
- `ACCEPTANCE.json`, `COMPLETE.json`, `ARTIFACTS.json`: приёмка и целостность.

Не интерпретировать ноль перечисленных реальных состояний как отсутствие
совместимых моделей. `search_result=null` означает, что поиска не было.
