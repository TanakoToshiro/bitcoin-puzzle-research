# O2-J01 — точный общий сдвиг и число допустимых сочетаний

Обозначения O2-L01: p нечётен, наблюдается r_i=s_i mod2^k_i; K=k135>=k_i, R=r135, L=2^K. Для всех используемых в формуле индексов k_i>=1. Опорное состояние t=s135 принимает значения R+qL в [0,p). Маски с k_i=0 не задают перенос и в формулу ниже не включаются.

## Раннее условие совместимости

Для x_i=(s_i−t) mod p известны два остатка:

```
x_i mod2^k_i = r_i−R+epsilon_i*p mod2^k_i,
epsilon_i = 0 при x_i+t<p, иначе1.
```

Так как p нечётно и k_i>=1, два остатка различаются. Каждый выбранный x_i однозначно задаёт epsilon_i. Поэтому выбор x_i ограничивает один общий t:

```
epsilon_i=0: t <= p−1−x_i,
epsilon_i=1: t >= p−x_i.
```

Пересечение этих границ и прогрессии R+qL даёт пустое множество либо целочисленную прогрессию от t_first до t_last. Это необходимое и достаточное условие существования исходных s_i для ВСЕХ уже выбранных x_i; отдельного перебора t не нужно. При добавлении очередного x_i диапазон только сужается, ранее исключённые варианты возвращаться не могут.

## Генератор, не строящий запрещённые четверки

Три самые короткие сетки x_i перечисляются блоками. По ним вычисляются t_first,t_last. Для четвёртой сетки:

```
epsilon=0 допускает только x <= p−1−t_first;
epsilon=1 допускает только x >= p−t_last.
```

В каждой ветви x образуют прогрессию с шагом2^k. Границы находятся двоичным поиском; генерируются только попадающие в диапазон значения. Поэтому запрещённые полные четверки не проверяются поштучно. Трёхкомпонентные префиксы всё ещё перечисляются; алгоритм не является полиномиальным по разрядности.

После вычисления A,B,C и очередного предыдущего значения на сетке5 проверяется не только отдельный остаток, но и обновляется тот же интервал t. Это использует остальные поздние наблюдения и положительные маски более ранних индексов, кратных5. Таким образом отсеиваются кандидаты, у которых каждый отдельный остаток подходил, но общего сдвига для всех состояний не существовало. Изменения не затрагивают восстановление корня шага5, итоговый независимый проектор и полные ветви первого порядка/constant.

## Замкнутая формула без перебора

Пусть M — число допустимых опорных t, N_i — число абсолютных состояний s_i в [0,p) с маской r_i, G_i=L/2^k_i. Все эти числа вычисляются целочисленным делением.

Для каждого t_q=R+qL обозначим S_i(q) множество допустимых x_i. Отображение s_i -> (s_i−t_q) mod p биективно, поэтому |S_i(q)|=N_i независимо от q.

При переходе от q−1 к q в S_i добавляются значения с epsilon1 из промежутка [p−t_q,p−t_(q−1)), длина которого ровно L. У прогрессии с шагом2^k_i это **ровно G_i новых элементов**. Элементы с epsilon0 могут только уходить, с epsilon1 — только приходить; два класса остатков различны. Поэтому

```
|S_i(q−1) intersect S_i(q)| = N_i−G_i.
```

Множество q, при которых фиксированная четверка допустима, является интервалом: это пересечение её четырёх пороговых условий. Значит при движении по q каждая новая четверка входит ровно один раз, без повторного появления. Для произведений множеств имеем P=prod N_i и Q=prod(N_i−G_i); число новых четверок на каждом шаге q>=1 равно P−Q.

**Точное число хотя бы раз допустимых четверок:**

```
F = P + (M−1)*(P−Q) = M*P−(M−1)*Q.
```

При M=0: F=0. При M=1: F=P, Q вычислять не нужно (N_i−G_i тогда может быть отрицательным). При M>=2 имеем N_i>=G_i. Формула обобщается на любое число m наблюдений с ненулевой шириной и одной общей опорой. Она считает совместимость масок со сдвигом, **не число рекуррентных моделей**.

Важное условие: нельзя применять её к k_i=0 как к ещё одному переносу. Тогда два остатка совпадают, epsilon не определяется из x_i, и доказательство о новых элементах больше не работает. Также здесь не заявляется случай чётного p.

## Размер выигрыша

Если p/L велик и все сетки плотны, N_i≈p/2^k_i и M≈p/L. Для m=4 формула даёт F≈5*prod N_i, тогда как независимые два остатка каждой позиции давали≈16*prod N_i. Основной домен сокращается приблизительно в16/5=3.2раза: это **около1.678бит**, а не устранение экспоненты.

На настоящих масках точное число F вычислено непосредственно по целым данным. Прежние≈2^542 сочетания становятся≈2^540.322. Дальнейшая проверка общих переносов резко уменьшает число дорогих реконструкций, но выполняется уже после выбора четверки. Её нельзя дополнительно засчитать как сокращение входного перебора до перечисления или умножить эмпирические коэффициенты toy-тестов и выдать за доказанную скорость для n.

Исходная модель остаётся условной. Уменьшение избыточных сочетаний не даёт вероятности её истинности и не доказывает какой-либо бит настоящего ключа.
