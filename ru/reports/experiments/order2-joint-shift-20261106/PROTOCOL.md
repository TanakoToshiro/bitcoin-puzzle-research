# O2-J01 — общий сдвиг до четырёхкомпонентного перебора

6 ноября 2026. Новая папка после O2-L01, прежние checkpoints не изменять.

Проверить точный необходимый фильтр: x_i=(s_i−s135) mod p. Выбор одного из двух остатков x_i однозначно задаёт перенос epsilon_i при k_i>=1. Все выбранные x_i должны допускать ОДИН t=s135=R+q*2^K в [0,p), удовлетворяющий x_i+t<p при epsilon0 и x_i+t>=p при epsilon1.

Для четырёх опор115/120/125/130 перечислять три самые короткие сетки, поддерживать интервал допустимых t, затем генерировать только допустимые диапазоны четвёртой сетки. Полные запрещённые четверки не строить. После исключения A,B,C обновлять этот же интервал при каждой доступной маске на сетке5. Корень пятого шага, окончательный проектор и ветви первого порядка/constant оставить математически теми же.

Предварительная формула числа четверок, совместимых с одним сдвигом: N_i — число абсолютных значений s_i с данной маской, M — число допустимых s135, G_i=2^(K-k_i). При M>=1:

`F=prod(N_i)+(M-1)*(prod(N_i)-prod(N_i-G_i))`.

Для M=0 результат0; для M=1 использовать только prod(N_i), чтобы не придавать смысла отрицательным N_i-G_i. Доказать формулу через первый допустимый сдвиг и проверить независимым перебором, а не принимать её по совпадению синтетики.

Контроли:200 детерминированных малых входов (p7/11/17, случайные ненулевые ширины<=K), полный перебор четверок и всех t против формулы/генератора. Дополнительно полные старые INPUT O2-L01:18 p7/p17,10 новых p37..523,4 paired p127/p257,2 degenerate_controls. Всего34 завершённых входа должны дать ТОЧНО те же семейства и прогнозы. Не подставлять hidden truth в solver.

Тайминг: четыре заранее выбранных одинаковых входа O2-L01 p127-new0, p257-new0, p37-new0, p523-new0. Оба алгоритма в новых benchmark-каталогах, tracemalloc у обоих, сравнивать полные ответы. Это намеренное повторение для сравнения алгоритмов, не перезапись старых запусков. Лимит60с на ветвь/попытку; UNKNOWN/неполноту сохранять. Основная серия без tracemalloc; блок1024 трехкомпонентных префикса, хэш-цепочки.

Для p65537 и настоящего n только точные числа кандидатов по формуле и границы стоимости, без полного поиска. Не выводить вероятность MT/рекурсии из размера пространства. Не объявлять постоянный множитель снятием экспоненциального препятствия. Сохранить доказательство, код, машинные результаты, все промежуточные выводы и общий журнал после этапов.
