# O2-J01

Продолжение O2-L01. Начать с FINAL_REPORT.md, PROTOCOL.md, MATH.md. Только синтетический поиск; для настоящего n — точный подсчёт области масок, без поиска состояний.

Рабочая команда из этой папки:

> Исполняемый код/команды опущены в документационной копии.


Используется wrapper, потому что неизменённый старый solver при самостоятельном хэшировании ожидает имя solver.py. Его точные копии лежат в reviews/legacy_runtime. Первая попытка benchmark остановилась до вычислений на отсутствии этого имени; ERRORS.log сохранён. Wrapper меняет только размещение старой реализации для сравнения, проверяет байтовое совпадение; вычислительный код и старые checkpoints не редактировались. Контроли/34 завершённых входа повторно не запускались. RESUME_ADAPTER.json содержит объяснение и хэши.

joint_solver.py получает только INPUT. Для проверки результата используются EXPECTED из завершённого O2-L01, но они не входят в solver. Все83 наблюдения являются ограничениями, отдельного holdout нет. Поддержка модулей исходной рекурсии та же, что O2-L01; формула совместимости сдвига отдельно проверяется и modulo11.

search/generic — блоки1024 трехкомпонентных префикса, не четверок; generated_quads должен в сумме точно равняться формуле. search/first_order — прежняя полная ветвь. Сохранены непрерывные диапазоны, SHA-256-цепочки, код/вход, счётчики, время и семейства решений. Завершённые блоки не исполняются повторно. Для точечного продолжения:

> Исполняемый код/команды опущены в документационной копии.


Одна копия runner на каталог. Предел60с на ветвь, остановка между блоками; неполный результат не доказывает полноты прогнозов. Домен свыше10миллионов совместимых четверок не запускается. Вся основная серия без tracemalloc; четыре парных benchmark с tracemalloc у обоих методов. Метрика памяти не равна полному RSS.
