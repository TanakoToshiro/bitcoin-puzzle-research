# E9e — контроль версии libc++

Все проверки пройдены. Множитель 48271; CPU, Python и GPU согласованы. 20 RNG-векторов, 14 исторических BIP32-векторов, 80 родителей, 720 children, 4096 random low49 сравнений, 8256 contiguous low49 сравнений, 64 синтетических случая и границы/overflow.

Калибровка трёх блоков по 1048576: 819202–820395 состояний/с, все 16 схем. Оценка полного прохода по pipeline: 43.7 мин. Это не Windows wall-time и не завершённый поиск.

Полный проход и текущий статус сохраняются в [соседнем каталоге](<../bx-libcpp-full-20261101/RESULTS.md>). Старые GNU-снимки неизменны. См. ACCEPTANCE.json, benchmarks/, JOURNAL.md.
