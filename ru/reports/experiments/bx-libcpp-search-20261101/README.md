# E9e — BX/libc++: GPU-версия для полного поиска

Пользователь разрешил заменить генератор предыдущей проверки и запустить поиск. Это новая изолированная версия E9c: в `engine.cu` множитель RNG изменён с16807 на48271. **CPU-verifier также изменён** и находится в `cpu/bx-search`; эталоны и синтетические наблюдения заново сгенерированы `reference.py`. Все 16 BIP32-схем прежние. См. [протокол](<PROTOCOL.md>).

Исходное определение libc++ сохранено в `sources/llvm-3.5-random.h` с URL и SHA-256. Историческая сборка BX целиком не воспроизводилась, связь автора puzzle с ней не установлена. Предыдущий GNU-поиск исключил только свою реализацию; здесь проверяется другой поток entropy.

Полный запуск находится в [bx-libcpp-full-20261101](<../bx-libcpp-full-20261101/README.md>). Приёмка этой версии, её результаты и входы заморожены после `acceptance.py`; не менять их во время полного поиска.

Файлы: `DERIVATION.json` описывает источники изменений, `prepare.py` готовит примитивы и fingerprints в Windows venv, `batch_check.py prepare` готовит смежные данные. `RNG_EXPECTED.json` и `rng_oracle.cpp` обеспечивают независимый std::minstd_rand контроль. `driver.py controls` и `batch_check.py verify` выполняются в WSL. `build.sh` собирает sm_86 CUDA, `cpu/search.cpp` собирается g++ с OpenMP/libsecp256k1/OpenSSL, `acceptance.py` выполняет окончательную проверку и короткий замер.
