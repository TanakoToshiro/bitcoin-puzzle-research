# E6H — совместные ограничения верхних публичных ключей

CPU-исследование по замороженному протоколу — артефакт исходного исследования (`PROTOCOL.md`; вне снимка). Цель — любая нерешённая задача, в том числе с раскрытым публичным ключом. Рабочие проекты и прежние checkpoints не изменяются. Используются сохранённые данные E5 и независимая арифметика E3; сетевые обращения не требуются.

Результаты: RESULTS.md — артефакт исходного исследования (`RESULTS.md`; вне снимка). Ручные выводы: [NOTES.md](<NOTES.md>).

Команды из этой папки в PowerShell:

> Исполняемый код/команды опущены в документационной копии.


`--stop-after N` останавливает run/resume после N новых завершённых стадий. Изменение входов/исходников не разрешает продолжение старого запуска: нужен новый ID. Законченные стадии проверяются по SHA-256 и не повторяются. При тайм-ауте остаются завершённые стадии и журнал прерванной попытки; незавершённая стадия при продолжении начинается заново. Бюджет указан на одно обращение run/resume и не выделяет автоматически новый вычислительный цикл.

`acceptance.py ID` проверяет продолжение/пересборку и повреждённые входы на изолированной копии. Эта копия не является научным запуском. Её файлы сохраняются для аудита.

Изменённая игрушечная группа описана в протоколе. Восстановление её chaincode не является восстановлением chaincode настоящей цепочки Armory. Таблицы хранят количество записей и содержащихся в них точек, не измеренный пик RAM процесса. Короткие времена чувствительны к шуму; для масштаба важнее точное число групповых операций и назначений битов. Поиск на настоящей secp256k1 не запускался.

Версии и хеши научных исходников: config.json каждого запуска; точные копии — code/. Источники данных — inputs/. Все реальные кандидаты и 64 ветви — real-points.json; синтетические истины и решения — toy-*.json; числовая сводка — comparison.csv и summary.json. Нейтральный элемент группы кодируется JSON null.
