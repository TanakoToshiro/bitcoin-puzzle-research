# E14 — SX uniform16 high byte

Изолированная проверка исторического `uniform_int_distribution<uint16_t>(0,65535) >> 8`
на GNU16807 и LLVM48271. [Протокол](<PROTOCOL.md>), схемы — артефакт исходного исследования (`SCHEMES.json`; вне снимка),
[прогресс/результаты](<RESULTS.md>), [хронология](<JOURNAL.md>).

WSL Ubuntu-24.04, из этой папки:

> Исполняемый код/команды опущены в документационной копии.


После приёмки `run.py all` переиспользует результаты контролей/пилотов с теми же
входами, проверяет checkpoint-цепочки и продолжает только отсутствующие блоки.
SERIES.lock — flock с идентификацией worker через PID/start ticks в PROCESS.json.
STOP останавливает перед следующим блоком; убрать его перед продолжением.
Кандидат/ERROR требует разбора причины и не пропускается автоматически.

Windows launch_and_audit.ps1 выполняет поиск в фоне, затем независимые readback.py
и finalize_report.py. POSTRUN_STATUS.json — состояние координатора, HOST_PROCESS.json
— его идентичность. POSTRUN_MANIFEST.json фиксирует код этой последовательности.
Успех: COMPLETE.json + READBACK_COMPLETE.json + POSTRUN_STATUS:complete.
Итог появится в FINAL_REPORT.md и общем RESULTS.md. До этого полное исключение
40 моделей не заявляется. При ошибке сохраняются stderr/HOST_ERROR, отчёт об исключении не пишется.

prepare.py служит однократному переносу и генерации эталонов; не запускать поверх
принятой серии. Сборка воспроизводится из pinned исходников. Родители из старых
серий используются с новым RNG, это40 новых комбинаций, а не повтор прежних seed.
