# E2: исторический Python random и ограниченные integer seed

[Протокол](<PROTOCOL.md>), [результаты запусков](<RESULTS.md>), [промежуточные выводы](<NOTES.md>).

**Завершён:** [итоговый отчёт 20261030-102843-9581116c](<runs/20261030-102843-9581116c/CONCLUSION.md>). Все 20 физических пилотов полностью проверили `[0,1048576)` без совпавшего seed. 20 положительных контролей прошли. Основной поиск с контролями занял 560,587 с, архивы и проверки сохранены.

Работа выполняется в отдельной папке. Основной поиск исполняет настоящие CPython 2.7.9/3.4.2, собранные из официальных исходников, под WSL. Windows Python 3.11 управляет запуском и проверяет результаты. Исторические интерпретаторы не устанавливаются системно. Исходные архивы, архивы runtime, SHA-256, логи сборки и контрольные векторы сохраняются здесь; временный WSL-каталог восстанавливается из архива при необходимости.

Проверяется только `[0, 2^20)` для явных integer seed. Это 1 048 576 значений, 1/4096 диапазона 32-битных seed. Unix timestamp создания puzzle, строковые seed и автоматическая энтропия не входят. Две версии, пять физических API-схем и два шага дают 20 физических поисков; эквивалентная сборка слов добавляет четыре логических описания без повторного вычисления.

Структура запуска: `code/` — замороженный код и протокол; `inputs/` — данные, исторические векторы и метаданные runtime; `tasks/control-*` — восстановление синтетического seed; `tasks/pilot-*` — реальные решения. Каждый `shards/START-END.json` задаёт точный полуинтервал проверенных seed, число проверок и причины отклонения. `DONE.json` содержит контрольные суммы завершённого поиска. `EVENTS.jsonl` дописывается, `RESULTS.md` пересобирается из JSON, `NOTES.md` сохраняет интерпретации.

Остановка проверяется на границах блоков по 16384 seed; фактическое время записывается. Завершённые блоки пропускаются, незавершённый блок может вычислиться повторно и не учитывается дважды. Изменение входов или вычислительного кода требует нового запуска. Архивы старых интерпретаторов достаточны для возобновления после очистки `/tmp` без новой сборки.

Существенная историческая особенность: в этом диапазоне `randrange` у 2.7.9 запрашивает 257 бит из-за округления логарифма, а 3.4.2 — 256 бит через `bit_length`. Эти варианты имеют разный расход случайных чисел и проверяются отдельно. Эталонные исходники: [CPython 2.7.9](https://www.python.org/downloads/release/python-279/), [CPython 3.4.2](https://www.python.org/downloads/release/python-342/); точные хеши — в SOURCES.json/RUNTIMES.json.

`finalize.py` пересобирает только отчёт из готовых JSON и проверяет хеши; его хеш сохраняется в приёмке. Он ожидает завершённый отрицательный пилот и сохранённый контроль продолжения, а не выдаёт отрицательный вывод для частичного запуска. `test_checkpoint_resume.py ID` создаёт отдельную копию синтетического контроля для проверки возобновления; существующую копию не перезаписывает. Основной замороженный код при этих действиях не меняется.
