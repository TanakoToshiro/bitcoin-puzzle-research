# O2-N01 — воспроизведение

Из этой папки:

> Исполняемый код/команды опущены в документационной копии.


PROTOCOL.md и *.py зафиксированы в MANIFEST.json. Старые1320 файлов O2-J01 проверяются по COMPLETE; не изменяются. Solver получает только INPUT; EXPECTED используется проверяющим кодом после поиска. Нового подбора модели/масок по ответам нет. Полноразмерные контроли с данными префиксами — отдельная проверка арифметики, не слепое восстановление.

search/generic — блоки1024 троек(u,v,t), сохранены SHA-256-цепочки, диапазоны, счётчики всех запросов корней и выходных кандидатов. search/first_order — прежняя вырожденная ветвь. status=incomplete не означает противоречия/полной проекции. Лимит60с на попытку ветви; новые попытки только явной командой. Одна копия runner на каталог.

Продолжение конкретного входа:

> Исполняемый код/команды опущены в документационной копии.


Готовые блоки не пересчитываются. Законченные этапы runner повторно использует. Парные benchmark намеренно находятся в отдельных каталогах и используют одинаковый tracemalloc. Memory tracked != RSS. Корни не ускоряются скрытой таблицей размераp; вспомогательные инверсии downstream для toy всё ещё используют прежний массив, что не переносится на настоящий n.

Аналитические границы, аудит, пересборка отчёта:

> Исполняемый код/команды опущены в документационной копии.


finalize.py читает сохранённые результаты, не запускает поиск. RESULTS.md сохраняет промежуточные выводы; журнал ошибок при наличии ERRORS.log. Реальный поиск, GPU и облако в этом опыте отсутствуют.
