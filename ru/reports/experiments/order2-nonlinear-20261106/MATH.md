# O2-N01 — квадратное и кубическое условия

Работаем в F_p, p нечётное простое. Ось состояний и общий сдвиг те же, что O2-L01/J01: x135=0. Обозначим w=x115,u=x120,v=x125,t=x130; z=x110. Фиксация(u,v,t) — выбор кандидата префикса, а не получение этих скрытых состояний из данных бесплатно.

## Исключение коэффициентов

Разности шести значений(z,w,u,v,t,0):

```
d0=w-z; d1=u-w; c=v-u; d=t-v; e=-t.
```

Для разностей рекурсии второго порядка определитель матрицы Ганкеля3×3 равен нулю:

```
(w-z)*(c*e-d²) - (u-w)²*e + 2*(u-w)*c*d - c³ = 0 mod p.
```

Пусть K=c*e-d². При K!=0 это даёт точный квадратный многочлен

```
z=P2(w)=w-[e*(u-w)²-2*c*d*(u-w)+c³]/K mod p.
```

Для удобного исполнения вводим линейные многочлены:

```
D(w)=c²-(u-w)*d
AN(w)=d*c-(u-w)*e
CN(w)=v*D(w)-u*AN(w)-K*w.
```

При D(w)!=0 коэффициенты прореженной рекурсии равны A=AN/D, B=K/D, C=CN/D. Поэтому

```
P2(w)=[u*D(w)-AN(w)*w-CN(w)]/K
P3(w)=[w*D(w)-AN(w)*P2(w)-CN(w)]/K = x105.
```

Степени не выше2 и3. Эти условия в точности совпадают с обратным исполнением прежней рекурсии на сетке5. Они не являются новой независимой информацией сверх уже использованных наблюдений110/105; меняется способ доступа к этой информации до создания четверки.

## Полное получение кандидатов через корни

Вместо перебора всех w с маской115 новый алгоритм перебирает допустимые z с маской110 и решает P2(w)=z в F_p. Затем проверяет маску115, D!=0, один общий сдвиг для110/115/120/125/130/135, и кубическое P3(w) по маске105 с тем же сдвигом. Лишь после этих проверок создаётся четверка и запускается прежний полный downstream.

Все квадратные корни вычисляются точно через дискриминант и модульный квадратный корень. Таблица всех квадратных остатков не предвычисляется; используется Tonelli–Shanks (при p mod4=3 — короткая степень с проверкой). Контекст модуля общий, но результаты для каждого дискриминанта не кэшируются в таблицу размераp. Это важно для сопоставления стоимости с большим модулем.

Алгоритм полный: у любого совместимого w имеется ровно один z=P2(w), который попадёт в перебор z; полный решатель квадратного уравнения обязан вернуть w. Разные z не дублируют один w. Последующие условия необходимы. Вырожденные исходные цепочки по-прежнему покрыты отдельными ветвями O2-L01/J01.

## Особые случаи — их нельзя терять

K=0 не зависит от w. В невырожденной ветви это невозможно при B!=0; такой префикс пропускается только в generic-ветви. Последовательности первого порядка/constant продолжают проверяться отдельно.

D(w)=0 также не является отрицанием всей исходной модели. В generic-ветви его пропускают, а вырожденные семейства сохранены.

Квадратичный коэффициент P2 равен t/K. Если t=0, степень падает. При u=1,v=1,t=0 получается линейное P2(w)=w. При u=1,v=2,t=0 получается **постоянное P2(w)=5/4**. В последнем случае уравнение либо не имеет корней, либо допускает ВСЕ w; требуется обычное полное перечисление допустимых w с дальнейшей проверкой D и P3. Само наличие кубического/квадратичного условия не гарантирует сильного отсечения каждого префикса.

## Что действительно исключается до четвертого значения

Нелинейное условие K!=0 можно проверять уже на(u,v,t):

```
K=t*u+t*v-t²-v².
```

Для каждого v,t!=0 оно запрещает не более одного u. При t=0 K=0 только если v=0. Для полного поля число нулевых K среди p³ троек равно p². На маскированных сетках нельзя автоматически считать долю1/p, но есть строгая верхняя граница:

```
bad_prefixes <= N_v*(N_t-I[t=0 allowed])
                + N_u*I[t=0 allowed]*I[v=0 allowed].
```

При K!=0 D(w) либо не обращается в0, либо запрещает ровно одно w. Поэтому простой перенос проверок K,D перед перечислением даёт лишь ограниченное исключение; точная верхняя граница для реальных масок сохранена отдельно.

## Почему меньше выходных четверок не означает меньше работы

Новая схема перечисляет z110, маска которого на настоящих данных имеет109бит, тогда как маска w115 имеет114бит. До совместных границ сетка z примерно в32раза длиннее. При тех же(u,v,t) корней может оказаться мало, но каждый проверенный z требует решения уравнения. После этого часть корней ещё отбрасывается масками и общим сдвигом. Считать только выходящие четверки неправильно.

Внешняя фиксация трёх поздних значений сама по себе имеет огромный домен, даже при идеальном решении последнего неизвестного. Ни этот метод, ни малое число прошедших кубическую проверку кандидатов не являются практическим алгоритмом для256бит.

Этот эксперимент не проверяет все возможные способы решения ограниченных модульных многочленных систем. Отрицательный результат относится к конкретной точной схеме «перебрать x110 -> обратить P2 -> проверить P3» и её измеренной стоимости.
