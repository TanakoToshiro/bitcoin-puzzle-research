# SXM-02 — решение о поиске

Решение вступает в силу только после статуса passed в NATIVE_CONTROLS.json,
GPU_NATIVE_BRIDGE.json и verified в INPUT_READBACK.json.

**Рекомендован отдельный полный проход июньской MSVC low-byte модели.**
Это технически воспроизводимая гипотеза, а не доказательство выбора программы
автором Puzzle. Майский high-byte вариант по-прежнему не обоснован рабочей
штатной MSVC-командой. Повторять E14/E15 не требуется.

Фиксированная постановка будущего прохода:

- seed uint32, весь полуинтервал [0, 4294967296), включая 0;
- MSVC MT19937 от одного seed; по одному draw на байт;
- entropy[j] = MT.next() & 255, ровно 32 байта;
- стандартный BIP32 с пустым дополнительным преобразованием entropy;
- прежние 20 схем, точно SCHEMES.json из принятого pilot-low32, id 20–39;
- 4 096 блоков по 2²⁰ seed; всего 85 899 345 920 seed×scheme;
- GPU-фильтр по прежним 49 младшим битам известного №50, затем независимая
  CPU-проверка прошедших кандидатов по №1–50; holdout №51+ только после неё;
- source/target/scheme/kernel pins в run ID, устойчивые checkpoints;
  незавершённый блок не считается покрытым; overflow/crypto errors останавливают
  принятие результата; после окончания — независимая проверка непрерывности
  всех 4 096 блоков, счётчиков и входных хешей.

Пилот SXM-01: 909 754 seed/с для всех 20 схем, прогноз 78,68 минуты, диапазон
по пяти группам 76,19–81,45 минуты. Это прежнее измерение на той же машине и
том же неизменённом CUDA-ядре; оно не учитывает всю будущую checkpoint-обвязку.
Новое измерение и аренда GPU для принятия решения не нужны.

CLI-ограничение: нативные hd-priv/hd-pub этого снимка принимают xprv без LF/CRLF.
Обычный pipe между командами ошибочен; при воспроизведении нужно передавать
точную сериализованную строку. Валидность самого xprv и HD-математики проверяется
по полным BIP32-векторам и всем выбранным схемам. Код оригинального SX не патчен.

В этой серии выполнены только историческая сборка и синтетические контроли.
**Реальный полный проход не запущен, покрытие Puzzle = 0.** Синтетические
singleton-проверки и старые benchmark-блоки нельзя зачесть в него.
