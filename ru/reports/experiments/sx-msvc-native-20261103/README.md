# SXM-02

Продолжение исторического SX/MSVC-аудита. Основной результат — [RESULTS.md](<RESULTS.md>),
решение о будущем поиске — [FULL_SEARCH_DECISION.md](<FULL_SEARCH_DECISION.md>).

Рабочая полная нативная реконструкция:

- исходный EXE: `build/june5/sx.exe`;
- тестовый EXE с заданным uint32: `build/june5/sx-test-seed.exe`;
- изменения тестового EXE: `instrumented/coin.patch`;
- native/affine приёмка: `NATIVE_CONTROLS.json`;
- native/CUDA сопоставление: `GPU_NATIVE_BRIDGE.json`;
- повтор RNG x86/x64 с CTP-заголовками: `RNG_RECHECK.json`;
- проверка источников/артефактов: `INPUT_READBACK.json`;
- завершение и pins: `COMPLETE.json`, `FINAL_MANIFEST.json`.

Сборка выполнена напрямую cl/link по source lists исторических MSVC-проектов.
Установщики не запускались; системная установка VS/SDK не менялась. Исходники
оригинального SX не патчились. Нативные команды с сетевыми/кошелёчными побочными
действиями не исполнялись. Только синтетические ключи и offline HD-команды.

Пакеты и снимки уже сохранены. Не перезапускать подготовку/сборку внутри этой
запечатанной серии: для изменений создавать отдельную папку и новые pins.
Хеши артефактов можно прочитать и сверить без исполнения сборок. Результат
старой серии SXM-01 не редактировался; здесь явно записаны дополнения и уточнения.
