# SXM-02 — журнал восстановления

03.11.2026. Продолжение после запечатанного SXM-01.

1. Прочитаны результаты и протокол SXM-01. Создана отдельная серия; принятые
   результаты старых серий не редактировались.
2. Исходные URL libwallet/obelisk из install-sx.sh сейчас возвращают 404.
   libbitcoin получен из официального репозитория, libwallet — из EdgeApp
   (полная история, срез с MSVC), obelisk — из истории официального
   libbitcoin-server. BWallet получен для сравнения архивных веток.
   Первые сетевые запросы из ограниченной среды не разрешили DNS; разрешённая
   загрузка прошла. Установщики не запускались.
3. Первоначальный git archive применил CRLF-конверсию окружения; проверка Git
   blob остановила принятие. Экспорт заменён на cat-file --batch: каждый файл
   проверяется по исходному Git blob. Ошибка имени проекта в метаданных экспорта
   также исправлена до принятия SOURCE_PINS.
4. Порядок дат всех веток оказался недостаточен для выбора obelisk: более поздний
   README-коммит находится на другой ветке. Выбран merge MSVC-порта 661ba4f3
   от 24 мая, содержащий define.hpp. Первый снимок сохранён для сравнения.
5. Получены исторические пакеты NuGet из packages.config. Фильтр исключения
   тестовых проектов сначала ошибочно захватил имя workspace «btc test»;
   исправлен на относительный путь. Ошибка 404 для libsodium 0.5.0.0 связана
   с нормализацией версии в NuGet v3: правильный URL использует 0.5.0.
6. В локальный SDK добавлены заголовки um/shared и x64 import libraries из
   официального ISO Microsoft, только выбранными HTTP Range-запросами.
7. Первый hd-seed compile обнаружил C2280 в std::pair. Причина — в настройке
   воспроизведения: не был включён официальный CTP include overlay. Toolset.props
   Microsoft явно добавляет CTP/include перед VS2013/include. После исправления
   конфигурации исходный hd-seed.cpp компилируется без изменений. В SXM-01 overlay
   также отсутствовал: все его RNG-контроли повторены для x86/x64 с правильным
   порядком заголовков; выходы побайтно совпали (RNG_RECHECK.json).
8. Снимок SX от 3 июня: 79/80 library units проходят; stealth-show-addr требует
   отсутствующий в майском libwallet enum flags. Отдельно main.cpp даёт C2440:
   возврат enum class console_result как int без cast. Это реальные исходные
   несовместимости, а не повод исправлять исторический код вручную.
9. В истории найдены готовые исправления: enum libwallet f7289e1b от 5 июня и
   SX 76813dd9 от 5 июня (6 июня UTC). Выполнен новый полный экспорт и новая
   компиляция. hd-seed.cpp и utility/coin.cpp побайтно те же, что 3 июня.
   Все 157 library units и console main компилируются без правки исходников.
10. Линковка потребовала недостающие статические CRT /MT. Получены оригинальные
    Desktop x64 пакеты VS2013, хеши совпали с подписанным bootstrap manifest.
    MSI имеет Valid Authenticode. Попытка извлечь все managed CRT libraries
    выявила файл, продолжающийся в следующем CAB; он не нужен этой программе.
    В конфигурацию включены только полностью извлечённые libcmt.lib/libcpmt.lib
    с проверенными размерами. Линковка полного SX успешна.
11. Собрана отдельная инструментированная версия: тип random_device в coin.cpp
    заменён на тестовый источник uint32 и добавлена entropy-трасса. Engine,
    distribution и HD-код не менялись; сохранён diff. Системный RNG в контролях
    не вызывается. Исходный EXE проверяется через явный entropy-аргумент.
12. Первый CLI-контроль выявил штатный read_stream(trim=false): LF и CRLF
    остаются в ключе и отвергаются is_base58. Отдельный эксперимент показывает
    принятие точного xprv без завершающего перевода строки. Контроли используют
    именно такой ввод; исходники не исправляются. Обычный pipe hd-seed → hd-priv
    не выдаётся за работающий.
13. Проверка отрицательных индексов выявила ошибку ожидания теста: lexical_cast
    uint32 принимает -1 как UINT32_MAX. Это записано в INDEX_PARSING.json;
    отрицательные контроли заменены на abc и 4294967296. Предыдущие CALLS
    сохранены, полный приёмочный контроль запускается с исправленным ожиданием.

Завершение, точные счётчики и решение отражены в RESULTS.md и COMPLETE.json.
Никакие сетевые команды SX и никакой полный поиск Puzzle не запускались.
