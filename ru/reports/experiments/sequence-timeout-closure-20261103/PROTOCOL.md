# SEQ-14 — завершение оставшихся входов SEQ-08/09/12

Дата: 03.11.2026, Москва. Объём задан пользователем: закончить оставшиеся таймауты.
Выборка фиксируется до вычислений из RESOLUTION_MAP принятого SEQ-13:
12 older_unselected и 10 prepare_joint timeout SEQ-12 с последующей алгеброй.
Входы, маски, границы, модули, панели и конструкции не меняются.
Ранее отвеченные 28 математических входов SEQ-09/10 не пересчитываются.

Новая папка сохраняет исходные попытки побайтно. Для SEQ-12 используются
сохранённые конструкции, для остальных выполняется прежнее построение.
LLL тот же FLINT, delta=0.99, eta=0.51, transform=True, один проход.
Результат LLL сохраняется до точных проверок T*B=L, det(T)=±1 и det(B).
Сертификаты имеют прежнюю строгую границу sum(abs(row)) < modulus.
Алгебра — неизменный degree_solver SEQ-10; это явная замена raw F5B
для старых coupled_m1, аналогичная принятому SEQ-13.
Primal и legacy используют прежние декодеры, без перебора дополнительных строк.

Первый предохранительный лимит: 1800 с на подготовку/LLL, 600 с на
алгебру/декодирование, 1800 с на независимый аудит. Общего лимита,
оставляющего последние случаи без запуска, нет. Если лимит достигнут,
попытка сохраняется отдельно, причина исследуется; завершённой она не считается.
Нельзя автоматически перезапускать завершённый результат.

Новые отметки этапов: construction_ready, lll_started, lll_finished,
transform_verified, determinant_verified, certified_equations, algebra_finished,
decoded. Сохранённые полные промежуточные результаты можно использовать
без повторного LLL. Внутреннее состояние самого LLL не сохраняется.

Независимый аудит повторяет раскрытия, обе стороны равенства совместной
решётки исходным генераторам, T*B=L и унимодулярность, строгие уравнения,
точную алгебру и декодирование всех кандидатов по 135 состояниям/83 маскам.
Закрытие означает законченный результат зарегистрированного алгоритма:
эвристическое отсутствие кандидата/строгих уравнений не исключает гипотезу.
Случайные входы с unit_ideal исключаются только в своих границах.
Это синтетические проверки; реальный поиск и новые реальные ключи не заявляются.
