# Диагностика исполнения SEQ-14

После сохранения legacy-решётки обнаружена ошибка повторного чтения:
старый абсолютный scanner ожидает tuple-мономы, JSON возвращает list.
legacy_resume.py восстанавливает только тип элементов перед вызовом
неизменной функции; числа, строки, алгоритм и последующий декодер не меняются.
Исходная ошибка сохранена в worker_logs/solve/. LLL не повторяется.

Первый вход SEQ-12 остаётся внутри штатной LLL более пяти минут.
Отдельно, не меняя его файлов, проверяется поддерживаемый локальным FLINT
режим gram='exact' на той же сохранённой матрице. delta/eta прежние.
Это диагностика другого режима редукции; её нельзя выдавать за завершение
исходной approx-попытки. Результат принимается только с T*B=L и det(T)=±1.
Применение этого режима к основной серии требует отдельной записи решения.
