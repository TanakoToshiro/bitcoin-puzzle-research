# E9c — CUDA BX → BIP32, RTX 3070 Ti Laptop

[Результат и стоимость](<COSTS.md>), [живой журнал](<RESULTS.md>), [протокол](<PROTOCOL.md>), [промежуточные выводы/ошибки](<JOURNAL.md>).

Ровно 16 схем E9b. GPU вычисляет minstd_rand0 mod255 entropy 16/32, BIP32 master/parents/final child №50. Редкие выжившие передаются неизменённому CPU E9b для всех известных обучающих и отложенных скаляров. Полного прохода или аренды эта задача не выполняет.

Каждый scan ограничен 850 с до следующего блока. Для планового продолжения повторить ту же конфигурацию; max-blocks можно менять. Завершённые блоки не пересчитываются, последний частичный batch сохраняется. При полном training-совпадении дальнейшая работа останавливается для независимого рассмотрения. Ошибочный/переполненный блок не получает checkpoint. Не использовать это как разрешение полного многочасового запуска: для него нужно отдельное задание пользователя.

Измеренный WINDOWS_BENCH_TIMING.json фиксирует фактическую полную серию. При полностью готовом resume время будет только временем проверки кеша; им нельзя перезаписывать исходный таймер. GPU-event и host-clock значения сохранены отдельно из-за наблюдавшихся расхождений.

Данные prepare.py уже подготовлены Windows Python 3.11 из `.venv`, используя read-only Python/coincurve E9. Повторный запуск проверяет хэши. В WSL нужен только Python stdlib, libsecp256k1 и CUDA. Сборка: nvcc 13.2, sm_86, C++17, статический cudart. Исходная арифметика и MIT-лицензии скопированы из рабочих файлов с SHA; генератор рабочего kernels.cuh не запускался. Все пути сейчас рассчитаны на локальный workspace/WSL; перенос на аренду — отдельная версия с новой сборкой и маппингом входных путей.

Артефакты: PRIMITIVES.json, PREPARED.json, CONTROLS.json, controls/, benchmarks/, runs/, BUILD.json, GPU_INFO.json, telemetry.jsonl, IDENTITY.json, BENCH_DONE.json, ACCEPTANCE.json и FINAL_MANIFEST.json. Предварительная серия до исправления обвязки находится отдельно в pilot-before-resume-fix. Изменение вычислительного кода/данных требует новой версии, а не подмешивания результатов к этому снимку.
