# E9c — локальный перенос BX → BIP32 на CUDA выполнен

01.11.2026, Москва. RTX 3070 Ti Laptop, 8 ГиБ, sm_86. Ровно 16 схем исходной гипотезы; GPU вычисляет entropy/master/parents и child №50, CPU проверяет все training/holdout у выживших. Это поиск нормализованного начального состояния BX, не последовательный перебор приватных ключей Puzzle.

## Измеренная скорость и полный проход

| Метрика | Состояний/с, все 16 схем |
|---|---:|
| Консервативно: весь процесс по внешнему Windows Stopwatch | 629,826 |
| Основные серии: сумма состояний / сумма полного pipeline wall time | 824,019 |
| Медиана отдельных основных batch | 822,859 |
| Минимум–максимум batch | 788,995–876,943 |
| Суммарный CUDA-event таймер, отдельно | 804,481 |
| CPU E9b, 16 потоков Ryzen 9 6900HX | 32,266 |

Внешний процесс занял 240.37 с, включая инициализацию, калибровку, запись JSON/хэши, телеметрию и запуск WSL. Это намеренно консервативная оценка рабочего цикла, а не максимум ядра. Основные три серии содержат 144 batch и 183.24 с измеренного pipeline; каждый batch проверяет все 16 схем. State–scheme/s ровно в 16 раз больше; их нельзя выдавать за states/s. GPU events учитывают только kernel; CPU-проверка кандидатов и копирования включены в pipeline. Реальных выживших в измерениях 0, полных совпадений 0; ненулевая цена CPU-проверки отдельно проверена синтетикой.

Ускорение относительно сохранённой CPU-базы: **19.52×** по консервативному внешнему времени, **25.54×** по pipeline. Полный проход 2147483646 состояний экстраполируется в **56.83 минуты** / **43.44 минуты** соответственно, вместо 18.49 CPU-часа. Полный проход не запускался; стабильность на всё это время не измерена.

### Ограничение таймеров

В 109 основных batch CUDA events превышают API wall time более чем на 1%. Причина локального расхождения не установлена. Дополнительный time.time_ns даёт 812,622 states/s, а внешний Windows Stopwatch измеряет весь процесс независимо от Python-таймера WSL. Поэтому первичное число выше — внешнее, с явным включением накладных расходов. Нельзя молча вычитать CUDA time из wall time и называть разность ценой передач: при расхождении часов это некорректно. Согласно [документации NVIDIA](https://docs.nvidia.com/cuda/cuda-c-best-practices-guide/index.html), event timestamps используют часы GPU; это не диагноз обнаруженной разницы.

## Проверки

Контроли до окончательной серии: 16 SHA512, 72 HMAC, 168 public-key/invalid-scalar, 135 scalar-add/invalid-child случаев; 14 исторических BX-векторов; 80 родителей и 720 children; 4096 точных low49 сравнений на 256 состояниях; 64 сквозных synthetic сценария для всех 16 схем. Изменённый ранний фильтр отвергается на GPU, изменённое раннее training-наблюдение доходит до CPU и отвергается там, испорченный holdout отличается от полного совпадения. Эти искусственные восстановления не являются находками Puzzle.

После основной серии приёмка дополнительно сравнила все 8256 low49 значений для 516 состояний в непрерывных и граничных batch, включая некратные block size длины и конец пространства. Все совпали с независимым CPU-эталоном; 16 public keys также сверены простой Python-арифметикой. Эти дополнительные тесты не использовались для выбора параметров и не включены в статистику скорости.

Проверены границы, неполный batch, invalid range и buffer overflow. Переполнение не засчитывается как отрицательный блок: после повторения с достаточной ёмкостью возвращены все 32 ожидаемые записи. Реальный stop/resume: один блок, затем ещё три, затем ноль повторных вычислений; хвост имеет 2 состояния. Криптографические/launch/async ошибки делают блок незавершённым. Compute-sanitizer не установлен в доступном CUDA toolkit; запуск sanitizer не заявляется. Подробные артефакты — CONTROLS.json, controls/, RESUME_CONTROL.json; дополнительная итоговая проверка — ACCEPTANCE.json.

## Покрытие и ограничения гипотезы

Проведено 151,389,184 state-проверок в окончательных измерениях, включая намеренные повторы. Уникальное подтверждённое GPU-покрытие с предварительными законченными пробами и реальными контрольными блоками: **12,715,541 состояний (0.592114%)**. Пересечения объединены, прерванный незаписанный блок не включён, synthetic-примеры и произвольные эталонные состояния не прибавлялись. Старое CPU-покрытие здесь отдельно не суммируется.

Связь автора Puzzle с BX не установлена. Скорость не увеличивает вероятность этой гипотезы; отрицательный небольшой диапазон не исключает оставшиеся состояния. Неподдержанные retry/skip для недопустимых BIP32-узлов не заменяются молчаливым пропуском.

## Ресурсы и узкие места

Таблица окон — 524288 байт, явные device buffers поиска максимум 557064 байт. Это не полный VRAM footprint контекста CUDA. Наблюдаемый GPU-wide VRAM/температура/мощность/частоты сохранены в STATISTICS.json и telemetry.jsonl; power.limit сообщается N/A. Максимум memory.used включает драйвер и другие пользователи GPU, не является точным размером аллокаций алгоритма.

scan_kernel: 255 регистров/поток, 784 байт local frame; ptxas сообщает spills. Низкая потенциальная occupancy, индивидуальные field inversions и повторное HMAC-построение — обоснованные кандидаты для следующего профилирования, но их доли GPU-времени не измерены. Не переносить 94% CPU-профиля на GPU. Размер блока выбран из 64/128/256 по сохранённым пробам: SELECTION.json. Это небольшой подбор, не доказательство оптимума.

## RTX 4090

Локальная карта уже делает полный тест гипотезы по времени доступным. Для завершения этих 16 схем аренда не обязательна; полный локальный запуск потребует отдельного задания. Короткий тест RTX 4090 имеет смысл для проверки масштабирования и возможного расширения исследования, но её скорость здесь **не измерена**. Нельзя обещать множитель по числу CUDA cores или по прежним 6.2 млрд адресных проверок/с.

На [странице цен Runpod](https://www.runpod.io/pricing) при повторной проверке 01.11.2026 указано $0.89/ч для RTX 4090. [Страница модели](https://www.runpod.io/gpu-models/rtx-4090) одновременно содержит $0.89 в заголовке и $0.34 в тексте; реальный тариф/наличие требуют проверки перед заказом. Для условного расчёта используем $0.89, без развёртывания, хранения, загрузок и налогов. Аренда не оформлялась.

| Желаемый полный проход | Требуется states/s всех 16 | Условная вычислительная цена при $0.89/ч |
|---|---:|---:|
| 60 мин | 596,523 | $0.890 |
| 30 мин | 1,193,046 | $0.445 |
| 15 мин | 2,386,093 | $0.223 |
| 10 мин | 3,579,139 | $0.148 |

Это пороги, не прогноз RTX 4090. Пятнадцатиминутный отдельный тест стоил бы около $0.223 только за GPU-время при таком тарифе. Для другой машины нужна новая сборка/версия с контролями и переносимыми путями входных артефактов; текущая приёмка относится к локальной WSL-среде.

## История и воспроизводимость

Первая обвязка resume имела NameError до GPU-работы. Бенчмарк, начавшийся следующей PowerShell-командой, остановлен; исходник/измерения сохранены в pilot-before-resume-fix и исключены из окончательной статистики скорости. Завершённые корректные real-блоки сохраняют значение для покрытия. CUDA-бинарник и математика при исправлении не менялись. Ошибки и уточнения сохранены в errors/ и JOURNAL.md.
