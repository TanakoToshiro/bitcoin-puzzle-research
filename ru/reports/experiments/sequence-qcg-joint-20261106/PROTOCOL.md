# SEQ-23 — совместное нелинейное решение QCG на синтетике

Новый запрос пользователя: решать квадратичную модель с зависимостями между мономами, сначала на синтетике с исходными масками. SEQ-22 и прежние серии не изменяются. Реальные решения не являются входами нового поиска.

## Основная выборка

Четыре новые цепочки s[i+1]=a*s[i]²+b*s[i]+c mod n, a!=0, и две последовательности независимых состояний. n — порядок secp256k1, все 135 состояний; наблюдения ровно №1..70 и №75..135 шагом 5, младшие i−1 бит. Параметры a,b,c,s1 равномерны по rejection sampling SHAKE256, домен SEQ-23-v1. Состояния и параметры хранятся отдельно в CHECKER_TRUTH.json. Рабочий процесс получает только публичный INPUT.json; нет истинных старших битов, коэффициентов, начальных приближений или закрытых состояний. Случайная последовательность не объявляется заведомо несовместимой с моделью по одним маскам.

## Две эквивалентные нелинейные кодировки

Общие переменные a,b,c, 135 состояний s[i] и 134 квадратов z[i]. Обязательные связи z[i]=s[i]² mod n и s[i+1]=a*z[i]+b*s[i]+c mod n входят **в решаемую систему**, а не только в проверку кандидата. Произведения a*z и b*s также нелинейные выражения, не свободные координаты. Все 134 перехода сохраняются, включая скрытые промежуточные состояния в пропусках; свободной композиции степени 32 нет.

1. `nia`: Z3 QF_NIA, точные ограниченные целые. s²=z+n*k, a*z+b*s+c=s_next+n*l; 0≤s,z,b,c<n, 1≤a<n, 0≤k≤n−2, 0≤l≤2n−3. Маски s=r+2^bits*u, 0≤u≤floor((n−1−r)/2^bits). Индекс с bits=0 не добавляет информации.
2. `ff`: Z3 QF_FF, прямые полиномиальные равенства в F_n. Для каждой непустой маски s=r+2^bits*bitsum(u_0,…), каждый u_j∈{0,1}; отдельно задаётся точная верхняя граница двоичного u, исключающая обход маски через редукцию mod n. Это не два независимых продукта-решателя: обе кодировки используют один установленный Z3, но разные теории.

Обе сохраняют зависимости мономов полностью для данной модели. Никаких дополнительных HG-уравнений не требуется; сложность переносится в общий нелинейный поиск.

## Общий сдвиг и критерий успеха

Пусть M=2^max(bits)=2^134. Общий сдвиг d преобразует состояния s'=s+d mod n, коэффициенты a'=a, b'=b−2*a*d, c'=a*d²−b*d+c+d mod n. Если наблюдаемые состояния не пересекают границу модуля и d кратно M, маски сохраняются.

Без потери существования добавляется Or(s[i]<M) по наблюдаемым индексам с bits>0. Для любого допустимого решения можно вычесть M*floor(min_observed(s)/M) из всех состояний по n; наблюдаемые значения не переполняются, их маски сохраняются. Ненаблюдаемые состояния могут оборачиваться по n, что допустимо. Это корректная фиксация части свободы, не подстановка истинного значения и не утверждение об уникальности представителя.

Успех разделяется на (1) проверенное допустимое решение, (2) исходный класс общего сдвига, (3) точную исходную цепочку. Класс задаётся a, C=a*c+b/2−b²/4, y1=a*s1+b/2 mod n. Проверяется вся 135-шаговая цепочка. Любой SAT-кандидат перепроверяется обычной целочисленной арифметикой. Уникальность не утверждается без отдельного доказательства; поиск второго класса не входит в этот пилот.

## Проверка реализации перед основным запуском

Девять малых входов: p=7,11,17, по два QCG и одному случайному, горизонт 8, индексы 1,2,3,4,6,8, bits=min(i−1,bit_length(p)−2). Это тест кода и пропусков, **не исходные 256-битные маски**. Полный независимый перебор a,b,c,s1 даёт все допустимые решения. Обе SMT-кодировки должны вернуть правильный SAT/UNSAT и любой SAT-кандидат из полного множества.

Дополнительно полностью известная последовательность [2,7,6,9,7] mod 17: первые три перехода однозначно задают a=b=c=1, следующий должен дать 6 вместо 7. Точная модель UNSAT; снятие связей z=s² делает её SAT. Эта абляция прямо проверяет, что зависимости мономов действуют внутри поиска. Применяется только к этому техническому входу, не к основной серии.

На малых входах дополнительно проверяется эквивалентность фиксации общего сдвига и сохранение класса. Исходные QCG и их преобразованные представители должны удовлетворять всем сохранённым SMT-утверждениям после подстановки, без поиска и без передачи этих значений рабочим процессам основного запуска.

## Лимиты и статусы

Каждый малый SMT-запрос: 10 секунд внутри Z3, 25 секунд внешний предел. Каждая из 12 основных пар вход/кодировка: 60 секунд внутри Z3, 90 секунд внешний предел. Не более двух независимых рабочих процессов одновременно. Внутренний max_memory=768 MB; внешний предел private/working-set memory=1024 MiB на процесс, проверка раз в 0.25 с. Внешняя остановка применяется только к созданному рабочему процессу.

SAT, solver-UNSAT, unknown/timeout, memory limit, внешний timeout и техническая ошибка — разные статусы. UNSAT на положительном контроле или ошибка точности останавливает допуск. Непройденный малый контроль не разрешает основную серию. Таймаут не отрицательный результат и не доказательство отсутствия связи. Проверка чувствительности остаётся пилотной: четыре положительных входа не дают надёжной статистической оценки. Реальные ключи не проверяются даже при успехе пилота.

До запусков фиксируются код, аудитор, протокол, план, публичные входы, закрытый эталон и окружение. Все .smt2, ограничения, статистики и статусы сохраняются; таймауты можно отдельно продолжить с новыми лимитами, не меняя старые записи. Повторный запуск текущего каталога запрещён. Старые 10936 артефактов и зависимости проверяются по хешам/mtime в итоговом аудите.
