# SEQ-23: точность совместной системы и критериев

## Что решается

В отличие от SEQ-22, здесь есть поиск удовлетворяющего присваивания всей исходной нелинейной модели. Неизвестны a,b,c и состояния s[1]..s[135], а≠0, всё по простому модулю n — порядку secp256k1. Все 134 перехода заданы одновременно. В каждом переходе присутствует вспомогательный квадрат z[i] и два равенства:

```text
z[i] = s[i]² mod n
s[i+1] = a*z[i] + b*s[i] + c mod n.
```

Таким образом, мономы не стали независимыми линейными координатами. Равенство квадрата и произведения с общими коэффициентами участвуют в решении до получения кандидата. После исключения z получается в точности заданный QCG; после его введения максимальная степень каждого уравнения равна 2. Это не означает малой вычислительной сложности.

№70→75, №75→80 и другие интервалы содержат все промежуточные s. Нет ни сжатия пропусков, ни свободного полинома степени 32. Фактических констант a,b,c из синтетического эталона в рабочих запросах нет.

## Ограниченные целые

Для единственных представителей 0≤s,z<n существуют единственные целые k,l:

```text
s[i]² = z[i] + n*k[i]
a*z[i] + b*s[i] + c = s[i+1] + n*l[i].
```

Точные достаточные границы: 0≤k≤n−2 и 0≤l≤2n−3. Первая следует из (n−1)²; вторая — из 2(n−1)²+(n−1). Все переменные целые, поэтому ни дробных состояний, ни дробных частных нет. Маска задаётся равенством s=r+q*u, q=2^bits, с 0≤u≤floor((n−1−r)/q). Всего в полноразмерной модели 622 целочисленные переменные. Правильность представления не гарантирует, что QF_NIA-эвристика найдёт ответ в отведённое время.

## Конечное поле и точная маска

В поле F_n частные k,l не нужны. Наблюдаемое состояние записывается как r+q*u, где u раскладывается по двоичным полевым переменным v_j. Каждое v_j явно принадлежит {0,1}; bitsum даёт Σ2^j*v_j. При bits>0 длина разложения меньше разрядности n, поэтому само u не оборачивается по модулю. Дополнительно задано двоичное сравнение u≤U, U=floor((n−1−r)/q). Тогда 0≤r+q*u<n, и полевая запись имеет в точности требуемые младшие биты.

Без верхней границы r+q*u могло бы оборачиваться по n и давать другой остаток modulo q. Поэтому верхняя граница — часть исходной точной задачи, не эвристическое усиление. Для bits=0 нет информации, поэтому разложение этого состояния на биты не требуется. Ненаблюдаемые состояния также остаются полевыми переменными без раскрытия.

Полноразмерная полевая система: 3 коэффициента + 135 состояний + 134 квадрата + 17225 неизвестных двоичных переменных = **17497 переменных**. Утверждений 17659: 1 условие a≠0, 134 связи квадратов, 134 перехода, 17225 условий битов, 82 маски, 82 точные верхние границы и 1 условие выбора представителя общего сдвига. Это крупная нелинейная система, несмотря на степень 2 каждого арифметического равенства.

## Удаление части свободы общего сдвига

Для произвольного d∈F_n преобразование

```text
s'[i] = s[i]+d mod n
a' = a
b' = b−2*a*d mod n
c' = a*d²−b*d+c+d mod n
```

сохраняет все переходы. Пусть M=2^max(bits), для основной серии M=2^134. Обозначим минимум наблюдаемых состояний с bits>0 через m. Выбор d=−M*floor(m/M) сдвигает все наблюдаемые представители вниз, не пересекая 0 и n, а их младшие биты сохраняются. Ненаблюдаемые состояния могут оборачиваться по n; это не нарушает ни переходов, ни данных.

Поэтому ограничение «хотя бы одно информативно наблюдаемое состояние меньше M» сохраняет существование решения. В NIA это дизъюнкция неравенств; в FF — дизъюнкция обнулений соответствующих старших битов u. Значение m не передаётся решателю: он сам выбирает состояние и параметры. Это не единственный представитель каждого класса и не доказательство однозначности восстановления.

Для сравнения с эталоном используются инварианты общего сдвига:

```text
a,
C = a*c+b/2−b²/4 mod n,
y1 = a*s[1]+b/2 mod n.
```

Равенство этих трёх величин для двух QCG с a≠0 эквивалентно принадлежности одному классу общего полевого сдвига: b задаёт сдвиг d, равенство y1 связывает начальные состояния, равенство C даёт нужное преобразование c. Дальнейшие состояния совпадают с точностью до этого сдвига по индукции.

При этом сама модель может иметь и другие неоднозначности. Например, №1 не несёт наблюдаемых битов, и два прообраза одного s[2] под квадратичным переходом могут давать одинаковые позднейшие состояния. Поэтому допустимый SAT-кандидат считается решением системы даже при отличии от эталонного класса. «Проверенное решение», «эталонный класс сдвига» и «точная эталонная цепочка» учитываются отдельно; уникальность не исследуется этим пилотом.

## Проверка действия зависимостей во время поиска

Полностью наблюдаемые состояния [2,7,6,9,7] mod 17 несовместимы с QCG. Три различных входа 2,7,6 и выхода 7,6,9 однозначно задают квадратичный полином X²+X+1. Для входа 9 он даёт 6, а наблюдается 7.

При наличии z=s² обе кодировки отвечают UNSAT. При снятии **только этих** связей отвечают SAT: свободные z могут подстроить переходы. Такие SAT-модели не проходят проверку исходной QCG-рекурсии. Следовательно, зависимости действительно ограничивают поиск, а не лишь фильтруют его вывод.

## Проверки и ограничения интерпретации

Независимый полный перебор малых a,b,c,s1 проверяет ответы SMT. Все допустимые малые цепочки дополнительно преобразуются общим сдвигом: проверяются маски, членство в полном множестве решений и инварианты класса. Закрытая подстановка эталонных значений во все утверждения подтверждает совместимость положительных контролей с кодировкой; это **не запуск восстановления с известным ответом** и не измерение чувствительности.

Набор малого поля нужен только для проверки реализации. Там иной модуль и иной объём масок. Ответы на нём нельзя переносить на основной 256-битный набор. Случайный малый вход иногда допускает настоящую QCG, что корректно учитывает полный перебор; метка random не равнозначна UNSAT.

Неуспех по времени, памяти или внутреннему лимиту решателя сохраняется как вычислительная незавершённость. Никакое число таких остановок не доказывает отсутствие квадратичной связи у исходных ключей. Все реальные ключи остаются вне новой серии.
