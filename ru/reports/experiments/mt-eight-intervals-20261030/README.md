Параметры/код защищены manifest.json. Для нового варианта создать другую папку; не менять модель и не переиспользовать просмотренный подтверждающий набор как слепой. `controls.py` повторяет только 26 малых контролей и не требуется для продолжения завершённого запуска.

`runs/<case>-<algorithm>/request.json` — точный публичный вход; `result.json` — ответ, операции, время, память; DONE.json — хэши. Секреты отдельно в VERIFIER_ONLY_FIXTURES.json, исходная фиксация SHA в FIXTURES_HASH.json. Solver не открывает этот файл, не читает имена каталогов и запускается только с JSON в stdin. Независимые соли входят в сохранённые публичные входы. 56 задач: 24 основные, 16 по изменению K, 16 подтверждающих; 168 сравнительных запусков. Пилот хранится отдельно и не входит в SUMMARY/TABLES.

Ограниченный неуспех kangaroo не доказывает отсутствие ключа. Все положительные результаты проверяются точным умножением, а проверяющий процесс отдельно сравнивает секрет. Python tracemalloc не измеряет память нативной библиотеки. CPU, без облака и GPU.
