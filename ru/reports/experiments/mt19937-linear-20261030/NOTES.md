# E1: интерпретации и промежуточные выводы

## 2026-10-30 — до основных вычислений

Протокол зафиксирован в PROTOCOL.md. Схем восемь; seed не подбирается; проверяется проекция множества достижимых состояний на 70 неизвестных битов №71.

При разработке разделены обычное исключение для построения ступенчатой матрицы и полная редукция по наблюдениям для целевой проекции: остановка на первом свободном старшем столбце оставляет нижние опорные столбцы и непригодна для канонической проекции. До использования данных добавлены отдельный регрессионный контроль и сравнение 120 малых систем с полным перебором. Научные результаты ошибочным вариантом не вычислялись.

Первый набор из десяти контрольных тестов прошёл за 0,867 с: известный MT-вектор, CPython, символьное исполнение через несколько twist, ранг 19937, восстановление полного состояния, противоречия, XOR при свободных одиночных битах и упаковка. После добавления независимого проверяющего кода выполняется расширенный контроль с синтетическими данными и намеренным повреждением свидетельства.
