# E1: MT19937 → определённость битов Puzzle 71

Изолированный эксперимент. [Зафиксированный протокол](<PROTOCOL.md>), [численные результаты запусков](<RESULTS.md>), [интерпретации и промежуточные выводы](<NOTES.md>).

**Завершён:** [вывод и сертификаты запуска 20261030-093024-0567d283](<runs/20261030-093024-0567d283/CONCLUSION.md>). Во всех восьми схемах любой 70-битный остаток №71 совместим с известными решениями; найденных ограничений на биты или XOR нет. Это результат для произвольного достижимого состояния MT, не исключение узких seeded-моделей.

Используется Python 3.11 из существующего исследовательского окружения. Символическое исполнение и GF(2) используют Python integer, без Z3; coincurve применяется только для повторной проверки опубликованных решений. Внутреннее состояние не ищется по seed: рассматривается полный образ перехода MT размерности 19937.

`resume` проверяет хеши замороженного кода, данных и завершённых артефактов, а также версию среды. Использует `runs/ID/code/`, завершённые этапы не выполняет повторно. Незавершённая схема пересчитывается целиком; её уже сохранённые стадии доступны для чтения. Каждый вызов записывается отдельно в `invocation-N.json`, события дописываются в `EVENTS.jsonl`. Новый код для нового исследования запускать через `run`, не менять замороженную папку.

Матрицы сохраняются как простой бинарный формат, описанный в отчёте; pickle не используется. Каждый коэффициент — битовая маска координат состояния. В `witnesses.json` большие числа заданы hex: координата 0 — старший бит слова 0, координаты 1…19936 — последовательные младшие→старшие биты слов 1…623 до twist. Для числового воспроизведения установить индекс MT=624.

Граница результата: несовместимость исключает указанную схему; неопределённость в произвольном состоянии не исключает дополнительной информации от ограниченного seeding. Совместность не подтверждает историческое происхождение puzzle. Ускорение поиска не заявляется без полученных и независимо проверенных ограничений.

Она использует замороженный генератор и другую реализацию исключения, основной эксперимент не повторяет. `summarize_run.py` — добавленный после расчёта вспомогательный генератор отчёта, его хеш записан в приёмке; исходники самого запуска неизменны.
