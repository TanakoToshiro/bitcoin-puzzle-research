# SEQ-03 — скрытое состояние и модульная аффинная цепочка

[Итог](<FINAL_REPORT.md>), [исходная постановка](<PROTOCOL.md>),
[поправка о неоднозначности](<AMENDMENT-01.md>), [журнал](<JOURNAL.md>).

Первый конечный цикл завершён. Точное исключение всех -2^32<=a<=2^32
при любом c,s[1] modulo n; четыре положительных полноразмерных
восстановления a,d и множеств состояний. Общий SMT не прошёл контроли;
произвольный256-битный множитель остаётся открытым.

Исходные команды стадий:

Завершённые controls/real/SMT пропускаются. Перед повтором проверять seal.
`setup` и `audit` записывают файлы: для полного вычислительного повторения
использовать отдельную копию серии с новым набором результатов, сохраняя
принятую. Отчёт фиксирует фактически выполненный цикл, а не результаты
любого будущего изменения кода.

Файлы:

- `core.py`: точный модульный фильтр, решётка, прогрессии состояний, проекции.
- `study.py`: подготовка, синтетика/контроли, конечная реальная проверка.
- `smt_pilot.py`: общий неизвестный a, изолированные процессы/тайм-ауты.
- `audit.py`: независимые арифметические проверки без импорта `core.py`.
- `REAL.json`, `EXCLUSION_CERTIFICATE.json`: точное отрицательное заключение.
- `controls/`: наблюдения и истины синтетики, решётки и преобразования.
- `SMT_SUMMARY.json`, `smt/`: результаты, тайм-ауты и журналы процессов.
- `MANIFEST.json`: хэши основного кода/протокола/входа до реальной проверки.
- `REPRODUCIBILITY.json`: окружение и использованные локальные зависимости.
- `ARTIFACTS.json`: итоговый seal; `ACCEPTANCE.json`: итоговая приёмка.

В JSON восстановления `state`/`increment` — первоначальный представитель
Babai, который может нарушать наблюдения (`raw_babai_accepted=false`).
Поле `accepted` относится к непустому **исправленному** `state_families`,
а не к этому представителю. Использовать `difference` и прогрессии
`state_families`; не выдавать исходный представитель за найденный ключ.

Используется существующий Python3.11 и z3 из `.venv`. SymPy/python-flint
читаются из соседнего `child-derivation-audit-20261102/vendor`; никаких
установок, изменений пакетов, GPU или старых результатов нет. Старый
исследовательский код не импортируется. Запись bytecode отключена.

Серия не исследует кошельковые файлы и не отправляет транзакции.
Настоящий ключ или бит нерешённой задачи не получен.
