# SEQ-03 — скрытая модульная цепочка: первый цикл

Дата: 02.11.2026, Москва. Продолжение поиска связей после SEQ-01/02.

**Получено точное отрицательное заключение для одного нового класса:
скрытая аффинная цепочка modulo порядка secp256k1 с любым множителем
от −2^32 до 2^32 несовместима с опубликованными решениями.**
Прибавка и начальное состояние при этом разрешены произвольными во всём
256-битном диапазоне modulo n. Это не перебор коротких seed.

Одновременно обнаружена и проверена неоднозначность восстановления:
множество разных полных состояний и прибавок может давать те же
маскированные ключи. На четырёх искусственных цепочках восстановлены
множитель и инвариант цепочки, а все допустимые начальные состояния
описаны арифметическими прогрессиями. **Реального нового ключа, бита
или сокращения диапазона нерешённой Puzzle не получено.**

## 1. Отличие от предыдущих проверок

Модель:

```text
s[i+1] = (a*s[i] + c) mod n
r[i]   = s[i] mod 2^(i−1)
puzzle[i] = 2^(i−1) + r[i]
```

Здесь n — порядок группы secp256k1, а не модуль её координатного поля:

```text
n = FFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEBAAEDCE6AF48A03BBFD25E8CD0364141
```

SEQ-01/02 рассматривали прямые рекурсии наблюдаемых остатков modulo2^w.
Теперь при редукции полного состояния вычитается q*n. Поскольку n нечётно,
неизвестный q меняет младшие биты. Поэтому прежнее противоречие по чётности
не доказывало отрицательный результат этой серии.

Один шаг соответствует одному номеру puzzle, порядок прямой, a,c постоянны.
Разрешены 0<=s[i],c<n; нулевое скрытое состояние не запрещалось. Отрицательные
a представляют множители n−u. Историческое использование этой модели автором
не установлено. Маскирование исходного состояния — тоже предположение.

Вход — прежние83 опубликованных решения с тем же SHA-256. Множитель и
инвариант подбирались бы по №1–70; №75,80,…,135 предназначены для дополнительной
проверки. Эти данные ранее изучались и не являются новым закрытым тестом.

## 2. Точное исключение 8 589 934 593 множителей

Пусть q[i]=floor((a*s[i]+c)/n). При a>=0 значения q лежат в [0,a],
при a<0 — в [a,0]. Следовательно, |q[i]−q[i+1]|<=|a|.
Вычитаем два последовательных перехода:

```text
s[i+2] − (a+1)*s[i+1] + a*s[i] = (q[i]−q[i+1])*n
```

Для №68,69,70 известны общие младшие67 бит. Обозначим M=2^67,
d1=r[69]−r[68], d2=r[70]−r[69] (mod M). Для любого допустимого a:

```text
h = (d2−a*d1) * inverse(n,M) mod M
```

Должен существовать целый представитель h с |h|<=|a|.
При |a|<=B=2^32 достаточно проверить более широкое условие |h|<=B.
**Даже это расслабленное условие не выполняется ни для одного a в [-B,B].**

Полный диапазон посчитан точно через целочисленные суммы floor и
евклидовы преобразования. Прохода по8.6 млрд значениям не было.
Неизвестные старшие биты, c и s[1] из необходимого условия устранены.

Сертификат EXCLUSION_CERTIFICATE.json — артефакт исходного исследования (`EXCLUSION_CERTIFICATE.json`; вне снимка)
содержит исходные остатки, обратный элемент, коэффициенты и две суммы:

```text
8 589 934 593
+ 30 262 565 723 027 149 167
− 30 262 565 731 617 083 760
= 0
```

Это число допустимых a для расслабленного условия, а не p-значение.
Независимая реализация считала те же целочисленные точки по другой
рекурсивной формуле и получила тот же ноль. При точном противоречии
не требуется оценивать вероятность случайного лучшего совпадения.

Исключены a=0..2^32 и a=n−2^32..n−1 modulo n. Остальная часть
диапазона множителей этой проверкой не исключена.

## 3. Что восстановлено на искусственных цепочках

Первый положительный тест выявил ошибочную предпосылку первоначального
плана: нельзя требовать восстановления именно исходных s[1],c без
проверки их единственности. Поправка оформлена **до реального анализа**
в [AMENDMENT-01.md](<AMENDMENT-01.md>); исходный протокол сохранён.

Точная симметрия:

```text
s'[i] = (s[i]+delta) mod n
c'    = (c+(1−a)*delta) mod n
```

Она сохраняет рекурсию. Если delta кратна2^134 и ни одно наблюдаемое
s[i]+delta не пересекает0/n, сохраняются все83 наблюдаемых остатка.
Условие отсутствия перехода через границу существенно: это не утверждение
о неоднозначности любого возможного набора данных.

Инвариант общего сдвига:

```text
d = ((a−1)*s[1]+c) mod n
s[i] = (s[1]+T[i]*d) mod n
T[1]=0; T[i+1]=(a*T[i]+1) mod n
```

Восстановитель получает только маскированные наблюдения. Фильтр определяет
a; взвешенная решётка с двумя неизвестными, LLL и рациональный Babai
предлагают d. Для фиксированного a,d все s[1] затем находятся точно:
пороги перехода через n делят диапазон на интервалы, а внутри интервала
вложенные сравнения modulo2^b дают арифметическую прогрессию.
Прибавка определяется как c=d−(a−1)*s[1] mod n.

| Истинный a синтетики | Восстановлены a,d | Число допустимых s[1] после всех83 наблюдений, log2 | Вариантов маскированного №71 |
|---|---:|---:|---:|
| 1 664 525 | Да | 117.779 | 1 |
| −1 664 525 | Да | 116.366 | 1 |
| 2 147 483 647 | Да | 116.676 | 1 |
| −4 294 967 296 | Да | 116.019 | 1 |

Для LLL использовались №59–70; истинные состояния в восстановитель не
передавались. Проверены все наблюдения до70 и совместимость13 дополнительных
индексов. На каждом примере явно построены разные совместимые состояния
со сдвигом2^134. Проекция всех найденных семейств на №71 единственна и
совпадает с синтетической истиной. Это пример того, что предсказание
маскированного ключа иногда возможно без единственного полного состояния.
**Это не предсказание настоящего №71.**

LLL/Babai не перечисляет все возможные d. Неудача этого шага не означает
несовместности модели. Точное перечисление состояний условно на найденные a,d.

## 4. Произвольный множитель modulo n

Отдельно испытано прямое описание всех скрытых состояний и a,c в QF_NIA
(Z3),20 секунд на задачу, внешний ограничитель30 секунд, один поток,
лимит памяти решателя1 ГиБ.

На игрушечном модуле31 маски масштабированы по исходным номерам:
floor((i−1)*5/256). Исчерпывающий перебор a,c,s[1] установил:

| Контроль | Точное число решений | Прямой SMT |
|---|---:|---|
| Положительный, a=7 | 1 | unknown / timeout |
| Положительный, a=27 | 2 | остановлен внешним ограничителем |
| Случайный отрицательный | 0 | unknown / timeout |
| Полноразмерный положительный, произвольный a | Не подсчитывалось | unknown / timeout |

Прямое нелинейное описание не прошло положительные контроли. На настоящих
данных общий SMT-поиск поэтому **не запускался**. Это ограничение испытанного
алгоритма/формулировки, не доказательство отсутствия или наличия общей цепочки.
Результаты и stderr процессов: SMT_SUMMARY.json — артефакт исходного исследования (`SMT_SUMMARY.json`; вне снимка), smt/ — артефакт исходного исследования (`smt/`; вне снимка).

## 5. Проверки и сохранность

- 5000 floor-сумм и3000 подсчётов/перечислений сверены прямым перебором.
- 16 250 полных малых случаев проверили границы q и знаки уравнения.
- 800 малых задач точного множества состояний сверены полным перебором;
  также проверены их проекции на другие индексы.
- Четыре полноразмерных восстановления, четыре изменения одного наблюдения,
  a=0,1,−1 как вырожденные случаи;16 случайных последовательностей отвергнуты
  фильтром. Последнее — контроль поведения, не оценка универсальной мощности.
- Независимый аудит:4000 новых floor-примеров, реальный сертификат,
  все четыре множества состояний, U*B=B_reduced, det(U)=±1, коэффициенты Babai,
  прямое исполнение по представителям, включая концы прогрессий.
- Проверены SHA-256 и времена изменения162 файлов старых серий,
  включая их seals. Старые научные артефакты не изменены.

Основные контроли заняли2.203s, реальный фильтр около0.00058s,
независимый аудит около0.111s (без старта Python). SMT-процессы заняли
порядка полутора минут суммарно; один достиг внешнего watchdog.
Разработка и оформление в эти времена не входят. GPU не использовался;
библиотеки общей среды не устанавливались и не изменялись.

История содержит первый AssertionError на ложном требовании уникальности
state. Кроме того, исправлено затенение переменной в итоговом поле AUDIT;
ошибочный JSON сохранён отдельно, сам нулевой сертификат был правильным.
Результаты этих разработческих ошибок не скрывались и не принимались
за научный вывод.

Приёмка и неизменность повторного запуска: ACCEPTANCE.json — артефакт исходного исследования (`ACCEPTANCE.json`; вне снимка).
Команды и состав файлов: [README.md](<README.md>).

## 6. Что имеет смысл делать дальше

Текущий отрицательный результат закрывает именно короткий подписанный
множитель в постоянной одношаговой аффинной цепочке modulo n. Не закрыты:
большие множители, другие модули, перестановки/пропуски, переменные
параметры, другая функция вывода и криптографическая деривация.

Для большого неизвестного a нужен новый метод на разностях и переносах,
с устранением общего сдвига до решения. Сначала он должен восстанавливать
или точно ограничивать a,d на новых синтетических примерах и отличать
совместимость от предсказуемости. Простое увеличение тайм-аута нынешнего
QF_NIA или расширение списка формул этот этап не заменяет.

Математический контекст решёточного восстановления усечённых величин:
[Frieze et al., 1988](https://doi.org/10.1137/0217016).
Применимость к полностью неизвестному множителю здесь не доказана;
новизна алгоритма в мировой литературе не заявляется.
