# Связь пары Qx–Qy с половиной диапазона

Проверены те же 73 ключа. На ключ приходится одна публичная точка. Нулевые контроли сохранены из предыдущего расчёта, включая историю подписей. Использованы 2 047 калибровочных корпусов и 256 независимых нулевых корпусов на схему.

Для координат взяты номера четвертей поля. Тесты чётности сравнивают метку верхней половины диапазона ключа с равенством половин координат или чётностей их четвертей. Пирсон 2×16 проверяет распределение по 16 парам четвертей. Статистики откалиброваны эмпирически. Поправка min-P учитывает 3 теста пары, 27 тестов девяти пар с координатами и 133 теста всей серии на этих контролях.
