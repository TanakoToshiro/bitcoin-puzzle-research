# Развёртывание и подготовительные исправления

Научные входы не запускались до прохождения всех предварительных контролей.

1. В conda-forge не нашлось запрошенных flatter/msolve. Они собраны из
   закреплённых официальных исходников. Sage установлен отдельно.
2. Начальный prefix в /tmp исчез между запусками WSL. Окончательное
   окружение создано в /home/tanako/.local/share/cuso-seq15/env.
3. Для flatter закреплена совместимая Eigen 3.4 и явно задан путь
   заголовков prefix. Для msolve использован git archive с Unix-переносами;
   исходный Windows checkout не редактировался. 71 штатный тест прошёл.
4. Sage 10.9 удалил псевдоним MPolynomial.is_generator. Авторский MIHNP
   контроль обнаружил это до основной выборки. sage_compat.py заменяет
   только имя вызова на is_gen в памяти. Первый прототип адаптера терял
   closure для super(); ошибка сохранена, затем привязка исправлена и все
   контроли повторно прошли. Математические стратегии cuso неизменны.
5. Первый независимый аудит через HNF оказался медленным и был остановлен
   отдельно от научных процессов. Заменён эквивалентной точной проверкой:
   решение по треугольной исходной матрице, T·B=L, det(T)=±1. Все 302
   завершённые редукции проверены этим способом. Промежуточные результаты
   научных запусков не заменялись.

Предварительные манифесты и ошибки находятся в setup_logs. Финальный
манифест основной серии — RUN_MANIFEST.json; более лёгкая контрольная
выборка имеет отдельный CALIBRATION_MANIFEST.json. Она выбрана адаптивно
после наблюдения ограничений основной серии и не смешана с её статистикой.

flatter использован в штатной конфигурации cuso; это не прежний FLINT LLL
с delta=0.99/eta=0.51. Сравнение времени не является контролируемым
измерением эффективности одного лишь правила выбора сдвигов.
