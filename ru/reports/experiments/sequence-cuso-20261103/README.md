# SEQ-15 — cuso на сохранённых задачах

Итог и ограничения: [FINAL_REPORT.md](<FINAL_REPORT.md>).
Основная выборка: [PROTOCOL.md](<PROTOCOL.md>), RUN_PLAN.json — артефакт исходного исследования (`RUN_PLAN.json`; вне снимка),
SELECTED.json — артефакт исходного исследования (`SELECTED.json`; вне снимка). Позднее добавленные более лёгкие контроли:
[CALIBRATION_PROTOCOL.md](<CALIBRATION_PROTOCOL.md>).

Проверяется настоящий cuso 0.4.0 с двумя стратегиями автора. Исходники
в `sources/cuso` не изменены. `sage_compat.py` заменяет только удалённое
имя Sage API is_generator на is_gen в одной проверке типа аргумента.
Все параметры, полиномы, логи, завершённые решётки и аудиты сохранены.
Truth не передавался решателю. Новые реальные ключи не исследовались.

Окружение WSL: `LINUX_ENVIRONMENT.json`, точный conda-lock
`setup_logs/conda-explicit.txt`, сборка native-библиотек `build_native.sh`.
`bootstrap_env.sh` и первоначальные setup-логи оставлены как история
неуспешного начального развёртывания; для воспроизведения используется
сохранённый explicit lock, затем `build_native.sh`.
Runtime находится в `/home/tanako/.local/share/cuso-seq15/env`.

`run_experiment.sh` проверяет авторские примеры и вызывает основной runner.
`run_calibration.py` запускает отдельную дополнительную выборку.
Runner не пересчитывает записанный результат. Таймауты сохраняют вход,
журнал и завершённые промежуточные артефакты, но не внутреннее состояние
незавершённого Gröbner/графового вычисления. Изменение лимита требует новой
попытки в отдельном каталоге, прежний результат не перезаписывается.

Аудит: `audit_results.py` и тот же скрипт с `--calibration`.
Он использует независимую Windows-среду прежней серии: SymPy для раскрытия
исходных кубик, FLINT для точных преобразований решёток и проверенный
декодер только для уже возвращённых cuso корней.

После приёмки единственная штатная операция в этой папке — read-only
`verify.py` из `research/puzzle71-hypotheses/.venv/Scripts/python.exe -B`.
Прежние серии сохраняются по SHA-256 и времени изменения; upstream-код,
native-библиотеки и conda-пакеты закреплены отдельными манифестами.
