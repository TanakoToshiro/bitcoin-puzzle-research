# EXP-01 — воспроизведение исторического экспорта

03.11.2026. Завершено. [RESULTS.md](<RESULTS.md>), [PROTOCOL.md](<PROTOCOL.md>),
[MATH.md](<MATH.md>), [SUMMARY_FOR_MERGE.md](<SUMMARY_FOR_MERGE.md>).

Electrum1.7.4 CSV против точной модели CPython2.7.9 dict, Windows x86/amd64 и
Linux x86_64. Контрольный exporter1.9.8. Это настоящие исторические интерпретаторы
и неизменённые выделенные методы, с адаптерами вместо полного GUI/storage/network.
Нет работы с пользовательским кошельком, сетью Bitcoin или реальными seed.

Из этой папки, существующее окружение:

> Исполняемый код/команды опущены в документационной копии.


Завершённая серия только проверяется; native-job не повторяются. Незавершённая
серия продолжается через run.py, совпавшие DONE.json пропускаются после проверки
хэшей. В Windows sandbox32-bit runtime не запускается из-за relocation DLL:
реальные native-прогоны выполнены с разрешённым доступом за пределами sandbox.

Пересборка отчёта без повторного исполнения кошельков:

> Исполняемый код/команды опущены в документационной копии.


Для повторного аудита без переписывания сертификата используйте resume.py.
Не запускать finalize.py поверх запечатанного результата: он перезаписывает
временные метки итогового аудита; при необходимости нового независимого аудита
сохранять его отдельным файлом, как в предыдущих исследованиях.

`native_worker.py` совместим именно сPython2.7.9. `dict27.py` — независимая модель
наPython3.11. `public_mapper.py INPUT OUTPUT` принимает только MPK, размеры пулов,
публичные адреса импортов и profiles(longbits,sizebits,hash_secret). Пример
public/INPUT.json в текущем run не содержит seed/master/WIF/raw private keys.

Принятый run указан ACTIVE_RUN.json; внутри него NATIVE/VALIDATION/CSV/DONE для
21 профиля, публичные входы/выходы, CSV-метрики, SUMMARY и COMPLETE.
Корневой FINAL_CERT.json закрепляет отчёт, документы, код подготовки и итог run.
Подготовительные ошибки/неудачный run не удалены. Старые119 pinned-файлов
проверены, checkpoints прежних исследований не изменялись.

`prepare.py`, `unpack_windows.py`, `prepare_linux.py`, `make_inputs.py` — подготовка,
повторять её после завершения не требуется. MSI читался через MsiOpenDatabase
read-only, CAB извлекался expand.exe; msiexec/install/изменение системного Python
не использовались. Сборки/архивы остаются внутри этого каталога.
