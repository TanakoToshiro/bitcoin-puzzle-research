# EXP-01 — 03.11.2026, исторический порядок экспорта

Run998c4f7b58bcf26a. Подтверждён настоящий Electrum1.7.4 CSV dict-order
на CPython2.7.9 Windowsx86/amd64 и Linuxx86_64.21 профилей (unset,0,1,42,
4294967295,2random) ×6 synthetic wallets ×2 exporters =252 CSV файла.
76776 hash-проверок,546 реальных снимков dict, побайтное совпадение CSV.
Контрольный1.9.8 exporter — addresses(True), без заключительного dict-order.

Для одного R256/C3 wallet строка71: Win default receiving84, Linux default
receiving5, Win hashseed1 receiving37. Change-строки Win default83/99/114;
все3 входят в первые256. Наивная последовательная карта даёт255/256 ошибок
masked private values в этом Windows примере (№1 неизбежно1).
Эти числа синтетические, не новые сведения о реальной карте Puzzle.

Смена master изменила258/259 позиций Windows и259/259 Linux; unset→hashseed1
изменила258/259. Winx86/x64 default совпали в данном кошельке, но size_t
различается: контроль160 отрицательных коллизий изменил156 позиций.
Добавление receiving257 в данном default case не изменило порядок общих адресов;
не заявляется обязательное изменение при любом росте пула.

Public-only process получил MPK, размеры пулов, публичные импорты и hash-profile,
без seed/master/WIF/raw private keys. Все126 карт174/198 совпали. Random-secret
передавался известным: его восстановление не заявляется. Следовательно при
настоящем MPK такая карта вычислима; безMPK нет единой перестановки для всех seed.
Маскированные Puzzle-адреса не заменяют исходные raw-адреса.

Полный прогон~63.44с wall без подготовки/распаковки; public-only один кошелёк+21
профиль0.062–0.099с без startup. GPU/реальные master не перебирались.
Исходные методы1.7.4/1.9.8 неизменены, но GUI/storage/network подставные;
у1.9.8 WIF-поставщик — проверенные заранее значения. Не запуск полного PyQtGUI.
273 method snippets и910 loaded-module hashes перепроверены отдельно.
Ошибки адаптеров и старый failed run сохранены, успешные старые119 pins неизменны.

Результат меняет область применимости прежних последовательных проверок,
но не уменьшает пространство master и не устанавливает использование Electrum
автором. Следующий содержательный вход — MPK/связанный экспорт или обоснованный
кандидат исходного master с проверкой точной карты, а не произвольной перестановки.
