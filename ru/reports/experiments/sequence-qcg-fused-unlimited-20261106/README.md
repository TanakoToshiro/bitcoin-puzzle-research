# SEQ-29 — фоновый запуск QCG без ограничения времени

По поручению пользователя от 06.11.2026: запустить и подтвердить только успешный старт. Дальнейшая проверка — после нового сообщения пользователя. Это живой запуск, не итоговый отчёт или сертификат завершения.

Очередь: full00..full05, последовательно. Пока один вход работает, остальные ждут. Параметры: ff.preprocess=false, ff.fused_reduction=true, timeout=0 (таймер Z3 выключен), max_memory=8192 МиБ. Внешний таймер процесса удалён. Исходные маски, все связи мономов, encoder и worker SEQ-28 сохранены; каждый worker сравнивает тело SMT с SEQ-24.

Автоматический фоновый процесс контролирует память: максимум working/private 8 GiB с опросом 0.25 с, прежний аварийный резерв памяти компьютера 2 GiB. При превышении останавливает текущий worker и записывает причину. Перед новым входом проверяет наличие 10 GiB доступной памяти; при недостатке ждёт до 120 с и откладывает этот вход. Это защита по памяти, не предел времени решения. Внутренние алгоритмические бюджеты Z3 прежние.

Работа начинается заново; сохранённого checkpoint старого поиска нет. Процесс не переживает перезагрузку компьютера. Новые результаты по мере появления сохраняются в runs/fullXX; MEMORY.jsonl и PHASES.jsonl содержат журнал. queue.stdout.log и queue.stderr.log — вывод фонового управляющего процесса. RUN_STARTED.json и LAUNCH.json содержат идентификаторы процессов; START_CONFIRMED.json фиксирует только наблюдавшийся успешный старт, не текущее состояние в будущем. RUN.json появится после завершения очереди.

Ассистент не создаёт расписаний и не наблюдает за дальнейшим выполнением. Фоновый ограничитель памяти и запись журналов работают самостоятельно. Итоговый аудит/закрытие открытых задач в этом запуске ещё не выполнялись. Старые запечатанные серии не изменяются.
