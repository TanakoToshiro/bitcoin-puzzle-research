# O2-S01 — точные ограничения без перечисления классов

## Эквивалентная модель

Все состояния s_i и разности d_i канонические в [0,p). Положим d_i=(s_(i+1)−s_i) mod p. Исходная аффинная рекурсия эквивалентна системе

```
d_(i+2) = a*d_(i+1)+b*d_i mod p,
s_(i+1) = s_i+d_i mod p,
0 <= a < p, 1 <= b < p.
```

Из исходной рекурсии равенство для разностей получается вычитанием соседних строк. Обратно выражение c_i=s_(i+2)−a*s_(i+1)−b*s_i постоянно modulo p, поскольку c_(i+1)−c_i=d_(i+2)−a*d_(i+1)−b*d_i=0. Поэтому нет лишних последовательностей: c восстанавливается по первым трём s. Вырожденные последовательности меньшего порядка намеренно не отбрасываются.

Символически остаются неизвестными a,b,134 разности и135 состояний. Это факторизованная по c запись, но она содержит свободный общий сдвиг через состояния. Решатель не перечисляет классы заранее: ищет любые значения, удовлетворяющие ограничениям. Внутренний SAT-поиск всё равно может иметь экспоненциальную сложность; отсутствие внешнего цикла по классам не означает полиномиального алгоритма.

## Переносы и точные границы

В целых числах ту же систему можно записать так:

```
s_i+d_i = s_(i+1)+p*epsilon_i, epsilon_i in {0,1},
a*d_(i+1)+b*d_i = d_(i+2)+p*q_i,
0 <= q_i <= 2*p-4.
```

Последняя граница следует из 0<=a*d_(i+1)+b*d_i<=2*(p−1)^2 и floor(2*(p−1)^2/p)=2p−4 для p>=3. Переносы нельзя отбросить или предположить равными. Если проецировать сравнение на младшие биты, член p*q_i остаётся; при нечётном p он вообще не исчезает modulo2^k. Поэтому наблюдаемые младшие биты сами по себе не задают аналогичную рекурсию modulo2^k.

В реализации w=bit_length(p); a,b,s,d имеют w бит и беззнаковые ограничения <p. Сумма s+d вычисляется в w+1 битах. Сумма двух произведений и правая часть с q вычисляются в 2w+1 битах, q имеет w+1 бит. Эти ширины исключают неучтённое переполнение: суммы не достигают2^(w+1) и2^(2w+1) соответственно. Альтернативная кодировка использует URem той же полной суммы modulo p. Модуль p не заменяется2^w, XOR не используется вместо сложения.

Все135 индексов остаются в цепочке. Маски только на исходных83 номерах, старший установленный puzzle-бит не наблюдение. Поздние номера не сжимаются. На уменьшенных модулях ширины масштабируются с округлением вниз, как в O2-Q01.

## Проверка цели без перечисления состояний

После SAT проверяем свидетельство обычной целочисленной арифметикой и получаем r=s71 mod2^h. Добавляем только запрет этого r. Это исключает сразу ВСЕ состояния и классы с таким прогнозом. Каждый следующий SAT показывает новый возможный прогноз. Завершающий UNSAT доказывает, что найдено всё множество прогнозов для данной модели и входа. UNKNOWN не исключает ни одного не найденного значения; пустой список при UNKNOWN не означает пустую проекцию.

Это более слабая цель, чем восстановление всех коэффициентов/состояний, но даже первый SAT требует решения нелинейной модульной системы. Проверки на полностью раскрытых состояниях отдельно от проверок частичных масок: положительный полный контроль не подтверждает масштабирование на скрытых данных.
