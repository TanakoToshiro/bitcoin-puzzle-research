# O2-S01 — ограничения на коэффициенты и разности

6 ноября 2026, Europe/Moscow. Продолжение O2-Q01. **Точная модель без внешнего перечисления классов построена и проверена, но испытанный символический поиск не дал практического выигрыша. На всех28 частичных запросах основной серии достигнут лимит без SAT-свидетельства. Это предел двух конкретных кодировок/режимов Z3, не опровержение рекурсии и не доказательство невозможности восстановления. Реальные ключи не исследовались этим решателем.**

## Что именно сделано

Вместо перебора `(a,b,d1,d2)` записана система неизвестных модульных разностей:

```
d_(i+2) = a*d_(i+1)+b*d_i mod p
s_(i+1) = s_i+d_i mod p
```

Вторая точная запись сохраняет целочисленные переносы:

```
s_i+d_i = s_(i+1)+p*epsilon_i, epsilon_i in {0,1}
a*d_(i+1)+b*d_i = d_(i+2)+p*q_i, 0 <= q_i <= 2*p-4.
```

Коэффициенты a,b и все скрытые состояния неизвестны. Постоянная c исключена и восстанавливается из любого SAT-свидетельства. Доказана эквивалентность исходной аффинной рекурсии; разрядности расширены так, чтобы не терять старшие части произведений. Сохранены все135 позиций, маски наложены только на исходные83 номера. Пропуски не сжимались. [Математика](<MATH.md>).

Каждый найденный SAT-прогноз №71 должен блокироваться целиком, без перечисления остальных состояний того же класса. Только завершающий UNSAT доказывает полноту множества прогнозов. Этот приём корректен, но не гарантирует быстрый поиск первого свидетельства.

## Где остаётся препятствие

Общий сдвиг уже можно обрабатывать дёшево (O2-Q01). В новой записи узкое место — совместное определение неизвестных a,b и разностей в произведениях `a*d+b*d`, вместе с переносами q. Низкие биты наблюдений не позволяют отбросить p*q: p нечётно, поэтому этот член влияет даже на младшие биты. Битовая запись и явные границы переносов обеспечивают точность, но сами по себе не дали эффективного отсечения.

Внешний перебор примерно2^1024 классов заменён символическими ограничениями, однако внутренний SAT-поиск не обязан быть быстрым. На проверенных входах этот шаг **не оказался улучшением**. По таким результатам нет основания запускать его на реальном256-битном модуле, переносить перечисление на GPU или утверждать получение бита №71.

Для дальнейшего продвижения нужен новый способ сокращать пространство коэффициентов/старших частей до тяжёлого решателя — например, отдельная проверяемая схема исключения неизвестных или обработки ранга разностных последовательностей. Это направление следующей разработки, а не реализованный алгоритм и не обещанный выигрыш. Простое увеличение времени всех нынешних запросов на основании этого опыта не обосновано.
