# SXN-03 — переносимый поисковик для Ubuntu / RTX 4090

Подготовлен самостоятельный пакет `sx-newseed-4090-ubuntu` и архив
`sx-newseed-4090-ubuntu.tar.gz` в корне workspace. Пакет содержит 36 файлов,
897550 байт в архиве. SHA-256 архива:
`2d5f1140acf985be13c6d161dab4287906a6e883c79f19de5314d1f74f15c168`.

**Реализовано.** CUDA fat binary `sm_89` + `sm_86` + PTX89, сборка на Ubuntu,
обязательная предстартовая проверка конкретной сборки/GPU, подбор размера пакета
и threads по полным 100000 итерациям. Историческая модель и четыре X-only схемы
SXN-01/02 сохранены. Конечный домен — 4294967296 seed, 17179869184 seed×scheme.
Выбор пакета 65536/131072/262144 даёт 65536/32768/16384 непересекающихся блоков.
Это проверка планировщика, не выполненное покрытие полного домена.

После каждого завершённого пакета создаётся отдельная атомарная запись с
границами, счётчиками, кандидатами, CPU-проверками, временем, ссылкой на сборку
и хешем предыдущей записи. Файл синхронизируется на диск до публикации;
на Linux синхронизируется и каталог. При возобновлении пересчитывается вся
цепочка. Повреждение, пропуск, неверная конфигурация, незаконченный пакет и
переполнение GPU-буфера не могут молча увеличить зачтённое покрытие.

Кандидат перепроверяется независимыми scalar MT/hashlib/affine по известным
№1–50; совпавший кандидат сохраняется и останавливает поиск для анализа.
Holdout и настоящее решение №71 не использовались. После достижения конца
требуются повторное чтение покрытия и послепроходные GPU-контроли.

Запуск через `launch.py` переживает закрытие SSH. Для перезагрузки сервера
предоставлен отдельный systemd-шаблон; службы сейчас не устанавливались.
Копия на этом Windows-ПК обновляется исходящим SSH раз в минуту, с SHA-256,
проверкой диапазонов и повторным чтением локальных файлов. **По согласованной
политике сервер продолжает считать при выключенном ПК**, а клиент догружает
накопленное после подключения. Нет зависимости от Яндекс Диска или входящего
SSH-порта на ПК. Предоставлены ручной запуск и установщик задачи входа в Windows.

Референс — соседний `puzzle-ubuntu`: прочитаны README, `AtomicFile.cs`,
`ops/progress_store.py` и systemd unit. Перенесены принципы атомарности и работы
вне SSH; формат checkpoint создан для конечного uint32-прохода этой модели.
Конфиги/токены соседнего поисковика не копировались и не применялись.

**Проверено.**

- 24 сценария CPU-тестов на Windows Python 3.11 и Ubuntu/WSL, в том числе с
  `python -O`: блокировка, авария до/после публикации блока, stale checkpoint,
  повреждение и разрыв цепочки, неверный GPU-счётчик, candidate overflow,
  неудачная CPU-проверка, остановка, потеря соединения до/после header,
  обрыв потока после блока, постраничная догрузка, несовпадающий run/rollback,
  path traversal, повторная передача, возобновление из копии ПК.
- Native-контроли финальной GPU-сборки: 19 векторов / 76 children,
  45 крайних случаев modulo n, четыре planted hit, нечётные пакеты,
  границы uint32 и независимые CPU-свидетели.
- Реальный CUDA-процесс: planted-кандидат сохранён; остановка/возобновление
  завершили малый синтетический диапазон. Другой процесс принудительно убит
  SIGKILL после первого из двух пакетов 65536. После запуска подтверждённый
  первый блок не изменён; итог 131072 seed / 524288 пар, без разрывов/дублей.
- После пересборки хеш `.so` изменился при неизменных CUDA-исходниках.
  Предположение бинарной идентичности отклонено, первая ошибка чтения сохранена;
  аварийный тест полностью повторён на **финальном бинарнике**.
- Экспортер реально выполнен в Ubuntu/WSL, поток принят Windows-клиентом:
  3 seed / 12 пар / один synthetic-кандидат, повторная передача идемпотентна,
  CPU-кандидат повторно проверен на Windows. Транспорт в этом локальном тесте —
  WSL stdout; SSH-аутентификация с арендованным сервером ещё не проверялась.
- Архив перечитан по каждому файлу, затем распакован в изолированный каталог.
  Из него загружена CUDA-библиотека, и полный результат seed 0 совпал с CPU.
  Зависимости от соседних research-каталогов у поставки нет.
- PowerShell-установщик задачи проверен синтаксически. Задача не установлена.
  Все 64 опечатанных артефакта SXN-02 остались неизменными.

Проверки выполнены на RTX 3070 Ti Laptop в Ubuntu 24.04 / WSL, CUDA 13.2.
`sm_89` скомпилирован, но **физическая RTX 4090 ещё не арендована и не тестировалась**.
Её фактическую скорость определит `preflight.py` после аренды. Гарантии скорости
4090 или многосуточной устойчивости по локальному тесту не делаются.
Полный настоящий проход не запущен, покрытие Puzzle = 0.
