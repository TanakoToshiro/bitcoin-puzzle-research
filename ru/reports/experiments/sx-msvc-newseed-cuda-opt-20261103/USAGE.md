# Использование принятого batch API

Готовая WSL-библиотека: `libtail.so`; обёртка: `optimized.py`, класс `Optimized`.
CUDA 13.2, sm_86, системная libsecp256k1 для однократной таблицы базовой точки.
EC field-код и лицензии сохранены рядом. Сборка из исходников — `bash build_tail.sh`.
Прежний принятый каталог SXN-01 не изменяется.

Один синтетический пакет, без запуска полного поиска, из PowerShell:

API в WSL, из этого каталога:

> Исполняемый код/команды опущены в документационной копии.


По умолчанию target = `0x123456789ab`, bits = 49: синтетическая цель.
Параметр `target` — младшие биты скаляра, без установленного старшего бита
маски Puzzle. Номер схемы 0/1/2/3 = receive49 / receive50 / change49 / change50.
Каждый вызов всегда выполняет 100000 итераций, вариант 1, 256 threads,
chunk 1000. Рекомендуется 65536 seed; API допускает до 262144.
Диапазон должен целиком помещаться в `[0, 2^32)`.

`stats = [found, errors, processed_seeds, checked_schemes]`.
Невалидный root или недостаточный candidate buffer вызывает `RuntimeError`.
Такой пакет не считается законченным. Порядок кандидатов в Python нормализован.
Ни API, ни CLI не содержат checkpoint/resume-цикла полного домена.

`debug=True` дополнительно возвращает по 224 байта на seed:
text32 + stretch32 + X32 + children4×32. Это режим проверки; основной
benchmark не возвращает эти данные. Для elapsed используется
`CLOCK_MONOTONIC_RAW`, сверенный с внешним Windows Stopwatch.
Старые поля времени из `tail_driver.py` оставлены как историческая диагностика.

Доказательства воспроизведения сохранены в JSON. Повторный запуск скриптов
проверок/измерений перезаписывает их JSON, поэтому после опечатывания выполняйте
новые измерения в копии каталога. При простой сборке также изменятся хеши
бинарника/логов; итоговая печать относится к сохранённым файлам этого запуска.
