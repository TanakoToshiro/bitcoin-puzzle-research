# SXN-02 — профилирование и оптимизация CUDA newseed/genpriv

Цель: измерить дорогие операции принятой SXN-01 модели и ускорить её, сохранив
точные байты. Полный поиск Puzzle не запускается; все targets синтетические.
Старые исходники, бинарники и печати не изменяются.

Измерять отдельно MT/hex, stretch100000, форматирование/D2H, GPU public-key,
host parsing и четыре SHA256d/scalar-add/filter. Для device-фаз использовать
CUDA events, для host/end-to-end — UTC wall и perf_counter. Профиль не заменять
подсчётом инструкций или старой оценкой пропускной способности.

Допустимые оптимизации: специализация SHA256 для двух фиксированных блоков,
предвычисление padding schedule/констант, GPU integer intrinsics, независимые
цепочки в одном потоке, параметры запуска/порций, сокращение накладных расходов.
Ровно 100000 SHA256 раундов и прежние 16 MT draw %255 сохраняются.

Каждый измеряемый вариант сначала сравнить побайтно с принятым бинарником,
hashlib/affine и нативными сохранёнными случаями. Проверять края uint32, нулевые
байты, разные количества раундов/разбиения и размеры, не кратные блоку.
Синтетический полный pipeline: четыре схемы receive/change × i−1/i для i=50.

Проводить сравнения на одинаковых размерах, менять порядок baseline/optimized,
показывать разброс и выбранные параметры. Отклонённые варианты и ошибки сохранять.
Быстрые короткие замеры нужны для отбора; итог принять на полном stretch100000.
Экстраполяция uint32 — только измерение текущей реализации/машины, не гарантия
многосуточной работы или доказательство невозможности дальнейшей оптимизации.
