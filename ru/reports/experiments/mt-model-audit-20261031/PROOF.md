# Почему проверка исключённых известных ключей здесь ничего не предсказывает

Пусть s — 19937 координат состояния, A — сохранённая матрица 3767 наблюдаемых младших битов, y — опубликованные значения. Принудительные старшие биты не являются строками A. Для каждой из четырёх исследованных схем независимо проверено rank(A)=3767.

Добавим строку g, задающую raw256[254], и положим g·s=0. Проверено rank([A;g])=3768. Поэтому линейное отображение s ↦ (A·s,g·s) сюръективно: **для любого** y существует ровно 2^16169 решений (y,0). Если среди них есть нулевое состояние, остальные ненулевые всё равно существуют. Условие g·s=0 обеспечивает k256 < 2^255+2^254 < n. Для более низких номеров верхняя граница скаляра соблюдается автоматически.

Разделим y на обучающие наблюдения y_train и исключённый ключ y_test. Для любого значения y_test при фиксированном y_train существует состояние. Значит, нельзя вывести ни отдельный бит, ни нетривиальный XOR, ни другое запрещающее часть значений условие на исключённый остаток. Это точное утверждение о рассматриваемых моделях, не отсутствие обнаруженного статистического эффекта.

Обозначим B строки 154 битов остатка №155. Ранг [A;g;B] равен 3917 для getrandbits(i), stride=2: после фиксации наблюдений и guard остаётся проекция размерности 3917−3768=149. Это совместимо с наличием восьми интервалов. Полный ранг A не означает свободу всех будущих выходов: некоторые строки B могут лежать в строковом пространстве A.

Для каждой из трёх ближайших рассмотренных альтернатив ранг [A;g;B]=3922. Следовательно, размерность проекции №155 равна 154: **каждый** остаток №155 совместим с настоящими наблюдениями и guard. Поэтому объединение основной схемы с любой такой альтернативой уже содержит полный диапазон №155. Это точное покрытие проекции, не её аффинная оболочка как возможное завышение множества.

Ранги проверены с обоими направлениями выбора pivot. Свидетели дополнительно проверены числовым исполнением getrandbits. Вывод относится к произвольным внутренним состояниям, а не к конечному семейству seed; остальные неизвестные публичные точки не превращены в скалярные наблюдения. Полной совместимости со всеми ними не заявляем. Доказательство не определяет вероятность, с которой создатель выбрал конкретную программу.
