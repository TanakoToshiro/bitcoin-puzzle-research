# E1k — проверяемость модели и устойчивость восьми интервалов

2026-10-31. Продолжение E1j. Новые вычисления читают готовые строки E1e; генерация MT-матриц не выполняется. Уже просмотрены сохранённые значения rank=3767 и observation_count=3767 основной модели. Поэтому это диагностический аудит, не слепое подтверждение.

Основная модель: getrandbits(i), stride=2, без отказов, key_bits, принудительный старший бит не наблюдается. Проверить ранг независимо двумя порядками исключения. Добавить достаточное условие raw256[254]=0, которое гарантирует k256<n. При полном строковом ранге наблюдений с этим условием любое назначение наблюдаемых битов допустимо; тогда отдельное исключение решённых задач не может дать ни одного ограничения на исключённые биты. Проверить это конструктивно на 8 наборах от случайного MT-состояния и 8 независимых равномерных назначениях наблюдений. Это проверка математического вывода, не статистический выбор модели.

Близкие заранее выбранные альтернативы: getrandbits(i), stride=1; getrandbits(i-1), stride=1/2. Для каждой прочитать готовые строки проекции №155, проверить её ранг относительно наблюдений и условия допустимости №256. Объединять допустимые множества. Достаточно одной полной проекции для доказательства, что объединение покрывает весь диапазон; никаких вероятностей моделям не назначать. Объединение API не объявлять неизвестными отказами одной API.

Синтетические состояния доступны только проверяющему коду. Проверка восстановленных состояний: прямое числовое исполнение CPython MT getrandbits до №256 и сравнение всех наблюдений, целевых значений, допустимости скаляров. При расхождении остановиться. Сохранить состояния и RHS как воспроизводимые свидетели. Свобода состояния seed-процедурой не ограничивается: это именно прежняя постановка без перебора seed.

Нулевой результат прогноза — основание явно ослабить интерпретацию совпадения 83 ключей. Старые записи не переписывать. Результат: RESULTS.md, AUDIT.json, HOLDOUT.csv, свидетели и хэши входов. Команда повторного запуска проверяет DONE.json и пропускает завершённую работу.
