# E1k — совпадение известных ключей не проверяет эти четыре модели

2026-10-31. Завершено. Прочитаны готовые строки E1e; MT-матрицы не генерировались. Ранги независимо пересчитаны над прочитанными строками двумя порядками исключения, а не приняты из старого отчёта.

**Все 3767 наблюдаемых битов независимы как линейные функции 19937-битного состояния. Это верно и после условия raw256[254]=0, достаточного для допустимости скаляра №256.**

Следствие: любые назначения всех опубликованных младших битов допускают состояние. После исключения любой решённой задачи её остаток полностью свободен. Поэтому перебор отдельных holdout-запусков избыточен: для них доказан нулевой объём предсказания сразу. Принудительный старший бит не считается предсказанием.

| Модель | Ранг наблюдений | Ранг с guard | Ранг с №155 | Размерность №155 |
|---|---:|---:|---:|---:|
| api-bits_i-na-s2-zero | 3767 | 3768 | 3917 | 149 |
| api-bits_i-na-s1-zero | 3767 | 3768 | 3922 | 154 |
| api-bits_im1-na-s1-zero | 3767 | 3768 | 3922 | 154 |
| api-bits_im1-na-s2-zero | 3767 | 3768 | 3922 | 154 |

**Восемь интервалов сохраняются только при конкретном getrandbits(i), stride=2.** Уже getrandbits(i), stride=1 даёт все 2^154 остатков №155 при тех же настоящих наблюдениях и достаточном скалярном guard. Объединение этих альтернатив — полный исходный интервал; подтверждённого сокращения настоящего ключа нет.

У основной API нет неизвестных отказов. Stride/API — разные гипотезы, не новые истории randrange. Объединение не является доказательством ложности основной гипотезы: оно показывает зависимость сокращения от её выбора. Перечень конечен; полноты всех возможных программ генерации не заявляем.

Контроли: 64/64 набора наблюдений (половина от случайных MT-состояний, половина независимые случайные биты) конструктивно воспроизведены. Сохранено 88 состояний, включая 24 свидетеля произвольного №155 при настоящих наблюдениях в полных альтернативах. Проверено прямое числовое исполнение getrandbits до №256, а не только уравнения.

Исполнение свидетелей — CPython 3.11. Историческая эквивалентность getrandbits уже исследовалась ранее; новые исторические бинарники здесь не запускались. Происхождение состояния от конкретного seed не устанавливалось. Нелинейные условия остальных неизвестных публичных точек не налагались.

Время вычислений: 2.722 с. Машинный результат — артефакт исходного исследования (`AUDIT.json`; вне снимка), все holdout-следствия — артефакт исходного исследования (`HOLDOUT.csv`; вне снимка), состояния-свидетели — артефакт исходного исследования (`WITNESSES.json`; вне снимка), хэши — артефакт исходного исследования (`INPUTS.json`; вне снимка).

Продолжение: полезно только новое наблюдение, которое не является свободным в модели, ограничение способа получения состояния либо независимое основание выбрать конкретную программу генерации. Увеличение скорости условного поиска само по себе этих данных не добавляет.
