# SEQ-01 — связи младших битов и структура порядка

Зафиксировано 2026-11-02 до вычисления результатов. Только CPU, новая папка; старые эксперименты, общая среда и GPU-поиски не изменяются.

## Данные и смысл наблюдений

Источник: `../child-derivation-audit-20261102/inputs/known_solutions.json`, локальная копия с SHA-256. 83 решения: 1–70 подряд, затем 75,80,…,135. Перед анализом проверить диапазоны, public key и Base58Check-адреса через coincurve/hashlib.

Опубликованный private key — полный ключ соответствующего puzzle. В гипотезе предварительного маскирования исходного значения только биты 0…i−2 являются наблюдениями исходного выхода. Обязательный старший бит исключён. Неизвестные решения не превращаются в наблюдения с нулевым значением. Анализ ограничен младшими 32 битами; выше слишком мало последовательных наблюдений для выбранных моделей.

Для обучения используется №1–50. №51–70 — последовательная проверка, №75–135 — дополнительная проверка прогнозов точных моделей. Это НЕ новый закрытый тест: эти решения уже использовались прежними исследованиями. Номер puzzle не считается доказанным индексом кошелька; исследуется именно опубликованный порядок.

## A. Точные короткие зависимости

Ширины слов: 1,2,4,8,16,32 бита. Шаги: 1,2,3,4,5,8,10; каждую фазу рассматривать отдельно, не сжимая пропуски.

1. Неизвестные `a,c` в `x_next = a*x + c mod 2^b`. Все допустимые коэффициенты находить точным решением линейных конгруэнций, различать отсутствие решений, единственность и неоднозначность. Прогнозировать только при единственной паре. Неоднозначность не является опровержением.
2. Полиномы последовательного номера внутри фазы степени 0–3: нулевая соответствующая конечная разность по модулю 2^b. Проверять все обучающие переходы, не подгонять степень по тесту.
3. Для каждого отдельного бита 0–31: неизвестная аффинная XOR-рекурсия порядков 1,2,3,4,6,8; шаги 1,2,3,4, фазы отдельно. GF(2)-решатель возвращает inconsistent/unique/ambiguous. Неоднозначные системы не прогнозируют.

Для word-моделей не менее 8 обучающих переходов и 4 последовательных тестовых целей; для XOR не менее `2*(order+1)+4` обучающих уравнений и 4 тестовых целей. При нехватке данных комбинация пропускается и не считается проверенной.

Прогнозы точных моделей после №50 рекурсивные: фактические значения №51+ не подаются на вход прогноза. Фиксированные коэффициенты и обучающий хвост дают прогноз до №135. Оценка по №51–70: `(correct_bits−wrong_bits)/sqrt(total_bits)`. Максимум по всем допустимым моделям — статистика семейства A. Прогнозы сверять также со всеми подходящими известными решениями №75–135; они не используются для выбора модели.

## B. Фиксированные простые предикторы

Те же ширины и шаги, фазы объединены (одна формула). Предыдущие значения берутся по исходным индексам, все использованные биты должны быть наблюдаемы.

Формулы: `x1`, `2*x1−x2`, `3*x1−3*x2+x3`, `x1 XOR x2`, `x1 XOR x3`, `x1 XOR x2 XOR x3`; дополнительно для s=1,2,3,5,8 при s<b: `x1 XOR (x1>>s)` и `(x1<<s) XOR x2`. Все результаты modulo 2^b.

Это однопереходные диагностические предикторы: при тестировании используются реально известные предыдущие ключи. Их успех НЕ означает способность самостоятельно построить длинную цепочку. Не менее 8 обучающих и 6 тестовых строк. По обучению выбрать прямой либо инвертированный по всем b битам прогноз. Статистика модели — минимум из положительного стандартизованного преимущества на обучении и преимущества выбранной ориентации на тесте. Максимум — статистика семейства B. Учитывать реальные зависимости оценок через моделирование всего алгоритма.

## C. Порядок, фазы, блоки

На №1–70, с исключением обязательных битов:

- частоты единиц по битам 0–31;
- совпадение каждого бита на лагах 1…16, не менее 12 пар;
- частоты по фазам периодов 2,3,4,5,8,10, биты 0–15; фаза против остальных, не менее 6/12 наблюдений;
- смена частот до/после фиксированных границ 20,30,40,50, биты 0–15, не менее 10 с каждой стороны;
- блоки длины 10 и 16 против остальных, биты 0–15, не менее 8/12;
- суммарное совпадение младших b=4,8,16,32 бит на лагах 1,2,3,4,5,8,10,16, не менее 12 пар. Повторение одних позиций соседних блоков уже покрыто лагами, не отдельное открытие.

Каждая статистика — абсолютное отклонение от независимых равномерных битов в единицах теоретического стандартного отклонения. Максимум — статистика семейства C. Случайные контроли учитывают перекрывающиеся пары и множественный просмотр.

## Статистические выводы и бюджет

1023 независимые воспроизводимые нулевые последовательности: SHAKE-256 с опубликованным доменом/ID и номером реплики, затем маскирование ровно по тем же номерам. Это вычислительный нулевой эталон, не утверждение о происхождении puzzle. В каждой реплике повторить весь подбор/отбор A,B,C. Сохранять максимумы и счётчики подгонок по каждой реплике. Для каждого семейства `p=(1+count(null_max>=real_max))/(1023+1)`. Затем Holm по трём семействам при общем alpha=0.01. Минимальная разрешимая p=1/1024; доверительные интервалы Monte Carlo обязательны. Пограничный результат требует отдельной серии с большим числом реплик, не автоматического объявления открытия.

Сравнение со случайными данными отделяет аномалию от ожидаемого результата перебора формул, но не доказывает генератор/предсказание будущего. Общий отрицательный вывод ограничен перечисленными ширинами, порядками и разбиениями. Длинные нелинейные правила, криптографические derivation и произвольные перестановки не исследуются.

Вычислительный бюджет первой серии 30 минут после подготовки кода. Контроли до реального анализа: конгруэнции и GF(2) против исчерпывающего малого эталона, известные аффинная/полиномиальная/XOR/чередующаяся последовательности, смена режима, маскирование и отсутствие тестовых входов в рекурсивном прогнозе. Лимит фиксируется в журнале; неполная нулевая калибровка остаётся незавершённой.

Сохранять протокол, код/входные хэши, версии, контрольные результаты, таблицы реальных моделей и статистик, нулевые реплики частями, STATUS/JOURNAL/RESULTS. Совпадающий manifest позволяет resume без повторения законченных частей; изменение входов требует новой папки серии. Отчёт собирается из JSON без вычисления эксперимента.
