# E9d — полный локальный проход BX → BIP32

Разрешён пользователем отдельным указанием «Запусти проход полный». Начальные состояния 1..2147483646, все 16 схем из E9c, GPU-filter №50 + CPU training/holdout. Этот запуск намеренно повторяет небольшое покрытие прежних бенчмарков и последовательно проходит всю область с начала. Старый E9c и рабочие проекты не изменяются.

GPU/CPU реализация берётся из проверенного соседнего `bx-cuda-search-20261101`. Новая обвязка снимает прежний 15-минутный лимит только для явно разрешённого полного прохода. Блок 1048576 состояний; всего 2048 блоков, последний 1048574. Готовые блоки связаны SHA-цепочкой и пропускаются после проверки. Эксклюзивный RUN.lock предотвращает два одновременных запуска. Ошибка не засчитывает текущий блок; кандидат останавливает проход для независимого рассмотрения.

Текущее состояние: [RESULTS.md](<RESULTS.md>), STATUS.json — артефакт исходного исследования (`STATUS.json`; вне снимка), stdout.log/stderr.log. При завершении появляется COMPLETE.json с проверенными хэшами всех 2048 блоков. Отсутствие совпадения исключает только заданные 16 конечных BX/GNU-гипотез.

Для штатной остановки создать файл `STOP` в этой папке. После окончания текущего блока статус станет stopped. Для продолжения убрать STOP и снова выполнить `run`; завершённые блоки не повторяются. Не менять CUDA-код, эталоны или конфигурацию внутри этого запуска.

Windows запускает процесс WSL скрыто с отдельными stdout.log/stderr.log; окно чата для продолжения вычислений не требуется. Компьютер должен оставаться включённым и не переходить в сон. Глобальные настройки питания не изменялись. Средняя оценка по E9c — около 43–57 минут при сохранении скорости, фактический прогресс и ETA пересчитываются после каждого блока.
