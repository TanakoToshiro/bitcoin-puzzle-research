# SEQ-09 — зависимости мономов внутри решения

Результаты: [FINAL_REPORT.md](<FINAL_REPORT.md>). Новая изолированная серия
по указанию пользователя; принятые SEQ-01..08 не изменяются.

`coupled_solver.py` строит коэффициентную решётку полиномов. Строки,
прошедшие точную оценку `sum(abs(coefficient)*monomial_bound) < modulus`,
становятся целыми равенствами. Базис Грёбнера решает их как полиномы
от общих переменных: произведения и степени связаны уже при решении.
Кандидат дополнительно проверяется по полной цепочке и всем 83 маскам.

Сравнение: копия метода SEQ-08 (`baseline`), новая решётка mod n
(`coupled_m1`), ограниченная решётка mod n² для пяти состояний
(`coupled_m2`). План и лимиты неизменны: [PROTOCOL.md](<PROTOCOL.md>),
MANIFEST.json — артефакт исходного исследования (`MANIFEST.json`; вне снимка). Список новых seed находится в
`experiment.py:cases`; старые `data.py:cases` и `data.py:HIDDEN`
скопированы для происхождения кода и в этой серии не используются.

Из корня рабочего проекта, PowerShell:

> Исполняемый код/команды опущены в документационной копии.


Сначала проверяется целостность. При наличии принятых результатов
команды не повторяют вычисления; допускается дописывать только журнал.
Таймаут сохранён как завершённая попытка с ограниченным бюджетом и
автоматически не перезапускается. Для следующей серии нужна новая папка.

- `inputs/`: 48 заранее созданных входов; истина служит только оценке.
- `results/`: 112 исходов методов, включая таймауты.
- `lattices/`: точные матрицы, преобразования и сертифицированные полиномы.
- `progress/`: запись перед совместным решением; переживает его таймаут.
- `ALGEBRA_CONTROLS.json`: 16 исчерпывающих малых систем и 4 особых случая.
- `audit.py`, `inherited_audit.py`, `audit_common.py`: независимые формулы,
  другой алгоритм Грёбнера, проверка целых корней, цепочек и сдвигов.
  `inherited_audit.py` скопирован побайтно; прежний `main` не вызывается.
- `audit_packets/`, `AUDIT.json`: сертификаты аудита, в том числе
  решёток с незавершённой алгеброй.
- `CONTROLS.json`, `MEASUREMENTS.json`, `COMPARISON.json`: таблицы,
  этапы ограничений и парное сравнение.
- `REAL.json`: структура реальных ограничений и отдельные допуски поиска.
- `PRIOR_SNAPSHOT.json`: SHA256 и mtime всех прежних принятых файлов.
- `PROVENANCE.json`, `AUDIT_PROVENANCE.json`: происхождение копий.
- `ENVIRONMENT.json`: хэши уже существующих библиотек.
- `RESUME_CHECK.json`: продолжение без новых решёточных вычислений.
- `ACCEPTANCE.json`, `COMPLETE.json`, `ARTIFACTS.json`: приёмка и печать.

Один вычислительный CPU-процесс. Python 3.11.9, python-flint 0.9.0,
SymPy 1.14.0. GPU, установки и старые поисковые стадии не используются.
45 секунд на научный метод-запуск, 1200 секунд суммарно. Завершение
процесса может добавить небольшое время к измеренному wall time.
Аудит выполняется отдельно, до 120 секунд на сохранённый пакет.

Служебные команды `accept.py` и `accept.py seal` использованы для
проверки продолжения и окончательной печати. После печати принятые
артефакты не перезаписывать.
