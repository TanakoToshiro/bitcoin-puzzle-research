# SEQ-09 — связи между мономами внутри решателя

02.11.2026. Пользователь прямо разрешил использовать зависимости между
мономами при решении системы. Модель, модуль n, маски и ограничения
траектории прежние: SEQ-08, без полюсов, неаффинный дробно-линейный ход.

## Техническая калибровка до регистрации новых входов

На старых положительных примерах SEQ-08, общий генератор, исследован
только размер коротких полиномов простой решётки mod n. Панель5:
h12 — 9 полиномов с оценкой |g|<n; h16/20/24 — ни одного.
Панели9/13 при h20 — ни одного (минимальные оценки имеют 259/260 битов).
Это диагностика старых входов, не новая подтверждающая выборка.
Старые файлы/стадии не изменяются; истина не используется при выборе строк.
Новых результатов этой калибровке не приписывать.

## Из модульных условий в целые равенства

Сохраняются разности SEQ-08 и кубические G_j(u)=0 mod n.
В новой решётке строка означает ПОЛИНОМ, а не предполагаемые значения
независимых мономов. Координата монома u^alpha масштабируется на
B_alpha=product(X_i^alpha_i), где |u_i|<=X_i доказано исходными масками.

Если каждый генератор решётки обращается в 0 mod N на допустимом корне,
то любая целая комбинация имеет то же свойство. Для строки с коэффициентами
g_alpha вычисляем точную оценку H=sum(|g_alpha|*B_alpha).
Только если H<N, заключаем g(u)=0 НАД ЦЕЛЫМИ. Это достаточное условие,
а не необходимое: его провал не означает отсутствия полезного полинома.

Два заранее фиксированных варианта:

- `coupled_m1`, панели5/9/13, N=n. Решётка всех коэффициентных векторов,
  принадлежащих mod n линейной оболочке исходных G_j. Строится по RREF:
  нормированные строки G_j и n*моном для неповоротных координат.
- `coupled_m2`, только панель5, N=n². Единственный G нормируется по
  старшему моному L (graded lex), чтобы его коэффициент был 1 mod n.
  Мономы M — исходная поддержка вместе с константой и линейными мономами;
  новые столбцы S=M+M. Генераторы: G², n*u^beta*G для beta in M кроме L,
  n²*u^alpha для оставшихся ведущих координат. Разные ведущие мономы
  дают треугольный базис. Все генераторы делятся на n² на истинном корне.
  Это конкретная ограниченная система сдвигов, не весь идеал степени2.

Один LLL, delta=0.99, eta=0.51. Никакие несертифицированные строки не
приравниваются нулю. После строгой оценки можно делить полином на
ненулевой целый контент: это не меняет множество его нулей.

## Совместное нелинейное решение

Сертифицированные полиномы подаются в SymPy как выражения от одних
переменных u_i. Поэтому u_i*u_j, u_i² и прочие мономы связаны во время
вычисления базиса Грёбнера, а не только в последующей проверке.
Порядок grevlex, метод f5b, поле QQ. Для нульмерного идеала допускается
FGLM в lex при <=256 стандартных мономах; целые корни извлекаются
последовательным исключением и рациональным разложением унивариантных
полиномов, с лимитом256 узлов. Корни должны попасть в исходные интервалы.

Нет сертифицированных равенств, положительная размерность, лимит алгебры
и таймаут — разные исходы. Положительная размерность над QQ не доказывает
несколько целых ограниченных решений. Приёмка корней требует прежней
полной проверки относительной цепочки и всех83 масок через интервалы сдвига.
Глобальная единственность модели не заявляется.

## Новые парные входы и лимиты

Панели5/9/13, h=8,12,16,20,24,32; один общий и один инверсивный
новый генератор на уровень/панель:36 усиленных положительных входов.
В выбранной панели известны 256−h младших битов; вне её маски i−1.
На панель два случайных входа h16 и два положительных с настоящими
масками: ещё12 входов. Всего48 входов.

На каждом входе сравниваются `baseline` (копия SEQ-08 differences)
и `coupled_m1`. Для всех16 входов панели5 добавляется `coupled_m2`.
Всего112 метод-запусков. Общий и инверсивный примеры с настоящими
масками на каждой панели запускаются первыми. Seed фиксируются кодом.
45 секунд на один метод, 20 минут суммарно дочерних процессов.
Достигнутый лимит не считается отрицательным результатом модели.

Допуск реального поиска отдельный для каждого метода/панели: восстановлены
оба новых примера с настоящими масками. Без допуска только расчёт структуры;
никакого реального поиска и никаких выводов об отсутствии реальных моделей.
Промежуточные наборы после данных не добавлять, параметры не подбирать.

## Проверка

Исчерпывающий малый контроль связанного решения, включая систему,
где мономиальная линейная релаксация даёт лишние значения. Проверка
точных генераторов mod n/n², T*B=L, det(T)=±1 и весов. Для каждой
сертифицированной строки — точная оценка и независимая подстановка
истинного синтетического корня. Базис Грёбнера и конечные корни
сверяются независимо; полная цепочка и сдвиги проверяются прежними
независимыми формулами. SHA256/mtime SEQ-01..08 сохраняются.

Один вычислительный CPU-процесс; существующие SymPy/python-flint,
без GPU, установок и исполнения прежних поисковых стадий.
