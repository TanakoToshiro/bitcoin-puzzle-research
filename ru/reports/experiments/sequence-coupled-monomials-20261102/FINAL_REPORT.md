## Что изменилось математически

Остаётся модель `s[i+1]=(A*s[i]+B)/(C*s[i]+D) mod n`, где n — порядок
secp256k1, `AD−BC != 0`, `C != 0`, без полюсов на первых 135 состояниях.
Наблюдения: `r[i]=s[i] mod 2^(i−1)` для 83 известных ключей.
Исследуются скаляры исходных состояний; операции с точками кривой здесь
не используются. Модуль и порядок экспорта не меняются.

Из SEQ-08 сохранены соседние разности шагом5 и кубические инварианты:

```text
D[j] = r[next] − r[left] + 2^b[left] * (center[j] + u[j])
G(D0,D1,D2,D3) = D1*D3*(D0+D1) − D0*D2*(D2+D3) = 0 mod n
```

В прежней решётке координата представляла предполагаемое значение монома.
Теперь строка представляет коэффициенты полинома `g(u)`. Каждый генератор
даёт значение, кратное N, на любом допустимом истинном корне. При доказанных
границах `|u[i]| <= X[i]` вычисляется точная целая оценка:

```text
H = sum_alpha |g_alpha| * product_i X[i]^alpha[i]
H < N  =>  g(u) = 0 над целыми
```

Доказательство — треугольное неравенство и делимость на N. После этой
проверки можно удалить общий ненулевой целый множитель коэффициентов.
Провал оценки не означает, что полином бесполезен или решений нет.

`coupled_m1`: N=n, коэффициентная решётка линейной оболочки G_j mod n;
размерности 16/53/89 для 5/9/13 состояний. `coupled_m2`: N=n²,
один нормированный G, генераторы G², n*u^beta*G и n²*мономы;
размерность88, только панель5. Это ограниченный заранее заданный набор
сдвигов, без утверждения оптимальности или полноты всего идеала степени2.

Далее F5B/grevlex над QQ; для нульмерного идеала FGLM/lex, не более256
стандартных мономов и256 узлов извлечения целых корней. В полиномах
`u0*u1` является произведением тех же `u0` и `u1` уже при исключении.
FGLM требует нульмерности; используемые API и алгоритмы сверены с
[официальной документацией SymPy](https://docs.sympy.org/latest/modules/polys/reference.html).

Каждый корень проходит исходные интервалы, восстановление относительной
траектории из135 состояний и проверку всех83 масок точными интервалами
общего сдвига. Успех означает восстановление истинного синтетического
класса по сдвигу; глобальная единственность исходной модели не заявляется.

## Где возникло ограничение

На панелях5 и9 простая коэффициентная решётка теряет строгие целые равенства
раньше, чем прежняя эвристика перестаёт извлекать правильные относительные цепочки.
Потерянные парные восстановления перечислены в COMPARISON.json;
совместное решение само по себе этот недостаток входных равенств не снимает.

Для n² сохранено следующее число сертифицированных строк на двух
положительных входах каждого уровня: h8: 77/77; h12: 63/63; h16: 49/49; h20: 0/0; h24: 0/0; h32: 0/0.
Наличие большого числа строк ещё не означает конечную систему легко
извлекаемых корней. Записи progress фиксируют завершение LLL и сертификации
перед алгеброй; незаконченные базисы и корни не объявлены проверенными.

Ограничение45 секунд задано на весь метод-запуск, включая запуск процесса,
редукцию, проверку и алгебру. Итоговое время дочерних процессов:
1200.03 секунд; общий лимит1200 секунд.
Небольшое превышение45 секунд в отдельных wall-замерах связано с
завершением процесса. Общий лимит оставил
10 попыток незапущенными.
Последняя начатая попытка `coupled_m1/positive_p13_h24_general`
получила только оставшиеся около12 секунд общего бюджета и не сохранила
решётку; её нельзя сравнивать как полноценную45-секундную попытку.

Для настоящих масок верхние панели оставляют примерно122–182 скрытых
битов исходного состояния в зависимости от индекса, существенно больше,
чем h в усиленных контролях. На соответствующих синтетических примерах
нет успешного допуска; REAL.json содержит только структуру реальных
сравнений. Неудача этого алгоритма не исключает саму скрытую связь.

## Проверка результата

- 16 малых систем: все625 целых точек квадрата [-12,12]^2 сверены с
  извлечёнными корнями. Ещё4 случая проверяют положительную размерность,
  противоречие, нецелый корень и отрицательные корни. Сохранён пример,
  где независимый моном z даёт ложный ответ, нарушающий z=x*y.
- 101 точных решёточных сертификатов, из них
  14 с незавершённой последующей алгеброй.
  Проверены генераторы, веса, индекс, T*B=L и det(T)=±1.
- 11 попыток не оставили решёточного сертификата;
  они перечислены отдельно и не входят в число проверенных решёток.
- 1122 сертифицированных полиномиальных строк;
  для 954 строк дополнительно независимо
  подставлен истинный синтетический корень и получен точный целый ноль.
  Просмотрены все редуцированные строки, а не выбранные успешные.
- 12 законченных непустых систем
  перепроверены алгоритмом Buchberger вместо рабочего F5B. Целые корни
  повторно извлечены факторизацией исключающих полиномов. Незавершённые
  системы не решались в аудите под видом продолжения эксперимента.
- Принятые классы, вся траектория, интервалы общего сдвига и условные
  проекции №71 проверены независимыми формулами. Проекции относятся
  исключительно к синтетическим входам этой серии.
- SHA256 и mtime всех 1818 прежних принятых
  файлов SEQ-01..08 сохранены. Хэши существующих зависимостей проверены.
  Продолжение без новых вычислений подтверждает RESUME_CHECK.json.

## Вывод для продолжения

Требуемое изменение выполнено: зависимости между мономами реально
включены в решение, и законченные результаты подтверждены независимым
алгоритмом. Расширения области восстановления на этой выборке нет.

Следующий самостоятельный эксперимент должен различить два ограничения:
получение достаточных строгих полиномов и стоимость их совместного
решения. Для n² уже сохранены нетривиальные системы, на которых можно
отдельно проверить предварительное сокращение идеала или другой
алгебраический решатель. Для исходных масок одной замены решателя
недостаточно: сначала нужны полиномы, проходящие строгую оценку.
Ни смена алгоритма алгебры, ни расширение системы сдвигов в этой серии
после получения данных не запускались.
