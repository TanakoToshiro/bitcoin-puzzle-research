# Первичные материалы SEQ-09

Проверено 02.11.2026. Результаты эксперимента получены из локальных
сохранённых входов и сертификатов, а не из внешних источников.

- [SymPy 1.14.0: polynomial reference](https://docs.sympy.org/latest/modules/polys/reference.html).
  Проверены определения `groebner`, методов `f5b`/`buchberger`,
  `is_zero_dimensional` и `fglm`. FGLM применяется к нульмерному идеалу.
  Рабочий код использует F5B, независимый аудит — Buchberger.
- [Keegan Ryan, Solving Multivariate Coppersmith Problems with Known Moduli,
  ePrint 2024/1577](https://eprint.iacr.org/2024/1577).
  Прочитана страница с аннотацией: работа обсуждает выбор полиномиальных
  сдвигов для поиска малых решений модульных систем и компромисс с
  размерностью решётки. PDF по ссылке протокола вернул HTTP 403.
  Конкретные алгоритмы статьи не воспроизводились; она служит контекстом,
  а не обоснованием полноты выбранной здесь системы сдвигов.

Условие `H < N` выведено непосредственно: целая линейная комбинация
генераторов имеет значение, кратное N на допустимом корне; её абсолютное
значение ограничено H. Единственное кратное N в открытом интервале
`(-N,N)` — ноль. Это достаточное условие; обратное не утверждается.

Внутренние источники: принятые SEQ-06, SEQ-07 и SEQ-08. Копии их
вспомогательных реализаций проверены по SHA256. Старые поисковые стадии
не исполняются, старые контрольные входы не включены в новую выборку.
