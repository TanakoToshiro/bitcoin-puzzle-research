# E1b: сохраняемые промежуточные выводы

## 2026-10-30 — постановка

Пользователь запросил восстановление состояния для скрытых отказов randrange, переменной ширины и байтовой генерации без перебора seed. Зафиксированы 24 конфигурации и 36 линейных подсемейств. Для randrange(order) используются достаточные условия принятия/отказа, а не ложное утверждение, что общий нелинейный алгоритм полностью превращён в одну линейную систему.

Цель — проверить определённость состояния и №71. Полная свобода цели внутри одной допустимой подсемьи достаточна, чтобы исключить гарантированный бит/XOR во всей модели со скрытыми отказами. Положительная вероятность подсемьи и степень её типичности — отдельный вопрос; posterior здесь не вычисляется.

## 2026-10-30 — положительный контроль достаточного количества данных

В основном запуске `20261030-115651-2cf8bdc3` полное состояние восстановлено по 2493 последовательным 8-битным выходам, затем правильно предсказаны 128 будущих байтов. Оба исторических интерпретатора дали одинаковые контрольные выходы. Результат — артефакт исходного исследования (`runs/20261030-115651-2cf8bdc3/controls/dense-positive/result.json`; вне снимка). Это расширенная синтетическая последовательность, не наблюдения реального puzzle.

## 2026-10-30 — все контроли объёма puzzle пройдены

До применения приватных решений проверены все 36 ветвей. Каждый synthetic набор использует те же 83 номера и обрезку. Истинное состояние удовлетворяет модели; построено другое состояние с теми же известными ключами. Проверены произвольные состояния с естественными неизвестными отказами, выбранные нулевые/sparse истории и совпадение instrumented/обычного исторического Random.

У большинства ветвей синтетический целевой ранг равен 70. У `order2-na-s1-sparse` — 46: заранее выбранная история отказов создаёт дополнительные зависимости. Это не найденные биты реального №71, а характеристика условной ветви до проверки её совместности с настоящими ключами. Ветви order2 требуют особенно аккуратного различения условных связей и общего неизвестного расхода.

## 2026-10-30 — дополнительные истории order2 и завершение

Основной запуск дал 31 допустимую и пять несовместных ветвей, покрыв доказательством свободы цели 23 из 24 конфигураций. Для order2 stride1 нулевая и sparse истории несовместны, поэтому общий вывод по API делать было нельзя.

В отдельном заранее описанном дополнении 20261030-120642-c431f68d проверены one, geometric-a и geometric-b; все сначала прошли синтетические контроли. Первые две несовместны с настоящими ключами, geometric-b совместима и даёт d=70. Итого 39 ветвей: семь несовместны, 32 допустимы; для каждой из 24 конфигураций существует семейство с любым №71. Все ограничения принятия/отказа фактически воспроизведены историческими API.

38 состояний, выбранных только по №1–50 и заданным условиям истории, дали каждое 0/33 отложенных совпадений. Одна ветвь несовместна уже на обучении. После добавления всех ключей получены сертификаты полной свободы №71; их нельзя выдавать за успех предсказания. Произвольное выбранное состояние семейства не является доказанным состоянием создателя.

## 2026-10-30 — приёмка

ACCEPTANCE.json — артефакт исходного исследования (`ACCEPTANCE.json`; вне снимка): 2880 числовых воспроизведений свидетелей историческими API, независимые ранги и сертификаты. Достаточный положительный контроль: 2493 байтовых выхода, rank=19937, 128 правильных будущих байтов. Повреждённый сертификат отклонён. Resume пропустил 73+7 этапов, 856 файлов сохранили SHA-256/mtime. Один положительный контроль в дополнении переиспользован, а не пересчитан.

В допустимых подсемействах остаётся 7329–16170 свободных координат состояния; фиксация любого №71 оставляет как минимум 2^7259 состояний в соответствующей подсемье. Нулевое состояние исключается ненулевыми реальными наблюдениями. Это не подсчёт всех возможных скрытых историй и не доказательство отсутствия статистического смещения при ином prior.

Для несовместных ветвей поле state_nullity в промежуточных JSON/таблицах относится только к однородному ядру матрицы A; допустимых состояний у такой системы нет. Итоговые таблицы и текст отделяют их явно. Исторические результаты прежних E1/E2/E2b/E3 не менялись.
