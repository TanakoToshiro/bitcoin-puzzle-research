# E1b: восстановление состояния MT через исторические API

[Протокол](<PROTOCOL.md>), [журнал результатов](<RESULTS.md>), [промежуточные выводы](<NOTES.md>). Основной запуск: [20261030-115651-2cf8bdc3](<runs/20261030-115651-2cf8bdc3/RESULTS.md>).

**Завершено:** [итоговый отчёт](<CONCLUSION.md>), [таблица 24 конфигураций](<MODEL_TABLE.md>), приёмка — артефакт исходного исследования (`ACCEPTANCE.json`; вне снимка). После отдельного дополнения проверено 39 историй: 32 допустимы и сохраняют все 70 неизвестных битов №71 свободными, семь несовместны. Для каждой из 24 конфигураций есть допустимая подсемья с любым №71.

Здесь **не перебираются seed**. Исследуются все 19937 координат произвольного достижимого состояния MT и точные карты наблюдений. 24 конфигурации охватывают переменные ширины, байтовую генерацию, степенные randrange и randrange(order); в 12 случаях отдельно проверяется ненулевая история отклонений, всего 36 ветвей.

Неизвестные отклонения не считаются наблюдаемыми. Фиксированная история с условиями её допустимости задаёт подмножество полной модели. Если в таком подмножестве возможны все 2^70 остатков №71, в полной модели тоже не фиксируется ни бит, ни нетривиальный XOR. Это доказательство неединственности, а не оценка вероятностей: оно не доказывает равномерности posterior по всем неизвестным историям.

Исторические CPython 2.7.9/3.4.2 исполняются через сохранённые изолированные архивы `../python-seed-20261030/`. Их исходники и SHA-256 уже проверены; каждый запрос дополнительно сверяет бинарник и random.py. Независимая числовая арифметика и символические выражения сверяются до настоящих ключей. У instrumented Random проверяется тождественность обычному Random, включая конечное состояние. Настоящий seed при проверке задаётся не через seed(), а через явное состояние setstate().

Положительный контроль восстановил точное состояние по 2493 частичным выходам getrandbits(8) и предсказал следующие 128 байтов. Этот объём данных **не выдаётся за объём puzzle**. Контроли того же объёма, что puzzle, проверяют принадлежность исходного состояния решению и конструктивную неоднозначность. Отложенные реальные предсказания сохраняются после подбора только по №1–50, до добавления оставшихся решений.
