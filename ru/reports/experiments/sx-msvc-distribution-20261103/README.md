# SXM-01

[Результаты и решение](<RESULTS.md>): точный MSVC RNG восстановлен, нативные
контроли и ограниченный синтетический пилот завершены. Полного поиска Puzzle нет.

- [Протокол](<PROTOCOL.md>), [журнал](<JOURNAL.md>).
- Аудит источников — артефакт исходного исследования (`SOURCE_AUDIT.json`; вне снимка), история сборки — артефакт исходного исследования (`HISTORY_MATRIX.json`; вне снимка).
- Нативные контроли — артефакт исходного исследования (`RNG_CONTROLS.json`; вне снимка), GPU-контроли — артефакт исходного исследования (`pilot-low32/CONTROLS.json`; вне снимка).
- Пилот — артефакт исходного исследования (`pilot-low32/PILOT.json`; вне снимка), отдельный readback — артефакт исходного исследования (`READBACK.json`; вне снимка).

`toolchain/` — локально извлечённые оригинальные CTP/STL/CRT/SDK-файлы;
инсталляторы не запускались. `repository.git/` — публичная история SX/BX.
`snapshots/` — сохранённые исходники с Git blob/SHA-256 pins.

Подготовку и сборку поверх принятых результатов повторять не требуется.
Для проверки сохранённых результатов без CUDA и поиска:

> Исполняемый код/команды опущены в документационной копии.


Серия не содержит команды полного поиска. Следующий исторический контроль —
вся июньская SX-сборка; точный RNG больше угадывать не требуется.
