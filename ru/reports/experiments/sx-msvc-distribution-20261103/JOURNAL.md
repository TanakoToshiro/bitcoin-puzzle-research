# Журнал SXM-01

03.11.2026. Прочитаны MSVC-01 RESULTS/SOURCES, сохранённый SX hd-seed и проект
23.05.2014, результаты E14. В истории MSVC найдены последующие сообщения о
чистых сборках и добавлении hd-seed; ранние пометки WIP не считаются общим
доказательством незавершённости. Начат анализ полной истории и build graph.

Официальное объявление Microsoft от 18.11.2013 указывает: CTP содержит только
компилятор, требует VS2013 и совместим с CRT 12.0. Это определяет направление
проверки исторического STL, но ещё не устанавливает distribution.

## Восстановление инструментов и RNG

Клонирована публичная Git-история. CTP EXE и VS2013 bootstrapper прошли
Authenticode. Старые fwlink пакетов вернули 404. Загрузка целого ISO остановлена
после определения размера 5 ГБ, полный ISO не сохранён. Написан ISO9660/Joliet
reader с HTTP Range; извлечены нужные пакеты, hashes сверены с подписанным
манифестом. Системной установки не было.

MSI читались через read-only COM database. Начальный доступ к FieldCount давал
пустые JSON rows; исправлен GetProperty, таблицы повторно извлечены до приёмки.
Зависимости CTP (CRT и mspdb120) получены из официальных пакетов. Native x86/x64
собраны CTP 18.00.21114, RTM headers/libs 12.0.21005 и SDK 8.1.

Native controls: 12 553 cases / 459 136 words на архитектуру; совпадение x86/x64,
скалярного MT и сохранённых векторов, один draw на uint16 sample. Формула:
MT.next() & 65535. Сдвиг на 8, усечение uint8 и BX %255 различаются.

## История и пилот

211 snapshots: 47 high-byte (13 main безусловно исключены из проекта;
34 имеют глобальную invoke), 155 low-byte, заключительный %255. Июньские
source paths связны; вся SX-программа с внешними зависимостями нативно не
пересобрана. Это ограничение записано в протоколе пилота до его запуска.

Создан отдельный pilot-low32: только entropy32 и схемы id20…39. Исправлены
CRLF shell-файла, отсутствующая coincurve заменена сохранённым независимым
affine-эталоном, Windows separators нормализованы для WSL. Эти ошибки
подготовки не считались результатами поиска. Старые серии не запускались
и не изменялись.

GPU controls прошли. Пять синтетических групп: 20 971 520 seed × 20 схем,
23,052 с, 909 754 seed/с, прогноз 78,68 мин (76,19–81,45). Реальный target
Puzzle не использовался, покрытие реального поиска 0. Отдельный Windows
readback проверил 18 input hashes, 20 benchmark blocks и native outputs.

Решение: майский штатный MSVC high-byte вариант не перебирать. Для июньской
low-byte модели сохранить инструменты/контроли/измерения; полный проход
отложить до подтверждения нативного SX hd-seed с историческими зависимостями
либо проверяемого готового бинарника. Сам distribution восстановлен точно.
