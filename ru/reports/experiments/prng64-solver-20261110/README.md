Обе обвязки удерживают блокировку средствами Windows на RUN.lock. Существование файла
не означает активный процесс: защиту обеспечивает блокировка байта ОС.
PROCESS.json содержит PID/путь/время последнего запуска. Завершённые OUTPUT.json
и RESULT.json используются повторно. Изменение закреплённого кода запрещено;
для новой модели нужна отдельная серия. Не запускайте worker.py вручную в каталог,
которым одновременно управляет run.py.

Решателю передаются family и observations. CHECKER_SECRET.json читает только
проверяющая обвязка. Все найденные состояния перепроверяются численно; закрытый
synthetic-контроль требует не просто SAT, а полного перечисления с конечным UNSAT.
Контрольные положительные/отрицательные тесты с фиксированными состояниями служат
проверкой реализации и не выдаются за слепое восстановление.

Для CryptoMiniSat formula-*.json содержит точные CNF/XOR и блокировки состояний;
для cvc5/Z3 сохраняется SMT2. query-*.json фиксирует ответ, время, лимит, свидетеля,
причину UNKNOWN и хэш формулы. Отдельный кросс-контроль real/crosscheck использует
другой движок. Пилоты и неуспешные попытки сохраняются и входят в стоимость.

Виртуальное окружение локальное. Используются pycryptosat 5.18.0, cvc5 1.4.2,
z3-solver 5.3.3.0 и Python 3.11. Исходные сведения об интерфейсах сохранены в sources.
Времена измерены локально на CPU; они не являются оценкой полного перебора seed.
