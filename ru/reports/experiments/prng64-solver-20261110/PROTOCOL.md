# RNG64-03 — решение оставшихся 17 локальных задач

Продолжение RNG64-02, 10 ноября 2026. Старую серию не менять. Набор входов:
ровно 17 строк not_run_control_incomplete из prng64-assembly-20261110.
Те же синтетические значения, маски, семейства, packing, fitting №135/130,
holdout из остальных 81 решения, межключевые расстояния max(offsets)+1/+4.
Новые семейства, перестановки и расстояния не добавляются.

Новая постановка: прямое разворачивание линейного перехода на 128 битах
состояния; XOR-уравнения сохраняются явно. Нелинейность только в переносах
сложения выходных слов. CryptoMiniSat получает XOR+CNF. Второй движок cvc5
получает прямую модель битовых векторов с отдельными состояниями по шагам.
Для сравнения — исходный Z3 с лимитом 120 секунд, только если новые методы
не закончили контроль. Старые 20-секундные результаты сохранены как baseline.

Сначала исчерпывающие проверки уменьшенной разрядности и проверки полных
128-битных состояний с фиксацией входа, противоречия, неоднозначность, UNKNOWN.
Пилот: первые по ID представители четырёх пар family×endian из 17 строк;
CryptoMiniSat и cvc5, 10 секунд на запрос, до 4 состояний. Пилоты только synthetic.
Далее порядок движков выбирается по числу завершённых контролей, затем времени;
при равенстве CryptoMiniSat первым. Не читать скрытые состояния для выбора метода.

Для каждого из 17 входов: до 120 секунд/запрос, 240 секунд/метод,
до 8 локальных состояний. Не завершившие методы оставляют UNKNOWN, не UNSAT.
Следующий метод пробуется только если предыдущий не завершил. Скрытое состояние
передаётся только проверяющему коду, не API/процессу решателя. Повторный поиск
с новым движком не импортирует синтетический секрет как найденный свидетель.

Реальная задача допускается только после полного синтетического перечисления,
содержащего посаженное состояние, проверки 83 номеров, holdout и скрытого №71.
Реальные запросы используют только движки, прошедшие контроль этой строки;
при UNKNOWN реального входа можно сначала завершить контроль другого движка.
Все SAT проверять обычным исполнением. Завершённые UNSAT на реальных входах
перепроверить независимым движком с отдельным лимитом 120 секунд. Неудача
повторения отмечается отдельно и не превращается в опровержение первого UNSAT.
Локальный UNSAT исключает схему для любых межключевых расстояний. При локальных
состояниях проверить только два прежних расстояния; полный holdout-кандидат
останавливает серию до независимой адресной проверки.

Сохранять исходные входы, формулы XOR+CNF/SMT, ответы/свидетели/причины UNKNOWN,
версии, хэши и времена. Возобновление не повторяет завершённые этапы. При новом
лимите/коде — новая идентичность запуска. Подробные результаты, в том числе
незавершённые, публикуются отдельно от RNG64-02. GPU/облако не требуются.

Источники интерфейсов: https://github.com/msoos/cryptominisat/blob/master/python/README.md
и https://cvc5.github.io/docs/latest/options.html (прочитаны 10 ноября 2026).
