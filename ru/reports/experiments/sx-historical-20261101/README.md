# E12 — SX: историческая цепочка и ограниченный CPU-пилот

[Результаты](<RESULTS.md>), [числовой пилот](<PILOT_RESULTS.md>), [история RNG](<HISTORY.md>), [протокол восьми схем](<PILOT_PROTOCOL.md>), [дальнейший GPU-этап](<GPU_HANDOFF.md>).

Работа относится к публичным Bitcoin puzzle. Цель — проверить исторически достижимый слабый источник entropy для детерминированного кошелька. Использование SX автором не установлено. Полный поиск в этой папке не выполнен.

## Зафиксированные источники

- SX `69b29c08090f7b832d49e24bf385011793a43cd7`, 16 мая 2014: hd-seed/hd-priv/hd-pub и утилиты.
- libwallet: копии EdgeApp `495a0fa8448ffceb4a598201f27dafa0a99639e8` и BWallet `5a01940e282e94279403b7db211148fb49aac7ce`. HD header, implementation и тесты совпадают побайтно и по Git blob SHA1.
- libbitcoin-system `05423dc1669b06f695a7717e44710b8756d481a6`: прочитаны EC/HMAC API, подтверждены арифметика и формат сжатой точки.
- GNU GCC 4.8.2/4.9.2 `bits/random.h` и `random.tcc`; libc++ LLVM 3.5.0 `random` и `algorithm`. Распределения исполняются из извлечённых исходных функций.
- 87 снимков трёх исторических путей SX/BX; даты, URL, исходные тела и ошибки сохранены. Это не все ветки репозитория и не доказательство установленной у создателя сборки.

`SOURCES.json` содержит URL, время, SHA256, HTTP-статус и расположение тела; `sources/` сохраняет оригиналы. `errors/` хранит первоначальные ошибки сети. Исторические установщики только читались. Условия лицензий исходных проектов сохраняются в исходных снимках; LICENSE/COPYING libwallet также находятся в native/. Функции GCC и libc++ имеют собственные лицензии из сохранённых полных файлов, не объявляются оригинальным кодом этого проекта.

## Что исполнялось

Полный исходный `hd_keys.cpp`, его header и исторические тесты libwallet сохранены без изменения. `native/include/adapter.hpp` предоставляет явные адаптеры EC/HMAC/Base58/serialization к современным libsecp256k1/OpenSSL. Это воспроизведение исторических функций, **не сборка полного старого кошелька и не старый компилятор**. Вызовы сети/кошельков отсутствуют.

`prepare.py` извлекает исторические GNU operator() и классы libc++ distribution/independent_bits_engine. Современные стандартные minstd engines используются с параметрами, проверенными по старым заголовкам. Счётчик обращений проверяет отбраковку. Вспомогательные floorlog/clz и тестовый API заданы явно.

`model.py` — отдельная Python-реализация целочисленного RNG, BIP32 и Base58; `affine.py` — копия независимого аффинного эталона из исследовательской папки. `check.py` сравнивает 1173 случая, каждый с master, восемью direct children и одним вложенным BIP44 child. Это контроли криптографии; BIP44 не включён в восемь пилотных схем.

`native/faults.cpp` подставляет искусственные HMAC-выходы: невалидные master, child IL≥n, нулевой child и допустимый IL=0; проверяет отсутствие повторной выдачи HMAC. `native/scan.cpp` — отдельный однопоточный фильтр младших 49 бит №50. `pilot.py` сначала проверяет синтетику и границы, затем восемь блоков настоящего пилота. При выжившем фильтре он проверяет №1–50 и только затем №51+.

## Пересборка/воспроизведение в отдельной копии

Окончательные артефакты этой папки зафиксированы. Для пересборки скопировать папку в новый соседний каталог эксперимента и использовать новый каталог запуска пилота, сохранив оригинальный сертификат. Не перезаписывать принятую папку ради повторного замера. Для новой копии порядок:

1. `make_cases.py`, `prepare.py` — детерминированная подготовка из уже сохранённых исходников.
2. `bash build.sh` через WSL Ubuntu-24.04 — сборка и исторические контроли. Требуются локальные g++, OpenSSL и libsecp256k1.
3. `check.py` — сравнение C++ и Python, независимая аффинная арифметика.
4. `pilot.py` из Windows Python 3.11 — вызывает WSL-сканер. Неизменные завершённые вызовы берутся из `pilot/*.json`; изменившиеся входы вызывают отказ вместо смешивания данных. Для новой серии назначить новый RUN-каталог в новой копии.
5. `acceptance.py` — проверка исходных данных, покрытия, редких отказов и продолжения без повторов.

`fetch.py URLS-*.json` нужен только для повторного получения публичных источников. Существующие успешные снимки не перезагружает; ошибки среды архивирует. `history.py` пересобирает описательную таблицу из снимков, без сети и вычисления ключей.

Пилотный бюджет — 120 секунд внутреннего времени сканера, фактически 19,85 с для настоящих данных. Контроли и накладные расходы считаются отдельно. Паузы и частичное покрытие не превращаются в отрицательный полный результат. Версии: ENVIRONMENT.json; точные входы/отдельные времена: pilot/*.json.
