# E12 — журнал исполнения

01.11.2026, по указанию пользователя «начнём с sx». Отдельная папка, старые проекты/сертификаты не изменяются.

1. Подготовлен ограниченный сборщик публичных источников с URL/UTC/SHA256, лимитом16MiB и четырьмя одновременными чтениями. Первые8 запросов получили сетевую ошибку среды; ошибки сохранены, повторная разрешённая загрузка успешна. Первичные repo libwallet недоступны404; найдены две архивные копии с одинаковыми HD-blob. Первоначально предполагаемые GCC uniform_int_dist.h отсутствовали; нужные реализации обнаружены в random.h/random.tcc. Перемещённые файлы истории дают сохранённые404. Ни установщики, ни произвольные загруженные программы не исполнялись.

2. Прочитаны SX hd-seed/hd-priv/hd-pub, libwallet HD и тесты, зависимости EC/HMAC, исторические GNU/libc++ распределения. Установщик использовал изменяемые Git-ветки, полного исторического build-lock нет. Выбран фиксированный рабочий майский срез. Исходные HD-файлы сохранены без изменения, адаптеры явны и отдельно проверяются. Сборка g++13.3 наUbuntu24.04, OpenSSL3.0.13, libsecp256k1 pkg-config0.2.0; Python3.11.9/coincurve21.0.0. Старые полные бинарники не запускались.

3. Исторические C++-тесты прошли36 assertions. Пройдены1173 RNG-сценария,11730 extended-node сравнений,192 affine-проверки. Два исходных GNU operator() сопоставлены; схемы не дублируются как два RNG. На MSVC обнаружено историческое расширение типа distribution доuint16; оставлено отдельным вопросом.

4. До просмотра настоящего фильтра закреплён PILOT_PROTOCOL.md: только8 схем,32байта, direct master children,normal/hardened,i−1/i. Сканер проверен на8 planted состояниях с отрицательной мутацией,128 bits0-кандидатах и24 граничных случаях. Исторический код отдельно проверен на8 forced-HMAC отказах/граничных случаях: скрытых retry нет.

5. CPU-пилот завершил8 блоков, по262144 состояния на GNU/LLVM. Кандидатов нет. Внутреннее время19,85с, внешнее23,35с. Скорости/экстраполяции сохранены машинно. Полного прохода нет; нельзя исключить оставшиеся99,9878% состояний. Ни GPU, ни аренда не использовались.

6. Повторный запуск пилота проверен с запретом subprocess: все завершённые вызовы взяты из cache. Первая версия приёмки забыла снять этот запрет перед platform.platform(), который сам запускает Windows ver; приёмка остановилась только на сборе метаданных. Исправлено снятием monkeypatch в finally. Повторная приёмка прошла,51 JSON вызовов/входов не изменён, native-перерасчёта не было. Ошибка не затрагивала криптографические результаты.

7. Сохранены87 исторических снимков. В выбранной истории22июля2014 distribution сменился на%255; поздние соответствующие цепочки не следует повторять как новые SX-гипотезы. Исправление HMAC label13→12 байт не даёт новой модели из-за эквивалентности завершающего нуля при HMAC padding. Полноты всех веток, сборок и реально установленных зависимостей не заявляем.

8. Приёмка проверила83 известных ключа по диапазону/адресу и совпадение копии данных с принятым эталоном. Подготовлено отдельное GPU_HANDOFF.md с точным набором схем и критериями приёмки. Общие журналы обновлены. Окончательный COMPLETE.json фиксирует файлы этапа; следующий поиск должен иметь собственную папку и результаты.
