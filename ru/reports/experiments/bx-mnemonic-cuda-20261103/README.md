# BMC-01C — проверка Windows BX mnemonic-path завершена

03.11.2026 проверен полный диапазон `[0, 2³²)`: 375 652 270 допустимых
изменённых входов × 20 схем, кандидатов и ошибок 0. Все 4096 блоков проверены
Linux-аудитором и отдельно реализованным Windows readback.

- [Итоговый отчёт](<FINAL_REPORT.md>), [результат](<RESULTS.md>), сертификат readback — артефакт исходного исследования (`READBACK_COMPLETE.json`; вне снимка).
- Завершённый поиск — артефакт исходного исследования (`compact/COMPLETE.json`; вне снимка), зафиксированный манифест — артефакт исходного исследования (`compact/FINAL_MANIFEST.json`; вне снимка).
- [Протокол](<compact/PROTOCOL.md>), 20 схем — артефакт исходного исследования (`compact/SCHEMES.json`; вне снимка), контроли — артефакт исходного исследования (`compact/CONTROLS.json`; вне снимка).
- Runner controls — артефакт исходного исследования (`compact/RUNNER_CONTROLS.json`; вне снимка), пилоты — артефакт исходного исследования (`compact/PILOTS.json`; вне снимка), окружение — артефакт исходного исследования (`compact/ENVIRONMENT.json`; вне снимка).
- [Журнал](<JOURNAL.md>), статус — артефакт исходного исследования (`STATUS.json`; вне снимка).

Фактический полный проход выполнен реализацией в `compact/`: плотный список
допустимых изменённых входов ускорил пилот в 8,29 раза. Корень этой папки
содержит сохранённую исходную реализацию BMC-01 и её принятые контроли/пилоты;
полного прохода исходной реализацией не было. Сборку и поиск повторять не требуется.

Это продолжение BMD-01 — проверки официального Windows EXE. Цепочка использует
старый Electrum codec с потерей ведущих нулей, без BIP39/PBKDF2. Неизменённые
входы покрыты прежним E15. Вывод ограничен зарегистрированными RNG, 20 схемами,
индексами и маской; он не устанавливает программу автора Puzzle.

Этот аудитор не импортирует runner/common/CUDA и не запускает поиск. Он проверяет
покрытие диапазонов, категории, SHA-chain, pins кода и входов, происхождение
артефактов и однократный учёт 20 ранее вычисленных пилотных блоков.
