# BMC-01C — завершён полный тест BX mnemonic-path

**Полный исходный домен `[0, 2³²)` проверен: кандидатов 0, ошибок 0.**
Дата: 03.11.2026, Europe/Moscow. Этот результат исключает только 20
зарегистрированных схем нового codec-path при заданных RNG/индексах/маске.
Ни программа автора, ни неприменимость всех BX-кошельков этим не установлены.

## Фактическое покрытие

| Категория исходного MT seed | Число |
|---|---:|
| Всего uint32 seeds | 4,294,967,296 |
| Изменённые допустимые seed, новые HD-вычисления | 375,652,270 |
| Неизменённые, уже покрыты E15 | 2,557,460,402 |
| Нечётный hex, официальный BX отвергает | 1,361,854,624 |
| Чётный hex, менее 16 байт, BX отвергает | 0 |
| Новых seed×scheme | 7,513,045,400 |
| Полных блоков по 2²⁰ | 4,096 |
| Кандидатов фильтра №50 / ошибок | 0 / 0 |

Сумма категорий равна 4 294 967 296, пропусков/повторов нет. Доля changed_valid
по всему домену — **8.74633598%**. Это число исходных RNG-состояний,
а не доказанное число уникальных кошельков. Все 20 вариантов были
применены к каждому из этих seed; отбрасывание иных категорий проверено
историческим binary audit и точным GPU/CPU-сравнением.

Цепочка: Windows BX 2.0.0 uint32 → MT19937 → 32 outputs %255 → 8 BE uint32 chunks
→ unpadded hex каждого chunk → строгий hex parser → 16…31-byte seed → BIP32.
Допустимая изменённая строка содержит чётное число hex-символов от 32 до 62.
BIP39/PBKDF2 отсутствуют. Родители m, m/0, m/0'/0, m/0'/1 с normal/hardened
final i−1/i; m/44'/0'/0'/0 и /1 с normal final i−1/i.
Точный список — артефакт исходного исследования (`compact/SCHEMES.json`; вне снимка).
Маска 2^(i−1)+(raw mod 2^(i−1)); порядок и пропуски номеров не менялись.

## Скорость и завершение

- Первый принятый kernel: 879,398 исходных seed/s,
  прогноз 81.40 мин. Его code/controls/pilots
  сохранены как baseline; полного прохода им не было.
- Плотный changed_valid worklist сохранил те же вычисления и прошёл приёмку
  заново: 7,293,829 seed/s на пяти пилотных группах,
  ускорение 8.29×,
  прогноз 9.81 мин.
- Фактическое wall-время invocation полного прохода: **9.67 мин**.
  Оно включает block/checkpoint IO и пропускает уже вычисленные 20 пилотных блоков.
- Сумма API-времени всех 4096 принятых блоков, включая reuse пилота:
  7.30 мин; CUDA events 6.96 мин.
  Эти величины не складываются с invocation wall.
- Явно выделяемые данные GPU на блок 2²⁰: 42,500,120 байт
  (40.53 MiB), помимо context/module overhead.
  GPU: RTX 3070 Ti Laptop, CUDA 13.2. Облачная аренда не использовалась.

20 поисковых пилотных блоков использованы повторно как артефакты, без нового
вычисления, и входят в 4096 ровно один раз. Их hashes и равенство результатов
проверены отдельно. Synthetic controls и classify-only замеры в покрытие не входят.

## Приёмка и независимый аудит

CUDA сверена по 12 473 MT seeds / 399 136 words, всем границам исходных блоков,
native decoder traces и всем hex-length 8…64. Проверены переменные master lengths,
17 стандартных BIP32 vectors, 180 native HD cases, SHA/HMAC/EC/scalar-add,
точные HMAC messages и ведущие нули. Реальный scan по 20 выходам сопоставлен
с affine CPU в разнесённых интервалах. Проверки включали 20 positive / 20 negative
synthetic cases, verifier training/holdout controls, many candidates/overflow,
invalid HD builds, полный последний блок и domain bounds. Все прошли.

Runner проверен на stop/resume, неповторение готовых блоков, повреждённый/обрезанный
checkpoint, изменённые inputs, конкурентную блокировку, ошибку и candidate stop.
Ошибки не учитываются как отрицательный результат.

После завершения отдельный Linux audit и отдельно реализованный Windows
readback проверили 4096 диапазонов, SHA-chain, 4 категории, код/inputs/acceptance
и происхождение. Windows readback проверил 33
input hashes, 40 acceptance hashes и
940 origin hashes. Старые BMD/E15 артефакты сохранены.
COMPLETE — артефакт исходного исследования (`compact/COMPLETE.json`; вне снимка), Windows readback — артефакт исходного исследования (`compact/status-reviews/windows-readback-1793660048600239400.json`; вне снимка),
контроли — артефакт исходного исследования (`compact/CONTROLS.json`; вне снимка), пилот — артефакт исходного исследования (`compact/PILOTS.json`; вне снимка).

## Вывод для Bitcoin Puzzle

Ни один новый seed не совпал даже с 49-битным training-фильтром №50. Поэтому
кандидатов для проверки всех №1–50 не появилось, реальные holdout №51+ не
применялись и новые настоящие private keys/биты не получены.

**Подтверждённая ошибка декодера не объясняет известную последовательность
Puzzle в этих 20 сочетаниях.** Их дальнейший повторный перебор не нужен.
Иные пути, генераторы, маски, порядки или пользовательские композиции вне этого
вывода. Автоматического расширения на них не выполнялось.
