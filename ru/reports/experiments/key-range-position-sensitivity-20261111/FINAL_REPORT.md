# Устойчивость и чувствительность прогноза положения ключей

11 ноября 2026 года. План выполнен полностью. 73 ключа, 208 подписей, 20 пятиблочных разбиений. Основной расчёт и аудит заняли 568,1 с при лимите 900 с. Синтетических корпусов: 1534. Прежний критерий на архивных данных прошли 0/4 модели.

## Прогноз на архивных ключах

Средняя вероятность по 20 внеобучающим прогнозам оценивается один раз для каждого ключа. Выигрыш Brier — ошибка модели на метаданных минус ошибка модели с публичными признаками. У постоянного прогноза 0,5 ошибка Brier равна 0,25. Порог скорректированного p — 0,05 в обоих контролях. Перенос №11–60 → №61+ взят из прежнего протокола.

## Чувствительность к заданной связи

Синтетические скаляры отобраны по согласованию Qx≥P/2 с верхней половиной. Точки и подписи вычислены из самих скаляров. Столбец «Согласие» показывает фактическую долю совпадений. Уровни — параметры отбора, поэтому совпадение с заданным процентом приблизительное.

В столбце «Обнаружение» событие считается по хотя бы одной из четырёх моделей: скорректированное p≤0,05; для «С переносом» дополнительно требуются положительный выигрыш Brier и положительный выигрыш переноса.
