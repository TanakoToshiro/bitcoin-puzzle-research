# Устойчивость и чувствительность прогноза положения ключей

План фиксируется до нового запуска. Используются 73 ключа №11 и выше и 208 подписей. Все 83 прежних контекста остаются в симуляторе транзакций. data.py, screen.py, restricted.py копируются побайтно из предыдущего опыта. Четыре модели, признаки и параметры сохранены; nonce не входит в прогноз.

20 новых пятиблочных разбиений строятся по ключам независимо от меток. В каждой обучающей части отдельно вычисляются нормировка и веса. Для основного показателя усредняются 20 внеобучающих вероятностей каждого ключа, затем вычисляется Brier. Сохраняются и все отдельные показатели разбиений. Нельзя выбирать лучшее разбиение или считать повторения новыми наблюдениями. Прежнее разбиение воспроизводится отдельно для проверки совместимости.

Реальный агрегированный показатель сравнивается с 127 равномерными и 255 сохраняющими реальные четверти синтетическими корпусами. Каждый корпус проходит те же 20 разбиений. Поправка min-P охватывает четыре модели. Прежний перенос №11–60 → №61+ сохраняется. Для реальных данных требуется положительный выигрыш, положительный перенос и p≤0,05 при обоих контролях. Проверка остаётся разведочной на многократно просмотренных данных.

Слабая связь вводится отбором настоящих скаляров внутри выбранной четверти: кандидат принимается с вероятностью alpha, если Qx≥P/2 согласуется с верхней половиной диапазона, иначе с вероятностью 1−alpha. Alpha = 0,55/0,60/0,65/0,70 — номинальные уровни, фактическое согласие сохраняется. При alpha=0,5 этот отбор не менял бы равномерное распределение внутри четверти. Отдельные нулевые репликации генерируются непосредственно прежним равномерным методом.

Для каждого уровня предусмотрены 128 независимых корпусов на каждом из двух способов выбора четвертей: равномерные диапазоны и реальные четверти. Мощность оценивается отдельно для каждого способа по своей нулевой банке. У четверть-сохраняющего контроля метки совпадают с реальными; у равномерного они случайны. Эти две серии не выдаются за совместную оценку прохождения обоих p на одном новом корпусе. Дополнительно 64 свежих нулевых корпуса на способ оценивают частоту ложного обнаружения. Интервалы Вильсона отражают ошибку Монте-Карло при фиксированной сохранённой банке.

Синтетические точки и подписи вычисляются из принятых ключей. Сохраняются offsets, отдельные seed для подписей, используемые матрицы признаков, показатели всех разбиений и точные входы для повторения. Подписи необъяснённой январской группы используют прежний равномерный суррогат nonce и не входят в модели поздних подписей. Outpoint идентификаторы остаются фиксированными, как в предыдущем опыте.

Общий лимит основного процесса 900 секунд. На 840 секундах начинается штатное завершение с сохранением неполного покрытия. После калибровки репликации чередуются между уровнями и способами, чтобы при остановке не исследовать только слабейший уровень. Ни отсутствие чувствительности, ни отсутствие обнаружения на реальных ключах не исключают произвольные криптографические зависимости.
