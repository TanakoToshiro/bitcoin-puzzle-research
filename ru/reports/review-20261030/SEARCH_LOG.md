# Поиск и доступность источников

Дата обзора: 2026-10-30. Это журнал основных поисковых направлений и ограничений, а не исчерпывающий экспорт поисковой выдачи.

## Проверенные поисковые формулировки

- `bitcoin puzzle Mersenne Twister partial bits linear algebra rank 71`
- `bitcoin puzzle MT19937 state recovery Python random seed analysis`
- `"bitcoin puzzle" "rank" "MT19937"`
- `"bitcoin puzzle" "linear" "untwister"`
- `"bitcoin puzzle" "Mersenne" "linear algebra"`
- `"bitcoin puzzle" "partial" "untwister"`
- `Armory classic deterministic wallet computeChainedPrivateKey 2014 source`
- `"BitcoinArmory" "computeChainedPrivateKey"`
- `"mnfadel" "puzzle" "RFC"`

Дополнительно просмотрены найденные страницы авторских репозиториев, связанные документы и полные GitHub trees. Точные сохранённые версии и URL перечислены в SOURCES.json. Код выбран по связи с заявленными выводами; снимок файла сам по себе не означает полного аудита этого файла.

## Приоритет источников

Исходник/вектор конкретной исторической версии → авторский код и результаты → авторское описание → обсуждение. Перепечатки и поисковые описания использовались для обнаружения первоисточников, а не как независимое подтверждение результатов. Одинаковая публикация на Reddit и GitHub не считалась двумя экспериментами.

## Недоступные первоисточники

- `https://bitcointalk.org/index.php?topic=1306983.msg18765941`: HTTP 403 при прямой загрузке. Пересказы сообщения создателя доступны в других работах; оригинальный контекст не перепроверен.
- `https://github.com/mnfadel/bitcoin-puzzle-forensics` и GitHub API этого репозитория: HTTP 404. Поисковое описание перечисляет ECDSA/RFC6979/HNP; его научные выводы не приняты без доступных материалов.

Точные ошибки загрузки сохранены в PRIMARY_SOURCES.json. Повторный поиск может изменить доступность и должен создавать новую запись, а не стирать эту.

## Воспроизведение короткого локального аудита

Из корня `puzzle71-hypotheses`:

> Исполняемый код/команды опущены в документационной копии.


Скрипт не импортирует и не исполняет скачанные программы; проверяет снимки и независимо рассчитывает несколько контрпримеров. Запуск перезапишет AUDIT_RESULTS.json новой датой/временем; для сохранения исходного аудита сначала скопировать каталог обзора под новым ID. Скрипты загрузки являются средствами подготовки снимка: повторно не выполнять поверх зафиксированного обзора, поскольку HEAD и доступность внешних источников меняются. REVIEW_MANIFEST.json фиксирует итоговую версию артефактов этого обзора.
