# Дополнительная проверка положений без №1–10

11 ноября 2026. План записан до вычисления статистик этого сравнения, но после просмотра общей гистограммы. Это разведочный анализ многократно использованных данных, не новый закрытый тест.

Набор: все 73 решения с номером >10 из прежнего проверенного снимка. Положение x=(k−2^(n−1))/2^(n−1), диапазон [0,1). Для последовательности используются только 60 подряд идущих номеров 11–70. Пропуски 71–74 и далее не сжимаются.

Шесть заранее выбранных статистических проверок:

1. Отклонение распределения всех 73 положений от равномерного: двусторонняя статистика Колмогорова–Смирнова.
2. Неравномерность десяти интервалов: статистика Пирсона.
3. Отклонение среднего от 0,5.
4. Монотонный тренд по номеру задачи: модуль корреляции Спирмена, перестановочный тест.
5. Серийная зависимость №11–70: максимум модуля корреляции Пирсона на лагах 1–10; единый перестановочный тест максимума, а не выбор лучшего лага после просмотра.
6. Число серий выше/ниже 0,5 в №11–70; двустороннее отклонение от условного среднего при фиксированном числе значений с каждой стороны, перестановочный тест.

Для первых трёх тестов 50 000 симуляций независимых равномерных остатков с соответствующими разрядностями (округление вниз к сетке каждого номера). Для остальных 50 000 случайных перестановок. Числовые положения хранятся float64; выше его точности сетки практически непрерывны, младшие точные биты ключей в анализе не используются. Фиксированный seed NumPy 20261111; обработка блоками по 2500. Monte Carlo p=(extreme+1)/(50000+1), затем Holm для шести тестов, общий alpha=0,01. Публикуются также исходные p и все описательные результаты.

Ограничения: выборка решённых задач не является доказанно случайной выборкой исходной серии; неизвестные ключи исключены, не заменены нулями. Незначимость не доказывает независимости или отсутствия сложной связи. Поправка покрывает эти шесть тестов, не все прошлые исследования проекта. Вычисления не восстанавливают ключи и не запускают поиск.
