# Проверка недоступных вложений через Chrome — 03.11.2026

Повторная попытка **успешно получила доступ к Chrome**. Предыдущий отказ инструмента не воспроизвёлся. В инвентаризации также появился внутренний браузер; для этой проверки использован Chrome с уже существующей сессией. Изменения пользовательских настроек не выполнялись, причина прежнего отказа не установлена.

Проверены переходы по **15 различным URL**: 12 дали читаемую страницу, 3 завершились ошибкой инструмента/сети. Новых файлов получить не удалось, но появились важные уточнения. Все статусы и время наблюдений — в OBSERVATIONS.json — артефакт исходного исследования (`OBSERVATIONS.json`; вне снимка). Время выполнения: около 00:28–00:34 МСК.

Для `btcpass.zip` и `cuda92.zip` отдельные браузерные переходы не выполнены после клиентской блокировки на том же хосте. Другой `usp`-вариант ссылки `19Fp…` отдельно не проверялся: file ID тот же. Эти ограничения явно сохранены; полного успешного открытия всех прежних URL не заявляется.

Практический результат: браузерная проверка была нужна. Она различила отказ доступа, ошибку «не найдено», пустую видимую папку, сообщение об удалении владельцем и техническую ошибку навигации. **Неоднозначный Drive `1au9…` остаётся закрытым для текущего аккаунта, а не доказанно удалённым.** Сообщения владельцам и запросы доступа не отправлялись. Без доступной копии содержимого эта ссылка пока не даёт параметров Armory/Electrum/mSIGNA.
