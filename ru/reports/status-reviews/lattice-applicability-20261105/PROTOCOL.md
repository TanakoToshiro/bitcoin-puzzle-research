# LSCREEN-01 — дешёвая проверка применимости одной конструкции

05.11.2026. Проверка не расширяет решётки и не раскрывает дополнительные биты.
Используются принятый снимок 83 решений и исходная гипотеза
`key[i] = 2^(i−1) + (s[i] mod 2^(i−1))`, `0 ≤ s[i] < n`.

До расчёта зафиксированы все девять перекрывающихся панелей из пяти
наблюдений на индексах 75,80,...,135. На каждой строится одна кубика
Мёбиуса в четырёх центрированных разностях. Проверяются все максимальные
по делимости мономы: обратимость коэффициента modulo n и вес W(M) ≥ n.
Теорема SEQ-16 тогда исключает строгие HG-L1 сертификаты во всех степенях
идеала (n,G), при любом допустимом порядке мономов и корректной редукции.

Точная область вывода: отдельная кубика, данный модуль, данные переменные,
прямоугольные границы и строгий критерий взвешенной L1-нормы. Не исключаются
сама модель Мёбиуса, корни, совместные уравнения, более точное описание
области допустимых переменных и другие решёточные методы.

Контроли: одна фиксированная цепь Мёбиуса с матрицей (7,11;13,17),
начальным состоянием 19; одна независимая последовательность состояний
из SHAKE256 с доменом LSCREEN-01/null/20261105. Обе имеют те же индексы
и маски. Это арифметические контроли, не оценка статистической мощности.
Проверка препятствия получает только наблюдения; полные контрольные
состояния используются отдельно для проверки кубики и границ.

Раскрытие кубики проверяется двумя способами: операциями над полиномами
и прямым разложением четырёх произведений трёх аффинных форм. Проверяются
целочисленные тождества нормировки идеала. LLL, Gröbner и поиск корней
не запускаются. Никаких выводов о числе независимых наблюдаемых битов
по их простому суммированию не делается.

До вычислений сохраняются входы, хеши кода и протокола. Три источника и
два их принятых манифеста проверяются по SHA-256 и времени изменения.
Новые результаты пишутся только в эту папку. `screen.py --verify` читает
снимок и повторяет дешёвую проверку в памяти, не изменяя файлов.
