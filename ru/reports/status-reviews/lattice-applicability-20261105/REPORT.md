# LSCREEN-01 — проверка применимости на исходных масках

**На всех девяти проверенных панелях настоящих ключей подтверждено препятствие для отдельной кубики Мёбиуса.** Строгий HG-L1 критерий в степенях идеала (n,G) недостижим при любом числе полиномиальных сдвигов. Увеличение этой решётки или времени её редукции не устраняет доказанное препятствие.

Это ограничение конкретной конструкции, переменных, прямоугольных границ и критерия. Оно не исключает модель Мёбиуса, допустимые скрытые состояния, совместные инварианты или другие решёточные методы.

Модуль n меньше 2^256. У каждой кубики четыре максимальных по делимости монома; все четыре коэффициента обратимы modulo n. Проверены два раскрытия кубики и целочисленные тождества нормировки идеала. По доказательству SEQ-16 это даёт нижнюю границу n^m для взвешенной L1-нормы любого ненулевого элемента (n,G)^m, для любого m≥1.

Одна заведомая цепь Мёбиуса с теми же исходными масками также получила препятствие на всех девяти панелях, хотя её истинные скрытые значения удовлетворяют всем кубикам. Одна случайная последовательность получила то же препятствие; её сгенерированные полные состояния кубикам не удовлетворяют. Последнее не доказывает отсутствия других допустимых дополнений масок. Эти контроли проверяют арифметику; они не являются статистической оценкой чувствительности.

27 проверок заняли 0.017698 с в этом запуске, без старта интерпретатора, подготовки входов и оформления. LLL, Gröbner и восстановление не выполнялись; дополнительных битов не раскрывалось. Это проверка применимости стратегии, а не обнаружение отпечатка решётки в данных.

Проверены хеши и mtime пяти прочитанных источников/манифестов; весь прежний архив заново не хешировался. Научные файлы старых серий не изменялись. Входы: INPUTS.json; точные сертификаты: RESULTS.json; источники: SOURCES.json.
