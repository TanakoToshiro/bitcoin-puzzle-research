# Снимок публичных решений

[Начало](../README.md)

[source.txt](puzzle-solutions/source.txt) — неизменённая по содержанию публичная таблица, используемая основными исследованиями. В снимке 83 известных решения: №1–70, затем №75–135 с шагом 5. Это не заявление о текущем числе решённых задач.

[source.json](puzzle-solutions/source.json) содержит URL, время загрузки 30 октября 2026 года и SHA-256 оригинальных байтов. В текстовом экспорте окончания строк могут быть нормализованы; исходный и экспортный хеши различаются в [манифесте](../metadata/source-manifest.csv). Неизвестные ключи не становятся наблюдениями генератора.
