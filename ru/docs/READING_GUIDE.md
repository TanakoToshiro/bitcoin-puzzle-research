# Маршруты чтения

[Начало](../README.md)

## За несколько минут

[Краткий итог](RESEARCH_SUMMARY.md) → [новые результаты](LATEST_RESULTS.md) → [открытые вопросы](OPEN_QUESTIONS.md).

## Для технического обзора

[Методика](METHODS_AND_LIMITS.md) → [подробная сводка](../reports/README.md) → нужная [тема](../topics/README.md) → INDEX серии → FINAL_REPORT/RESULTS → протокол и математический разбор → журнал исправлений.

## Для независимого рецензента или Codex

Начните с [задания рецензенту](REVIEW_GUIDE.md). Проверяйте различие между полным проходом, ограниченной выборкой, неполным SAT и синтетическим успехом. Старые планы не выполнять как текущие инструкции.

Для исторической последовательности используйте [общий журнал](../reports/RESULTS.md) и [указатель](DOCUMENT_INDEX.md). Позднее уточнение имеет приоритет только для той же модели и постановки. Оно не переписывает исходный отчёт задним числом.
