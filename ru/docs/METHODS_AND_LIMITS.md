## Что наблюдается

Основной снимок содержит 83 известных решения: №1–70 и №75–135 с шагом 5. Это опубликованные полные приватные ключи Puzzle, а не фрагменты этих приватных ключей. Частичными являются наблюдения предполагаемого более широкого исходного raw-значения.

В распространённой проверяемой гипотезе key[i] = 2^(i−1) + (raw[i] mod 2^(i−1)). Принудительно установленный старший бит не наблюдение генератора. Маска является предположением; номера пропусков не сжимаются. Публичная точка Puzzle-ключа не заменяет raw-точку исходного кошелька.

## Как читать статус

| Статус в сводке | Допустимый смысл |
|---|---|
| Полный отрицательный проход | Все элементы объявленного конечного домена проверены для конкретных схем |
| Точное противоречие / UNSAT | В заявленной модели нет решения; читать ограничения и способ проверки |
| Сигнал не найден | Выбранные статистики и выборка не подтвердили эффект; важна мощность |
| Синтетический успех | Метод работает при указанных условиях контроля, не обязательно на Puzzle |
| Тайм-аут / память / UNKNOWN | Попытка не завершена математически |
| Условное восстановление | Нужны дополнительные данные, например настоящий MPK/chaincode |
| Цикл завершён | Выполнен план с его пределами, что может включать нерешённые задачи |

## Общие ограничения

- Известные ключи многократно просмотрены. Новое разбиение того же корпуса не является независимым подтверждением.
- Несколько подписей одного ключа не равны нескольким независимым ключам; записи разделяются вместе.
- Успех на малом модуле, усиленной маске или диапазоне вокруг известной истины не переносится автоматически на исходный размер.
- Восстановленный через известный приватный ключ nonce — диагностический объект, а не доступный признак неизвестного ключа.
- Поле по порядку secp256k1 и кольцо по степени двойки имеют разную арифметику.
- SHA-256 подтверждает целостность указанной версии, а не истинность её научного вывода.
- Совпадение подписи с программой показывает совместимость пути подписания; не доказывает, какой генератор использовался в 2015 году.
- Отсутствие файла или доступа к источнику не является отрицательным результатом по содержимому.

Полные протоколы находятся рядом с отчётами. [Указатель](DOCUMENT_INDEX.md).
